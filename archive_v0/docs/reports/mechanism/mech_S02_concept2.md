# S02 구상 2안 — 같은 형번 1:1 교체, 새 부품 0 (기구설계부 2번, 방향: 부품 수·구매가 최소)

## 요약
- 안: 남은 `STEP대기_` 8바디(형번 4종: `CJ2B16-30SZ`, `HFS8-4080-2850`·`-680`·`-1580`)를 **같은 형번의 실물 STEP으로 1:1 교체**한다. 새 구매품·새 가공품·새 조인트 0, 동작 연구 변경 0, 부품 수 증감 0, 세트 비용 증감 0원.
- 구동: 새 구동 없음. 가동은 기존 `J_T06_KNIFE`(slider −30~0, 대기 0) 하나뿐이고, 실린더 로드·로드 끝 너트는 S01 `CJ2B16-60SZ`와 같은 방식으로 `T06_KNIFE` 안에 넣는다. T07 형재 6개는 `BASE`+`T07` 리지드 고정.
- 핵심 수치: 실물 형재는 40×80 외곽 안쪽이므로 모든 틈은 지금 값 이상(680 ↔ `SV2RL28-1800_F_RAIL` 10.02, X 대차 ↔ 680 66.14, G4 ↔ 매트 64.80, 판 ↔ 매트 89.22). 형재 질량 88.3 → 약 30.8 kg(−57.5 kg).
- 막힘: 4종 모두 stepcheck '없음'(2026-10-31 재확인). 받기는 구매부 몫이고 미스미 로그인 상태에 달렸다(D-37·D-41).
- 못 받았을 때(같은 방향, 부품 0): 이미 승인된 T07-X02(1580 상자에서 캡 끼움부 자리 비우기)만 해서 판정 못 한 4쌍을 판정 가능하게 하고, 4종은 '못 받은 형번 목록'으로 과제를 닫는다.
- 기각: 같은 계열 STEP으로 대체(`CJ2B16-60SZ`, `HFS8-4080-460` 늘리기) — E-10 위반·동작 위험. 이어 붙이기(1300+1580 등) — 부품 증가.
- 미완: 실물 30SZ 외곽(D-37) 미확인이라 `LHFR16_T06` 2.85 틈은 교체 뒤 다시 잰다. 형재 단면 2차 모멘트는 미확인(강도 손계산은 하중 경로 불변으로 대상 아님, E-18).

## 1. 근거 규칙 (원문)
- E-10: "형번이 정해지지 않은 추정 바디, `REF`로 자리만 잡는 것은 금지다." 이름은 `STEP대기_<형번>`. → 같은 계열 STEP을 늘려 실물이라 부르지 않는다.
- E-18: 체결만 바뀐 자리는 손계산, FEA는 형상·하중 경로가 바뀐 부품만. → 이번 교체는 외곽·하중 경로 불변, 질량만 준다.
- U-08: 구매품은 요구서 3-1 주 구매처(미스미 표준가, 모르면 "미확인").
- 지시문 방향: 부품 수·구매가 최소(기성품 최대 활용, 가장 단순한 구동). U-03 커스텀이되 효율적으로.
- M-08 원문(정상 겹침): "볼트 나사부의 탭 물림(채움률 < 0.5), 구매처 CAD끼리의 미세 겹침, 설계상 압입". → 실물 형재 ↔ 실물 캡 끼움은 구매처 CAD끼리라 해당, 지금 상자 ↔ 캡은 해당 안 됨(T07-X01 기각과 같음).

### 2-4. 하중 손계산
- 형재: 외곽·지지점·하중 불변, 자중만 준다. 형재 6개 부피 상자 32,704,000 mm³ → 실물 약 1,115 mm² × 10,220 mm = 11,395,000 mm³. 알루미늄 2.7 g/cm³: 88.3 → 30.8 kg. 모든 받침·체결 하중이 줄어드므로 SF는 지금 이상. HFS8-4080 단면 2차 모멘트는 미확인(가격·카탈로그 로그인 필요)이라 처짐 수치는 내지 않는다. E-18에 따라 대상 아님.
- 실린더: 같은 형번이라 칼 하중 경로 불변(T06 해석 그대로). 참고로 Ø16 단면적 π/4 × 16² = 201 mm², 0.5 MPa에서 이론 추력 100.5 N(스프링력 미확인, D-37). FEA는 '해석 못 함 — 환경 없음(자료대기 D-16)'.
