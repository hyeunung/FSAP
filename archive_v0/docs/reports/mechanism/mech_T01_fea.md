### 0-2. 계산 모델

| 대상 | 모델 | 검증 |
|---|---|---|
| 링1·링2 | 72요소 원형 곡선보(면외 그릴리지: 처짐 w, 굽힘, 비틀림). 받침 = 실린더 로드(링1 r190, 링2 r410) 수직, 가이드 샤프트(PSFJ16, 부시 위 자유 길이 70)가 링 기울기를 막는 회전 스프링 k = EI/L = 9.5e6 N·mm/rad. 비교용으로 회전 자유(핀) 경계도 풂. 큰 매트 방향 β 0~90°(5° 간격)를 돌려 가장 나쁜 값 | 직선 단순보 등분포 처짐 오차 −0.05 %, 모멘트 0 %. 30° 기울인 외팔보 끝 하중 오차 0 %(변환 확인) |
| 스파이더 | 허브 바깥(r150)에서 외팔보, ㄷ 단면 I = 2.43e6 mm⁴(도심 밑에서 86.2), 옆 굽힘 I = 7.71e5 | 손계산 |
| 허브 | 다리 밑 r100(들림)·r150(누름) 짝힘을 받는 판 띠 외팔(받침 끝 r_s에서 고정, 유효 폭 = 60 + 2(150 − r_s), 120° 호 이하) | 손계산 |
| 기둥·원판·Y판 | 외팔보·판 띠 | 손계산 |

- 교차 검증(CalculiX 등)은 하지 못했다(환경 없음). 링 모델은 넓은 고리(폭/반경 0.5)를 보로 본 근사이고, 링2 막힘 경우는 처짐이 판 두께의 수십 배라 선형 범위를 벗어난다(아래 2절). 엔진 솔버 환경이 생기면 링2·허브를 STEP 그대로 다시 푼다(M-09 "what-if 결과를 낙관적으로 읽지 않는다").
- 진공: 매트+원판·매트+링1 계에서 대기압이 상쇄된다(땅 접촉력 = 홈 흡인력, 선정 1-2와 같음). 원판·링1에 걸리는 순하중은 무게뿐이고, 진공 홈의 국부 굽힘은 홈 상세(디테일링)에서 본다. 원판 밑 진공 포트가 원판을 기둥 쪽으로 당기는 힘 73 N(58 kPa × Ø40)은 기둥 윗끝이 받는다.

## 3. 동작 문제 — 링2 t3 (실린더 막힘에 영구 변형)

| 항목 | 내용 |
|---|---|
| 무엇 | 링2(A5052 t3, R310~520)는 120° 떨어진 받침 3곳(로드 r410·샤프트 r460)에만 얹혀 받침 사이 호 길이가 약 870이다. 보 단면 I = 210 × 3³/12 = 472 mm⁴로 약하다 |
| 수치 | 링이 올라가다 한 점에 걸리면(손 끼임, 링 올림 순서 제약 실패로 베드 밑에 걸림) 실린더 3개 추력 301.6 N이 걸린 점으로 모인다. 힘 제어 모델(받침 수직 자유, 샤프트가 기울기를 막음) SF **1.17**, 받침 강체 상한 SF **0.84**. 둘 다 **< 1.2**이고 선형 처짐이 121 mm(판 두께의 40배)라 실제로는 판이 휘어 남는다 |
| 왜 동작 문제 | 지시 "부러짐·영구 변형(SF < 1.2) … kind='동작'". 링2가 휘면 받침 높이가 달라지고 내린 링2(띠 밑 −70)–부시 플랜지(−80) 틈 10을 잃을 수 있다 |
| 고치는 법 | **`P_T01_RING2` 두께 t3 → t5(A5052, 레이저 평판 그대로).** 아래 표에서 두 막힘 모델 모두 SF ≥ 2를 넘는 가장 얇은 두께다. 띠(STRAP)는 그대로 |
| 고친 뒤 확인할 것 | 링2 밑면이 −5 → −7, 띠가 Z −12~−7이 된다(윗면 −2 유지). 내린 상태 띠 밑 −72 ↔ 부시 플랜지 윗면 −80: 틈 8. 모델링부가 E-03 동작 검사(전 연구)를 다시 돌린다 |

## 미완

- 엔진 솔버 해석(TET10)과 교차 검증: 환경 없음(D-16). 링2·허브는 판·고리를 보로 본 근사이고, 링2 막힘 경우는 큰 처짐(비선형)이다. 환경이 생기면 STEP 그대로 다시 푼다.
- 진공 홈·포트 상세, 볼트 자리가 아직 없어 원판·링1 홈 밑살, 볼트 구멍 둘레 응력은 보지 못했다(디테일링).
- 구매품 허용치(DG 허용 모멘트·출력 테이블 지름, CJ2B16 스프링력, LHFR16 허용 모멘트·하중)는 카탈로그 확인 전(D-17).
- 링2 두께 변경(3절)은 모델에 반영되지 않았다. 모델링부가 고치고 E-03 검사를 다시 해야 한다.

## 워크플로우 메모

- 해석부 지시가 FEA 파이썬이 없을 때 "손계산"만 말하고 어떤 부품을 어디까지 볼지 정하지 않는다. 이번에는 표준 라이브러리 곡선보 모델을 직접 짰다. 엔진 `engine/fea/`에 numpy 없이 도는 손계산 도우미(보·판 띠·링 그릴리지, 검증 포함)를 두면 환경 없는 컴퓨터에서도 같은 방법으로 낼 수 있겠다(이번 `fea/cases/mech_T01_handcalc.py`의 `Grid`·`ring_model`이 후보).
- 해석용 임시 STEP이 부품마다 따로라 맞닿음·받침 관계(어느 면이 어디에 얹히는지, 실린더 로드는 수직, 샤프트는 기울기만 받는 등)가 STEP에 없다. 모델링부가 STEP과 함께 "받침·하중 전달 표"(부품, 맞닿는 면 Z, 받침 종류)를 내 주면 해석부가 보고서를 거슬러 읽지 않아도 된다.
- 하중 지시 "액추에이터 추력(보어와 요구서 2-4 운전 압력)"인데 2-4가 "운전 압력 미정"이다. 요구서 양식 2-4에 압력 값이 비면 0-6 공급 압력을 쓴다는 기본값을 적어 두면 좋겠다.
- `stepcheck.py`와 같이 Windows 콘솔 cp1252에서 한글 출력이 멈춘다(이번 스크립트 요약 출력도 `PYTHONIOENCODING=utf-8`로 돌렸다).
