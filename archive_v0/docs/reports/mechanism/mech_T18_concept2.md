## 요약

- 방향: **새 가공품·새 형상 부품 0.** 두 판(`P_T18_YNB`·`P_T18_XNP`)은 같은 t8 판금으로 두고 **재질을 SUS304 → 듀플렉스 S32205(SUS329J3L, Rp0.2 ≥ 450 MPa)** 로 바꾼다. 윤곽만 빈 자리로 넓힌다. 체결은 이미 쓰는 M5 형번(CB5·HNTT8-5)을 늘린다.
- YNB: 웹 X 50~120 → **X 5~120(폭 115)**, 안 R8 → **R16(2t)**, 윗다리 Y −610 → **−590**, CB5-16 2 → **4개**(Y −625). SF 웹 **2.89**, 윗다리 2.99, 볼트(분리) **3.04**.
- XNP: 평판을 **T자**로. 형재 면 띠 Y −550~−270 · Z −478~−408, 혀 Y −470~−350 · Z −581~−478. CB5-20+HNTT8-5 4 → **10조**(아래 열 7 · 윗 열 3). SF 판 **2.64**, T너트 허용 2.0 kN 대비 당김 **2.05** · 밂 **2.49**.
- 너트 플랜지 볼트: Y 너트 CB5-20 → **CB5-25 + 평와셔 t2**(물림 5 → **8**), X 너트 STEP대기_CB8-25 → **CB5-25 + 대형 평와셔 t2**(물림 8 → **8 ≥ 7.5 = 1.5d**, 끝 돌출 2 → 0). M8로는 t8 탭에서 물림 12가 원리적으로 안 된다(3절).
- 행정·조인트·끝 틈: J_MAT_X −620~620 · J_MAT_Y −860~40 그대로, X 6·5, Y 109·65.5 유지(웹 면·너트 자리 그대로). XNP +X 두께 증가 0. YNB 볼트 끝–받침 틈 2.0 그대로(CB5-16, Y판 t10).
- **측정 요약의 체결 SF 0.66·0.71·1.68은 잘못 환산된 값**이다. 1131 N 결과의 '조임' SF(외력과 무관)를 하중비로 나눴다. 2364 N으로 다시 풀면 지금 형상의 진짜 약점은 YNB 볼트 **분리 1.45**, XNP→T너트 **분리 1.20 · T너트 허용 0.60**이다(2절).
- 부품 수 **+22**(볼트 +8, T너트 +6, 와셔 +8). 가공품은 늘지 않는다. 가격 미확인.
- 미완: 듀플렉스 t8 R16 굽힘을 업체에 확인해야 한다(공급·굽힘 반경). T너트 허용치는 D-54 임시값이다. CB5-25·와셔 STEP이 없다(구매부). XNP 띠(Y −550~−270)와 YNB 윗다리 새 볼트 자리는 **측정하지 않은 영역**이라 모델링부가 짧은 clearance로 확인해야 한다(6절).

## 2. 지금 형상 2364 N 재판정 — 측정 요약의 체결 SF 바로잡기

`handcalc.calc`(엔진, 읽기만)에 2364 N 외력을 직접 넣었다(`c2_calc.json` now). 측정부 m2_calc는 1131 N 결과에서 **조임** 칸(예압 4 kN·10 kN 기준이라 외력과 무관)을 골라 k = 2.09로 나눴다.

## 9. 위험·대안

- **듀플렉스 공급·굽힘:** t8 S32205는 국내 판재로 흔하지만, 절곡은 SUS304보다 힘이 약 2배 들고 되튐이 크다. 업체가 안 R16을 못 하면 R24(Ki 1.12, SF 2.97)로 바꾸고, 윗다리 볼트 열을 Y −620으로 옮긴다(구멍–접선 2t 유지). 재질은 문서에 없는 결정이라 선정부·사용자 확인 대상이다.
- **T너트 허용치가 임시값이다(D-54).** 실제 값이 2.0 kN보다 작으면 10조로도 모자란다. 크면 6조로 줄인다.
- **측정하지 않은 영역 2곳**(6절). 모델링부가 짧게 확인한다. 띠가 막히면 Y −520~−300(아래 열 6 + 위 열 3, 당김 T너트 1.76)으로 줄인다. 이 경우 SF 2가 안 되므로 D-54 확정이 필요하다.
- **참고안(채택 안 함):** 서보–볼나사 커플링을 백래시 없는 기계식 토크 리미터로 바꾸는 안이다(두 축, 부품 수 0). 오조작 하중을 근원에서 묶어 이 과제의 모든 판·체결 여유가 커진다. 하지만 완료 판정이 2364 N 기준이고, 리미터 관성·비틀림 강성이 위치 정밀(C5)에 주는 영향을 모르며, 문서에 없는 결정이다.
