## 5. 손계산

### 5-1. 기둥 장공 강도(새로 바꾼 형상, E-18)
- 하중은 DP-2 fea1 '관 뿌리 오조작'(−221, 레버 220.5, σ 3.57, 단면계수 Z = π(60⁴−40⁴)/(32·60) = 17,017 mm³) → M = 60,750 N·mm, 윗끝 힘 275.5 N. 장공 높이 −203 레버 202.5 → **M = 55,790 N·mm**.
- 온 관 I = π(60⁴−40⁴)/64 = 510,509 mm⁴. 장공 3개(120°), 가장 불리한 굽힘 방향: 하나가 끝 섬유(y̅ 25), 둘이 y̅ 12.5. ΔI ≈ 5.5·10·25² + 2·5.5·10·12.5² = 34,375 + 17,188 = 51,563 → I' = 458,946, Z' = 15,298 mm³.
- σ 공칭 = 3.65 MPa, Kt 2.5(보수) → 9.12 MPa. PET-CF 층간 자리값 20 MPa → **SF 2.19 ≥ 2(오조작 기준)**. Kt 없이 5.48. 기준 +10 % 밖이라 FEA로 판정이 갈리지 않지만, 해석 못 함 — 환경 없음(자료대기 D-16) → 환경이 생기면 `P_T01_POST` STEP으로 확인만.
- 비교: 둥근 구멍 Ø10(관 2줄 나란히)이면 ΔI 93,750 → SF 1.99(기준 −0.5 %). 그래서 세로 장공(관 2줄 위아래)으로 했다.

### 5-2. 꼬임 여유
- 꼬임 길이 L: 관이 축으로 모이는 −233 → Y판 결속 −370 = **137**(장공 −203부터 보면 167, 보수로 137).
- 6줄 묶음(반지름 약 4) 한 바퀴 감김 늘어남 = √(137² + (2π·4)²) − 137 = **2.29 mm/줄(1.7 %)** → 꼬임 구간에 활 모양 여유 20을 둔다(관 길이에 포함).
- 관 자체 비틀림(보수, 각 관이 한 바퀴): J = π(4⁴−2.5⁴)/32 = 21.3 mm⁴, G 약 10 MPa(PU 자리값, 미확인) → T = GJθ/L = 10·21.3·2π/137 = 9.8 N·mm/줄, 6줄 **0.06 N·m**. DGM200R 회전 묶음 기준으로 무시할 크기(허용치는 D-36 (2) 카탈로그 확인 전).
- 겉면 전단 변형 γ = rθ/L = 2·2π/137 = 0.092. 관 피로 수명은 모델로 판정하지 않고 시제품 확인(요구서 7절)에 기록한다.
