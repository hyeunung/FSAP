## 워크플로우 메모

- 원장 commit 빠짐: S01(v0.4.2) 검사 뒤 `ledger.py commit`이 없었다. 그래서 T06 scope에 S01 부품 100여 개가 '새로·없어짐'으로 올라왔다. 버전을 저장하는 단계(또는 최종 회귀)가 끝나면 commit을 반드시 하도록 지시문에 넣으면 좋겠다.
- `ledger.py`·`brief.py`가 Windows cp1252 콘솔에서 UnicodeEncodeError로 멈춘다. `PYTHONIOENCODING=utf-8`을 주면 돈다. 도구가 stdout을 utf-8로 다시 설정하거나 지시문에 환경 변수를 적으면 좋겠다.
- `motion.interference`를 전 기구(5,236쌍)에 걸면 구매품 내부 메시 깊이 쌍(레일–블록 1.67, 실린더–로드 0.14, 부피 0/None) 때문에 2,400 s에 표본 10%에서 끊긴다. 전체 검사는 "새 단계 단계별 clearance(움직임 ↔ 고정) + 새 부품 motion.interference"로 나누는 편이 빠르다(이번 6분). 안내서 '동작 검사'에 적으면 좋겠다.
- `joint.sweep` 기본 step은 "contact sweep collision budget" 오류가 난다(모델링부와 같은 현상). step 1 + occurrences 하나로 줄이면 돈다.
- 지시문은 `tools/machine.json`을 가리키지만 이 기계의 기계 정의는 `tools/motion_states.json`이다.
