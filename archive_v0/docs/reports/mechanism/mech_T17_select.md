- **완료 판정을 과제 안에서 채우는 안은 C1과 C3뿐이다.** C2는 진공 연결의 절반(MAT_Y → BASE 이젝터)을 T16에 넘긴다. 그러면 T16 캐리어가 진공관 2줄을 X ±620·Y −860~40로 끌고 다닌다(진공 응답·관 길이가 불리하다). C1은 이젝터를 MAT_Y로 올려서 진공관을 MAT_Y·MAT_ROT 안에서 끝낸다. 캐리어로는 SUP Ø6 2줄이 건넌다. 캐리어를 건너는 줄 수는 C2와 같다(C1 보고서의 "2줄 준다"는 인정하지 않는다).
- **C1 대 C3:** 둘 다 동작은 되지만 C3는 부품 +41, 판금·곡선 출력이 늘고 좁은 틈(2)이 두 곳이다. C1은 +10이다. L2 M-10 "세트 총비용과 부품 수·조립 공수·정렬 조정 필요 여부·고장점 수를 한 표로", L3 U-06 "부품 수가 적고 조립·정렬이 쉬운 쪽"에 따라 C1이다.
- **C1 대 C2(차순위):** C2는 부품이 4개 적다. 하지만 T16에 진공 2줄이 더해지고, T11 관 묶음과 0.5 틈이 있다. 이 과제 범위에서 완료되는 C1을 고른다. C1 모델링이 막히면 C2의 꼬임 높이(Z −351.5~−215)를 쓰되 이젝터는 C1 자리로 올리는 합성안으로 간다.

## 4. 고친 좌표(지시서에 반영)

### 4-1. TCLAMP 클립 높이
- 원안: 팔·C클립 Z −410~−400, 꼬임 시작 −400.
- 문제: Y판 밑 가로관(Z −420)에서 세로(19.05, −711)로 올라오는 굽힘 R20(중심 X 39.05, Z −400)은 Z −400에서 끝난다. Z −410~−400은 원호 위라 클립이 원호를 물고, 팔(X 22~36)과 관이 X 22 부근에서 약 2.5 겹친다.
- 고침: C클립 고리 Z **−398~−388**, 팔 Z −398~−388, 기둥 Z −398~−374. 관 세로 시작 −400, 꼬임 구간은 −388 → −190(L198).

### 4-2. 처짐
- L198 늘음 8.36(3.97 %), 필요 8.36 + 2 = 10.36. h14 여유 10.34 < 10.36 → **h15**(여유 11.87, R28.8, 관 최소 Y −729, 모터와 23.5).

### 4-3. 기둥 바깥 관 잡이

## 워크플로우 메모

- `edit.checkpoint`로 받은 번호(73)를 같은 세션 바로 다음 호출에서 `edit.restore_checkpoint`가 "no checkpoint 73"으로 거부했다. 측정부도 같았다(번호 70). 체크포인트가 batch 호출 경계를 넘지 못하는 것 같다 · 근거: 이 보고서 머리, mech_T17_measure.md 7절 · 안내서 '원복'에 "체크포인트는 같은 batch 안에서만 — 읽기 부서는 undo 횟수로 원복하고 프로브 이름 수 0을 확인"을 적으면 좋겠다.
