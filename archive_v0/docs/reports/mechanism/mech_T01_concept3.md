## 1. 무엇을 하는 안인가

| 항목 | 내용 |
|---|---|
| 한 줄 | 바늘 바로 밑(베드 아래)에 축이 있는 **선회대**가 ±91° 돌고, 그 위 **반경 이송축**이 매트 중심을 바늘에서 100~836 mm 거리에 두며, 끝의 **자전 테이블**이 매트를 돌린다. 매트는 뒷면만 **중심 진공 원판(항상) + 진공 링 A + 받침 링 B(큰 매트일 때만 올림)** 로 잡고, 바깥은 선회대에 붙은 **좌우 날개 받침**이 받친다 |
| 왜 다른가(구상 1·2와) | X·Y·회전 골격은 바늘을 축으로 매트를 꺾을 때(③ 오목·홈 입구·홈 바닥, 노루발 들고 도는 구간) 매트 중심을 반경 600~836 원호로 X·Y 보간해야 한다(꺾임 2 rad/s면 X 1.61 m/s). 극좌표 골격은 **같은 꺾임이 선회대 한 축만 도는 것**이다(r·φ 정지). 또 선회대 좌표에서 베드는 늘 중심 근처에만 있어서, 선회대에 붙인 받침(날개)은 바늘에서 120 mm 뒤부터 매트를 받칠 수 있다 |
| 잡는 법 | 매트 **뒷면만** 진공. 파일 면은 아무것도 닿지 않는다(4-1·C-03) |
| 크기 대응 | 형상 지그 없음(C-08). 링 A·B는 매트 크기 등급(진공 새는지 시험)으로 올림/내림을 **로딩 때 한 번** 정한다(사이클 중 움직이지 않음, 구상 1의 "링이 베드를 피해 사이클 중 내려감"과 다름) |
| 바뀌는 것 | 준비부 골격 P-01의 `J_MAT_X`(직선 X)·`J_MAT_Y`(직선 Y)·`J_MAT_ROT`를 `J_TT`(회전, 세계 원점 Z축)·`J_R`(선회대 −Y_t 직선)·`J_PHI`(회전)로 바꾼다. 컴포넌트 이름 `MAT_X`·`MAT_Y`·`MAT_ROT`는 그대로 쓴다(MAT_X = 선회대, MAT_Y = 반경 캐리지, MAT_ROT = 자전부·받침) |

## 2. 구동 방식·행정·대기/작동 위치

### 2-1. 변환식 (기존 키 → 극좌표 키)

기존 연구의 매트 중심 (X, Y) = (`J_MAT_X`, `J_MAT_Y`), 매트 각 ψ = `J_MAT_ROT`.

| 새 조인트 | 식 | 뜻 |
|---|---|---|
| `J_R` | r = √(X² + Y²) | 바늘–매트 중심 거리 |
| `J_TT` | θ = atan2(X, −Y) (연속으로 풂) | 선회대 각, 반시계 + (Z축). θ = 0이면 반경 방향이 세계 −Y |
| `J_PHI` | φ = ψ − θ | 선회대에 대한 매트 각 |
| 역변환 확인 | X = r·sin θ, Y = −r·cos θ, ψ = θ + φ | 모델링부가 두 점으로 부호 확인(WF-055 슬라이더 방향) |

- 키는 **매 단계(정수)마다** 둔다. 기존 키는 직선 구간 양 끝에만 있어(X·Y 선형이면 정확) 극좌표로 두 키만 이으면 바늘이 윤곽에서 **227.6 mm** 벗어난다(`c3_polar_keysonly.json`). 매 단계 키면 보간 오차 큰·홈 매트 **0.19 mm**(기존 X·Y 키와 같음), 작은 매트 0.50 mm, 상태별 정밀 연구 0.002~0.004 mm. 키 값은 `c3_polar.json`의 `keys`(연구별 `J_TT`·`J_R`·`J_PHI`, 단계 수는 기존과 같음 — 상태표 `motion_states.json`의 단계 번호를 그대로 쓴다).

## 9. 모델링 지시 초안 (선정부가 CAD로 확인 뒤 확정)

1. 다른 이름으로 저장(E-05): 골격 교체 → 가운데 자리 +1(요구서 8-2).
2. 조인트: `J_MAT_X`·`J_MAT_Y`·`J_MAT_ROT`를 지우고
   - `J_TT` revolute, BASE → MAT_X, 원점 (0,0,0), z [0,0,1], 한계 −100~100°
   - `J_R` slider, MAT_X → MAT_Y, 원점 (0,0,0), 방향 선회대 −Y(z [0,−1,0]), 한계 90~860. **부호 확인**(WF-055): `J_TT` 0·`J_R` 700 → MAT_ROT 원점 (0,−700,0); `J_TT` 43.53·`J_R` 827.6 → (570.0, −600.0)
   - `J_PHI` revolute, MAT_Y → MAT_ROT, 원점 (0,0,0), z [0,0,1], 한계 없음
   - `J_RING_A`·`J_RING_B` slider, MAT_ROT → RING_A / RING_B 컴포넌트, z [0,0,1], 한계 −150~0. 링 판·가이드 축은 링 컴포넌트, 실린더 몸통·부시·스파이더는 MAT_ROT
   - 매트 9개는 지금처럼 MAT_ROT 리지드 그룹(링은 그룹에 넣지 않음, M-07)
3. 동작 연구 7개 다시 만들기: `c3_polar.json` `keys`의 `J_TT`·`J_R`·`J_PHI`(매 단계) + 기존 `J_HEAD_ROT`·`J_PRESSER`·`J_NEEDLE` 키 그대로 + 링 상수(큰·홈·대기 0, 작은 −150). 단계 수·상태표는 기존과 같음. 생성기에 극좌표 선택지를 넣는 것은 생성기 담당 몫(같은 식, 2-1절). `상태_링_내림` 연구 하나 추가.

## 10. 제어 순서 제약 (U-09, 설계검토서에 남길 것)

- 링 A·B 오르내림은 대기 자세(r ≥ 700)에서만. 작은 매트 등급이면 r < 700으로 움직이기 전에 링 내림 확인.
- 링 A 진공이 서지 않거나 링 공압이 떨어지면 반경 이송 금지(링 A가 진공 힘 900 N으로 눌림).
- 안전 인터록: 엔코더로 계산한 베드 자리가 받침 좌표에서 (링 바깥 반경 + 45) 안으로 들어올 경로면 정지 — 로딩 중심 어긋남·D-01 밖 형상 대비.
- ③ 꺾임(노루발 들고 바늘 내림)은 `J_TT`만 돌린다. 선회 중심과 바늘의 어긋남(맞춤 오차)은 `J_R`·`J_PHI` 보정으로 지운다(바늘이 옆으로 끌리지 않게).
- 진공 확인(원판) 전에는 ② 시작 금지.
