# 구동 T10 구상 3 — 실린더·안내 블록 그대로, 패드만 +X 4.10 어긋나게(T홈 끝 고정)

기구설계부 3번, 2026-11-01. CAD 안 씀. 근거 자료 `docs/reports/mechanism/mech_T10_measure.md`(측정부, v0.6.13). 좌표는 측정 자료와 같다(세계 좌표, 대기 자세, 바늘점 원점, 매트 밑면 Z 0, mm).

**요약**
- 방안 C: CJ2B10-15Z·SNJ·로드·NTJ ×2·`P_T05_GUIDE`(위판 구멍 포함)는 **한 곳도 옮기지 않는다.** `P_T05_PAD`만 다시 출력한다. 누름 면을 +X로 4.10 옮겨 (−140.90~−112.90, 562.5~582.5, 43~63)로 하고, T홈 닫힌 끝은 세계 좌표 그대로 둔다(목 끝 X −128.8, 너트 주머니 끝 X −126.75). 그래서 패드 안에서 로드 축은 −X 면에서 9.90 자리가 된다(가운데에서 −4.10).
- 판정: 패드 중심 X −126.90 ↔ 테이프 중심 −126.9025, 차 **0.0025**(≤ 0.5 합격). 누름 면적 560/560 mm². 패드 행정 외곽은 측정 프로브 `Q_STROKE_NEW`와 같은 상자라 겹침이 0이다(옆벽 0.85~4.79, 앞·뒷벽 0.3, 바닥 0.01).
- 정적 겹침 T05-V1(1.842 mm³)은 패드와 관계가 없다. 작업 대상 외피 `MAT_TAPE_PATH`의 끝 조각을 비틀림 0°로 끝내 Y 552.5에서 자르면 없어진다(T05-V1이 낸 방법). 그러면 간섭 0이 된다.
- 바뀌는 부품은 1개(`P_T05_PAD` 다시 출력)다. 구매품 0, 부품 수 증감 0. 안 A와 달리 위판을 다시 출력하지 않는다. 그래서 안내 블록(97 980 mm³, DP-3 앞벽·R3·R1 마감)을 다시 검증할 필요가 없다.
- **약점(미완·위험): 누름 힘의 작용선은 그대로 X −131에 있다.** 압력 중심이 테이프 가운데에서 4.10 떨어지고, 압력은 −X 가장자리 1.88 : +X 가장자리 0.12(평균 대비)로 기운다. 덮음은 고쳐지지만 장력·쏠림은 지금과 같다. 시제품 확인으로 넘긴다(요구서 7절). 압력이 고르게 걸리는 것이 목표라면 안 A가 낫다(5절).

## 1. 왜 이 방향인가(앞의 두 방향과 다른 점)

| 안 | 옮기는 것 | 바꾸는 가공품 | 작용선 |
|---|---|---|---|
| A(측정 안 A, 다른 부서) | 실린더·패드 +X 4.10 | 패드 + 안내 블록(위판 구멍) | 테이프 가운데 |
| B(11.145° 돌림, 다른 부서) | 패드 돌림 + 주머니 벽 | 패드 + 안내 블록(주머니) | 테이프 가운데 |
| **C(이 안)** | **패드 누름 면만** | **패드만** | X −131 그대로(4.10 어긋남) |

테이프 쪽(길·롤·안내 블록)을 옮기는 안은 T05-M10에서 기각됐으므로 내지 않는다. 실린더를 기울이는 안(로드가 6.1° 기울어 Z 49에서 X −126.9에 닿게)도 따져 봤다. 그러면 로드에 옆힘 F·sin6.1° = 4.2 N이 걸린다. CJ2 카탈로그는 로드에 옆하중을 주지 말라고 하므로(M-06) 버렸다.

## 2. 구동 방식·행정·자세·순서

구동 원리는 바뀌지 않는다. `CJ2B10-15Z`(SMC 복동 Ø10, 행정 15)가 위판 Ø8.2 구멍(−131, 572.5)에 SNJ로 매달려 있고, `J_T05_PAD`가 Z 직선으로 −13.5~0을 움직인다. machine.json의 조인트·한계·연구 키도 그대로다.

| 상태 | J_T05_PAD | 패드 bbox(이 안) | 틈 |
|---|---|---|---|
| 올림(실 끼우기) | 0 | (−140.90, 562.5, 55.5)~(−112.90, 582.5, 75.5) | 위판 밑면 Z 85.5까지 10.0, +X 옆벽 0.85(Y 582.5)/4.79(Y 562.5), 앞·뒷벽 0.3 |
| 작동·대기·저장(①~④) | −12.5 | Z 43~63 | 테이프 윗면 Z 43에 닿음(누름), 옆벽·앞뒷벽 위와 같음 |
| 테이프 없음(스토퍼) | −13.5 | Z 42~62 | 받침면 Z 42에 닿음(측정 바닥 0.01은 −13.49 프로브 값) |

순서는 T05-S04 그대로다. ① 대기에서 앞끝을 누른다 → ②~③ 봉제가 끌고 압력으로 장력을 조정한다 → ④ 절단 뒤 새 앞끝을 누른다. 실을 끼울 때만 0으로 올린다. 떨어지는 조각은 T05에 없다(절단 조각은 T06).

## 4. 판정·손계산

### 4-1. 위치

- 테이프 중심 X(Y 572.5) = −22 − 0.197 × 532.5 = **−126.9025**(측정부 슬랩 실측, 오차 0.01).
- 패드 중심 = (−140.90 + (−112.90)) / 2 = **−126.90**. 차 0.0025 ≤ 0.5이므로 **합격**.
- 길에 수직인 거리도 0.0025 × cos11.145° ≈ 0.002다.
- 가장자리 여유: 테이프 가장자리 X(Y 572.5) −143.21~−110.59 ↔ 패드 −140.90~−112.90. 양쪽 2.31(X), 길에 수직 2.27. Y 562.5·582.5 끝에서도 ±1.97 안이라 패드 전부가 테이프 위에 있다. 면적은 560/560(측정 안 A의 덮음과 같은 상자).

### 4-2. 간섭(상태별)

| 짝 | 근거 | 값 |
|---|---|---|
| 패드 행정 외곽(Z 42.01~75.5) ↔ 안내 블록·평판·롤·허브·헤드·테이프 외피 | 측정 `Q_STROKE_NEW`(이 안의 패드 외곽과 똑같은 상자) | 0 |
| 실린더·SNJ·로드 ↔ 위판 | 옮기지 않음, v0.6.13 현행 | 0(지금 상태) |
| NTJ ↔ 패드 T홈 | 세계 좌표 그대로, 주머니 끝 세계 X 그대로 | 지금과 같은 틈 |
| 패드 −X 빼기 30 | 측정 `Q_OUT_NEW` | 0 |
| `MAT_TAPE_PATH` ↔ `P_T05_GUIDE`(T05-V1) | 끝 조각을 0°로 하고 Y 552.5에서 자름. 겹침 bbox Y 553.16~555.89가 잘린 쪽 밖 받침면 앞모서리이므로 없어진다 | 1.842 → 0(검증에서 `inspect.interference`로 확인) |
| 전 사이클(8연구) | 패드 외곽은 행정 전 구간 상자로 이미 쟀고, 다른 조인트는 Z ≤ 13 또는 Y ≤ 40 | 0 예상, 검증이 `motion.interference`로 다시 확인 |

### 4-3. 하중(새로 바꾼 패드만, E-02)

- 밀기: Ø10, 0.5 MPa → F = 78.5 × 0.5 = **39.3 N**. 당기기: (78.5 − 12.6) × 0.5 = 33.0 N(DP-3 32.99 N과 같음).
- 로드 끝 면압: 접촉 자리가 그대로라 DP-3 SF 9.6과 같다.
- T홈 턱(t2.6, 돌출 1.5): 너트가 닿는 길이(NTJ 8.08)가 같으니 SF는 24.9로 그대로다. 보수적으로 턱 길이 비(14.15/18.25)를 곱해도 **SF ≥ 19.3**이다.
- 편심: e = 4.10, 누름 면 길이 L = 28(X), L/6 = 4.67 > e이므로 면 전체가 닿아 있다(들뜸 없음). 압력은 p = F/A · (1 ± 6e/L) = 0.070 × (1 ± 0.879)이므로 **−X 끝 0.132 MPa, +X 끝 0.0085 MPa**다. 테이프 가장자리 사이의 마찰 쏠림 모멘트는 μF·e = μ × 161 N·mm다(지금과 같다).
- 로드 옆하중: 패드는 NTJ가 T홈 주머니 틈(Z 0.4) 안에 떠 있는 상태라 기울어지는 것을 테이프 면압이 받는다. 로드에는 축 방향 힘만 걸린다(M-06 CJ2 "로드에 옆하중 금지"를 지킨다). 패드가 기울려면 주머니 틈 0.4를 다 써야 하고, 그 각은 0.4/8.08 ≈ 0.05 rad 이하다. 실제 기울기는 테이프 압축 강성(D-06 미정)으로 정해진다. 7절로 넘긴다.
- 처짐: 패드 PET-CF 20 높이 덩어리라 무시한다.
- 해석: 해석 못 함 — 환경 없음(자료대기 D-16). 형상·하중 경로가 바뀐 곳은 턱 길이뿐이라 손계산으로 충분하다(E-18).

## 5. 위험·미완

1. **작용선이 4.10 어긋나 있다(가장 큰 약점).** 이 안은 완료 판정(기하 중심 ≤ 0.5, 간섭 0)은 맞추지만, 압력 중심은 지금과 같다. 덮지 못하던 +X 가장자리 4~8은 이제 덮이지만 압력은 평균의 0.12만 받는다. 장력 조정과 테이프 쏠림·주름이 지금보다 나아진다고 말할 수 없다. 요구서 7절(시제품 확인) 항목으로 기록한다. 압력이 고르게 걸려야 한다면 안 A(위판 구멍 이동)를 고른다. 안 A의 추가 비용은 안내 블록을 다시 출력하는 것 하나다.
2. 패드가 미세하게 기울어(≤ 0.05 rad, 테이프 강성 미정) 누름 면 −X 끝이 더 파고들 수 있다. 영구 눌림자국 금지(C-03)는 테이프(매트가 아님)라 직접 해당하지 않지만, 테이프 표면 자국은 7절에서 확인한다.
3. T05-V1을 지우는 것은 작업 대상 외피(표현)를 고치는 것이다. 실제 테이프가 받침면 앞모서리를 넘는 거동은 DP-3 R1 리드인이 맡고, 시제품에서 확인한다.
4. 렌치: SNJ 스패너 조건은 지금과 같다(측정 6절, 앞벽 R3 판 프로브 11.4 mm³는 현행 그대로). M-01·M-02 판정은 검증으로 넘긴다. BOM은 CJ2B10-15Z ×1(SNJ·NTJ 동봉)으로 수량·외형이 바뀌지 않는다. 높이 사슬도 바뀌지 않는다.
5. 새 동작 문제: T05-V1 정적 겹침 1.842 mm³(kind='동작'). DP-3 보고서의 '0'과 다르다.

## 6. 구매·가공·비용

- 구매품: 바뀌지 않음. `CJ2B10-15Z` STEP 있음(stepcheck: `CJ2B10-15Z\CJ2B10-15Z.stp`). 가격은 요구서 3-1 가격표에 없어 미확인이다. 카탈로그 허용치(M-06): 로드 옆하중 0을 지킨다(4-3).
- 가공품: `P_T05_PAD` PET-CF 3D 출력(U-05 두 번째, 판금으로는 T홈 덩어리를 만들 수 없음). 다시 출력, 질량 +0.4 g.
- 부품 수 증감 0. 세트 비용 증감은 패드 재출력분 정도(재료 +0.4 g, 미확인 소액)다. 안 A보다는 안내 블록 재출력 한 번이 빠진다.
