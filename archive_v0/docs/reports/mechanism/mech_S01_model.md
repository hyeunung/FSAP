## 워크플로우 메모

- MCP 서버 안내가 headless라 CLI로 모델링했다(사용자는 앱에서 실시간으로 못 봄). 사용자 앱을 켠 뒤 MCP 서버를 다시 띄워야 "T06부터 MCP" 지시가 지켜진다.
- `joint.sweep`(CLI 0.27.1)은 occurrence를 좁혀도 "motion exceeds contact sweep collision budget"로 거부됐다(나사면 많은 SMC STEP). 안내서 '조인트 자기 점검'에 임시 동작 연구 + `motion.interference` 대안을 적으면 좋겠다.
- 전체 occurrence `motion.interference`는 매트 모형끼리 쌍(불리언 100초대) 때문에 1단계에 527초가 걸려 540~996단계 연구는 예산 안에 못 끈다. 안내서에 "작업 대상끼리는 빼고 바뀐 부품 대 전체"를 기본으로 적으면 좋겠다.
- `file.insert_step` matrix는 부모 로컬, `solid.box`·스케치 좌표는 세계(대기 자세)다. 지시서의 "MAT_Y 로컬 = 세계 + (0, 700, 0)"은 맞지만, root에 세계 행렬로 넣고 reparent하는 쪽이 틀릴 일이 없다.
- SolidCraft flat BOM은 purchased 아래 하위 부품을 세지 않아 형재 아래 캡이 빠진다(inseparable로 해결). 안내서 '목록'에 적어 두면 좋겠다.
- 지시서 지울 바디 수(26)와 목록(28)이 달랐다.
