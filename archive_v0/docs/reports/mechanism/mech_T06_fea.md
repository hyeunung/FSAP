**요약(10줄)**

- 디테일 1: 팔 칼 막힘 SF **1.67** < 2(선정 값과 같음). t4면 2.97.

- 미완: LHFR16 허용 하중(D-37 (6), 반경 하중 183 N), 축–팔 체결이 우력을 받는다는 전제(D-37 (2)), SK85 열처리 조건. 고체 FEA는 환경이 생기면(D-16) 팔 + 칼 + 축으로 다시 한다.

## 5. 미완

- 고체 FEA(팔 + 칼 + 축, 오조작 T)는 해석 못 함 — 환경 없음(D-16). 오조작 T SF 1.22는 동작 경계 1.2의 +10 % 안이다. 환경이 생기면 가장 먼저 푼다.
- 축–팔 체결(D-37 (2), 후보 `PSFJT16-100-M5`)이 우력을 받는다는 전제로 풀었다. 형번이 정해지면 체결부 나사 강도를 다시 본다.
- SK85 열처리 조건이 미확인이다. 풀림 항복 390 MPa로 보수하게 봤다.
- 실린더 행정 끝 충격(속도 미정)은 넣지 않았다. 스피드 컨트롤러 값은 PLC·시제품에서 정한다(요구서 7).
- STEP·도면은 완성본일 때 한꺼번에 낸다(E-06).

## 워크플로우 메모

- 해석부 지시가 "하중: 액추에이터 추력 · 작업 저항 · 자중"만 들고 있어, 오조작 하중(매트 미끄럼 417.5 N)을 새 부품에 어느 방향으로 줄지는 해석부가 정해야 했다. models.json에 "오조작 하중 방향은 실제 출처(테이프 줄 방향 등)로" 같은 공통 칸이 있으면 부서마다 판단이 갈리지 않는다.
- Windows 기본 콘솔(cp1252)에서 엔진 `handcalc.py --help`가 한글 출력 때문에 UnicodeEncodeError로 멈춘다. `PYTHONIOENCODING=utf-8`을 붙여야 돈다. 실행 규칙 (5)에 넣으면 좋겠다.
