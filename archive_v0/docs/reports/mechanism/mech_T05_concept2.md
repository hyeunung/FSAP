## 1. 구동 방식

### 1-1. 생각 — 왜 모터가 없어도 되나

- 이 기계의 헤드는 이송이 없고(T02 기종 조건 "이송 없음") 매트가 바늘 밑을 지나며 움직인다(C-01). 바늘이 테이프와 매트를 함께 꿰매므로, 꿰맨 테이프는 매트와 함께 끌려가고 그만큼 롤에서 풀린다. **공급량 = 봉제된 둘레 길이**가 저절로 맞는다(측정 3-2: 바깥면 기준 0.9~1.033배 차이도 테이프가 바늘에 물린 뒤 매트를 따라가므로 따로 맞출 필요 없음).
- 모터가 해야 할 일은 "장력을 바꾸는 것"뿐이다. 장력은 롤 쪽 끌림 + 패드 마찰이므로, **패드를 누르는 힘을 바꾸면 장력이 바뀐다.** 패드 위치는 테이프 위에 그대로이고 힘만 바뀐다 → 요구서 2-4의 "누르기" 끝점 동작, 둥근 실린더 + 압력 조절로 충분하다.
- 패드는 롤 지름과 무관하게 장력을 정한다(롤 쪽 끌림 ≤ 0.55 N, 3-2). 롤 브레이크로 장력을 거는 방식은 지름이 Ø76 → Ø194로 바뀌면 같은 토크에서 장력이 2.6배 달라지므로 택하지 않았다.
- 같은 실린더가 ④ 이음매·절단 때 테이프를 꽉 잡아(최대 압력) 절단(T06) 중 테이프가 바인더에서 빠지지 않게 하고, ⑤ 이후 새 앞끝을 바인더에 남긴다 → 클램프 부품을 따로 두지 않는다(T06과 공유 후보, 결정은 T06).

## 워크플로우 메모

- 구상 부서 여러 명이 동시에 돌 때 지시문 (6) "쓴 임시값과 그 근거를 … 자료대기 '쓰는 곳'에 적는다"를 그대로 하면 같은 D-번호를 나눠 갖거나 `waiting-list.md` 한 줄(D-06 칸은 한 줄이 수천 자)을 동시에 고쳐 서로 덮을 위험이 있다 · 구상 단계는 보고서 표에만 쓰고 선정이 옮기게 하거나, 구상 부서별 임시 번호(D-T05-c2-A 등) 규칙이 필요하다.
- stepcheck.py·excerpt.py가 Windows 기본 콘솔 코드페이지(cp1252)에서 한글 출력 때 UnicodeEncodeError로 멈춘다 · `PYTHONIOENCODING=utf-8`을 주면 된다 · 엔진 도구 쪽에서 stdout 재설정 또는 지시문 실행 환경에 환경 변수 명시 후보.
- 측정 프로브가 X −76~−34(윗팔 밑 바깥) 띠를 비워 두어, 롤 자리에서 바인더로 비스듬히 가는 경로를 수치로 판정하지 못했다 · 측정 단계에서 후보 상자 사이 틈도 덮는 큰 상자(예: X −300~34 전체)를 함께 재면 구상이 프로브 사이 추론을 하지 않아도 된다.
