# T13 선정(PM + 원칙 감사) — 헤드 받침 강성·배치 (v0.10.0, 엔진 v3.4.0)

**요약(10줄)**
- **선정: T13-S = 구상 3(T13-C3) 닫힌 판금 비틀림 상자 + 보강 두 가지.** ① 옆판 아래 치마를 앞으로 Y 470까지 늘려, 무게 모멘트(D-31, 기둥 하나에 1 g 141.6 N·m)를 580 옆면 볼트 4개로 받는다. ② 580 앞끝–1900_B 맞댐에 판금 L `P_T13_FBL_T1/T2`를 넣는다. 차순위는 T13-C1(헤드판을 t12로 고치는 조건).
- 바꾸는 것은 새 바디뿐이다. 기둥·580·T19 다리·헤드판은 그대로 두고 옮기지 않는다. 새 바디는 판금 4개(`P_T13_SLEEVE`·`P_T13_REAR`·`P_T13_FBL_T1/T2`)와 `CB5-12` 30개, `HNTT8-5` 30개다. stepcheck 결과 둘 다 **실물 STEP이 있어 새 STEP대기_가 0이다**.
- 흔들림(끌림 20 N, 바늘점 X, 580 굽힘 포함, `tools/out/mech_T13/select_calc.json`): 비틀림 모드는 0.065이고, 볼트 미끄럼 ×2를 넣으면 0.130이다. 공통 몫(1900_B 약축·580 X 외팔)까지 더한 보수 합계는 **0.290 ≤ 0.657**이다. X 밀림 상한은 0.46으로 지금 1.869에서 줄고, 0.657 안이다.
- 기각 이유. 구상 2는 X 밀림 상한 1.869를 그대로 두고, 체결을 그리지 않으며, HBLFSN8 렌치 결함(T19-D8)도 남긴다. 구상 1은 헤드판 t6을 X ±190으로 넓히는데, 비틀림 처짐이 4.7 mm로 나와 반박됐다. 게다가 부품 +77, 새 STEP대기_ 4종, M8 볼트, T19 다리 이동이 따른다.
- CAD 확인(MCP, 이미 열린 v0.10.0, SHA `5b41baaf…840dfd` 측정과 같음): 판·치마·L·렌치 길 프로브 19개 ↔ 이웃 106바디의 `inspect.clearance`에서 **겹침 0**이다. 맞닿음은 기둥·580·헤드판·1900_B·다리 윗모서리에서만 생긴다. 렌치 길 22 mm 안에 남의 부품이 없다. 근처 최소 틈은 HBLFSN8_U 5.0, 헤드 6.0, 캡 6.7이다.
- 높이 사슬 −900/66/16/138/−680/80/−600/460/−140/6/−134는 그대로다. 조인트·연구·작업 대상 길도 그대로다. Z −680~−600 띠에는 움직이는 것이 없다(측정 2-2).
- 강도(새 부품만, 손계산): 치마 볼트 무리 1 g 250 N는 미끄럼 SF 2.8이고, 3 g 751 N는 지압 SF 4.1이다. 기둥 볼트 무리는 3 g 556 N다. 맞댐 L은 3 g에서 볼트당 397 N이고 미끄럼 SF 1.76, 지압은 충분하다. 판 τ는 0.127 MPa다.
- 디테일(기록만, E-02): HNTT8-5가 먼저 넣는 형인지 뒤에 넣는 형인지, CB5-12 물림 8.5, 치마 굽힘 해방 홈, 헤드판–기둥 체결(DL-X06, D-10 뒤)이 남았다.
- 미완·외부: 한도 D-08 임시, 형재 I·J D-27, 너트 미끄럼 계수, 헤드 무게 D-10. FEA는 못 했다(환경 없음, D-16).
- 문서는 바꾸지 않았다(읽기, 저장 없음). 프로브는 `edit.checkpoint 169` → `edit.restore_checkpoint`로 지웠고, `motion.play 대기 0`은 moved false였다.
