## 7. 설계검토서에 남길 PLC 제약 (U-09 "PLC에 넘길 동작 순서 제약 … 은 설계검토서에 기록해 둔다")

설계검토서(`docs/review/`)가 아직 없어 여기 적고, 검토서를 만들 때 옮긴다. d = 축 (x, y)에서 베드 자리 [X ±50] × [Y −30~+660]까지 평면 거리.

1. 링1(R300): 덮임 시험을 통과하면 올림. d − 300 < 40이면 내리고 그 사이클에는 다시 올리지 않는다.
2. 링2(R520): d − 520 < 40이면 내리고 > 60이면 올린다.
3. 링1을 내리기 전에 링1 진공을 끊는다.
4. 링 올림과 되감기는 매트가 없을 때만 한다(CAD: 링1 올림 ↔ 작은 매트 가공 뒤 형상 5,061 mm³).
5. 축이 베드로 다가오는 속도 ≤ 133 mm/s(링 내림 0.3 s 자리값, D-12).
6. 인터록: d < (올라가 있는 링 반경 + 15)가 되는 경로면 정지한다.
7. 진공 확인 전에는 ② 시작 금지.
8. 회전 누적은 −400~+40° 안이다(호스).
9. 큰 매트 꺾임은 0.4 rad/s 이하(X 볼나사 위험 속도 약 335 mm/s).

## 워크플로우 메모

- 선정 지시서의 빈 공간 좌표(Y 묶음 Z −380~−260)를 지시 부품(DG·Y판)과 대조하지 않아 모델링에서야 겹침이 나왔다. 선정 단계의 프로브 검사에 '비워 둘 공간' 상자도 넣어 지시 부품과 겹침 0을 확인하게 하면 좋겠다.
- 절차 3 "이름에 재질·제작 방법"과 지시서의 정한 바디 이름(`P_T01_DISC`)이 부딪친다. SolidCraft 바디에는 설명 칸이 없어 컴포넌트 속성에 적었다. 안내서 '재질'에 SolidCraft에서 재질·만드는 법을 어디에 적는지(바디 이름 접미, 컴포넌트 속성, 바디마다 하위 컴포넌트) 한 가지로 정해 두면 좋겠다.
- 같은 평면 옆면을 가진 두 바디의 join은 SolidCraft가 거부한다(ㄷ 웹 + 다리). 판금 ㄷ·L은 단면 하나를 그려 밀어내는 것이 안전하다 — 안내서 모델링 함정에 더하면 좋겠다.
- 모델링부 출력 스키마에 needs_step 칸이 없다(공통 규칙 (10)은 needs_step·자료대기에 남기라고 한다). 자료대기 D-17에만 남겼다.
- `stepcheck.py`는 Windows 기본 콘솔 인코딩(cp1252)에서 한글을 찍다가 멈춘다. `PYTHONIOENCODING=utf-8`로 돌렸다. 도구 안에서 `sys.stdout.reconfigure(encoding='utf-8')`를 하면 좋겠다.
