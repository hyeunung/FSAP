## 1. 왜 이 안인가

| 고른 것 | 이유 |
|---|---|
| 테이프를 세워 보냄(폭 Z) | 길 `A`의 폭이 24라 눕히면 32가 안 들어간다(측정 2-1). 바인더 입구 면은 X −34~−10 · Z 26~60으로 높이 34 ≥ 32다. 롤부터 세워 두면 비틀기용 롤러가 필요 없다 |
| 롤·롤러 축 모두 세로 | 테이프가 세워져 있으니 축이 Z면 감김이 평면 안에서 끝난다. 롤도 세로 축이어서 위로 빼고 바꾼다(M-02) |
| 정량 공급(스테핑) + 스프링 댄서 | "오목·볼록에서 장력을 바꿀 수 있는 구동"을 모터 하나로 한다. 공급비(0.9~1.033)와 댄서 목표 각(장력)을 상태마다 바꾼다. 연속으로 바뀌는 값이라 전동이다(요구서 2-4). 공압 레귤레이터(ITV) 댄서는 부품과 공압 배관이 늘어 택하지 않았다(U-06) |
| 공압 0 | 닙은 스프링으로 닫히고 끼울 때 손잡이로 연다. 끝점 동작 실린더가 필요한 단계(①~⑤)가 없다 |
| 헤드 기둥에 고정 | C-01 "헤드 고정"이므로 매트·이송에 달면 꼬인다. HEAD 리지드라 `J_HEAD_ROT`를 써도 길이 따라 돈다(측정 1-3) |
| 롤 `B`를 아래로 내림(Z 27~59) | `B`(Z 100~300)에 두면 테이프를 Z 43까지 내리려고 꺾는 롤러가 하나 더 든다. `C_L`(X ≤ −76, Z 11.5~400)도 모든 단계에서 비어 있다(측정 2-1) |

## 9. 위험

1. 닙 미끄럼 SF 2.0(μ 0.6 임시). 테이프 표면(누벅 등, D-06)에 따라 달라진다. 모자라면 구동 롤러 감김각을 90°로 늘린다(G2를 옮겨 감김, 부품 수 변화 없음) — 시제품(요구서 7).
2. 모터축 오버행 허용치를 확인하지 못했다(M-06). 모자라면 롤러 밑을 선반 부시로 받친다(+1, 동심 맞춤 필요).
3. 바인더 입구 Z 여유가 ±1.0이다. 선반 처짐 0.38과 아이들러 플랜지 공차가 쌓인다. 바인더 속 통로(T02-S01)가 정해지면 입구 높이에 맞춰 G5 높이를 조정 와셔로 맞춘다(디테일).
4. X −76~−34 띠(선반 혀·건넘 구간·누름 열림)는 측정 프로브 밖이다. 헤드 bbox로만 비었다고 봤으니 모델링 검사에서 반드시 잰다.
5. 헤드 기둥 탭(D-10): 실제 헤드 주물에 볼트 자리가 없으면 장착 방식이 바뀐다.
6. 장력 목표값(볼록 −10°, 오목 +10°의 방향과 크기)은 근거가 없다. 측정 3-2의 비율은 기록용이다. 날개 늘어남·주름·들뜸은 요구서 7절에서 시제품으로 정한다.
7. 선반 바닥이 매트 위 6 mm다(Z 17 대 11). 매트가 휘거나 들뜨면(D-04 매트 평탄도 미정) 닿을 수 있다. 측정 모형은 평판이다.
