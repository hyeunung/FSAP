- 정적 전수: 새 바디끼리·새 바디 ↔ BASE 맞댐면(G2 ↔ `1900_F` 앞면 Y −1020 거리 0, 겹침 0).

## 워크플로우 메모

- `excerpt.py`가 Windows 기본 콘솔 인코딩(cp1252)에서 한글 출력 중 `UnicodeEncodeError`로 멈춘다 · `PYTHONIOENCODING=utf-8`을 주면 된다 · 엔진 도구가 `sys.stdout.reconfigure(encoding='utf-8')`를 하거나 지시문에 환경 변수를 적으면 좋겠다.
- 지시문은 "python -B -I로 gmsh를 써서 bbox를 잰다"인데 이 컴퓨터에 gmsh가 없다(`ModuleNotFoundError`) · 대신 측정부 `r_out.json`의 부피로 단면적·실제 길이를 구했다 · 지시문에 "gmsh 없으면 측정부 bbox/부피 사용"을 적어 두면 좋겠다.
- `HFS8-4080-1900_F/B` bbox가 X ±1425로 나와 측정부가 BASE를 ±1425로, 자동 배출 자리 A4·A5를 |X| ≥ 1426으로 잡았다. 부피로 보면 실제 끝은 ±950이다 · 구매품 STEP bbox를 그대로 쓰면 외곽을 잘못 잡는다 · 측정 도구가 형재는 부피 ÷ 단면으로 길이를 교차 확인하면 좋겠다(이 구상의 A4·A5 판정은 더 바깥이라 그대로 맞다).
- 구상 3명이 동시에 자료대기에 새 D-번호를 쓰면 번호가 겹친다 · 이 구상은 제안만 했다 · 구상 단계의 새 D-번호는 PM(선정)이 매기도록 지시문에 적으면 좋겠다.
