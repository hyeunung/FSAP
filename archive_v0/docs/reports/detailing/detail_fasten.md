## 워크플로우 메모

- groups.json 체결 묶음이 볼트 0일 때 비어 있어, 체결 '자리' 묶음(E-19)을 이 부서가 손으로 묶었다. 구멍·맞닿음 자리 기반 묶음이 있으면 좋다.
- `inspect.clearance {bodies: 프로브}`만 주면 프로브끼리만 잰다. 모델 전체와 재려면 `against`에 바디 이름 전부를 줘야 한다(첫 회 헛돌림).
- 스냅샷 체결 목록이 이전 표 항목만 모아서 구멍 0인 하중 부품(허브·링·Y판 등)이 빠졌다. 스냅샷에 '구멍 0 + 다른 부품과 맞닿음' 목록을 넣으면 좋다.
