## 6. 디테일·기록

1. 원판 인서트 `MBIS5-6.5-8`: 미스미 표기 "적응 상대물 열가소성 수지"라서 Rigid 10K(광경화 열경화성)에는 열압입으로 붙지 않는다. 접착(에폭시) 압입이나 열경화 수지용 인서트가 필요하다. 조임 1.5 N·m의 예압 1,500 N이 그대로 빠짐 하중인데 빠짐 강도 자료가 없다. 형번 확인은 구매부, 자료대기(D-43 계열)로.
2. 링2 막힘(받침 강체) SF 2.22는 기준 2의 +11 %다. Ø10 구멍으로 지난 2.33에서 내려갔다. ±10 % 밖이라 FEA 대상은 아니다.
3. 회전 묶음 질량 −4.55 kg, 관성 −0.563 kg·m²(허브 +0.012, 스파이더 3개 −0.575)로 DG 토크·하중 여유가 늘었다. 허용값은 D-17·D-36 (2)로 미확인이다.
4. 판금 A5052 질별은 H32 가정(Rp 175 보수)이다. O재(약 90 MPa)면 발 국부가 더 나빠지므로 도면에 H32 이상을 지정한다.

## 7. 해석 못 함 — 환경 없음(D-16)

- 기준 ±10 % 안 값은 0이다(링2 강체 2.22는 +11 %).
- `handcalc beam` 결과 발 국부(t/L = 0.27, 보로 보기 어려움)는 `needs_fea: true`다. 환경이 생기면 발 + 허브 + 볼트 예압 고체 FEA(두께 방향 2요소)로 다시 보고, 그때 `feacache put`으로 넣는다. 이번에는 FEA를 돌리지 않아 `feacache`를 쓰지 않았다.

## 워크플로우 메모

- 지시문의 E-18 흐름(체결만 → handcalc, 형상 바뀜 → FEA)에서 환경이 없을 때 하중 경로가 바뀐 판 국부(발)를 어떻게 판정할지 정해진 게 없다. 이번에는 예압 무시 외팔(상한)과 편심 이음 열림 하중을 함께 적었다.
- `handcalc` 체결 표는 너트 물림(표준 너트)과 탭 물림을 구분하지 않아 M4 + 너트가 항상 `ok=false`가 된다.
