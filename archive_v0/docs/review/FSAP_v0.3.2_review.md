# 설계검토서 FSAP_v0.3.2 (변경분) — 구동 T04 가장자리 센서 배치

**요약**
- 바뀐 부품: 노루발 `P_T02_FOOT`(컴포넌트 `PRESSER`, Rigid 10K SLA) 하나. 화이버 주머니 12.0×3.15×8 · 검출 슬릿 11.0×1.0(바닥 관통) · 화이버 통로 Ø2.6(+X 옆면 출구)을 깎음. 부피 15,887.24 → 15,481.37 mm³.
- 판정: **pass**(동작 문제 0). 검출 ③ 2,348/2,348단계 걸림, 간섭 v0.3.1 기준선과 같음(새 쌍 0).
- 강도: 해석 못 함 — 환경 없음(D-16). 손계산 오조작 SF 1.42(Kt 넣어 1.29) < 필요 2 → 디테일.
- 미완: 화이버 머리 형번·STEP(D-32, 미스미 로그인 풀림), 디테일 5건.

## 1. 이 버전이 생긴 이유

요구서 5절 T04 "바늘 앞에서 가장자리를 봉제 중에 읽는다. 홈 안에서도 가장자리를 놓치지 않는 자리." 결정로그 C-02(카메라 없음, 가장자리 센서로 따라감). v0.3.1에는 센서 자리가 없었다. 선정(T04-S01~S07)에서 C2 "노루발 내장 반사형 영역 화이버 1개"를 골랐고, 노루발 안에 자리만 깎았다. 형상이 바뀌어 수 번호 +1(요구서 8-2, E-05).

## 6. 제어 순서 제약 (U-09, `mech_T04_select.md` 5-4)

1. 검출 값은 바늘이 침판 위로 올라간 구간(`J_NEEDLE` 0 쪽)에서만 샘플한다.
2. 노루발 내림(검출 거리 12.1)과 들림(22.1)마다 기준값(침판 반사)을 따로 둔다.
3. 홈 입구 피벗·홈 직선 17단계에서는 현 위 경계 중 A(−Y) 끝 쪽 경계를 버린다.
4. ④ 이음매·절단 중에는 검출 값을 쓰지 않는다.
5. ①·⑤ 로딩·배출 중에는 쓰지 않는다. ② 시작점 찾기에서 현에 경계가 생긴 뒤에 바인더를 물린다.

앰프(E3NX-FA11 후보)·배선은 PLC 단계, BOM에 넣지 않음.
