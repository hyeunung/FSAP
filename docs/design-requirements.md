### 0-8 전체 구동 개념 (모델링 시작 조건, 엔진 E-01)

**상태: 초안(2026-11-03), 사용자 동의 전.** 대화 과정·이유는 [v1.0 구동 개념 대화 기록](concept/v1-drive-concept-discussion.md). v0.x(헤드 이송 없음·기계 서보가 매트를 한 땀씩 옮김)는 버리고, 2차 벤치마크([보고서](../reports/매트%20바인딩기%20벤치마크%20조사.md))와 사용자 대화로 다시 세운 개념이다. 대상은 **카펫 매트**(코일 매트는 범위 밖, 사용자 2026-11-03 "일단 카펫매트라 생각하고 진행하자").

| 칸 | 내용 |
|---|---|
| 0-8-1 핵심 원리 | **매트를 끄는 것은 재봉 헤드다.** 헤드는 고정, 바늘 둘레의 3중 이송(아래 톱니·바늘 이송·교대 노루발)이 테이프로 감쌀 가장자리 띠만 물고 한 땀씩 끈다(Dürkopp 867 방식, R375A·US6557478). 매트 몸통은 가운데 **작은 진공 원판**이 뒷면을 잡고, 둘레는 **에어 테이블**이 띄워 받친다(파일 면에 아무것도 닿지 않음, C-03). 원판은 **자유 회전 + 조향 서보**, 원판 밑 **X·Y 받침은 따라가기 모드**(헤드가 끄는 대로 따라가고 필요하면 서보가 보조). 바늘 앞 가장자리 센서가 원판 회전으로 방향을 잡는다(C-02, US5367966). **모서리·홈 바닥**: 바늘을 꽂은 채 멈춤 → 노루발 들기 → 바늘 중심 회전(이때만 X·Y·회전 위치 모드) → 센서가 가장자리를 다시 잡으면 재개(US5367966). **헤드는 Dürkopp 867-392342 차 매트 바인딩 모델을 기둥 없게 개조**: 윗헤드(바늘·노루발·위 이송·바인더)는 위 브리지에 매달고, 아랫유닛(가마·톱니)은 바늘 밑 작은 받침에만 두고 동기. 좁은 홈 안에서 홈 건너편 매트 몸통이 헤드 밑을 지나가야 하기 때문(사용자 사진 2026-11-03, R375X "매트가 헤드 밑을 지나며 자유롭게") |
| 0-8-2 간섭을 푸는 방법 | ① 작업면(에어 테이블 윗면 = 바늘판 윗면) 위에는 바늘 둘레 헤드 묶음만 있다. 브리지·윗헤드 몸체는 매트 위 높이 여유(임시 ≥ 매트 두께 + 노루발 들림 20 + 여유) 위로, 아랫유닛은 작업면 아래로. ② 진공 원판은 가장 작은 매트(300×200) 안쪽에 들 크기, 원판 가장자리와 바늘 사이 최소 거리 ≥ 아랫유닛 받침 반폭 + 틈(D-10). ③ 좁은 홈: 노루발·바인더 끝·센서 묶음의 폭 < 가장 좁은 홈 폭(D-02), 홈 바닥 180° 회전 중 반대 벽과 틈 > 0. ④ 테이프 길(롤→867 바인더)은 윗헤드 쪽 높이로 지나가 매트와 만나지 않는다(867 공식 사진: 베드 뒤 오른쪽 세운 핀 안내). ⑤ 툴 카세트(바인더·테이프 안내·절단·접기)는 위치 결정 핀 + 원터치 클램프로 붙는다 |
| 0-8-3 유닛 나누기·배치 | 아래 유닛 표. 좌표: 바늘점 원점, 작업면 Z 0, 매트 이송 방향 +Y(작업자 반대쪽), 작업자 −Y |
| 0-8-4 한 사이클 타이밍 | ① 작업자가 매트를 원판 위 표시에 맞춰 올리고 시작(진공·에어 ON) → ② X·Y·회전 위치 모드로 시작점(직선 구간)을 바늘 앞에 가져감, 센서 확인, 테이프 앞끝(바인더에 남아 있음)을 바늘 밑에 두고 노루발 내림 → ③ 봉제: 헤드 이송 + 회전 조향 + X·Y 따라가기, 테이프는 867 바인더가 차동 공급(오목·볼록 조절) → ④ 모서리·홈 바닥마다 멈춤·노루발 들기·바늘 중심 회전·재개 → ⑤ 남은 둘레 계산, 끝나기 전에 절단·접기 유닛이 '겹침 + 접어 넣기' 길이로 자르고 끝을 접음 → 시작부 위로 겹쳐 박기 → 자동 사절, 새 앞끝은 바인더에 남음(US6044783A·US4688499) → ⑥ 노루발 들기, 진공 OFF, 작업자가 꺼냄. 겹침: ③과 테이프 공급은 동시, ⑤의 절단·접기는 봉제가 이어지는 중에. 사이클 목표 D-12(참고 R375A 45~50 s) |
| 0-8-5 된다는 근거 | 행정(계산, 사각 매트·바늘 중심 회전): 30×20 원판 중심 80×300, 120×120 → 250×1200, 150×150 → 310×1500, 2열형 120×50 → 400×1200 mm. 매트가 휘두르는 영역 최대 약 2.1 × 3.0 m(150×150). 원판 회전 한 바퀴 360°/사이클. 헤드 수치(Dürkopp 867 공식 PDF): 3000 땀/분, 땀 길이 ≤ 12, 봉제 중 노루발 밑 ≤ 10, 들림 20, 가마 Ø32. 사이클 개략: 둘레 6 m(150×150), 땀 4 mm(임시, D-12)·2000 rpm → 8 m/min → 봉제 약 45 s + 모서리. **모르는 것**: 헤드 이송이 원판·받침을 끌 수 있는 힘(따라가기 저항을 낮추고 모자라면 서보 보조), 분리형 헤드의 구매·개조 가능성(D-10), 가장 좁은 홈(사진 추정 폭 25·깊이 150·바닥 R12.5, D-02·D-03)에서의 실제 마감 — 공개 최소값은 TITAN 안쪽 R30이라 시제품 확인(7절), 자동 접어 넣기 이음매 모양(7절) |
| 0-8-6 확립(사용자 동의) | **아직 없음** |
