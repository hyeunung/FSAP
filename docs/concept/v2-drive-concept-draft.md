## 왜 다시 세우나

지금 0-8(v1.0)의 매트 잡기(진공 원판 + 자유 회전 조향 + X·Y 따라가기 받침 + 에어 테이블)는 특허 US6557478에서 왔다. R375X 사진을 보기 전에 정한 것이다. 사진으로 본 R375X는 다르다.

| | v1.0 (지금 0-8) | R375X (사진) |
|---|---|---|
| 매트 받침 | 에어 테이블 + 가운데 진공 원판 | **볼 트랜스퍼 테이블**, 매트는 그냥 놓임 |
| 방향 잡기 | 원판 조향 서보 | **서보 바퀴 2개**(바늘 옆 + 먼 쪽 대차)의 속도 차이 |
| 매트 X·Y 이동 | X·Y 받침(따라가기 / 위치 모드) | 없음 — 헤드 이송이 끌고 바퀴가 돕는다 |
| 헤드 | 867 분리형(윗헤드 매달기) | 같음(기둥 없이 보에 매달린 것으로 보임) |
| 시작점 맞추기 | X·Y·회전 위치 모드로 가져감 | 작업자가 올려 노루발 밑에 둠 |

사용자 발언: "진공원판 안해도 되는거 아닌가...", "r375x 보니까 밑에 롤러를 두면서 조금만 롤러가 살짝 누르면서 돌아도 쉽게 이동하도록 아래 볼롤을 둬서 자국안나고 잘도나보다", "안돌면 저걸 해둘 이유가 없지 않나?"(바퀴 밑 원판).

## 0-8-1 핵심 원리 (초안)

- **매트를 끄는 것은 재봉 헤드다**(C-13 그대로). 헤드는 고정이고, 3중 이송이 가장자리 띠를 한 땀씩 끈다.
- **매트는 볼 트랜스퍼 테이블 위에 그냥 놓인다.** 수지 볼이라 뒷면을 긁지 않고, 어느 방향으로든 가볍게 움직인다. 잡는 장치는 없다.
- **방향은 서보 바퀴 2개가 잡는다.** 둘 다 매트 윗면을 약하게(공압, 레귤레이터로 조절) 누르며 Y로 민다.
  - 바늘 옆 바퀴(바늘에서 몸통 쪽)
  - 먼 쪽 바퀴: 전폭 X 대차에 달리고, 매트 크기에 맞춰 바늘에서 멀리 둔다. 작은 힘으로 큰 회전 모멘트를 낸다.
  - 두 바퀴가 헤드 이송과 같은 속도면 직진하고, 속도가 다르면 바늘을 중심으로 돈다.
- **두 바퀴는 바늘을 지나는 X선 위에 둔다**(사진: 두 바퀴가 보 앞 같은 Y 줄). 바늘 중심으로 돌 때 그 선 위의 점은 Y로만 움직이므로, 축이 X인 바퀴의 미는 방향이 회전 접선과 맞아 미끄러짐이 없다. 바늘에서 거리 d인 바퀴 속도 = **v + ω·d**(v 헤드 이송, ω 회전 속도). 직선 ω = 0, 곡선 ω = v/R(센서 보정), 모서리 v = 0. 먼 쪽 바퀴의 d는 대차 X 위치로 안다(사진의 노란 눈금 띠·서보 대차, 매트별 파라미터를 프로그램에 저장).
- **봉제 중 매트는 늘 약한 힘으로 잡혀 있어야 한다**(요구, 사용자 2026-11-03 "랏빠를 잘 치려면 결국 매트를 어느정도의 힘으로는 잡아주고 있어야하거든 누른 자국안날정도로"). 볼 테이블 위 매트는 너무 자유로워서, 잡지 않으면 테이프가 고르게 안 감긴다. 바퀴는 돌리는 것뿐 아니라 **잡는 것**이 일이다. 잡는 힘은 자국이 안 나는 한도 안(공압 조절, 한도는 시제품, 7절).
- **바늘 옆 바퀴(+ 슈)가 늘 잡고, 먼 쪽 바퀴는 필요할 때 뒤를 잡는다**(사용자 2026-11-03 "바늘옆에서 하나가 잡지만 뒤도 필요시엔 잡아주는게 좋지 않아?"). 필요할 때(임시): ① 큰 매트 모서리·곡선 회전(토크, 0-8-5 계산) ② 긴 매트의 반대쪽 끝이 볼 위에서 흐를 때 ③ 좁은 홈에서 바늘 옆 바퀴를 들 때(방향을 대신 잡음) ④ 프로그램(매트 종류)에서 켜 둔 경우. 내리는 조건: 바퀴 밑에 매트가 있고 d₂ ≥ 2·d₁ + 바퀴 묶음 폭(임시). 자리가 없는 작은 매트(사진: 작은 매트일 때 매트 밖 볼 위)는 바늘 옆 바퀴 + 슈만 잡는다. 두 바퀴가 서로 싸워 파일 면을 긁지 않게, 바늘 옆 바퀴는 속도 기준, 먼 쪽 바퀴는 토크(힘) 제어로 보조한다(임시). **바퀴는 미는 장치가 아니다**(매트를 끄는 것은 헤드 이송): 직선에서는 헤드와 같은 속도로 돌며 눌러 잡기만 하고(뒤 바퀴는 토크 ≈ 0), 곡선에서는 속도 차이로 방향만 틀고, 헤드가 멈춘 모서리에서만 바늘을 축으로 회전력을 낸다. 바퀴는 축 방향(X)으로 잘 안 밀려서 매트가 옆으로 흐르는 것을 막는다. 바퀴를 돌리는 것은 전동 서보, 누르는 것은 공압이다(사진).
- **가장자리를 바인더에 꽉 넣기**(사용자 2026-11-03 "살짝 눌러 잡고 전동모터로 랏빠쪽 꽉끼게하려고 살짝 미나?"): 바늘 옆 바퀴를 헤드 이송보다 아주 살짝 빠르게 돌리면 매트가 바늘을 축으로 살짝 돌아(위에서 보아 시계 방향) 바늘 앞에서 들어오는 가장자리가 바인더 쪽(+X)으로 붙는다. 너무 깊이 들어가면 가장자리 센서가 바퀴 속도를 줄인다 — 직선에서도 속도 차이가 0이 아니라 바인더 쪽으로 살짝 기울어 있고, 센서가 깊이를 맞춘다(추정, 사진 구조와 맞음). 보조안: 바퀴 축을 바인더 쪽으로 몇 도 틀어 다는 방법(일반 가장자리 안내 롤러 방식, R375X 사진으로는 판단 불가) — 바퀴 묶음에 각도 조절 자리를 남기고 시제품에서 비교한다.
- **가장자리 센서가 바퀴 속도 차이를 정한다.** 바늘 앞 슈 위의 광센서다(C-02, US5367966 비례 조향).
- **모서리·홈 바닥:** 바늘을 꽂은 채 멈춘다 → 노루발을 든다 → 바퀴만 돌려 바늘 중심으로 회전한다 → 센서가 가장자리를 다시 잡으면 재개한다(US5367966, US5493980A).
- **바퀴 밑:** 바늘 옆 바퀴 밑에는 볼 없는 자유 회전 원판(사진 약 Ø250)을 둔다. 바퀴가 볼 위가 아니라 평판 위에서 누르게 해서 볼 점자국을 피한다(CN112726042A와 같은 발상). 먼 쪽 바퀴 밑은 사진으로 알 수 없다. 초안: 넓고 무른 바퀴로 볼 위를 누른다. 자국은 시제품에서 판정한다(D-신규).
- **헤드:** 3중 이송 헤드(C-25, 기종은 견적 뒤)를 기둥 없게 개조한다. 윗헤드는 보에 매달고 아랫유닛(가마·톱니)은 테이블 밑에 둔다(C-18 그대로).

## 0-8-2 간섭을 푸는 방법 (초안)

1. 테이블 윗면(볼 윗면) = 바늘판 윗면이다. 그 위에는 바늘 둘레 헤드 묶음, 슈, 두 바퀴만 있다. 보·윗헤드 몸체·대차는 매트 위 높이 여유 위에 있다.
2. **좁은 U홈(폭 25, D-02·D-14)** — R375X 사진에 없는 경우라 우리가 푼다.
   - 홈 안을 박을 때 바늘 옆 바퀴가 홈 빈 공간 위에 오면 바퀴를 든다(공압).
   - 그 구간의 방향은 먼 쪽 바퀴와 헤드 이송만으로 잡는다.
   - 바퀴 밑에 매트가 있는지 보는 센서를 바퀴 묶음에 하나 단다.
   - 노루발·바인더 끝·슈 묶음 폭 < 가장 좁은 홈 폭, 홈 바닥 180° 회전 중 반대 벽과 틈 > 0(v1.0과 같은 조건).
3. **먼 쪽 대차:** 매트가 도는 동안 대차와 기둥이 매트에 부딪히지 않게, 대차 바퀴는 공압으로 들고 X를 옮긴 뒤 내린다.
4. 테이프 길(롤 → 바인더)은 윗헤드 높이로 지나가서 매트와 만나지 않는다(v1.0과 같음).
5. 툴 카세트(바인더·안내·절단·접기)는 위치 결정 핀 + 원터치 클램프로 붙인다(v1.0과 같음, C-20).

## 0-8-4 한 사이클 (초안)

1. 작업자가 매트를 볼 테이블에 올리고, 직선 구간의 가장자리를 노루발 밑 표시에 맞춘다(C-19 이음매는 직선 구간). 시작을 누른다.
2. 노루발·바퀴·슈가 내려온다. 먼 쪽 대차는 프로그램(매트 크기)의 d₂로 X 이동해 내린다(작은 매트는 비켜 선 채). 센서가 가장자리를 확인한다.
3. 봉제한다. 헤드 이송이 끌고, 두 바퀴가 속도 차이로 방향을 잡고, 테이프는 바인더가 공급한다.
4. 모서리·홈 바닥마다 멈춘다 → 노루발을 든다 → 바퀴로 회전한다 → 재개한다. 좁은 홈에서는 바늘 옆 바퀴를 든다.
5. 끝나기 전에 테이프를 자르고 끝을 접는다 → 시작부 위로 겹쳐 박는다 → 자동 사절한다(v1.0과 같음).
6. 노루발·바퀴·슈를 들고, 작업자가 꺼낸다.

사이클 목표 D-12(참고 R375A 45~50 s).

## 0-8-5 된다는 근거와 모르는 것

**근거**
- 상용 기계 R375X가 이 구조로 카매트를 박는다(사진).
- 바퀴 차동 회전은 US5493980A(소멸)·CN106757804A(거절)에 있어 자유롭게 쓸 수 있다.
- **먼 쪽 바퀴가 필요한 이유(개략 계산, 가정: 매트 6 kg/1.44 m², 볼 마찰 무시, 모서리 90°를 약 1 s에 돌림):**

  | | 작은 매트 30×20 | 큰 매트 120×120 |
  |---|---|---|
  | 바늘(모서리) 중심 관성 | 약 0.02 kg·m² | 약 5.8 kg·m² |
  | 회전 토크 | 약 0.1 N·m | 약 36 N·m |
  | 바늘 옆 바퀴(d ≈ 0.1 m) 힘 | 약 1 N — 충분 | 약 360 N — 파일 면에서 미끄러지고, 그만큼 누르면 자국 |
  | 먼 쪽 바퀴(d ≈ 0.8 m) 힘 | 필요 없음 | 약 45 N — 가볍게 눌러도 됨 |

  매트 질량·볼 저항·회전 시간은 자료대기(D-신규)로 두고, 값이 오면 다시 계산한다.
- 매트 휘두름 영역: 매트는 늘 바늘의 −X 쪽에 있다. 1500×1500이면 X 약 2.1 m(대각) × Y 약 3.0 m(v1.0 계산과 같음) → 볼 테이블 크기다.

**모르는 것 → 자료대기 신규**
- 매트를 잡는 힘(테이프가 고르게 감기는 최소 ~ 자국이 안 나는 최대), 바늘 옆 바퀴 최소 거리 d₁·바퀴 묶음 폭, 두 바퀴 제어 방식(속도 + 토크 보조)
- 가장자리를 바인더 쪽으로 붙이는 세기: 바늘 옆 바퀴 속도 차이(%)·바퀴 틀기 각도(°), 바인더 안 가장자리 목표 깊이 — 시제품
- 바퀴와 매트 사이 미끄러짐: 직선·곡선은 속도 어긋남(바퀴 지름 오차, 파일 눌림에 따른 유효 반경, 땀 길이 편차), 모서리는 회전력 > 마찰 한도. 시제품에서 잰다. 모서리는 회전 시간을 늘리면 필요한 힘이 시간 제곱에 반비례해 준다
- 바퀴 누름 힘·바퀴 재질·경도·지름. 자국이 안 나는 한계는 시제품에서 판정한다(7절).
- 볼 유닛 형번·피치·하중, 매트를 끌 때 볼 저항
- 먼 쪽 바퀴 밑 받침(볼 위 / 평판 띠)
- 두 바퀴 역할 분담(추정, 사진·계산): 두 바퀴와 바늘이 정말 한 줄(같은 Y)인지, 봉제 중 대차가 움직이는지, 먼 쪽 바퀴가 큰 매트에서만 내려오는지 — R375X 동작 영상으로 확인(사용자가 Rimac에 요청 가능)
- 바늘 옆 바퀴 매달기(스윙 암 / 세로 가이드 / X 가이드) — 사진으로 결론이 안 남. 초안은 스윙 암 + 공압
- 보 앞면 볼나사 X축 + 3위치 실린더의 용도(윗헤드 매달기·승강 추정)
- 테이블 밑 아랫유닛 구조(사진 없음)
- 분리형 헤드 구매·개조 가능성(D-10, C-25)

## 0-8-6 동의 전에 정할 것 (사용자 결정)

1. **C-03 고치기.** 지금은 "롤러로 파일 면을 세게·좁게·반복해서 누르지 않는다"이다. 바퀴가 파일 면을 누르므로 "누름 힘을 낮게·조절되게 하고, 자국은 시제품에서 판정한다"로 바꾼다. 근거는 사용자 발언 "원래 기존에도 롤러써서 하는게 있었는데 그게 결국 너무 롤러가 쌔게 눌러서 안된다 했거든"(문제는 롤러 자체가 아니라 센 힘)과 R375X.
2. **v1.0.x 동결 → v2.0.0 새로 시작.** v0.x 때처럼 파일은 보관하고 지우지 않는다(C-12 방식).
3. **좁은 홈 안:** 바늘 옆 바퀴 들기 + 먼 쪽 바퀴만으로 방향을 잡는다(위 0-8-2 ②). 다른 안이 있으면 말씀해 주시면 된다.
4. **특허 KR102139457B1(픽스로봇, 위아래 롤러 차동 조향)** 은 한국에서 살아 있을 수 있다. 우리 안은 위 바퀴 2개(아래는 자유 원판·볼)라 구조가 다르지만, 납품 전에 변리사 확인이 필요하다(돈이 드는 선택이라 사용자 결정).
