## 1. RI.MA.C. R375X (벤치마크, C-01)

이탈리아 Cerano의 Ri.Ma.C. SRL. "New generation for car mat binding". https://www.rimac.it/en/products/r375x/

| 항목 | 공개 내용 |
|---|---|
| 동작 | 외곽 판독(profile reading)과 매트 자동 회전을 함께 쓴다. 재봉 헤드 구조를 고쳐 매트가 헤드 밑을 지나며 자유롭게 움직이고, 회전 공간이 늘었다 |
| 헤드 | 이동 여부는 적혀 있지 않다. 설명으로는 고정 |
| 구성 | 개조 재봉 헤드, 새 공급 유닛, 새 테이프 커팅 유닛, 형상 인식, 자동 회전, 터치스크린 |
| 옵션 | 테이프 열절단(Hot tape cutting): 올이 풀리는 테이프용 |
| 운전 | 작업자가 수동으로 올리고 시작, 이후 자동. 형상별 프로그램 불필요. 1명이 최대 3대 |
| HMI | 파라미터를 프로그램으로 저장·불러오기 |
| 수치 | 매트 20×30 ~ 120×120 cm(요청 시 150×150), 최대 2000 rpm, 220 V 50/60 Hz, 2000 W, 압축공기 6 bar |
| 공개 안 된 것 | 무게, 외형, 테이프 폭, 땀 길이, 생산량, 센서 종류, **좁은 홈 처리 여부**(D-14). 영상·브로셔 없음 |

### 같은 회사 이전 모델 R375A

https://www.rimac.it/en/products/r375/

- "a particular system of edge reading and car-mat moving". 센서 종류는 밝히지 않음.
- 재봉 헤드 **Durkopp 867-290342를 바인딩용으로 개조**, 2000 rpm.
- 매트 최대 80×60 cm. 220 V, 2000 W, 6 bar.
- 앞좌석 매트 약 45~50초, 뒷좌석 약 35~40초(로딩 제외).
- R375A는 기계 뒤로 자동 배출, R375A-SC는 수동 배출.
- 옵션: 테이프 열절단, Habraken System(누벅 테이프의 장력을 줄여 매트를 평평하게).

## 4. 정리: 가져올 것과 앞서야 할 것

| 가져올 것 | 출처 |
|---|---|
| 헤드 고정, 매트가 헤드 밑을 지나며 회전 | R375X, 특허 대부분 |
| 바늘 앞 가장자리 센서로 봉제 중 추적 | R375 계열, US6557478, US5367966, Richpeace |
| 롤러 없이 넓게 잡기(진공 원판·판 클램프) | US6557478, US5367966 |
| 급한 꺾임: 바늘 내림 + 노루발 들고 회전, 필요하면 헤드 회전 | US5367966, US6557478 |
| 테이프 자동 공급·커팅, 열절단 옵션 | R375X, CN207958657U |

| 앞서야 할 것 | 이유 |
|---|---|
| 좁은 V자·U자 홈까지 깔끔한 마감 | 대기업 납품. 벤치마크·특허 어디에도 답이 없다 |
| 영구 눌림자국 없음 | 전임 의뢰 기계 퇴짜 사유 |
| 시작·끝 이음매 자동 처리 | 특허들은 사람이 마무리. 사람 손 없이(C-05) |
