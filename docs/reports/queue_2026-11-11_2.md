- **M02R**: 같은 이유로 그대로 다시 넣는 것이 아니다(WF-123). 1회차 완료 판정(mech_M02R_donecheck2.md 3절)이 고칠 자리를 정했다 — 회전 SF 식에 로드 마찰 f를 넣고(N_land = N_free + (N/MPa)·p − g·f), (a)(b)(c) 세 조건을 함께 맞춘다. f는 카탈로그 값(M-06), 없으면 새 D-번호 임시값. CDQ2A20-25DMZ의 최저 사용 압력 0.05 MPa(f 15.7 N)면 창이 닫히므로 같은 외형의 저마찰 사양(최저 사용 압력 ≤ 0.03 MPa급, f ≤ 9.4 N)을 임시 형번으로 두고 진행한다(E-12). 형번 변경은 돈이 드는 선택이라 user_wait에 결정 항목으로 남긴다(구동은 막지 않음). 걷어 낼 것 목록·U8 회로 유지는 1회차 정리(queue_2026-11-11_1.md)와 같다. 바퀴 기울기(접지점 Y 이동·기울기각)가 회전 SF·자국에 주는 영향은 손계산하고 7절에 적는다.
- **SIM-01**: 1회차는 M02R 저장본이 없어 막혔다. M02R이 이번에 저장되면 풀리므로 M02R 뒤 직렬로 둔다. 남은 일은 check4(U4 묶음 against, budget_s 600)와 영상 5연구(frames ≥ 150)뿐이다. 구상 부서는 설계 파일을 한 번만 연다(1회차 11번, E-04 위반).
- **RX-06·RX-08**은 요구서에 'M02R 뒤'(같은 부품)라 적혀 있다. RX-03은 SIM-01 테이프 줄로 시야를 본다. RX 과제 발자국(바디·상자)은 모델 목록에서 확인하지 못해 bodies를 비웠다 — 모두 직렬.
- 사용자 원문 "이거 안보이냐고;;": 1회차가 새 형상을 그리지 못해 앱에는 옛 크랭크 U4(v2.10.2)가 그대로 보인다. 이번 라운드 첫 과제 M02R을 앱(MCP)에서 그려 저장해야 사용자 화면에 정정이 보인다.

- 1회차 과제 정리 뒤 요구서 5절에 RX-01~09(C-42)가 들어와 열린 구동 과제가 2 → 11로 늘었다. 과제 정리가 라운드 사이에 요구서를 다시 읽어 잡았다.
