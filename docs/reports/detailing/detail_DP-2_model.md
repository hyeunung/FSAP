## 워크플로우 메모

- `inspect.clearance`가 동축 원통 쌍(볼트–탭 등)을 "boolean Intersect no result"로 `unchecked` 처리한다. 나사 물림 판정에 쓸 수 없다 — 볼트 검사 절차(안내서)는 좌표 일치로 보는 수밖에 없음.
- `motion.interference`가 바디 수 많은 occurrence(MAT_ROT 140여 바디)를 "too many bodies for a contact sweep"로 거부. 검사 사본에서 작은 체결품을 지워 돌렸다.
- `component.delete` 한 번 약 29 s, 공유 바디 `body.rename` 약 20 s(CLI run 11분 중 대부분).
- MCP `open`이 같은 경로를 다시 열 때 세션의 저장 안 한 편집을 버리지 않았다(시험 편집이 남음) — 안내서 '원복'(open = 버림)과 다름. 저장본은 안 바뀜(mtime 그대로).
- `selection.delete {occurrences}`는 결과 `deleted: []`를 주지만 실제로 지운다.
