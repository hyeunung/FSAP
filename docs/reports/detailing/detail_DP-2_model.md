## 워크플로우 메모

- 지시서 ⑤(인서트 옮김)의 근거 수치가 틀렸다 · 체결부가 구매품 인서트의 나사 구간을 볼트 반대 끝에서 세었다(−5.0~+3.2, 실제 3.0~11.2) · 체결부가 '나사 구간'을 낼 때 암나사 바디 상자가 볼트 생크 구간 안에 드는지 한 번 대조하면 걸러진다.
- T홈 바닥 깊이가 점 표본(±0.5)으로 넘어와 끝–바닥 계획 0.75가 실측 0.50이었다 · 길이를 정하는 수치는 `inspect.clearance`(볼트 ↔ 형재) 한 번으로 재는 편이 정확하다.
- `ledger.py sigpatch`의 `--removed` 하나가 서명 키('유닛/이름')와 체결 목록 이름('이름')에 함께 쓰인다 · 두 형식이 달라 볼트 189개가 체결 목록에서 안 지워진다 · 두 형식을 모두 넘겨서 풀었다. 도구가 키의 '/' 뒤도 맞춰 보면 된다.
- 저장본을 CLI로 새로 열어 재면 쓸어 만든 관 4개의 상자가 0.5~1.2 넓게 나온다(부피 · 무게중심 같음) · 저장 확인이 '위치 이탈'로 잘못 읽을 수 있다 · 저장 확인은 상자와 함께 부피 · 무게중심으로 본다.
- 같은 컴포넌트의 occurrence 일부만 형번이 바뀌는 볼트가 많다(`CB5-12_M03_3` 45개 중 40개) · 볼트 컴포넌트를 과제 꼬리표로만 나눠 길이가 다른 자리가 섞였다 · 넣을 때 형번 + 물리는 상대로 나누면 길이 바꿈이 바디 하나 고치는 일이 된다.
- 앱 MCP가 `3D_Modeling/`을 못 열어(--allow-path 없음) 사용자가 앱에서 편집을 볼 수 없었다 · 실행 머리글이 미리 적어 줘서 헤드리스로 바로 갔다 · MCP 서버 설정에 `--allow-path <workspace>`를 넣으면 풀린다(사용자 설정).
