# 디테일링 DP-2 모델링 보고서 — 수정 1회차 (T01 회전 묶음)

- 저장 파일은 `3D_Modeling/FSAP_v0.6.7.sc`다. v0.6.6 저장본에서 CLI `run --save`로 새 번호 파일에 저장했다. MCP 서버 안내가 `Backend: headless`라서 지시 (2)의 예외 조항대로 CLI를 썼고, 그래서 사용자 앱 화면에는 보이지 않는다. `tools/config.json` doc는 v0.6.7로 바꿨다. 생성기는 `tools/gen_dp2_r1.py`(300단계)다.
- 바뀐 가공품은 셋이다.
  - 새로 만든 것: `P_T01_NUTPLATE_R1/R2_1~3` ×6, `P_T01_FOOTPLATE_1~3_N·_P` ×6
  - 고친 것: `P_T01_POST`(밑 플랜지 t12와 카운터보어)
- 체결품은 이렇게 바뀌었다.
  - `STEP대기_LBNR4_T01_*` ×24를 지웠다. CB4-16은 너트판 M4 탭에 6만큼 물린다.
  - 실물 `CB5-12_T01_SP*` ×12를 `STEP대기_CB5-18_T01_SP*` ×12로 바꿨다(E-10).
- 핵심 수치
  - M4 물림 3.2 → **6**(= 1.5d)
  - 너트 스패너 자리 문제는 너트가 없어져서 사라졌다.
  - 발 볼트 물림은 8 그대로다(≥ 7.5).
  - 기둥 플랜지는 t12, 627.5 g(+37.3 g)이다.
  - 정적 새 겹침은 0이다(나사 물림 36쌍만 겹친다). 프로브 45개 겹침 0, unchecked 0. 링 13위치 겹침 0.
  - 서명 비교 결과 바뀐 것은 POST뿐이다. 추가와 삭제는 의도한 것만 있다.
- 미완
  - CB5-18 STEP 대기(D-37)가 새로 생겼다.
  - 재질(A5052/SS400)은 해석부 탭 손계산으로 확정한다. 이번 묶음은 해석 환경이 없다(D-16).
  - 조인트·행정·배치 변경은 0이다. 임시 STEP 13개를 `tools/out/detail/DP-2/stepout/`에 냈다.

## 4. 해석부에 넘길 것

- 너트판: A5052 M4 탭 나사산 전단(물림 6, 조임 ≤ 1.5 N·m)과 판 굽힘 운전 SF ≥ 3. 미달이면 같은 치수로 SS400 t6으로 바꾼다(지시 (6)).
- 누름판: A5052 t6, 레버(다리 평평한 곳 33 → 볼트 44)는 판 안쪽 끝 34 기준이다. 검증 손계산 σ 52.1 MPa, SF 3.36.

## 워크플로우 메모

- MCP 서버가 headless로 떠서 이번에도 CLI로 모델링했다(지시 (2) 예외 조항). 사용자 앱 화면에는 보이지 않는다.
- `inspect.clearance`는 같은 축 볼트–탭 쌍 일부를 여전히 unchecked(불 연산 실패)로 낸다(허브 ↔ CB5-16 PB 3). 지난 회차에 unchecked를 열림으로 센 것이 문제였으므로, 이번에는 unchecked를 쌍마다 따로 적었다.
