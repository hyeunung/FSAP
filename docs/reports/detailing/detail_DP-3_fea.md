## 워크플로우 메모

- 재질을 바꾸는 묶음의 완료 판정에 좌면 항목이 없다 · 근거: A5052 → PET-CF로 볼트 41개 좌면 SF가 1.54 → 0.44가 됐는데 완료 판정은 '재질 · matcheck'뿐이라 모델링 · 검도가 못 봤다 · 재질 변경 묶음에는 '머리 좌면 SF ≥ 1(조임 토크 명시)'를 완료 판정에 넣으면 좋겠다.
- `fea/models.json`의 하중 표가 형상을 따라가지 않는다 · 근거: `P_M07_BEAM`은 v2.3.4(경간 3,530 · HMI 없음) 그대로인데 기둥이 X 1310으로 옮겨지고 HMI 팔이 달렸다. 전체 해석부는 지난 값을 재사용했다 · 표의 버전이 지금 문서와 다르면 서명 질량으로 하중을 다시 내라는 점검이 있으면 좋겠다.
- `handcalc.calc`는 모재 하나로 좌면과 암나사를 같이 본다 · 근거: PET-CF 부품을 강관 탭에 조이는 자리는 좌면(PET-CF)과 암나사(SS400)가 달라 좌면을 따로 계산했다 · 인자를 `--seat-base`로 나누면 좋겠다.
- 검도가 불합격을 낸 뒤 같은 STEP으로 해석부가 돌았다 · 이번에는 수정(메움 · 탭 끝 1 mm)이 강도와 무관해 결과가 그대로지만, 수정이 단면을 바꾸는 묶음이면 해석을 두 번 돌게 된다.
- 요구서에 조임 토크 표가 없다(DP-2 메모와 같음, 반복) · 플라스틱 좌면 · 얇은 판 탭이 묶음마다 '조건'으로 나온다.
