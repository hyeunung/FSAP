## 1. 이번 회차 지시와 근거

검증부가 1회차 미완 3건을 "이번 회차에 끝낸다"로 돌려보냈다.

| 문제 | 이번에 한 것 |
|---|---|
| 설계검토서 '정비'가 없다(마지막 검토서 v0.6.7) | `docs/review/FSAP_v0.6.10_review.md`를 만들어 1절(변경 표)·6절(정비)을 적었다. 나머지 절은 검토서 작성 부서가 채운다고 머리에 적었다 |
| 허브 심 손계산 안 함 | `fea/cases/detail_DP-3_hub_handcalc.py`로 했다(3-2절) |
| 구멍 위상 표시를 그리지 않음 | 플랜지 테두리 홈 ×4를 그렸다(2절) |

- 규칙 U-10(마감·디자인 품질)과 M-02(정비성). M-02 원문: "'○○를 달기 전에 조인다'처럼 조립 순서 제약으로만 풀리는 볼트는 결함". 표시가 없으면 구멍을 볼트에 맞추기 어렵다.
- E-18 원문: "체결만 바뀐 자리는 손계산, FEA는 형상·하중 경로가 바뀐 부품만". 허브는 형상이 바뀐 부품이다. FEA는 해석 못 함 — 환경 없음(D-16)이라 손계산으로 했다.

## 2. 바꾼 것 (전 → 후 · 이유)

| 부품 | 전(v0.6.9) | 후(v0.6.10) | 이유 |
|---|---|---|---|
| `P_T05_HUB` | 플랜지 Ø200 t3 + 심 Ø76, 렌치 구멍 Ø9 ×4(+X 면 막힌 구멍) | 같음 + 플랜지 테두리 홈 폭 1.2 × 깊이 0.8 × 축 방향 3(관통) ×4 | 막힌 렌치 구멍은 작업자 쪽(−X·위)에서 안 보인다. 맞춤 표시가 있어야 롤을 돌려 구멍을 볼트에 맞출 수 있다 |

- 자리: 허브 축(Y 750, Z 200) 기준 0°·90°·180°·270°. 홈 가운데 (Y 750, Z 300)·(Y 850, Z 200)·(Y 750, Z 100)·(Y 650, Z 200). 렌치 구멍(45°·135°·225°·315°)의 가운데다.
- 맞춤 기준: 홀더 위 클램프 틈(Y 749.25~750.75, 윗면 Z 229). 구멍이 볼트에 맞으면 위 홈이 그 바로 위(Z 300)에 온다. 이미 있는 형상을 기준으로 써서 새 부품이 없다. 90° 간격이라 어느 홈이 위로 와도 구멍 4개가 동시에 맞는다.
- 글자 각인이 아니라 홈으로 한 이유: 출력품(PET-CF FDM)에서 1.2 mm 홈은 깨끗하게 나오고 프리미티브 하나로 그려진다(U-10 "가공품은 프리미티브로 깨끗하게"). 테두리 띠 r99.2~100은 롤(r97) 밖이라 롤·테이프와 닿지 않는다.
- 바꾸지 않은 것: 허브 바깥 모양, 롤 자리, 축 끼움 Ø16.3, 렌치 구멍, 볼트 자리·지름·길이(U-12 M5), 다른 모든 부품. 조인트·행정·배치·구동 방식·테이프 길 그대로(changed_joints false).
- 생성기: `tools/gen_dp3_detail.py fix2` → `tools/out/detail/DP-3/build_fix2.json`(10단계). 명령: `solidcraft-cli run build_fix2.json --in FSAP_v0.6.9.sc --save FSAP_v0.6.10.sc`.
- 실행 경로: SolidCraft MCP 서버 안내의 Backend가 headless(앱이 꺼져 있음)였다. 공통 규칙 (2)대로 CLI로 했다. 사용자가 앱에서 실시간으로 보지 못했다.
