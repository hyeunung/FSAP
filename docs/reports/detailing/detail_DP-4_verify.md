## 워크플로우 메모

- 프로브를 `solid.cylinder {operation: "new", name}`으로 만들면 name은 피처 이름이고 바디는 `Body1…`이 된다 · 근거: 프로브 이름으로 부른 `inspect.clearance`가 쌍 0(pairs_checked + pairs_pruned = 0)으로 돌아왔고 '쟀는가' 판정이 이것을 잡았다 · 안내서 '볼트 검사' 3에 "프로브 바디 이름은 응답의 created_bodies로" 한 줄이 있으면 좋겠다.
- `edit.restore_checkpoint`는 `checkpoint` id를 꼭 줘야 한다(없으면 거부) · 안내서 '원복'에 인자를 적으면 좋겠다.
- 완료 판정의 경고 수(255 → 254)가 옛 기준선으로 적혀 있었다 · 근거: DP-2 · DP-3 뒤 259 · 묶음 지시서를 쓸 때 직전 저장본의 경고 수를 다시 읽으면 좋겠다.
- 묶음 지시가 결정로그의 '시험해서 안 된 형상'을 다시 시켰다(모델링부 메모와 같음) · 검도가 불합격을 내도 수정 회차로는 풀리지 않고 PM 예외 판정이 먼저다.
