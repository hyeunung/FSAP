- 같은 이름 바디(블록 8개 → 이름 4, NTJ 12개 → 이름 6)가 서명(`signatures.json`, 이름 키)·스냅샷 `document.inspect` 표시 목록(150)·`inspect.clearance {against: 이름}`에서 하나로 접힌다. 근거: Y −540 블록 위 프로브의 nearest에 블록이 안 나옴(`pm1_summary.txt`), 구매부가 "블록 4개"로 잘못 냄. 개선: 서명·검사 도구가 이름 중복을 경고하고, 모델링부가 바디 이름을 유일하게 두는 규칙.
- 체결부가 블록 탭 깊이를 20.6으로 적었으나 실물 면은 10.4였다. 탭 깊이는 원통 면 원점·중심으로 계산하는 도우미가 있으면 좋다.
- 판금부 SF-07이 "낮은 머리 M5"를 제안했다(U-12 위반). 부서 지시문에 U-12 원문을 넣으면 좋다.
