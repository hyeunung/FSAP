# 과제 목록: 구동 라운드 8회차 (2026-11-09, 엔진 v3.9.3)

- 기준 모델: `3D_Modeling/FSAP_v2.8.2.sc` (tools/config.json doc). 지시문의 "최신 v2.6.5"는 지난 기록이다(그 뒤 v2.6.7~v2.8.2 저장, 7회차까지 새 번호 없음).
- STEP대기_ 목록: BOM `docs/bom/FSAP_v2.8.2_purchased.csv`의 모델 바디 칸에서 읽음. PM은 CAD를 열지 않았다(사용자: SolidCraft 앱 꺼져 있음, 읽기만이라 BOM으로 충분).
- **같은 일이 세 번째다.** 5·6·7회차 STEPWAIT 모두 `tools/out/step_wait.json`의 낡은 6형번 목록(F39-LSGF, MHMF022·MHMF042, VRXF-PB-60-10, KC-40340, 2400.05.12PZ — MHMF·VRXF는 C-36에서 HG-KR23·HG-KR43·PGX62-H-10 실물로 이미 바뀜)을 다시 써서 "미스미 형번 없음, 받기 시도 없음"으로 끝났다. 모델에는 형번이 정해진 `STEP대기_SCXW46-14-15`(D-143)·`STEP대기_PSCS16_F01_*` ×4(D-147)가 남아 있고, 이 둘은 step_wait.json waiting에 없다(한 번도 받아 보지 않음) → 규칙대로 STEPWAIT를 넣는다. 막힌 이유가 사이트·형번이 아니라 낡은 목록이라 WF-123에 해당하지 않는다.
  - **라운드 시작 STEP 재시도는 step_wait.json을 다시 쓰지 말고 v2.8.2 BOM의 `STEP대기_` 행으로 목록을 새로 만들어야 한다**(E-21 '같은 결과 다시 쓰기'를 이 경우에 쓰면 안 됨). 워크플로우 메모 후보(3회 반복).
  - `purchased-step/`·PartsLibrary: SCXW46-12-19·SCXW46-15-19만 있고 SCXW46-14-15·PSCS16·AS2201F-01-06SA는 없음(stepcheck 대신 목록 확인).
- 미스미 로그인: **확인 못 함**(지난 라운드 결과 login). 사용자가 2026-11-08 다시 로그인했다고 함 — 구매부는 받기 전 화면 머리로 확인, 풀려 있으면 기다리지 않고 임시 형상 유지(실행 규칙 10). 봇 확인 페이지는 넘기지 않는다.
- REG-02: 해결(v2.6.6~v2.6.7, 결정로그 C-34). 사용자 "가장 이상적인 방향으로 진행해"는 C-34(J_U6_HGT 삭제, U6을 U7 고정부에 리지드로, 높이 조정 `J_U7_HGT` 하나 −4~+6, POSE 8 정의에서 뺌)로 반영·검증됨(−4·0·+6 겹침 0). 다시 넣지 않는다.
- REG-01·RGSEE: 요구서 5절 해결(확인). 회귀 15~18 본 범위 새 겹침 0, 동작 문제 0. 못 본 범위는 회귀 실행기 문제(무거운 자세 호출 470 s 넘김, WF-210)라 설계 과제가 아니다. 같은 이유로 다시 넣지 않는다(WF-123).
- MOT-01·FUNC-01: '일부(완료 판정 미달)' — 구동은 끝났고 남은 미달은 디테일링 몫(E-02, WF-169). 넣지 않고 세지 않는다.
- LITE: 넣지 않음. runstats 가장 긴 열기 764 s(회귀) > 240 s이나 LITE는 이미 한 번 함(v2.6.5).
- 서보(지시 f): MHMF는 C-36으로 HG-KR 실물. MSMF 결정은 모델을 막지 않는다. HFS8-4080 4000 정척(C-33)은 형상 그대로.
- 커버·외장은 넣지 않음(규칙 14).
