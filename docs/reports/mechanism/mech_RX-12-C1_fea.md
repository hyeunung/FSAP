# 구동 후보 RX-12-C1 해석 — 접이 매트 받침 U2_FLAP(v2.27.0)

## 요약

- 대상: 새 하중 부품 15종(STEP `tools/out/mech_RX-12-C1/stepout/`) + 체결. **FEA 못 함 — 환경 없음(자료대기 D-16)**. 모두 손계산(`fea/cases/mech_RX-12-C1_handcalc.py` → `fea/results/mech_RX-12-C1_handcalc.json`). CAD 안 씀.
- 해석 모델: `fea/models.json`에 RX12C1 부품 14줄 새로 넣음(표에 없던 부품, 옛 모델 없음 → 비교 대상 없음).
- 정적(운전 ×3 g, 오조작 손 100 N): 판 t5 SF 5.0(처짐 0.49), 막대 L2 SF 14, XN SF 25, 빗장 막대 SF 7.2, 가스 스프링 핀 P 굽힘 SF 3.14, 혀(빗장 뺀 0°) SF 5.9, CB6-20 나사 SF 16. 모두 맞음.
- **동작 문제 1건: 펴는 중 손을 놓으면(감쇠 없음) 판이 스스로 올라와 13.5 J(공차 끝 20.3 J)로 혀가 CB6-20 머리를 친다.** 혀는 경첩 축에서 23 mm라 흡수 행정이 없다. 판 묶음 굽힘만 완충으로 잡아 혀 힘 11~34 kN, 혀 SF 0.10~0.32(< 1.2). 고침: 펴짐 속도 제한(오일 감쇠 가스 스프링·병렬 댐퍼) + 단단한 멈춤을 바깥(r ≈ 700) 완충 멈춤으로. 설계안 디테일 RX12C1-D11(“감쇠 필요”)을 수치로 다시 판정한 것이다.
- 디테일: 귀판 CB5-12 ×2 미끄럼 SF 0.76(새, D8과 같은 계통), 경첩 잎 볼트 미끄럼 SF 1.53, 올림 멈춤 블록 미끄럼 SF 2.01(설계안 값 확인), 경첩 허용 하중 자료 없음(STEP대기_HHPSN8).
- 완료 판정 항목(넓이 0·빗장 Z ±0.15·손 힘·로딩 자리·간섭 0·BOM)은 검도에서 모두 맞음 → completion_met true. 동작 문제 1건 → pass false.
- RX-12-C4 SF ≥ 1.106의 받침 조건(폄·빗장 잠김)은 정적으로 버틴다(판 처짐 ≤ 0.5 mm, 매트 하중 수 N).

## 4. 동작 문제 — 펴는 중 손 놓침(감쇠 없는 올림)

| 항목 | 값 |
|---|---|
| 올림 에너지(−75 → 0°, 순 모멘트 > 0 적분) | 명목 13.5 J · 공차 끝 20.3 J(설계안 어림 12 J와 같은 계통) |
| 판 묶음 경첩 관성 | 141/g × (0.353² + 0.20²) = 2.37 kg·m² |
| 0° 도착 각속도 | 3.38 rad/s(공차 끝 4.15), 앞 모서리(r 710) 2.4 m/s |
| 맞는 곳 | 혀 팔 밑면 ↔ CB6-20 머리, 경첩 축에서 **23 mm**. 빗장은 펴는 동안 빠져 있음(18) |
| 완충 | 혀·나사·블록은 거의 단단함(혀 외팔 39.6 kN/mm). 판 묶음(막대 3 + 판) 굽힘만 완충: k_θ = 0.3·EI/L · EI/L · 3EI/L = 2.2 · 7.4 · 22.1 kN·m/rad |
| 최대 모멘트 M = ω√(I·k_θ) + 7.39 | 252 · 454 · 781 N·m |
| 혀 힘 M / 0.023 | 11.0 · 19.7 · 34.0 kN → 혀 첫 항복 3.55 kN 대비 **SF 0.32 · 0.18 · 0.10** |
| SF 2를 지키는 0° 도착 한도(혀 그대로) | ω ≤ 0.21 rad/s = 로드 펴짐 속도 ≤ **10 mm/s**(0°의 dL/dφ 49.9 mm/rad) |

왜 동작인가: 받침은 손으로 접고 펴는 부품이고, 0~−75°에서 가스 스프링이 판을 스스로 들어 올린다(손 힘 ≤ 14 N로 맞춘 결과). 작업자가 펴다가 손을 놓는 것은 예상되는 오조작(M-09 오조작 SF 2)이며, 그때 혀가 부러지거나 CB6-20·블록이 휘면 0° 높이(볼 꼭대기 Z 0)와 빗장 정렬이 깨진다(완료 판정 ‘0° 폄 자리 Z ±0.15’를 지키지 못함). 혀 자리(r 23)에서는 어떤 완충재도 흡수 행정이 모자란다(13.5 J를 1.75 kN 이하로 받으려면 혀 자리에서 15 mm, 판으로 37°).

고침(하나 이상, 형상 변경은 작음):
1. **펴짐 속도 제한(필수)**: 가스 스프링을 펴짐 오일 감쇠형으로 지정하거나(형번 미확정 — 지금 STEP대기_GASSPRING_F1120_S60_L325) 같은 고리에 병렬 선형 댐퍼를 단다. 목표: 0° 도착 로드 속도 ≤ 10 mm/s(혀 그대로일 때) — 일반 감쇠형으로 맞추기 어렵다면 2와 함께.
2. **단단한 멈춤을 바깥으로**: 0° 위 멈춤을 경첩 쪽 혀(r 23) 대신 빗장 블록 A·B 위(XN 쪽, r ≈ 700)에 우레탄 범퍼(k 약 100 N/mm)로 둔다. 감쇠로 로드 20 mm/s(ω 0.40 rad/s, 0.19 J)면 범퍼 힘 약 195 N, 빗장 블록 볼트 미끄럼 1.2 kN 안. 혀–CB6-20은 높이 맞춤 기준으로만 남긴다(빗장 정렬보다 0.06 낮은 지금 자리 그대로).
3. 위 둘을 할 때까지 BOM·설계검토서에 “펴는 동안 손을 놓지 말 것”을 쓰는 것은 대책이 아니다(오조작 하중 기준).

## 워크플로우 메모

1. 해석부 정적 체크만 보면 이 받침은 모두 넉넉하다. 손으로 다루는 스프링 띄움 부품(접이 판·뚜껑)은 “손 놓침 = 감쇠 없는 운동 에너지가 단단한 멈춤에 걸림” 경우를 오조작 하중으로 늘 봐야 한다 — 설계안에서 디테일(D11)로 내려가 검도까지 통과했다. M-09 오조작 하중 예시에 ‘스프링·중력으로 스스로 움직이는 부품의 손 놓침 충격’을 넣으면 좋다.
2. 해석 환경이 없어 경첩·가스 스프링 같은 구매품 허용값은 형번이 정해져야 판정된다(STEP대기_ 임시 부품은 허용 하중 칸을 BOM에 남겨야 함).
