## 워크플로우 메모

1. MCP 서버가 `--allow-path` 없이 떠 있었다(실행 지시 (f)는 설정돼 있다고 함). 임시 허용 폴더로 복사해 열고 저장한 뒤 복사해 옮겼다. 서버가 다시 뜰 때마다 허용 폴더 이름(pid)이 바뀌어 스테이지 파일을 다시 복사해야 했다.
2. `batch` 안의 `inspect.measure` 단계(요약 · 바디 지정)가 MCP 서버를 끊었다(3번 재현, 앱은 살아 있음). `measure` 도구 단독 호출은 된다.
3. 동작 연구 REST는 J_U7_HGT를 키로 갖지 않는다. 자세 검사에서 J_U7_HGT를 6으로 몬 뒤 `motion.play REST 0`으로 돌려도 6이 남아, 첫 저장본에 U7_FIXED · U6 묶음이 Z +6으로 저장됐다 — 저장본 대 이전 판 occurrence 비교로 잡아 0으로 되돌려 다시 저장했다. REST 연구에 J_U7_HGT 0 키를 넣는 것은 준비 단계 과제 후보.
4. 실패하는 마지막 단계(`solid.remove` 없는 바디)를 둔 `batch`로 프로브를 만들고 재고 되돌리면 체크포인트 없이 원복된다(결과는 남음).
