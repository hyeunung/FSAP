# T18 구상 3 — X 랙·피니언(서보·감속기가 MAT_X에 탐) + Y 볼나사 BSS2020-1250 뒤 직결

기구설계부 3번, 2026-11-01. CAD를 쓰지 않았다(지시). 대상 `3D_Modeling/FSAP_v0.7.2.sc`의 측정 자료 `mech_T18_measure.md`, 세계 bbox 표 `tools/out/mech_T18/world_standby.json`, 손계산 `tools/out/mech_T18/concept3_calc.py` → `concept3_calc.json`.

## 요약

- **X축 구동 원리를 바꾼다.** BSS2020-1450 볼나사 대신 BASE `HFS8-4080-1900_F` 안쪽 면(Y −980) 아래 T홈에 **랙 m1.5**(X −680~680)를 달고, MAT_X `P_T08_XPLATE_F` 밑에 판금 브래킷 `P_T18_XMB`로 **400 W 서보 + 유성 감속기 1:5 + 피니언 z20(PCD 30)**을 매단다. 모터가 MAT_X와 함께 움직인다.
- 이것으로 측정 8절의 막힌 것 **1·2·3·5가 함께 없어진다**. BASE에 X 지지 유닛 받침(새 가로대·세로 받침)이 필요 없고, −X 끝 밖 모터 자리도 필요 없다. 1300 밑 X 너트 다리판이 없어서 DGM 케이블 길(Z −478 아래)도 막지 않는다. 돌아가는 긴 축이 없으니 위험 속도 제약도 없다(SF 1.37 문제 소멸, D-12의 '큰 매트 꺾임 ≤ 0.4 rad/s' 제약도 풀림).
- **Y축은 비워 둔 공간 그대로 볼나사**로 둔다. 다만 D-24의 **BSS2020-1100은 지지 간격 1180에 150 mm 모자란다**(아래 3-1). 전체 길이 1250(`BSS2020-1250`)이 필요하다. 고정측은 뒤(460_B), 서보는 뒤(Y 243~420)에 커플링으로 직결한다.
- 손계산(임시값): X 서보 피크 SF 5.21, 관성비 13.1(SF 2.30), 랙 치 SF 5.42, 피니언 치 SF 3.58, 감속기 출력 토크 SF 3.31. Y 위험 속도 SF 2.07(측정부 보수값)·좌굴 SF 62.9, 서보 피크 SF 5.26, 관성비 13.9(SF 2.16). **감속기 반경 하중만 임시 허용 500 N에서 SF 1.95** → 감속기는 출력축 허용 반경 하중 ≥ 520 N인 것으로 고른다(선정 조건).
- 행정 J_MAT_X −620~620·J_MAT_Y −860~40 그대로. 조인트·연구 변경 없음.
- 미완: 랙·피니언·감속기·서보·지지 유닛·커플링 미스미 형번과 STEP(구매부). 카탈로그 허용치 전부 임시값(D 후보 5건, 8절). 새 X 구동 자리는 세계 bbox 표로만 확인했고 CAD 프로브는 모델링·검도에서.

## 2. 구동 방식·행정·대기/작동 위치·순서

| 축 | 방식 | 행정 | 대기 | 작동 |

## 9. 위험

1. **랙 백래시·이음.** 랙–피니언은 볼나사보다 백래시가 크다(0.05~0.1급, 미확인). 봉제점 위치 정밀은 핵심 기능(U-01 "비용보다 접합 정밀도가 중요")이다. 가장자리 센서가 바늘 앞 위치를 닫힌 고리로 따라가서 오차는 센서가 보정하지만, 방향이 바뀌는 오목 모서리에서 백래시 만큼 늦는다. 대책: 장공 + 미는 볼트로 맞물림을 최소로, 필요하면 랙 한 줄에 피니언 2개(예압) — 부품 +3. 랙 이음(680 × 2)이면 이음 피치 오차가 생긴다 → 한 개 1360이 있으면 그것.
2. **실밥·먼지.** 랙 이가 위를 보고 매트 아래 1.4 m 넓이에 있다. 실밥이 이에 낄 수 있다. 1900_F 그늘(레일 밑 Z −652)이라 직접 떨어지지는 않지만 시제품 확인(요구서 7절에 적을 후보).
3. **한쪽 구동 요.** 랙이 앞 1900_F 하나뿐이라 요 모멘트 135.7 N·m가 레일 블록 옆 하중(블록당 57.5 N)으로 간다. 블록 허용 모멘트 미확인(M-06).
4. **Y 축 길이.** 받아 둔 BSS2020-1100이 쓸모없어진다(어느 구상이든 지지 간격 1180이면 같다). 1250이 미스미 길이 체계에 없으면 지지 간격을 줄이는 구조 변경이 필요해진다.
5. **움직이는 X 모터 케이블.** X 서보 케이블이 MAT_X와 함께 ±620 움직인다(볼나사 X는 모터 고정). 케이블 베어(케이블 체인) 길이 하나가 늘어난다 — 배선 길 과제.
6. 새 X 구동 자리(X ±665 · Y −980~−780 · Z −680~−572)는 세계 bbox 표로 비었음을 확인했을 뿐 CAD 프로브·동작 연구로 재지 않았다.

## 워크플로우 메모

- 측정부가 받아 둔 BSS2020-1100을 Y축 그대로 쓰는 전제로 공간을 냈는데, 지지 간격 1180보다 축이 짧다. 측정 단계에서 "구매품 길이 ↔ 지지 간격" 사슬을 한 줄 계산해 두면 구상 세 명이 같은 실수를 피한다.
- `stepcheck.py`는 `--project`를 서브커맨드 앞에 줘도 형번 없이 부르면 예외로 멈춘다(`--help`도 예외). 사용법 출력이 있으면 좋겠다.
