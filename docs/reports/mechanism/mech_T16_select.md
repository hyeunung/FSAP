## 워크플로우 메모

- 구상 3안 모두 캐리어 채움을 서로 다른 기준으로 셈했다(C2·C3는 셈이 없음). 카탈로그부가 내용물 목록과 채움(지름 합 × 1.1)을 표에 먼저 두면 구상이 같은 기준으로 판정한다.
- 측정 보고서 프로브 표의 '막는 것' 범위를 구상이 그 부품의 전체 bbox로 읽었다. C1은 TCLAMP_2를 X ≤ −45로 읽었는데, 이는 프로브 안에 든 부분일 뿐이었다. 측정부가 통로를 막는 부품의 전체 bbox를 같은 줄에 적으면 이런 오독이 줄어든다.
- 관(TU) 경로 상자를 그릴 때 "U자 다리 간격 ≥ 2R"을 구상 단계에서 손계산하지 않았다(C1 SUP 19.3 < 30).
- 앱에 같은 파일이 이미 열려 있으면, 읽기 부서의 'open 1회'를 생략해도 되는지 안내서에 한 줄이 필요하다(여기서는 dirty false·바디·피처 수 일치로 생략했다).
- 휘는 구매품(케이블 캐리어)은 조인트로 고리가 반 속도로 움직이는 것을 만들 수 없다. 그래서 대기 3분할 바디 + 쓸림 외곽 상자로 지시했다. 엔진 안내서에 '가요 구매품 모델링' 절이 필요하다.
