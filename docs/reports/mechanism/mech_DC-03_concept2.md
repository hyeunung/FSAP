# DC-03 구상 2 — X·Y 케이블 베어, 부품 최소안 (기구설계부 2번, CAD 안 씀)

## 요약
- 방향: 기성 케이블 베어 2개(X 1·Y 1)에 모든 가동 배관·배선을 몰아 넣고, 가공품은 판금 5개(Y 받침 홈통 1·걸이 2·Y 움직이는 끝 1·X 움직이는 끝 받침 1)만. 고정 끝은 베어 자체 끝 브래킷을 바닥틀·홈통에 바로 볼트(가공품 0).
- X 베어: 측정 통로 PX2(Y 1080~1545, Z −380~−45) 안에 세운 고리(XZ면). 내고 56급·외고 70·내폭 125·**R125**, 높이 2·125+70 = **320 ≤ 335**. 고정점 X −741(행정 가운데)·바닥틀 윗면, 움직이는 끝은 테이블(U5, X와 리지드) 밑면 X(보) −1250. 길이 L ≈ 1.20 m. 송풍 호스 Ø50도 이 베어로(N04 입구가 같은 쪽).
- Y 베어: 측정 통로 PY1(U4_X 좌표 X −1300~−1175, Z −360~−125) 안 세운 고리(YZ면). 내고 25급·외고 35·내폭 50·**R75**, 높이 185. 고정점 Y 0(홈통 위), 움직이는 끝 P_N02_MBKT −X 면. L ≈ 1.09 m.
- 굽힘: X R125 ≥ 가동 케이블 7.5d(Ø10 → 75)·호스 Ø50 임시 R75, Y R75 ≥ 7.5d(Ø8 → 60)·TU0604 R15. 모두 됨(임시값).
- 상태별 틈: X 베어↔YMBKT 20(Y), ↔테이블 밑면 20(Z), Y 베어↔레일 홈통 밑 6.5, ↔MBKT 브래킷 외 AZM 35 이상. 매트(Z ≥ 0)와 높이 분리. 손계산 홈통 처짐 0.14 mm·SF 32.
- 부품 +7(구매 2·가공 5), 제거 0. 비용 미확인(요구서 3-1 가격표에 베어 없음, 미스미 로그인 풀림).
- 미완: 베어 형번·규격·STEP(모두 provisional, 자료대기 후보 D-88), 바닥틀 윗면이 판인지(X 베어 아래 가닥이 놓일 면), 테이블 밑면 볼트 자리(N04).

## 2. 구동 방식·행정·자세
베어는 자체 구동이 없다. 기존 조인트 J_U4_X(하드 −200~1217.5)·J_U4_Y(하드 −355~1155)에 끝을 묶기만 한다(E-15, 새 조인트 없음). 고리 위치는 두 끝의 평균을 따라가는 종속 위치(L' = L − πR):
`고리 X_L = (X_고정 + X_움직임 + L')/2`

### 2-3. 길이 조건 (끝이 고리를 넘지 않음)

## 4. 하중 손계산 (E-18, 새로 만든 것만)
하중(임시): 베어 + 케이블 2 kg/m(두 가닥 겹친다고 보수) = 0.0196 N/mm, 홈통 자중 단면 328 mm² × 7.85e−6 × 9.81 = 0.0253 N/mm, 합 w = 0.045 N/mm.
- 홈통 단면(U, 바닥 114×2, 날개 2×25 둘): 도심 5.12, I = 17,950 mm⁴, c = 21.9.
- 걸이 간격 960(Y 100 ↔ 1060), 단순 지지: δ = 5wL⁴/(384EI) = 5·0.045·960⁴/(384·205,000·17,950) = **0.14 mm**. M = wL²/8 = 5,184 N·mm, σ = 6.3 MPa → SPCC 항복 205(임시) **SF 32**(과사양이지만 t2는 판금 최소 굽힘 강성·볼트 자리로 정함, 다듬기는 디테일).
- 걸이 인장: 반력 ≈ 0.045 × 1140 / 2 + 올림 묶음 0.6 kg ≈ 32 N, 단면 40×3 = 120 mm² → 0.27 MPa.
- 베어 끝 밀고 당김(가감속): 움직이는 질량 ~1.5 kg × 모서리 가속 1.53 m/s²(N03-Q4) ≈ 2.3 N. 걸이 Y 방향 외팔 굽힘 δ = FL³/(3EI) = 2.3·318³/(3·205,000·16,000) = 0.008 mm.
- 볼트: 각 끝 M5 2개, 2.3 N 전단 — 판정 불필요 수준. 렌치 접근은 디테일 기록만(E-02).
- X 베어: 바닥틀에 놓임, 위 가닥 자립 759 ≤ 카탈로그 ~1.5 m(임시). FEA: 해석 못 함 — 환경 없음(D-16). 판정값이 기준에서 멀다.
- 가동 마찰: 베어는 J_U4_X·Y 따라가기 저항에 더해진다. 위 가닥 끄는 힘 ≈ 무게 1.5 kg × 마찰 0.3 ≈ 4.4 N(X 베어 아래 가닥이 바닥틀에 미끄러지지 않으므로 이것뿐). N03-Q3 헤드 쪽 20 N 보조와 합쳐 서보 토크 여유 판정은 다음 부서(임시값).

### 왜 내고 56급인가 (벤치마크·표 그대로가 안 되는 곳)
표의 X 35급(외고 46, R125 높이 296)은 송풍 호스 Ø50을 못 싣는다(catalog.md 메모). 가장 단순한 길은 베어 하나에 다 싣는 것이고, 56급을 R125로 쓰면 320 ≤ 335(15 남음)로 통로에 든다. 대안(송풍기를 움직이는 테이블에 얹어 전원선만 베어로)은 X 가동 질량 +수 kg·재봉부 진동원 이동이라 N04 소관 → 이 안은 고르지 않음. 56급 R125가 없으면: (a) 호스를 Ø32(내고 35 안)로 줄이거나 Ø25 두 줄 → 표의 35급 R125(296) 그대로, (b) 외고 80까지는 330 ≤ 335로 됨.
