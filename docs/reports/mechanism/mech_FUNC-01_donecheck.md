## 2. 문제

### P1 — ① 먼 쪽 바퀴(U5) 45 N이 MGPM25의 최저 사용 압력보다 낮은 압력에 기대고 있다

- 설계안: 무게 58 N 가운데 13 N을 로드 쪽 압력으로 받쳐 45 N으로 누른다(F01-Q2). 로드 쪽 단면은 약 412 mm²(로드 Ø10 가정)이다. 13/412 = 0.032 MPa이고, 계산서 ① 표의 'U5 조정 범위 60.5~156.2 N'도 레귤레이터 하한 0.005 MPa로 셈했다.
- 모자라는 것(M-06 "구매품 허용치 수치로"):
  - SMC MGP 계열 Ø20~100의 최저 사용 압력은 0.1 MPa다(카탈로그 기억값, catalog.md 표에 없음 → 임시값). 0.032 MPa는 그 값의 1/3이다. 이 압력에서는 출력 힘을 카탈로그가 보장하지 않는다.
  - 같은 계산에서 실린더·가이드 봉 미끄럼 저항을 0으로 두었다. 최저 사용 압력은 무부하 미끄럼 저항을 넘는 압력이다. 그래서 저항은 최대 0.1 × 412 ≈ 41 N까지 될 수 있다. 자국 한도까지 남은 여유 51.6 − 45 = 6.6 N은 이 범위보다 작다.
  - ②(18 N)·⑥(18 N)도 U5 45 N이 전제다.
- 고칠 자리:
  1. `mech_FUNC-01_calc.md` ① 표와 `handcalc.py`에 U5 미끄럼 저항 f를 넣는다. MGPM25-40Z 카탈로그 값이나 임시값(최저 사용 압력 0.1 MPa → f ≤ 41 N, 불리한 쪽)을 쓰고, 새 D-번호나 D-145에 적는다. 그다음 판정식 `25 ≤ F − f`, `F + f ≤ 51.6`로 다시 판정한다.
  2. F01-Q2 받침 방식을 바꾼다. 실린더 두 쪽 압력이 모두 최저 사용 압력 0.1 MPa 이상이 되게 한다. 예: 로드 쪽 0.2 MPa(82.4 N 올림)와 머리 쪽 약 0.141 MPa(69.4 N 내림)를 걸면 차이 13 N이 위로 받친다. 이 방식이면 IR1000-01BG가 하나 더 필요하다(수량 3 → 4, 새 구매품 아님). 압력 범위 0.005~0.2 MPa 안이다. 아니면 들림 질량 58 N 자체를 받치는 다른 수단을 쓴다. 그 경우에도 이 실린더를 0.1 MPa 아래에서 쓰지 않는다.
  3. f를 넣었을 때 두 판정식을 함께 만족하는 F가 없으면(f > 13.3 N), ①을 불성립으로 둔다. 그리고 F01-Q2를 저마찰 실린더나 받침 스프링 같은 형번 조정(E-18)으로 고친 뒤 다시 낸다. ②·⑥의 18 N도 새 F−f 기준으로 다시 계산한다.
