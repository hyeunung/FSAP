### 1-1. 캐리어 길이·고리 위치(손계산)

L = S/2 + πR + k, 고리 중심 p = (L − πR + F + M)/2.

- **Y 캐리어**: S 900, R 50, 링크 20(임시) × 31 = 620 → k = 620 − 450 − 157.1 = 12.9 ≥ 0
  - 이동단 로컬 y_m = 92 → M = J_Y + 92 ∈ [−768, 132], F = −768 + 450 = −318
  - p_min = −318 + 6.5 = −311.5(J_Y −860), p_max = 132 + 6.5 = 138.5(J_Y 40)
  - 고리 바깥 끝 = p + R + H/2 = 138.5 + 50 + 14 = 202.5. 이 점은 Z −436(≥ −478)이라 허용 Y ≤ 240(측정 Y-A "Z ≥ −478이면 Y −1060~240")
  - Z < −478인 고리 아랫부분: 바깥 반지름 64에서 cosθ > 42/64 → Y 오프셋 ≤ 48.3 → Y ≤ 186.8. 460_B(Y 203~, Z ≤ −478)와 16.2 떨어짐
- **X 캐리어**: S 1,240, R 75, 링크 20(임시) × 43 = 860 → k = 860 − 620 − 235.6 = 4.4 ≥ 0
  - x_m = 131 → M ∈ [−489, 751], F = 131
  - p_max = 753.2. 고리 바깥 끝 = 753.2 + 75 + 18 = 846.2 ≤ 받침판 +X 끝 870(틈 23.8)
  - −X 끝: 이동단 브래킷 X −492 ≥ 받침판 −600(틈 108)

## 5. 하중 손계산(새로 만든 것만, E-02·E-18)

1. **XGLIDE**(두 끝 단순지지, 스팬 1,323 = 1140 안쪽 사이)
   - 단면: 윗판 212 × 2, 날개 2 × (2 × 35). 중립축은 윗면에서 8.36 → I = 72,008 mm⁴
   - 하중: 판 2.2 kg + 캐리어·케이블 약 1.0 kg(임시) → w = 0.0237 N/mm
   - 처짐 δ = 5wL⁴/(384EI) = 5 × 0.0237 × 3.064e12 / (384 × 70,000 × 72,008) = **0.19 mm**
   - 응력 σ = (wL²/8)·c/I = 5,185 × 28.6 / 72,008 = **2.1 MPa**. A5052-H34 내력 약 195 → SF 약 95
2. **XMEND**(캐리어 미는 힘)
   - 힘: 가속 5 m/s²(임시) × 0.8 kg + 미끄럼 μ 0.3 × 0.8 × 9.81 → F 약 6.4 N
   - 굽힘: 팔 80 → M = 512 N·mm. Z = 46 × 3²/6 = 69 → σ = **7.4 MPa**(SF 26)
   - 처짐 δ = FL³/(3EI) = 6.4 × 512,000 / (3 × 70,000 × 103.5) = **0.15 mm**
   - 볼트 당김: 512/18 = 28 N(M5 + T너트에는 매우 작음)
3. **YTRAY**
   - 아랫줄 + 케이블 약 0.31 kg → 3 N. 바닥 외팔 47 → σ = 6M/(bt²) = 6 × 70 / (486 × 4) = 0.2 MPa
   - 볼트 3개 하중은 무시할 만하다
4. **YMEND**: 미는 힘 약 1.5 N + 마찰, 무시할 만하다. Y판 M5 탭 물림 10 ≥ 1.5d 7.5(M-03)

## 워크플로우 메모

- 측정 프로브는 Y판 밑(MAT_Y)과 MAT_X·BASE 통로만 덮었다. 이번 과제처럼 "밸브를 MAT_Y에 싣는" 안은 Y판 위 SUP 구멍 자리(측정 밖)가 필요하다. 측정부에 이동단 위 공간 프로브도 같이 요청하면 구상이 '측정 밖'을 남기지 않는다.
- 카탈로그 표에 캐리어 내폭이 W30까지만 있어서, X 캐리어(채움 45)는 표 밖 임시 표기가 됐다. 카탈로그부가 채움 계산(케이블 지름 합 × 1.1)을 먼저 해 폭 범위를 넓혀 조사하면 좋겠다.
