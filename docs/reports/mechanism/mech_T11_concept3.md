## 3. 구동 방식·행정·순서

### 3-1. 원리
안쪽 원통 바깥면(관 중심 r_i = 228)에는 회전 쪽으로 관이 감기고, 바깥 벽 안쪽(관 중심 r_o = 285)에는 정지 쪽으로 감긴다. 둘 사이에 U자 되돌림(반경 r_u = (285 − 228)/2 = 28.5)이 하나 있다. 관 길이가 일정하다는 조건 r_i·a + r_o·b + π·r_u = L에서 U자 꼭지의 각 ψ는 dψ = r_i/(r_i + r_o)·dφ = **0.4444·dφ**로 움직인다. 관은 감겼다 풀리며 굴러갈 뿐 비틀리지 않는다.

- a = ψ − φ_i(안쪽 고정점 → U자), b = ψ − φ_o(바깥 고정점 → U자)
- 회전 −Δ일 때 a는 +0.5556Δ 커지고 b는 −0.4444Δ 작아진다.

### 3-2. 고정점·행정(대기 = J_MAT_ROT 0)

### 3-3. 동작 순서

## 10. 위험

1. **U자 고리의 실제 거동**: 띠가 벽·원통에 붙어 구르는지, 바닥 끌림으로 처지거나 뒤집히지 않는지는 유연 거동이라 모델로 판정하지 않는다. 요구서 7절(시제품)에 기록할 거리다. 대책 자리는 바닥 위 PE 미끄럼 테이프와 U자 반경 28.5(최소 R의 1.9배 이상)다.
2. 회전 한계: J_MAT_ROT는 "한계 없음"이다. −438°를 넘거나 +45° 넘게 거꾸로 돌면 고정점이 당겨진다. PLC 소프트 한계·원점 센서 자리가 필요하다(**구동 후보 ③**, U-09).
3. 틈 3.0(원통 밑 ↔ 바닥)이 판금·DG 공차 사슬에 걸린다. 디테일링에서 공차를 판정하고, 모자라면 다리를 2 늘린다(벽 위 → 날개 17에서 여유).
4. R1 피팅 정비는 원통 안쪽 + 바닥 밑 옆 틈으로만 된다(6절). 검증에서 손 길 상자를 다시 재야 한다.
5. 진공 띠 Ø6은 자리만 잡았다. 회전 쪽 진공 끝(원판·링1)이 정해지지 않았다(**구동 후보 ②**).
6. X·Y 케이블 캐리어 형번·받침 판금은 경로 상자뿐이다(**구동 후보 ①**). DGM 모터 케이블도 같이 넣어야 한다.
7. 평판 관 `TFU*` 미스미 형번은 확인하지 않았다. 대체는 낱개 관 다발이다(8절).
8. 측정 프로브 밖 공간(원통·홈통 고리, B1~B4)은 bbox 손계산으로만 봤다. 검증에서 `motion.interference`로 4개 연구를 돌려야 한다. 홈통 쪽은 MAT_Y, 원통 쪽은 MAT_ROT 리지드다.
