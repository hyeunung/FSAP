## 3. 움직이는 축 — 다시 셈
- J_U5_X(0~1380): 길이 (x_c − x_f) + 75π + (x_c − x_m) = (s/2 + 57.45) + 235.62 + (764.95 − s/2) = 1,058.0으로 s와 상관없음. 끝 직선은 아래 57.45~747.45, 위 764.95~74.95로 ≥ 46(한 링크). 고정점 −1222.5는 행정 가운데 (−1930 − 550)/2 = −1240에서 17.5 떨어짐. 체인 안 관 Z 658~676 / 809~827은 안 높이 655~680 / 805~830 안에 듦. 관 길이는 822.4 + π·69.5 = 1,040.7, 822.4 + π·81.5 = 1,078.4로 일정 → 맞음.
- J_U4_PRESS: 이음점이 핀 축 위에 있어 자리가 그대로다. 설계안은 실린더가 레버 각 10.49°만큼 돈다고 봤다. 실제로는 로드 핀 (−160, 0, 122)(mech_M02_model.md)이 레버 핀 (−300, 70)에서 r = 149.3이라 호 27.3, 실린더에 수직인 몫 27.3·52/149.3 = 9.5, 핀 사이 약 190 → 실린더는 **약 2.9°**만 돈다. 그래서 A 꺾임은 9.2°보다 작고(약 2.5°), 자유 구간 R 266은 안전 쪽 값이다. U4C_B 세로 다리 X 이동도 ≤ 약 5(+X 쪽, 레버가 내릴 때 로드 핀이 +X 9.5)라 헤드 U3(X −80)까지 틈은 15 이상이다. 설계안 근거의 '0.183×76 = 13.9'는 지렛대 길이를 잘못 잡았지만(세로 다리 아래 끝 dz 약 −86), 결론은 안전 쪽이다. 같은 방향이라 받침 P_M02_BASE(X ≤ −140) 쪽으로 다가가지 않는다(대기 때 bbox 틈 0.5, (−136.5, 32.6, 217.9)) → 맞음.
