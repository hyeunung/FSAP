# T18 측정 — X·Y 이송 구동 유닛(볼나사·지지 유닛·너트 받침·커플링·서보·모터 브래킷)

측정부, 2026-11-01. 대상 `3D_Modeling/FSAP_v0.7.2.sc`(tools/config.json doc). CLI로 저장본에 대고 쟀고(`solidcraft-cli run --results`, `--save` 없음), MCP는 쓰지 않았다.

## 요약

- **already_ok = false.** v0.7.2에 X·Y 볼나사·지지 유닛·너트 받침·커플링·서보·모터 브래킷 바디가 **0개**다. 완료 판정의 "새 구매품 실물 STEP"과 "손계산 SF ≥ 2"를 판정할 대상이 없다.
- 비워 둔 공간은 실제로 비어 있다. 프로브 18개를 넣고 대기 자세 정적 검사 → 모델 바디와 겹침 **0 mm³**. X·Y 전 행정 래스터(J_MAT_X −620~620 × J_MAT_Y −860~40, 881표본)와 X·Y 단독 5 mm 연구에서도 BASE·MAT_X·MAT_Y와 새 겹침 **0**(truncated false).
- 조인트 한계는 J_MAT_X −620~620·J_MAT_Y −860~40이다(joint.list 값). 동작 연구들이 실제로 쓰는 범위는 X ±600.1·Y −836.1~10이다.
- 실물 STEP `BSS2020-1100`·`-1450`은 받아 둔 상태다(stepcheck '있음'). 단품 실측: 축 Ø20, bbox 길이 1100/1450(부피÷단면은 1060/1410), 너트 70 길이 · 66 × 46 각진 플랜지. STEP 재질은 'Default'라 넣을 때 지정해야 한다.
- 막힌 것 1: **X 볼나사 지지 유닛을 달 BASE 면이 없다.** X 공간(Y −470~−350, Z −580~−480) 밑과 −X 끝 바깥(X −1150~−950)은 비어 있다(1900 형재까지 510.5 mm). 가로대 자리 X ±(910~950)는 1900_F·_B와 맞닿기만 하고 비어 있다.
- 막힌 것 2(참고 손계산): X 축 BSS2020-1450을 고정–지지로 쓰면 위험 속도 1235 rpm이고, D-12 빈 이동 300 mm/s(900 rpm)에 대해 **SF 1.37 < 2**다. 고정–고정 L 1350이면 SF 2.30이다. Y 축(지지 간격 1180, 고정–지지)은 SF 2.07이다.
- 미완: 서보·지지 유닛·커플링·모터 브래킷 형번이 정해지지 않아 카탈로그 허용치를 보지 못했다. 골지름 17.2와 마찰계수는 임시값이다.
