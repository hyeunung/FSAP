## 1. 근거 규칙 (원문)
- E-18: "FEA는 형상·하중 경로가 바뀐 부품만" — 구멍 → 장공은 Z 하중 경로(볼트 몸 받침 → 마찰)가 바뀐 것이라 손계산 대상.
- 해석부 지시: "부러짐·영구 변형(SF < 1.2)·동작을 망가뜨리는 처짐만 kind='동작'". 미끄럼은 재료 파손은 아니지만 조정 위치가 영구히 바뀌어 바인더·카세트 자리가 틀어진다 → 영구 변위로 보고 SF < 1.2를 동작으로 셌다(μ 보수값 기준, 판단 근거 2절).
- 요구서 6-1(비어 있음) → M-09 기본값: 운전 SF 3, 오조작 SF 2.
- M-02: "조정은 장공 + 미는 볼트" — 지금 모델에는 미는 볼트가 없다(디테일 DC2-04-X1로 미룸). 이 계산이 그것을 구동 단계 문제로 당긴다.
