## 2. 지난 문제 확인 — 회전력 (손계산 독립 재계산)
식: 가진 토크 = 0.4·40 N·0.1 m (U4) + 0.4·40 N·0.44 m (U5 내렸을 때) = 1.60 / 8.64 N·m. 필요 = 구름 T_roll + I·α(정지→정지 삼각, α = 4θ/t²) + 원판 끌림 + 띠 μs·40·0.44. `fix1calc.json` 값을 위 식으로 다시 셈 — 모든 행 차 ≤ 0.006(원판 등가 관성 I_disk 0.0217 더한 행의 반올림 차).

| 경우 | 최저 SF | 구간 |
|---|---|---|
| 완료 판정 조건 그대로(띠·원판 뺌) | U4 혼자 1.044 / U4+U5 2.673 | 입구2 −75→−30 9.5 s / 입구1 m2 4.1 s |
| + 원판 끌림 | 1.013 | 입구2 U4만 |
| + 띠 μs 0.15 | 1.013 | 입구2 U4만 |
| + 띠 μs 0.30 | **1.009** | 입구1 m2 피벗 4.1 s |
| 구름 0.05(참고) | 0.456 | U4 혼자 — 구름 ≤ 0.02 선정 조건(D-96)이 필요한 이유 |

U4 혼자 구간 시간: 꼭짓점 −35→−75 40° = 3.5 + 4.5 = 8.0 s, 입구2 45° 9.5 s — 둘 다 ≥ 6 s. 참고: 입구2를 6 s로 줄이면 SF 0.84라 9.5 s가 맞다(`U4_only_at_6s`).
시간 키는 `tools/machine.json _timing.CYCLE_V`(연구는 단계만): 입구1 4.1, 꼭짓점 2.0×4·1.3, U4만 3.5·4.5, 입구2 U4만 9.5, U4+U5 2.6 — 보고 값과 같음.
