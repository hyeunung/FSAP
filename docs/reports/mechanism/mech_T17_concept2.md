# 구동 T17 구상 2 — 진공 배관 회전부 건너기(부품 수·구매가 최소)

기구설계부 2번, 2026-11-02, 엔진 v3.4.0. CAD 사용 0, 브라우저 0. 기준 `3D_Modeling/FSAP_v0.8.4.sc`(측정 `mech_T17_measure.md`, 해시 `9be097737d6b4331`). 방향: 부품 수·구매가 최소, 가장 단순한 구동.

**요약(10줄)**
- **방식: 로터리 조인트 없이 꼬임 관 2줄(TU0604 Ø6).** 원판 회로·링1 회로를 따로 둔다(T01-S05). 이젝터 2개는 BASE 그대로 둔다. MAT_Y → BASE 건너기는 T16 몫(T11-S03)이다. T17의 끝은 Y판 밑 인계점 (X −27 / −19, Y −450, Z −394 / −382)이다.
- **꼬임 구간은 T11 관과 같은 높이에 둔다.** 기둥 속 안내 보스 Z −220~−210이 위 고정이고, Y판 밑이 아래 고정이다. 길이 L 136.5, r15에서 ±180°일 때 늘음 7.9 mm(5.8 %)다. 관 여유 12 mm로 받는다. 나선 굽힘 R141 ≥ R20이다.
- 원판: 가운데 밑면에 `MBIS5-6.5-8` 인서트 + `STEP대기_KQ2S06-M5A`, 윗면까지 Ø3. 링1: r100 θ30 밑면에 M5 탭 + `STEP대기_KQ2S06-M5A`, 윗면까지 Ø3. 진공 면 Z −0.5는 그대로다.
- 링1 행정 60은 기둥 벽 장공(6.5×18, θ30, Z −50.3~−32.3) 밖의 **구름 고리 R22.5**로 받는다. 고리 바닥은 링1 0일 때 Z −100.5, −60일 때 −130.5다.
- 금지 구역: r ≥ 70의 회전부는 작은매트 사이클 내내 Z ≤ −70.5다(≤ −59 지킴). 허브 볼트 머리까지 96, YNB까지 X 36 이상 떨어진다. Y판 밑 관은 Z ≥ −397이라 YMB 제약(Z ≤ −400)에 들지 않는다. 이젝터 자리 QY_EJ는 쓰지 않는다.
- 부품 +6: 관 2·이음 2·인서트 1·결속 밴드 1. 고치는 가공품 4개(원판·기둥·링1·Y판)는 구멍·장공·보스만 더한다. 새 가공품 0, 새 조인트 0이다. 세트 비용 약 +1.2만 원(임시)이다. 로터리 조인트 MQR2-M5(약 9만 원)보다 싸다.
- 미완: KQ2S06-M5A·TU0604·결속 밴드는 STEP·카탈로그 미확인이다(provisional, 미스미 봇 확인). Ø6 굽힘 반경은 새 자료대기 임시 R15이고, 설계는 R20으로 했다. 모델링 뒤 회전 연구로 T11 관과 꼬임이 부딪치는지 확인해야 한다.

## 1. 근거로 쓴 규칙

- E-03 "합격은 동작·간섭". 강도·렌치 접근은 디테일로 기록만 한다(E-02).
- U-03 "커스텀이되 효율적으로", M-10 부품 수·세트 비용. 그래서 로터리 조인트(구매 9만 원, STEP 없음, 가운데 관통형 형번 미정)를 쓰지 않는다. J_MAT_ROT −360~0은 연속 회전이 아니다(측정 2-4).
- U-05 가공 순서(판금 → 3D 출력 → 기성 → 가공). 새 가공품은 없다. 이미 3D 출력품인 기둥(PET-CF)·원판(Rigid 10K)에 형상을 더하고, A5052 링1·Y판에는 구멍만 낸다.
- U-07·E-10 "구매품은 실제 STEP만, 형번 없는 추정 바디 금지". 이음은 형번이 있는 `STEP대기_KQ2S06-M5A`로 둔다. 관·밴드는 T11-S06 방식대로 바디로 그리지 않고 경로 상자(`motion_states.json` `t17_routes`)로 둔다.
- T11-S04: 꼬임 중립은 J_MAT_ROT −180°이고, 결속은 그 자세에서 조인다.
- 실행 규칙 14: 관 덮개는 만들지 않는다.

## 4. 손계산

계산은 `tools/out/mech_T17/twist_calc.py`와 같은 식으로 손으로 했다.

**꼬임.** 위 고정(보스 가운데) Z −215, 아래 Y판 밑 −351.5, L = 136.5, r_c = 15, ±180°(중립 −180°).
- 호 길이 r·π = 47.12. 나선 길이 √(136.5² + 47.12²) = 144.40. **늘음 7.90 mm(5.79 %)**.
- 관 여유: 결속(Y −560)과 Y판 구멍 사이에 12 mm를 더 둔다(늘음의 1.5배). 관은 보스 구멍으로 미끄러지므로 늘음은 여유가 받는다. 관 자체 변형률은 ≈ 0이다. **판정 7.90 ≤ 12 합격(임시).**
- 나선 굽힘 반경: c = L/π = 43.45, R = r + c²/r = 15 + 125.9 = **141** ≥ R20 ≥ R15(Ø6 임시) ≥ R10(D-46).
- T11 관(L148.5, Z −203~−351.5)과 꼬이는 양 차이: Z −215에서 T11은 이미 180·12/148.5 = 14.5° 돌아 있다. 반지름이 다르다(T11 ≤ 10, 진공 관 안쪽 12). 그래서 위상 차 최대 ±14.5°는 지름 방향 틈 2를 쓰지 않는다. 다만 관이 당겨지면 안쪽으로 붙는 쪽이라 회전 연구가 필요하다(위험 1).

**굽힘 반경(설계 R20).** S자 R491, 벽 안·밖 R20, 구름 고리 R22.5, Y판 밑 R20, 나선 R141. 최소 R20 ≥ 임시 R15(catalog.md TU0604) → 합격(임시).

**기둥 장공(새로 만든 형상, 강도는 기록만).**
- 기둥 관 r20~30: Z = π(60⁴ − 40⁴)/(32·60) = 17,017 mm³.
- 장공 한 개는 바깥 끝 근처 6.5×10 단면을 뺀다. ΔI ≈ 65·25² = 40,625 / I 510,500 → −8 %, Z ≈ 15,650.
- 가정 하중: DP-2 관 뿌리 오조작 275.6 N(T11 선정 1-1)을 매트 높이 Z 0에 가로로. M(Z −40) = 275.6 × 40 = 11,024 N·mm. σ = 0.70 MPa.
- PET-CF 출력 층간 약 25 MPa(임시)로 SF ≈ 35. T11 장공(Z −203, SF 2.19)보다 팔이 짧아 더 유리하다. 디테일 기록만 한다(E-02).

**원판 인서트.**
- KQ2 M5 조임 1~1.5 N·m. 인서트는 이미 원판 고정 ×3에 쓰는 같은 형번이다.
- 진공 힘: 이음 면적 Ø5 × 100 kPa ≈ 2 N. 무시한다.
- 새는 길: 인서트 바깥 널링을 따라 기둥 속 대기에서 Ø3로 샌다. 인서트를 넣을 때 실런트를 바른다(디테일 D2).

**진공 부피(참고).** TU0604 안지름 4 → 12.57 mm²/mm. T17 구간은 관 A 약 0.55 m, 관 B 약 0.75 m다(+T16 구간 미정). 관 1 m당 12.6 cm³다. 반응 시간은 T16 길이가 정해진 뒤 본다(요구서 7절 시제품 확인 후보).
