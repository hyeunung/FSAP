# RX-08 해석부 — U4 중간 높이 스토퍼 실린더 강도 (2026-11-12, v2.12.1)

요약(10줄 안):
- 대상: 새 하중 부품 `P_RX08_STOP_BRKT_밀링`(SUS304), `P_RX08_STOP_BLOCK_밀링`(SUS304), 고친 `P_M02_BASE`(SUS304 t8, M5 탭 2개·관 장공). CAD를 쓰지 않았다. **해석 못 함 — 환경 없음(D-16)**, 그래서 손계산으로 했다(`fea/cases/mech_RX-08_handcalc.py` → `fea/results/mech_RX-08_handcalc.json`).
- 하중: 스토퍼 반력 F = T / 43.5 mm. 운전은 0.2 MPa(IR1000 상한)에 무게 몫 ×3 g를 더해 **373.3 N**, 오조작은 공급 0.5 MPa 전부에 3 g를 더해 **553.1 N**이다. 모델링부 값 204.3 N은 1 g·0.2 MPa 기준이다.
- **동작 문제 0**: 모든 부품에서 SF ≥ 1.2이다. 부러짐·영구 변형은 없다.
- 디테일 1: 브래킷 윗판(12 × 8 단면, 기둥 Y 86 → 볼트 Y 69·79)은 비틀림과 굽힘을 같이 받는다. SF가 운전 **2.07**(기준 3), 오조작 **1.40**(기준 2)으로 모자란다. 윗판을 t8에서 t12(Z 230~242)로 키우면 4.28 / 2.89로 만족한다.
- 만족: 발 6.16/4.16, 기둥 5.56/3.75, BASE 탭 둘레 4.55/3.07, 블록 63 이상, 립 30.7, 그네 윗판 20.6, 윗판 볼트 CB5-16 나사산 6.21/4.19(예압 대 분리 5.06), 조절 볼트 CB8-20 21.6.
- 완료 판정 문구 '실린더 힘 ≥ 누름 반력 × SF': 245.4 N ≥ 145.6 × 1.5 = 218.4 N이므로 **SF 1.69**로 만족한다(설정 0.102 MPa). 0.2 MPa에서는 1.20이지만, 받침 면이 수평이라 실린더 축으로 가는 힘은 0이다.
- 완료 판정은 **미달**(completion false)이다. 강도 때문이 아니라 검도 1회차(`mech_RX-08_verify1.md`)의 '과제 범위 간섭 0'이 미달이기 때문이다: 레일 STEP 바디 `Chamfer2`(X −335~235, Remove86 타임라인 오류)가 관 클램프 L_4·L_5와 각 1,871.3 mm³ 겹친다. 사용자가 "이거 안보이냐고"라고 한 것이 이것으로 보인다. 해석부 범위 밖이라 여기서 고치지 않았다.
- `fea/models.json`에 브래킷·블록 행을 더하고 BASE 하중을 더했다. BASE의 옛 모델은 `_옛 모델(RX-06 v2.11.0)`에 남겼다. 경계조건은 바꾸지 않았다.

## 워크플로우 메모

- 해석부 지시에는 "검도·체결부가 끝난 뒤"라고 돼 있다. 그런데 검도 1회차가 불합격(동작 1)인 채로 해석부가 불렸다. 그 겹침이 사용자 지적("이거 안보이냐고")과 닿아 있으면, 해석보다 수정 회차가 먼저여야 한다.
- 해석 환경이 없어 E-18의 'FEA 대상'(하중 길이 바뀐 부품)도 계속 손계산으로 갈음하고 있다(D-16). 윗판 비틀림처럼 3D 하중 분배가 들어가는 자리는 손계산이 보수 쪽으로 치우친다.
