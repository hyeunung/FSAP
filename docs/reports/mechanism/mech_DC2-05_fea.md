# 해석부 — DC2-05 먼 쪽 바퀴 밑 받침 (2026-11-04, 동시 과제 E-25, CAD 안 씀)

요약
- 대상(새 하중 부품만): `P_DC205_STRIP`(A5052 띠), `P_DC205_DISC` ×8(SUS304 t4 누름판), `CB5-12_DC205` ×8. 해석 모델 바꿈 없음(새 행만 더함 → `tools/out/DC2-05/docs/fea-models.md`).
- FEA 못 함 — 환경 없음(자료대기 D-16). 전부 손계산: `fea/cases/mech_DC2-05_handcalc.py` → `fea/results/mech_DC2-05_handcalc.json`.
- 띠: 보스 없는 빈 구멍 Ø36 위 오조작 453.3 N에서 σ 9.0 MPa(SF 21.6), 처짐 0.002 mm. 과사양 note(두께 8은 높이 ±0.1·평면도·탭 물림 때문이라 줄이지 않음).
- **문제 1(동작): 누름판이 표준 조임 토크에서 항복한다.** 4.5 N·m → 예압 4,500 N, 누름판 가운데 σ 386 MPa(Timoshenko 확인 619) > SUS304 σy 205, SF 0.53(0.33). 보스 밑 틈 0.2는 탄성으로 닫히는 데 13,800 N이 들어 보스가 힘을 받기 전에 판이 접시꼴로 영구 변형한다. 같은 토크에서 A5052 보스 탭 조임 전단 SF 1.19.
- 고치는 법(형상 그대로): CB5-12 조임 토크 **0.6 N·m 지정 + 중강도 나사 고정제**(예압 600 N, 누름판 SF 2.48~3.98, 탭 전단 여유 충분). 띠는 보스 Ø35.6이 구멍 Ø36에 끼워 위치를 잡으므로 큰 예압이 필요 없다(끌림 136 N은 보스가 받음).
- 완료 판정 항목(받침 연속·윗면 ±0.1·간섭 0)은 강도 항목이 아니고, 누름판 변형은 띠 윗면 높이(판 W2 윗면 기준)를 바꾸지 않는다 → completion_met true. 동작 문제 1이라 pass false.
- 미완: 띠 윗면 마찰 μ 0.15~0.3(시제품, 요구서 7절)은 설계안대로 기록만.

## 4. 고치는 법 (모델링부·도면)
- 형상은 바꾸지 않는다. CB5-12_DC205 ×8의 조임 토크를 **0.6 N·m**으로 도면·BOM 비고에 지정하고, 중강도 나사 고정제(풀림 막이)를 쓴다. 예압 600 N에서 누름판 SF 2.48~3.98, 탭 전단 여유 충분.
- 다른 안(참고): 누름판 t4 → t6이면 1.0 N·m에서 SF 약 3.4이나 볼트 물림이 5.8로 1.5d(7.5) 아래가 돼 CB5-15(STEP 있는지 미확인)로 바꿔야 한다. 안 A가 가장 작다.
- 판 W2(M04-F2)는 띠가 바퀴 하중을 넓게 퍼뜨려 같거나 좋아진다. 판정 안 함(E-02), 기록.
