# RX-12-C2 해석부 1 — 새 기둥 L `P_RX12C2_LBRK_COL_U` · `_L` 손계산

요약
- 대상: 이번에 새로 만든 하중 부품 `P_RX12C2_LBRK_COL_U` · `_L`(SUS304 t4, 폭 40, 다리 40, Ø5.5 — STEP 원 반지름 2.75로 확인). R2 받이 `HFS8-4080-140_RX12C2`(외팔 140)를 기둥 −Y 면에 붙인다.
- FEA는 못 했다. 환경이 없다(D-16). 그래서 손계산만 했다: `fea/cases/mech_RX-12-C2_handcalc.py` → `fea/results/mech_RX-12-C2_handcalc.json`.
- 위 L 세운 다리의 운전 SF는 **7.93**이다(기준 3, 됨). 오조작(손 100 N −Y 당김)은 **1.67**로 기준 2에 못 미친다. 1.2 이상이라 **디테일**이다. 볼트 머리 좌면 끝을 기준으로 한 what-if는 2.12다.
- 아래 L(손 +Y 밀기)은 3.02다. 새 볼트 CB5-16 + HNTT8-5의 운전 SF는 8.65다(암나사 전단, 물림 4 가정).
- what-if(표 하중 방향 밖): 손 100 N이 X 옆으로 걸리면 140을 Z축으로 돌리는 힘이 14,000 N·mm다. 볼트 마찰로 버틸 수 있는 5,600 N·mm의 2.5배다. 140 쪽 볼트가 L마다 1개뿐이라서다. 디테일로 기록한다.
- 동작 문제(SF < 1.2)는 0이다. 해석 모델은 바꾸지 않았고 `fea/models.json`에 `P_RX12C2_LBRK_COL` 행을 새로 더했다.
- 완료 판정 세 항목(받침 밖 넓이·오목 틈·간섭)은 기하 항목이다. 검도·완료 점검(`mech_RX-12-C2_donecheck.md`) 값을 그대로 쓴다. 강도 항목은 완료 판정에 없다.

## 1. 일의 크기 (E-18)

E-18 원문: "체결만 바뀐 자리는 손계산, FEA는 형상·하중 경로가 바뀐 부품만". 새로 생긴 하중 경로는 기둥 L 2개다. 판넬 PX와 보 연장은 설계 보고서 4절 손계산(판넬 SF 8.4, 보 처짐 비 1.17)을 그대로 쓴다. 이번에 바뀐 것은 없다. L은 판 두께/다리 = 4/40 = 0.1이라 보 손계산으로 충분하다. 해석 환경도 없다(D-16).
