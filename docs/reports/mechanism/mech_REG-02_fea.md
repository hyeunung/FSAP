## 1. 일의 크기(E-18)와 하중 경로
- 등급 M, 새 하중 부품 1(판) + 바뀐 체결(장공 볼트 CB5-12 → CB5-16, 스터드 새로). 형상·하중 경로가 바뀐 것은 판뿐이다. 볼트는 "이번에 새로 만들거나 옮긴 것만 본다"는 부서 지시대로 CB5-16_REG02_1~4·스터드만 본다.
- 쌓임(Y): UPPER −Y 면(Y −90) | BASE 붙임면 t3(+판 패드 1) 또는 HOLDER 날개 A t4 | 판 t5 | 볼트 머리(1·2 직접, 3·4 와셔 M5 t1).
- 조여 있을 때: 면 안(XZ) 하중은 볼트 예압 마찰로 UPPER에 간다. 묶음 하나만 미끄러지려면 UPPER 면과 판 면 두 면이 다 미끄러져야 하고(각 볼트 쌓임마다 같은 예압으로 눌림), 두 묶음이 함께 미끄러지면 4볼트 무리가 받는다. 둘 중 작은 쪽으로 판정.
- 높이 조정 중(장공 볼트 풀림, 1 g 정적): U6 무게 → 스터드 1·2 → 판 → 스터드 3·4 → HOLDER → 미는 볼트 M4 ×2(DC2-04 블록).
- 하중·임시값은 DC2-04와 같다(D-127): U6 1.0 kg·U7 2.5 kg·판 0.30 kg ×3 g = 111.9 N, 손 100 N, CJ2B16 막힘 100.5 N(0.5 MPa, D-111), CB5 4.5 N·m → 예압 4,500 N, μ 0.15(판정)/0.20(참고), UPPER 모재 SS400 대용(D-10). 판정 요구서 6-1 "기본값 — M-09"(운전 SF 3, 오조작 SF 2), SF < 1.2만 '동작'.
- STEP 확인: `tools/out/mech_REG-02/stepout/P_REG02_HGT_PLATE.step` 솔리드 1, 점 436, 최대 X 44·Z 330·최소 X −80·Y −99(최소 Z 0·최대 Y 0은 배치 원점 점) — 모델링부 bbox X −80~44·Y −99~−93·Z 157~330과 같음.

## 3. 문제
1. **동작 — CB5-16_REG02_3·4 탭 뭉개짐(조임).** 어디: UPPER −Y 면 M5 탭, X 18·36 · Z 310. 수치: 물림 6 mm(판 t5 + 와셔 t1 + 날개 t4 위로 16 − 10), 조임 4.5 N·m 예압 4,500 N에서 암나사 전단 SF 1.15 < 1.2(SS400 대용). 옛 CB5-12_M05_11·12는 물림 7에서 1.35. 고치는 법: 볼트를 **CB5-20**으로(물림 10, SF ≈ 1.9; 모델링부 확인 탭 깊이 12 안). 같이 1·2도 CB5-20 + 와셔로 맞추면 네 볼트가 같은 형번·같은 쌓임이 된다. 헤드 기종이 정해져 UPPER가 알루미늄이면 2d(10) 이상 물림 필요(D-10).
2. **디테일 — CB5-16_REG02_1·2 물림 7·머리 좌면.** 조임 암나사 1.35 < 2, SUS304 판 장공 위 머리 좌면 p_G SF 1.20. 고치는 법: CB5-20 + 평 와셔 M5(Ø10·t1, D-127과 같은 것) → 물림 10·좌면 2.35.
3. 기록(문제 아님): 판·스터드·미는 볼트는 과사양(판 t5를 t3로 줄여도 면 밖 SF > 30) — 판 두께는 패드·장공 받침면 평탄도 몫으로 두는 것이 낫다(줄이라는 지시 아님, M-09 note).
4. 기록: 스터드 FH4-M4 SUS 판금 t3 압입 최소 두께·구멍 Ø는 카탈로그 확인(D-142) — 하중 5 N 수준이라 강도 판정에는 영향 없음.
