## 2. 구동 방식·행정·대기/작동 위치·순서

- 구동은 그대로다. `CJ2B16-60SZ` 단동 압출, 행정 60, J_RING2 −60~0(0 올림 대기, −60 내림), J_RING1 같음. 로드 끝 미는 접촉(DL-D11) 그대로.
- 바뀌는 것은 **실린더 몸통의 축 둘레 방향**뿐이다. S01-M06의 넣는 행렬 R = Rz(θ)·R0에서 θ에 180°를 더한다(θ = 90·210·330° → 270·30·150°). 몸통 bbox는 축 둘레 대칭(±9.15)이라 바뀌지 않는다. 어깨 −98.5, 보스 Ø10, SNJ, 로드·NTJ는 같다.
- 배관(정지 형상, 조인트 없음):
  - 회전 쪽(MAT_ROT에 리지드): 포트 → L 피팅(출구 위) → 위로 굽힘 → 스파이더 ㄷ 안쪽 레인(Z −206~−200)을 따라 안쪽 → 기둥 관벽 구멍 → 기둥 속에서 아래로.
  - 꼬임 구간: 기둥 구멍 Z −203 ~ 굽힘 시작 Z −375, Ø40 중심 길(측정 Q_CORE 겹침 0).
  - 정지 쪽(MAT_Y에 리지드): Y판 창(X ±47.5) 밑에서 R25로 +Y로 꺾어 클램프 → 이송 배관 경로 상자(T16).
- 동작 순서 제약(PLC 단계 U-09로 넘김, 형상 없음):
  1. **누적 회전 −360°~0°** 를 넘지 않는다. 사이클마다 끝에 `되감기`(이미 있는 연구, −360 → 0)를 한다. 지금 `motion_states.json`의 `J_MAT_ROT`는 "한계 없음"이라 모델링부가 조인트 한계를 **−360~0**으로 넣는 것을 권한다(사이클 3개 joint_extent가 모두 [−360, 0]이라 연구는 바뀌지 않는다).
  2. 조립 때 클램프는 **J_MAT_ROT −180°**에서 조인다(꼬임 중립). 그러면 운전 중 꼬임이 ±180°다.
  3. 원점 복귀·비상 정지 뒤 재기동도 되감기 방향(0 쪽)으로만 돈다.

## 5. 하중 손계산

**꼬임**(중립 −180°, ±180°, 꼬임 길이 L = −203 → −375 = 172, 묶음 바깥 관 중심 반지름 6):
- 나선 길이 √(172² + (π·6)²) = 173.03 → 늘음 **1.03 mm(0.6 %)**. 굽힘 K(중심선 길이 39)의 처짐과 관 탄성으로 받는다. 조립을 0°에서 잘못 하면(360°) √(172² + (2π·6)²) = 176.1 → 4.1(2.4 %), 그래도 된다.
- 관 자체 비틀림 전단 변형 γ = r·θ/L = 2·π/172 = **0.037**(겉 r 2). 우레탄 탄성 범위 안(카탈로그 값 미확인).
- 꼬임 토크: 우레탄 G ≈ 20 MPa(가정), J(Ø4/2.5) = 21.3 mm⁴, J(Ø6/4) = 102 mm⁴. ΣGJ = 20·(6·21.3 + 2·102) = 6,636 N·mm². T = ΣGJ·θ/L = 6,636·π/172 = **121 N·mm = 0.12 N·m**. DGM200R-AZAC 토크(D-17 미확인)의 아주 작은 몫이다. 클램프 볼트 반력은 0.12 N·m / 64(볼트 간격) ≈ 1.9 N.

**기둥 관벽 구멍**(`P_T01_POST` Ø60/Ø40, 구멍 Ø6 ×6을 같은 Z −203에):
- 하중 경로: 기둥 위는 원판 `P_T01_DISC` Ø110 하나만 받는다(링1·링2는 스파이더 → 허브). 옆힘 가정 F = 50 N(봉제 이송 끌림, 임시, 근거 없음 → 자료대기 제안)이 Z 0에 걸리면 구멍 단면 굽힘 M = 50 × 203 = 10.15 N·m.
- 단면: I(관) = π/64·(60⁴ − 40⁴) = 510,500 mm⁴. 구멍 6개가 빼는 몫 ≈ Σ A·(25 sin θ)² = 60 · 625 · 3 = 112,500 → I_net = 398,000 mm⁴. 단면적 1,571 → 1,211 mm²(77 %).
- σ = M·c / I_net = 10,150 · 30 / 398,000 = 0.77 MPa, 구멍 응력 집중 Kt 3 → **2.3 MPa**. PET-CF 층간 강도 20 MPa(가정, 세로 출력이라 층이 수평) → **SF 8.7**.
- 비틀림(원판 + 작은 매트 관성, 가정 5 N·m): J_net ≈ 1.021e6 − 225,000 = 796,000 mm⁴ → τ = 0.19 MPa × 3 = 0.57 MPa → SF > 20. 축 압축(원판·매트 무게 < 100 N) 0.08 MPa.
- 처짐: 바뀐 것은 Z −206~−200 6 mm 띠뿐이라 기둥 처짐 변화는 무시할 만하다.
- FEA: 해석 못 함 — 환경 없음(자료대기 D-16). 하중 경로는 바뀌지 않고 단면만 줄어 손계산으로 둔다(E-18).

**클램프**: 묶음 무게 < 0.2 N + 꼬임 반력 1.9 N. 출력 몸통 날개 t6 · 볼트 CB5-16 ×2는 과사양이나 M5 하나 지름(U-12)과 출력 최소 살로 정해진 값이라 기록만(M-09, 디테일링).

## 8. 위험

1. **꼬임 수명**: 우레탄 관 8줄 ±180° 반복 꼬임의 수명은 모델로 판정하지 못한다(요구서 7절 시제품 확인에 기록). 묶음이 Ø40 구멍 가장자리(허브 SUS 레이저 Ø40 · Z −241~−233)에 닿아 쓸릴 수 있다 → 허브 구멍 끝 C0.5·버 제거는 디테일링(E-02 기록만). 묶음이 매달려 가운데 있으면 틈 11.5.
2. **되감기 누락**: PLC가 되감기를 빠뜨리거나 한 방향으로 계속 돌면 관이 끊긴다. 조인트 한계 −360~0 권고와 동작 순서 제약 1을 PLC 단계(U-09)에 넘긴다. 사이클이 −360보다 더 돌아야 하는 매트(이음매 겹침 등)가 나오면 꼬임 여유를 다시 본다.
3. **최소 굽힘 반경**: TU0425 R10이 카탈로그와 다르면 B1·B2 상자를 넓힌다(공간 있음, 6절).
4. **피팅 형번 표기**: KQ2L04-M5A의 미스미 표기·STEP이 없으면 E-10 임시 형상. 외곽이 측정 상자(10 × 16 × 11)보다 크면 F 상자 재검사.
5. **기둥 구멍 강도**: 옆힘 50 N·층간 20 MPa는 가정이다. SF 8.7이라 두 배 틀려도 2 이상.
6. **진공 관 두 줄**은 자리만 잡았다. 진공 관이 Ø8이면 묶음 등가 Ø17.6 → 외곽 Ø19, Ø40 구멍 틈 10.5로 여전히 된다.
7. 이 안은 대기 bbox와 측정 자료의 동작 결과로 낸 손판정이다. 모델링 뒤 `motion.interference`(사이클 3개·되감기, budget_s 넉넉히, truncated 확인)로 F·B·R·G·V·K·C·클램프를 다시 본다.

자료대기 제안(새 번호는 선정·문서 담당이 매김): (a) KQ2L04-M5A·TU0425 STEP·허용치(조임 토크, 최소 굽힘 반경, 사용 압력), (b) 봉제 중 매트 옆힘(기둥 굽힘 가정 50 N), (c) PET-CF 층간 강도(가정 20 MPa), (d) 우레탄 관 반복 꼬임 수명(요구서 7절).
