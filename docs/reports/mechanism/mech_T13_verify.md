## 워크플로우 메모
- `ledger.py scope --project tools`가 `AttributeError: 'str' object has no attribute 'get'`로 멈췄다(`states_for`). `tools/machine.json`이 없어 `motion_states.json`을 쓰는데, 그 `joints` 값이 사전이 아닌 설명 문자열이다(WF-086 대체 파일 형식 차이). 임시 변환본(scratchpad `machine_tmp.json`, 조인트마다 {desc, unit})을 `--machine`으로 주면 돈다. 범위는 모델링부 보고서 3-1·3-2와 지시서의 바뀐 부품 목록으로 정했다. 엔진 쪽 후보: `states_for`가 문자열 조인트를 받아들이거나, 프로젝트 `machine.json`을 만든다.
- `motion.interference {occurrences:["T13"], against:["MAT_X","MAT_Y","MAT_ROT"], samples:5}`는 "too many bodies for a contact sweep"로 거부됐다. 과제 안 검사는 `joint.drive` + `inspect.clearance`(자세당 0.04~0.15초)가 빠르다. 다만 against 이름 목록을 자세마다 다시 보내야 해 인자가 커진다.
- `document.inspect {measure:false}`도 0.8 MB를 돌려준다. 바디 이름만 필요하면 `component.list {compact, bodies}`를 시험해 볼 만하다.
