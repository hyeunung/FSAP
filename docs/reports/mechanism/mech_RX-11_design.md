식(앞 계산과 같음): have = μ·F4·d₁ + μ·F5·d₂ (μ 0.4, 40 N, d₁ 0.1) / need = 볼 구름 0.02·Rg + 원판 끌림 0.048 + 노루발 끌림 0.096 + (I_매트 + I_원판 0.0217 + **I_롤러**)·4θ/t² + **T_바퀴 밑 롤러** + **T_바퀴 밖 롤러**. 띠 항 μs 0.30·40 N·d₂는 없앴다.
