## 3. 남기는 것(문제 아님)

- 봉제 자세(J_U3_PRESSER −4~6)에서 노루발 bbox는 Z 8~86까지 바늘 둘레를 덮는다. 겨눔 선은 X · Y ≤ 3.5인 t ≥ 15(Z ≤ 25.0)에서 그 bbox에 들어간다. 노루발 · 코는 임시 형상(D-10 · D-211)이라 공기 줄기가 바늘에 닿는지 노루발에 먼저 닿는지는 모델로 정할 수 없다. 굽힘 노즐이라 실물에서 손으로 맞춘다(설계안 47행). 7절 확인 대상으로 둔다.
- RX08_B 꼬리 X 1164.5 ↔ LBRK 2.5는 X 1167에서 0.0을 잰 뒤 2.5 옮긴 계산값이다. 검도가 실물로 다시 잰다.
