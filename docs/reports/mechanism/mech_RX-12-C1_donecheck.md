# 구동 후보 RX-12-C1 완료 판정 확인(원칙 감사) — 설계안 RX-12-C1-A

## 요약

- 대상 설계안 RX-12-C1-A(+X 끝 경첩 내림식 접이 받침 U2_FLAP + 고정 혀 판), 보고서 `mech_RX-12-C1_design.md`. CAD 사용 0(읽기만, 계산은 파이썬 재실행과 손계산).
- **판정: ok = false — 고칠 것 3**(같은 설계자가 그 자리만 고친다).
  1. 긴 막대 `P_RX12C1_FLAP_BAR_L2`(가운데 Y −750)가 볼 줄 j = 4(Y −750)의 볼 7개 몸통과 겹친다(정적 간섭).
  2. 빗장을 빼면 판 −X 끝을 받칠 것이 없다. 손잡이(X 1105~1127)와 −X 끝(X 405) 사이가 722라 한 사람이 동시에 잡을 수 없다. 판(14.4 kg, 모멘트 약 50 N·m)이 자유 낙하해 −90°를 지나 :9에 부딪힌다. 멈춤 자리를 정하지 않았다.
  3. 경첩 잎 좌표가 XP 막대와 기둥 안쪽에 있다(판쪽 X 1097~1100은 막대 X 1085~1100 안, 기둥쪽 X 1110~1113은 기둥 X 1110~1150 안).
- 맞는 것: 받침 밖 넓이(재실행해도 W 0 · P 0, 엄격 W 200 mm²), 접힘 자리 · P1 비움(틈 82), 쓸림 반지름 701.1 · 빗장 블록과 1.9 mm, 관 TU0604와 Y 57 떨어짐, 로딩 자리.
- 디테일(E-02, 기록만): 경첩 SF 1.36 임시, 손 하중 가정값 — 판정에 넣지 않음.

## 1. 확인 방법

- `tools/out/mech_RX-12-C1/c1_design_final2.py`를 다시 돌렸다. 결과 `{'W': seam_as_support 0.0 (W2 114), seam_open 200.0}, {'P': 0.0, 0.0}`가 설계안과 같다.
- 회전 기하: 축 (X 1105, Z −48), 축 기준 점 (dx, dz)를 접음 방향으로 90° 돌린다. 식은 X' = 1105 − dz, Z' = −48 + dx(접음 끝). 지나는 동안 X = 1105 + r cos θ이다.
- 볼 형상: 서명 `STEP대기_BALL_D25_M04` bbox Ø44 × Z −30~0, 부피 26,641 mm³(판 밑 몸통이 남는다).

## 2. 항목별

| 완료 판정 | 다시 계산 | 판정 |
|---|---|---|
| ① RX-12 매트(와 MAT_P) 전 구간 받침 밖 넓이 0 | 재실행 결과 W 0 · P 0이다(이음 틈 ≤ 5를 받침으로 침). 엄격 값은 W 200 mm²(E2–혀 틈 2 × 100)이다. 매트 두께 10에 틈 5 이하는 외팔이 아니라 이음이므로, 7절로 넘길 근거로 받아들인다. 포켓 안 매트 끝 X 1032.6 · Y −1152.7은 받침 X 1100 · Y −1200 안이다. 넓이 계산은 RX-12 판정 기준(패널)과 같다 | 맞음(넓이). 다만 받침 판이 정적 간섭 없이 서야 성립한다 → 문제 1 |
| ② 로딩 자리·작업자 접근 유지 | 로딩 X ≤ 6.5 · Y −300은 포켓 밖이다. 접힘 판은 X 1057~1100(볼 꼭대기 dz 48 → X 1057)이고 P1(X ≤ 975)과 82 떨어진다. 빗장 블록 X 400~402는 Z −165~−20, Y 띠 2곳이다. **그러나 접음 순서가 한 사람 손으로 되지 않는다**: 순서는 "빗장 +18 뺌 → −X 끝을 손으로 받치고 내림"이다. 빗장을 빼는 손잡이 A(X 1127, Y −412)는 기계 +X 옆(X ≥ 1150)에서만 닿는다. 거기서 −X 끝(X 405)까지 745다. 빼는 순간 −X 끝 받침이 0이고, 141 N × 0.353 m = 50 N·m가 판을 돌려 떨어뜨린다(위치 에너지 약 50 J). −90°에서 판은 최대 속도다. 멈춤이 없어 계속 돈다. 바 면(X 1100)이 :9(X 1110, Z −250~−330)에 닿는 각은 반지름 약 202에서 틈 10이다. 약 −93°에서 부딪힌다. 펼 때도 같다: 들어 올린 판 −X 끝(X 405, Z −8)을 받친 채 +X 옆의 빗장을 꽂을 수 없다 | **안 맞음 → 문제 2** |
| ③ 기존 매트 연구 과제 범위 간섭 0 | 폄 자리는 E1과 5, E2와 5, 혀와 1 떨어진다. 쓸림: 판 모서리 (405, −8)은 r 701.1이고 θ 180°에서 X 403.9 · Z −48이다. 빗장 블록 X ≤ 402와 1.9(간섭 0). 막대 XN 아래 모서리 r 700.0. 빼낸 빗장 끝 (410, −28)은 r 695.3 → X 409.7. 빼낸 손잡이 (dx 18, dz −20~−28)는 지나는 동안 X ≤ 1139이고 Y −412/−1088이다. 기둥 Y 띠(−345~−265, −1215~−1135) 밖이다. 관 TU0604(Y ≥ −248)는 판(Y ≤ −305)과 Y로 57 떨어진다. **그러나 새 바디끼리 정적 간섭이 있다**: 볼 줄 Y = −350 − 100j는 j = 4에서 −750이다. 긴 막대 L2는 Y −755~−745 · Z −43~−13 · X 423~1085다. 볼 몸통(Z −30~−13, 판 밑)은 X 450~1050의 7곳에서 같은 Y 중심으로 막대를 지난다. L1(−400)과 L3(−1100)은 볼 줄 사이(가장 가까운 볼 가장자리와 23)라 문제없다. 경첩 잎: 판쪽 X 1097~1100은 XP 막대 X 1085~1100 안이고, 기둥쪽 X 1110~1113은 기둥 X 1110~1150 안이다(지시서대로 그리면 겹친다) | **안 맞음 → 문제 1·3** |

## 3. 고칠 자리

| # | 무엇 | 고칠 자리(치수) |
|---|---|---|
| 1 | L2–볼 줄 j = 4 겹침(볼 7개) | 7-1 `P_RX12C1_FLAP_BAR_L2` 가운데를 Y −750에서 **Y −800**으로 옮긴다(막대 Y −805~−795, 볼 Y −750 · −850 가장자리 −772 · −828과 23씩). 경간은 400 · 300이 된다. 판 처짐 0.054 × (400/350)⁴ ≈ 0.09 mm로 다시 적는다. 판 막대 구멍 4개도 같은 Y로 옮긴다 |
| 2 | 빗장을 빼면 판이 자유 낙하하고 멈춤이 없다. 한 사람이 −X 끝을 받치며 빗장을 뺄 수 없다(손 거리 722~745) | (a) **멈춤**: J_U2_FLAP 범위 끝 −90°에 맞닿는 멈춤 자리를 정한다. 예: :9 −X 면 X 1110 · Z −290 근처에 고무 멈춤을 두고, 접힘 판 XP 막대 면 X 1100과 맞춘다. 이 자리를 7-2와 machine.json 범위에 넣는다. (b) **내림 속도**: 빗장이 빠진 뒤에도 판이 손 없이 떨어지지 않는 수단을 정한다. 예: 경첩에 회전 댐퍼나 가스 스프링(지금 디테일 RX12C1-D2 → 구동으로)을 두되, 모멘트 50 N·m 안팎을 받는 값으로 한다. 또는 빗장 손잡이를 −X 끝 앞 모서리(X 405~425 · Y −1200 쪽)로 옮겨, 같은 손 자리에서 판을 받치며 빼게 한다. 어느 쪽이든 2절 순서 문장("빗장 뺌 → 받치고 내림")을 그 수단대로 고친다 |
| 3 | 경첩 잎이 막대·기둥 안에 있음 | 7-1 경첩 간이 형상: 판쪽 잎 **X 1100~1103**(XP +X 면에 붙음), 기둥쪽 잎 **X 1107~1110**(기둥 −X 면에 붙음), 축통 Ø10 중심 X 1105. 쓸림 재계산은 필요 없다(잎 dz 범위 그대로) |

## 4. 디테일(E-02, 판정에 넣지 않음)

- 경첩 임시 허용 150 N/개에 대해 SF 1.36이다(손 기댐 가정 300 N). 실물 형번이 나오면 다시 계산한다(RX12C1-D1).
- 쓸림 중 판 모서리와 빗장 블록의 틈은 1.9 mm다. 판 공차와 경첩 유격이 쌓이면 줄어든다. 블록 +X 면 모서리 모따기는 디테일(RX12C1-D3 옆에 기록).

## 5. 임시값

D-96(볼), D-01·D-02·D-03(MAT_W), D-213(MAT_P), D-106(로딩), D-04(이음 틈 ≤ 5를 받침으로 치는 근거), 손 하중 가정 300 N · 100 N, 경첩 150 N/개(임시). 새 임시값 없음.
