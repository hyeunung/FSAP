# 해석부 — M07-K1 받침틀 브래킷 교체(M5, 렌치 길) — v2.5.3

**요약**
- 대상: 판금 L SUS304 t6 149개(S 60·T 9·C 80) + CB5-16 298 + HNTT8-5 298(저장본 v2.5.3, 모델링부 보고 `mech_M07-K1_model.md`). 해석 못 함 — 환경 없음(자료대기 D-16) → 손계산만.
- **해석 모델 바꿈(이유)**: 모델링부 손계산은 다리를 볼트 머리 가장자리에서 고정한 외팔(팔 = 구멍 − 4.25, 응력 집중 없음)이었다. 실제로는 다른 다리가 형재 면에 눌려 굽힘 구석 쪽이 고정단이고 최대 굽힘이 굽힘 R 자리에 온다 → 굽힘 구석(t + R = 12) 고정 + 곡률보 Kt 1.3. 옛 모델도 같은 형상으로 풀어 남김(T형 옛 2.32 ↔ 새 **2.27**).
- **새로 본 하중 경우**: M04 가로대 끝 XB 16 + M04R 6은 가로대 무게가 브래킷으로만 간다(모델링부는 옆힘 286 N만 봄). CM1 끝 반력 473.8 N(자중 ×3 g + 손 100 N) → 편심 굽힘 SF **2.60**·비틀림 **2.62**, 볼트 지렛대 948 N에서 나사 인장 16.5·분리 4.2.
- 최소 SF **2.27**(T형 YM 9개, 오조작 옆힘) ≥ 2(M-09). 전부 통과. 동작 문제 0.
- 물림 7.5 = 1.5d(저장본 측정, 모델링부), 조임 암나사 전단 1.62 ≥ 1.0, 좌면 SF 3.3.
- 디테일(기록만): ① T형 SF 2.27이 기준 +13.5%로 FEA 권장(두께/길이 ≥ 0.1, 환경 생기면 T형 STEP 고체 FEA). ② 가로대 끝은 마찰만 보면 SF 1.27 — 하중이 홈과 수직이라 T너트 목이 형상으로 받지만, T너트 목·홈 턱 허용 하중은 카탈로그 값 없음(D-54). ③ S·C형 과사양(SF 7.2·26.5, 옆힘).
- 미완: 없음. 산출: `fea/cases/mech_M07-K1_fea1_handcalc.py`, `fea/results/mech_M07-K1_fea1_handcalc.json`, `fea/models.json` 2행 추가.

## 1. 일의 크기(E-18)

규칙 E-18 원문 "체결만 바뀐 자리는 손계산, FEA는 형상·하중 경로가 바뀐 부품만, 완료 판정에 강도 항목이 있으면 등급 S도 FEA". 판금 L은 새 형상이고 완료 판정에 '손계산 SF ≥ 2(M-09)'가 있어 FEA 대상이지만, 엔진 해석 환경(engine/fea/.venv)이 이 컴퓨터에 없어 **해석 못 함 — 환경 없음(D-16)**. 지시대로 설치하지 않고 손계산(`handcalc.py` 보·체결)으로 판정. 같은 형상은 묶어 가장 불리한 것만(E-19): 옆힘은 팔이 가장 긴 T형, 수직 하중은 반력이 가장 큰 CM1 끝.

## 4. 문제·디테일(E-02 기록만)

- 동작 문제: 0.
- 디테일 M07K-F1: T형 YM 9개 SF 2.27(기준 +13.5%). 두께/길이 ≥ 0.1이라 `handcalc.py beam`이 needs_fea. 환경이 생기면 `tools/out/mech_M07-K1/stepout/P_M07_LBRKT_PX_PZ.step` 고체 FEA(굽힘 R 자리 두께 방향 2요소). 고칠 안이 필요하면 다리 A 폭 30 → 40(SF 3.0) 또는 굽힘 구석 리브 하나.
- 디테일 M07K-F2: 가로대 끝(XB 16·M04R 6) 수직 하중은 T너트 목–홈 턱 형상 물림이 받는다. 마찰만이면 SF 1.27. 미스미 HNTT8-5·8 시리즈 홈 턱 허용 하중 확인(D-54 '쓰는 곳'에 M07-K1 더할 것).
- 디테일 M07K-F3(과사양 note, M-09): S·C형 옆힘 SF 7.2·26.5. 두께는 판금 규칙·구멍 자리로 정해 다운사이징은 하지 않음(모델링부 M07K-D2와 같은 내용).
- 해석 못 함 — 환경 없음(D-16): 임시 STEP 4개는 해석용(E-06 예외). `P_M04_LBRKT_PY_PZ.step`은 첫 저장 T형이라 지금 C형과 다름 — C형은 `P_M07_LBRKC_PZ_PX.step`과 같은 단면으로 판정.
