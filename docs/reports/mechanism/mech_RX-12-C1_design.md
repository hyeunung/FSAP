# 구동 후보 RX-12-C1 설계안 — +X·−Y 포켓 위 접이 매트 받침(U2_FLAP)

## 요약

- 대상 `3D_Modeling/FSAP_v2.25.0.sc`(측정과 같은 앱 세션, MCP `view.pick` 광선 101개만 — 편집·자세 변경 0, 저장 0).
- **방식: +X 끝 경첩 접이 받침(내림식).** 포켓 위 X 405~1100 · Y −1200~−305에 볼 판(A5052 t5 + 볼 63, 피치 100, 볼 꼭대기 Z 0)을 두고, +X 끝(X 1105 · Z −48)의 경첩 2개로 아래로 90° 접는다. 접으면 X 1057~1127 · Z −748~−30에 세로로 걸려 **P1 서는 자리(X 400~975) 전체가 비고**(틈 82), 펴면 −X 끝을 빗장 막대 2개(SUS303 Ø8)가 테이블 틀 쪽 고정 블록에 꽂혀 받친다. 손잡이는 +X 끝(기계 +X 옆에서 닿음).
- 고정 혀 판 `P_RX12C1_TAB_PL`(A5052 t8, X 976~1150 · Y −300~−200, 볼 1)이 E2 패널이 없는 모서리를 받친다. 경첩 기둥 2개(HFS8-4080 234·200, :9 윗면) 중 +Y 기둥이 혀 판도 받친다.
- **받침 밖 넓이(포켓 X > 400 · Y < −200, 이음 틈 ≤ 5 mm는 받침으로 침): MAT_W 323,536 → 0 mm², MAT_P 39,904 → 0 mm²**(210·122단계 전부, `tools/out/mech_RX-12-C1/c1_design_final2.py` → `c1_design_final.json`). 이음 틈까지 뺀 엄격 값은 W 200 mm²(E2–혀 판 틈 X 975~977, 실물은 1 mm로 둬서 100 mm²) · P 0.
- 새 조인트 3: `J_U2_FLAP`(회전 Y축, 0 = 폄 · −90° = 접음), `J_U2_FLAP_LATCH_A/B`(미끄럼 X, 0 = 꽂음 · +18 = 뺌). 새 상태 "정비: 북 교체(받침 접음)".
- 부품 +144(가공 15 · 구매 129), 바디 증가 같음. 움직이는 질량 약 14.4 kg, 손 들기 힘 약 71 N.
- 손계산: 막대 손 300 N σ 34.5 MPa(SF 5.6), 판 처짐 자중 0.05 mm, 빗장 막대 SF 11.7, 경첩 임시 허용 150 N/개에 대해 SF 1.36(손 기댐) · 4.3(자중). FEA 못 함(환경 없음 D-16) — 등급 L이지만 이 과제 판정은 동작·간섭(E-02)이고 강도는 디테일로 기록.
- 미완: 경첩 `HHPSN8`·볼 D-96은 STEP대기 임시(provisional). 손잡이 빗장 잠금·볼트 렌치 길·판 이음 마감은 디테일(RX12C1-D1~D6).

## 1. 출발점(basis)

벤치마크 없음 — 요구서 0-8-3 U2 '새로 하는 것'(바늘 옆 원판 자리·테이프 길 자리 외에 v2.1 RX-12에서 드러난 +X 넘어감 받침). R375X 사진에는 작업자 쪽 포켓이 없다(테이블이 넓음). 볼·피치·판 높이는 M04/M04R 볼 테이블(C-31: 피치 100, 볼 꼭대기 Z 0, 판 Z −12~−8)을 그대로 옮긴다. 접는 이유는 DC2-03 P1(DC203-R1 "서는 자리 P1 … 바닥틀을 비운다")을 지키기 위해서다.
