## 워크플로우 메모

- regrun 시험은 파일 열기가 호출 상한 절반에 가까운 파일(230 s / 480 s)에서 trial_limit 기본 120 s로는 첫 단계(모든 쌍 처음 계산 34 s 이상)를 못 넘긴다. 실행기가 open_s를 알면 시험 단계 수를 자동으로 줄이거나, 열기가 상한 절반을 넘으면 경고해야 한다.
- regrun이 시간 초과 묶음을 죽일 때 Windows에서 손자 프로세스(solidcraft-cli)가 남는다(프로세스 트리째 죽이지 않음). 이번에 2.5 GB짜리 남은 프로세스 6개를 손으로 지웠다.
- SolidCraft 저장 캐시가 바디 하나 때문에 통째로 거부되면 매 CLI 열기가 피처 전부를 다시 계산한다(227 s). 안내서 '연결' 열기 실측 표에 "캐시 거부 시"를 더하고, 저장 확인에 `bench-open`의 `refused`를 보게 하면 좋다.
- 관(Pipe) 바디가 끼면 `inspect.clearance` 한 자세가 수십~수백 초로 늘었다.
