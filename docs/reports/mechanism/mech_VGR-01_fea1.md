# VGR-01 해석부 수정 1회차 검산 — CYCLE_V 시간 키 (2026-11-10, 기준 FSAP_v2.8.5.sc)

## 요약
- 바뀐 부품 0. v2.8.5는 형상·부품·조인트·연구가 v2.8.4와 같고(mech_VGR-01_model1.md, 2,763바디 차 0), `tools/machine.json` `_timing.CYCLE_V` 시간 키만 바뀌었다. 해석 모델은 그대로 두었다. 바뀐 것은 시간 출처를 machine.json에서 직접 읽게 한 것뿐이다. FEA는 하지 않았다(해석 못 함, 환경 없음 D-16). 이 계산은 마찰·관성 계산이라 FEA 대상도 아니다.
- 지난 해석(mech_VGR-01_fea.md)의 동작 문제 1건(U5 밑 PTFE 띠 미끄럼이 셈에 빠져 U4+U5 SF 0.70~0.99)은 **고쳐졌다**. 새 키에서 띠 μs 0.30에 원판 끌림까지 넣어도 최저 SF는 **1.009**(입구1 m2 피벗 4.1 s)다.
- 완료 판정 조건(구름 0.02·μ 0.4·U4 40 N·가속 포함)에서 **U4 혼자** 구간의 SF는 꼭짓점 −35→−50 3.5 s 1.056, −50→−75 4.5 s 1.054(U4 혼자 합 8.0 s ≥ 6), 입구2 −75→−30 9.5 s **1.045**(≥ 6 s)다. **U4+U5** 최저는 2.628이다(띠·원판을 빼면 2.673).
- 지난 디테일(원판 끌림을 넣으면 입구2 9.0 s SF 0.997)도 고쳐졌다. 9.5 s에서 1.012다(필요 최소 9.10 s).
- 실제 각가속도는 machine.json `_timing.한계`(원판 끌림 포함) 안이다. 꼭짓점 0.0862 ≤ 0.0933 rad/s², 입구2 0.0348 ≤ 0.0379 rad/s².
- 새 하중 부품 `P_M02_WHEEL_U4_drive`는 접선 16 N·0.96 N·m로, 기존 P_M02_WHEEL 모델(3.5 N·m·58.3 N) 안이다. 새 강도 계산은 필요 없다.
- 동작 문제 0, 디테일 0. 이 부서 몫의 완료 판정 항목(회전 SF 둘)은 충족했다. 간섭·반대 벽 틈은 검도가 v2.8.4에서 0·≥ 5.7로 쟀고 형상이 같다. 테이프 처리 방법은 결정로그에, 요구서 ③은 고쳐 적혀 있다.
- 미완: 구름 0.02(D-96)와 띠 μs(D-97)의 실측은 7절 저울 시험으로 남는다. 구름이 0.05면 U4 혼자 SF가 0.46~0.50이므로 D-96 선정 조건이 꼭 필요하다.
