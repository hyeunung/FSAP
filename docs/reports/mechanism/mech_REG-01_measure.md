## 3. 비어 있는 공간·작업 대상

- KDM 소켓 둘레의 빈 공간: 아래 −Z 쪽 롤러 윗면 Z 614까지 HGT 0에서 9.34(−4에서 5.42). +X 쪽은 플러그(같은 유닛). −X 쪽은 관 6줄이 맞닿음. 이 과제는 형상을 바꾸지 않으므로 통로 프로브는 더 재지 않았다.
- 작업 대상(매트 L·S·G, 테이프, 이음매)은 Z 0~12에서 움직인다. KDM(Z ≥ 619)과 600 mm 넘게 떨어져 이 과제와 상관없다. 떨어진 조각 없음.

## 4. 같은 실수를 막기 위한 기록

- WF-123: 조각을 더 쪼개는 방법은 쓰지 않았다. 느렸던 것은 조각 크기가 아니라 관↔소켓 같은 평면 맞닿음 쌍 하나였다(지난 라운드 heavy_pieces 86·87·88·90 = TU0604_M08K_U7_1·2·3·5가 든 조각).
- DC2-08 수정 1: 관 끝 = 소켓 면 X 11.7 같은 평면이라 불리언이 느리다(65분·6.4 GB 미완). 검사 사본에서 0.02 옮겨야 끝난다.
- `joint.drive J_U7_HGT`는 값을 바꿀 때마다 앱에서 62~73 s 걸린다. HGT를 여러 번 바꾸는 묶음은 앱을 5분 넘게 붙잡는다. 같은 HGT 상태끼리 묶어 바꾸는 수를 줄인다(이번 순서: 0 → −4(24·33) → +6(25·34) → 0(26~32)).
- 다음 회귀 제안(구상·회귀 담당): `TU0604_M08K_U7_1~6 ↔ KDM10S-06_M08`을 machine.json `baseline_overlaps`(의도된 맞닿음, M-08)에 올리고 이 문서의 프로브 결과를 근거로 적는다. 그러면 regrun이 이 쌍을 빼고 돌아 U7@26이 다시 못 본 범위로 남지 않는다. 형상 쪽 해법(관 끝을 X 11.68로 0.02 줄이기)은 형상 변경이라 이 과제의 완료 판정 '형상 변경 0'에 어긋나므로 하지 않았다.
