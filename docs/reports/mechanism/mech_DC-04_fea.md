# DC-04 해석부 — 카세트 인출 안내(P_DC04_HANGER·P_DC04_CARRIER) 강도 (v1.0.5)

요약(10줄 안쪽)
- 대상: 새로 힘을 받는 부품 `P_DC04_HANGER`(SUS304 t3), `P_DC04_CARRIER`(SUS304 t4)와 새 체결 CB5-12 ×3·레일 M3·플런저 핀이다. 기존 부품은 보지 않았다.
- 해석 못 함 — 환경 없음(D-16). 대신 손계산으로 했다(`fea/cases/mech_DC-04_handcalc.py` → `fea/results/mech_DC-04_handcalc.json`, 엔진 handcalc import).
- 하중(D-83 임시): 3.3 kg. 운전은 ×3 g = 97.1 N, 오조작은 손 100 N + 1 g = 132.4 N(인출 511, 카세트 +Y 끝)이다.
- 운전 최소 SF는 CB5-12 분리(예압/외력) 4.34다(기준 3). 오조작 최소 SF는 레일 M3 암나사 전단 2.51이다(기준 2).
- 오조작에서 볼트 분리는 2.63, 다리 굽힘은 2.65, 플랜지는 2.89다. 기준 ±10 % 안에 드는 값은 없다. 그래서 FEA로 판정이 갈리지 않는다.
- 카세트 내려앉음은 운전 0.10 mm, 오조작 0.22 mm다. 밑 틈 4(U6) 안이고, 위 틈 1.0(UPPER)은 오히려 커진다.
- 동작 문제는 0이다. 디테일은 2건이다. 하나는 끝 탭 충돌 참고 사례(완충 없이 0.5 m/s면 SF 0.95)다. 다른 하나는 레일 M3 물림 3 < 1.5d로, 이미 있는 DC-04-D1이다.
- 완료 판정(정비 길 간섭 0, 손 닿는 거리 ≤ 600)에는 강도 항목이 없다. 모델링부 수치(mech_DC-04_model.md 4절, 카세트 498·가마 474 ≤ D-82 600)로 충족된다.
- 해석 모델 표 `fea/models.json`에 두 부품을 더했다. 기존 모델을 바꾼 것은 없다.

## 1. 일의 크기(E-18)
E-18 원문: "체결만 바뀐 자리는 손계산, FEA는 형상·하중 경로가 바뀐 부품만". 두 부품은 새 형상이고 하중 경로도 새로 생겼다. 그래서 원래는 FEA 대상이다. 하지만 해석 환경이 없다(D-16). 두 부품 모두 t/L < 0.1인 얇은 판이라 `handcalc.beam`을 먼저 썼다. 지시문은 "기준 ±10% 안이거나 보로 볼 수 없는 형상일 때만 고체 FEA"라고 한다.
- 플랜지 굽힘 구간(팔 6, t/L 0.5)은 보로 보기 짧아 needs_fea가 표시된다. 다만 SF 2.89는 기준 2의 +45 %라 판정이 갈리지 않는다. 환경이 생기면 `tools/out/mech_DC-04/stepout/P_DC04_HANGER.step`으로 확인만 하면 된다.
- 같은 것은 묶었다(E-19): CB5-12 3개 중 가장 불리한 것 하나(인출 511에서 X 480)가 하중을 전부 받는다고 봤다.

## 2. 모델(경계조건, fea/models.json)
| 부품 | 고정 | 하중 |

하중 출처:
- 질량 3.3 kg·손 100 N·봉제 반력 50 N은 D-83 임시값이다.
- 자중 ×3 g은 지시문을 따랐다.
- 판정 기준은 요구서 6-1(비었음)이라 M-09 기본값을 썼다(운전 SF 3, 오조작 SF 2). SUS304 Rp0.2는 205다.
- 867 UPPER 모재는 미정이다(D-10). 그래서 암나사는 A5052로 보수적으로 봤다. SS400으로 봐도 결과가 같다(최소값은 분리 쪽에서 나온다).

## 4. 문제
| kind | 무엇 | 어디 | 수치 | 고치는 방법 |
|---|---|---|---|---|
| 디테일 | 카세트를 세게 당겨 끝 탭에 부딪치면 탭이 휠 수 있다 | P_DC04_HANGER 끝 탭 X 531~534 · Y −75~−49 · Z 64~92 | 완충 없음, 0.5 m/s, 멈춤 1 mm(가정)이면 412 N, SF 0.95 | 캐리어 +X 면이나 탭에 우레탄 완충(행정 3이면 약 275 N, SF 약 1.4)을 단다. 또는 탭을 겹접기(t6 상당)로 바꾸고 D-83에 당김 속도를 더한다 |
| 디테일 | 레일 M3 물림 3 < 1.5d 4.5(이미 DC-04-D1) | 다리 t3 | 강도 SF는 2.51로 충족하지만, 규칙 M-01(물림 ≥ 1.5d)은 미달이다 | 너트로 받거나 판 두께를 늘린다(DC-04-D1 그대로) |

동작 문제(부러짐·영구 변형 SF < 1.2·동작을 망가뜨리는 처짐)는 0이다. 충돌 사례는 정해진 하중 목록(액추에이터 추력·작업 저항·자중 ×3 g·D-83 손 100 N) 밖의 가정이라 동작 문제로 세지 않았다. 판정 근거로 쓰지도 않았다.

## 5. 완료 판정
- "+X 정비 면에서 카세트 인출 길·가마 꺼내는 길 과제 범위 간섭 0": 모델링부 4-1·4-2 결과는 MAINT·511에서 0이다. 이 부서는 CAD를 쓰지 않으므로 다시 재지 않았다.
- "정비 자세 손 닿는 거리 ≤ 임시 기준(D-82 600)": 카세트 498·가마 474·플런저 572로 충족한다.
- 강도 항목은 완료 판정에 없다. 위 손계산 결과도 기준을 충족한다. → completion_met true.

## 6. 자료대기
- D-16: 해석 못 함 — 환경 없음. 환경이 생기면 `stepout/P_DC04_HANGER.step`으로 플랜지·다리 고체 FEA를 돌려 확인만 한다(판정이 갈리지 않음).
- D-83: 블록 정적 모멘트 MC를 20 N·m 임시로 뒀고, 조임 토크도 4 N·m 임시다. 카세트 당김 속도(충돌)는 값이 없다 → 받으면 이 스크립트를 다시 돌린다.
- D-10: 867 UPPER 모재·탭 자리.

## 워크플로우 메모
- 지시문 하중 목록(추력·작업 저항·자중 ×3 g)에 손으로 움직이는 부품의 끝 멈춤 충돌이 빠져 있다. 손 인출 부품은 충돌 하중 사례를 기본으로 넣는 편이 좋다.
- handcalc `calc`는 물림 비율 < 1.5d이면 SF가 충분해도 ok false를 낸다. 그래서 이미 디테일로 올라간 M-01 항목과 강도 판정이 섞여 보인다.
