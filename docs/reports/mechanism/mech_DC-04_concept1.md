## 1. 근거 규칙
- E-02 "구동부 → 브래킷 → 디테일": 강도 여유·볼트·판금 규칙은 기록만.
- 요구서 2-3 "바늘·노루발·바인더·테이프 롤처럼 자주 바꾸는 것은 브래킷을 떼지 않고 바꾼다" → 카세트·가마 모두 브래킷을 떼지 않는다.
- M-02 "한 부품을 정비하려고 관계없는 부품을 떼야 하면 결함이다" → 가마 정비에 LINK·서보를 떼지 않게 묶음째 뺀다.
- 0-8-2 ⑤ "툴 카세트는 위치 결정 핀 + 원터치 클램프로 붙는다" → 카세트는 핀 2 + 걸쇠.
- N01-S01 "매트 띠(Z 0~11)에는 바늘만 둔다… Z ≥ 12" → 새 부품 모두 Z ≥ 92 또는 Z ≤ −60.
- DC-05-S03·측정 4절 "구동 자리를 다시 옮기지 않는다" → 서보 자리는 그대로, 정비 때만 묶음째 미끄러진다(운전 위치 불변).
- 실행 규칙 14 "정비 문은 구동 과제로 만들지 않는다" → 문·가드 없음.
- 실행 규칙 6 → 모르는 값은 D-82 임시값(9절).

## 6. 하중 손계산(E-18, 새로 만든 것만)
- 카세트 질량 3 kg 임시(D-82) → W 29.4 N.
  - 받침판 P_DC04_CAR 외팔(블록 중심 X 50 → 카세트 중심 X 0, L 50), 단면은 판 자체 폭 24 × t4(최소 단면).

    - σ = M·2/I = 23.0 MPa, SPCC 항복 205 → SF 8.9
    - δ = W·L³/(3EI) = 29.4·125,000/(3·206,000·128) = 0.046 mm
  - 블록 SSEB13: 정정격 C0 6 kN(임시) vs 29.4 N → SF 204. 피치 모멘트 1.47 N·m vs 허용 임시 15 N·m → SF 10.
  - 손 인출력: 블록 저항 ≈ μ 0.005·29.4 + 실 저항 ≈ 5 N 미만(임시).
- 아랫유닛 묶음 질량 23.9 kg 임시(LOWER 10 임시 + LINK 704,320 mm³ × 7.85 = 5.53 + STAND 4 + 서보 1.2 + 판 220×160×10 × 7.85 = 2.76 + 끝판 0.1 ≈ 23.6, 23.9로 둠) → W 234 N. 무게중심 X 278(대기).
  - 블록 중심 468·527(간격 59). 무게중심이 −X 밖이라 앞 블록은 당김.
    - 대기: R 앞 = 234·(468−278)/59 = 754 N(당김), R 뒤 = 988 N

    - 레일 2줄로 나누면 블록당 최대 494 N vs C0 14 kN(임시) → SF 28
  - 레일은 바닥틀 안(X 435~975)에만 있어 외팔 없음.
