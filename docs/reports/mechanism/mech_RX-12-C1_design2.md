# 구동 후보 RX-12-C1 설계안 수정 2회차 — 접이 매트 받침(U2_FLAP)

## 요약

- 같은 안이다(+X 끝 경첩 내림식 접이 받침, `mech_RX-12-C1_design.md`·`_design1.md`). 지적된 곳 하나만 고쳤다. 0° 폄 자리를 무엇이 정하는지가 문제였다.
- 고친 것 ①: **0°는 경첩 쪽 올림 멈춤이 정한다.** 판 쪽 혀 `P_RX12C1_UPSTOP_TONGUE`를 XP +X 면에 단다(팔 X 1106~1135 · Y −1132~−1108 · Z −23~−13). 그 밑 기둥 B +Y 면에 멈춤 블록 `P_RX12C1_UPSTOP_BLK`(X 1118~1145 · Y −1135~−1108 · Z −80~−40)를 두고, 블록에 조절 멈춤 나사 CB6-20을 세운다(머리 윗면 Z −23, 축에서 팔 23).
- 고친 것 ②: 가스 스프링은 늘어난 눈 중심 간 **325**짜리(`STEP대기_GASSPRING_F1120_S60_L325`)로 바꿨다. 자리(P (1055, −48) · A (1073, −368))는 그대로다. 0°에서 길이 320.51은 완전 신장보다 **4.49 짧다**. 길이 공차 ±2에서도 2.49~6.49 짧아서, 스프링 내부 멈춤이 0°를 정하는 일은 없다.
- 고친 것 ③: 빗장 A·B는 멈춤에 놓인 판을 잠그기만 한다(위아래 하중을 받는 자리가 아니다).
- 핵심 수치(명목 F1 1,120 N): 0° 순 올림 모멘트는 +7.39 N·m이고, 멈춤 나사가 받는 힘은 **321 N**이다(공차 끝 73~597 N). 0~−75°에서 가장 큰 순 모멘트는 13.9 N·m라 손 힘은 35 N 이하다. −90°에서 −8.34 N·m로 POM 멈춤에 놓인다. 가장 짧은 길이 271.6은 허용 하한 265보다 길다.
- 받침 밖 넓이(W 0 · P 0 mm²), P1 비움, 1회차의 나머지 수치는 바뀌지 않았다. 부품 수는 이번에 +9다(가공 2, 구매 7. 가스 스프링은 바꿔 끼워 0). 누계는 +181이다.
- 미완: SolidCraft 앱이 켜져 있지 않아(127.0.0.1:27878 연결 시간 초과) 자리 확인은 서명 bbox(v2.25.0, 3,372부품)와 손계산으로 했다. 가스 스프링은 아직 임시(provisional)다.

## 3. 자리 확인(feasibility)

`mcp__solidcraft__running` 호출 결과는 "no SolidCraft app is listening at 127.0.0.1:27878 (connection timed out)"이었다. 이 부서는 읽기 부서라 앱을 켜지 않았다. 새 자리는 측정 서명 `tools/out/signatures.json`(v2.25.0 REST, 3,372부품 bbox)으로 확인했다.

|---|---|---|
| 혀(플랜지 + 팔) | 1100~1135 · −1132~−1108 · −43~−13 | 없음 |

혀의 접힘 쓸림(축 (1105, −48)에 대한 상대 좌표) 계산은 이렇다.

- 팔 점은 dz 25~35, 반지름 25~46이다. 내리는 쪽(반시계)으로 돌면 처음 속도 방향이 (−dz, dx)여서 −X와 위로 간다. 그래서 0°에서 바로 나사 머리를 떠난다.
- 0 → −90° 동안 dz는 처음 값보다 작아지지 않는다. −90°에서 팔은 X 1070~1080 · Z −48~−13에 온다.
- 플랜지는 dx −5~+1이라 처음부터 기둥 B에서 멀어진다.

가스 스프링 쪽(Y −1235)과 POM 멈춤(Y −400·−1100, Z ≤ −260)은 1회차 그대로다. 멈춤 블록과 POM 멈춤 B(Y −1125~−1075, X 1095~1110, Z −330~−255)는 Z로 175 떨어진다.

볼트 렌치 길(새 볼트)은 다음과 같다.

- 혀 → XP CB5-12 2개: +X에서 조인다. 판을 접으면 −90°에서 X 1080 근처로 오고, 둘레가 열린다.
- 블록 → 기둥 B CB5-16 2개: +Y에서 L렌치로 조인다. Z −62·−74이고, L3 막대 바닥 Z −43과 14 떨어진다. 긴 팔은 아래 Z −250까지 비어 있다.
- 멈춤 나사 CB6-20: 판을 접으면 위가 열려 5 mm 육각 렌치로 돌린다.

## 4. 작업 대상

판 윗면·볼·막대는 바뀌지 않았다. 바뀐 것은 0°의 정확도뿐이다. 이제 0°는 멈춤 나사로 맞춘 자리다. 빗장 틈 0.3이 r 700에서 만드는 기울기는 ±0.15 mm 이하라, 볼 꼭대기 Z 0이 유지된다. 받침 밖 넓이는 MAT_W 0 · MAT_P 0 mm²로 그대로다(이음 틈 ≤ 5는 받침으로 침, `c1_design_final.json`. 엄격 값은 W 200 · P 0). 새 부품은 X ≥ 1100 · Z ≤ −13이고, 매트 자리 X ≤ 1040 · Z ≥ 0과 만나지 않는다. 로딩 자리(D-106)와 P1(X 400~975)은 그대로다.
