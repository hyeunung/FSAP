## 워크플로우 메모

- `solid.fillet`의 두 번째 모서리 점이 MAT_Y 이동량(−700)만큼 어긋난 좌표로 거부됐다(첫 번째는 됨). 굽힘 R은 스케치 호(`sketch.arc.center_point`)로 그려 피했다.
- STEP으로 넣은 볼나사의 축 바디는 `selection.delete`(이름 `Cut-Extrude1`)와 `component.delete`(하위 SHAFT)로 지워지지 않고 남아, 다음 볼트 STEP의 같은 이름 바디와 섞여 `body.rename`이 엉뚱한 바디를 바꿨다. 고유 이름으로 먼저 바꾼 뒤 `selection.delete`하면 지워진다.
- 같은 STEP 안 같은 하위 부품이 두 번 놓이면(BSW 칼라, 커플링 볼트) 바디 이름이 공유돼 두 번째는 경로 이름(`BSW15_c (T18_Y:1/BSW15:1/BSW15_c:2)`)으로만 잡힌다.
- 여러 하위 부품이 있는 STEP을 컴포넌트 안에 넣으면 내부 리지드 묶음이 floating으로 나온다. 넣은 뒤 상위 컴포넌트와 리지드로 묶어야 한다.
- 원통으로 축을 가로질러 자르면 바디가 나뉘어 `(1)`·`(2)`가 생긴다. `solid.combine`으로 다시 합쳤다.
- `eval --json-out`은 측정만 남겨 간섭 결과가 없다(안내서대로 `run --results`). 처음 돌린 5개 동작 검사를 다시 돌렸다.
- MCP batch 응답이 볼트 STEP 하나에 수십 줄이라 126단계 batch 응답이 매우 길다.
