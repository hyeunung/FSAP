# 기구설계부 — M02 U4 바늘 옆 바퀴 설계안 (2026-11-04)

요약
- 설계안 1개(E-02 WF-176). 출발점은 R375X 사진의 바늘 옆 바퀴 묶음이다: 서보 → 인라인 유성 감속기 → 세운 판(출력) → 외팔 고무 바퀴, 핀 스윙 암, 세로 공압 실린더, 바퀴 밑 자유 회전 원판.
- 바뀌는 부품: U4 차지 상자 6개(MOUNT·HOLDER·DRIVE·WHEEL_TIRE·DISK·DISK_BRG)를 지우고 가공품 12개 + 구매품 묶음으로 바꾼다. 새 컴포넌트는 U4_DISK·U4_CYL·U4_ROD 3개다.
- 누름 구조: 피벗 (X −300, Z 70, 축 Y)에 레버 200을 둔다. 실린더 CDM2C20-25AZ(Ø20 st25)가 로드 핀 (−160, 122)을 누른다. 레버비 0.70.
- 누름 힘: 100 N이면 실린더 110 N(0.35 MPa), Ø20 0.5 MPa 157 N으로 SF 1.42다. Ø16은 0.55 MPa가 필요해 안 된다. 들기는 SF 4.1.
- 행정: J_U4_PRESS를 회전 조인트로 다시 정한다(−1.867°~8.627°). 바퀴 밑면은 Z 3.1~38.8까지 움직이고, 들기는 30, 매트 아래로 따라가는 여유는 6.9다. 바퀴 밑면을 재료 윗면(10/11/12)에 맞춰 따라가게 해서 M00-X6과 CYCLE_L 172 겹침을 없앤다(DC2-04 U4 몫).
- 작은 매트 모서리(0.5 s)는 0.296 N·m, 바퀴 힘 2.96 N이다. 30 N 누름일 때 SF 5.1이다. 서보 200 W(MHMF022L1U2M)와 감속 1/10으로 출력 정격 5.76 N·m를 낸다. 미끄럼 한도 3 N·m 대비 SF 1.9.
- CAD 확인(읽기만, MCP 파일 열기 1번): 새 부품 차지 상자 10개를 이웃 29바디와 대 보았다. U5가 가장 가까이 온 자세(d₂ 420)에서 겹침은 0이다. 머리판 통로 X −140~−80 · Z 195~560에 새 부품은 없다(DC2-06 마운트 틈 10 → 60).
- 미완: 구매품 STEP이 없다(서보·감속기·실린더·로드 끝·6004ZZ·핀·부시 → `STEP대기_`). E32-D36P1_2M·CB5-12/16/20만 STEP이 있다. 강도 디테일 3건은 기록만 한다(M02-X1~X3).

## 8. 제어 순서 제약 (U-09, 설계검토서로)

1. 바퀴 내림은 바퀴 앞 매트 유무 센서가 ON일 때만 한다.
2. 좁은 홈에서 바퀴를 들기 전에 먼 쪽 바퀴(U5) 내림을 확인한다. 들린 동안 방향은 U5 + 헤드 이송이 맡는다.
3. 바퀴 서보 토크 제한은 3.5 N·m 이하(감속기 정격 12 N·m 보호, 미끄럼 한도 3 N·m).
4. 배출 전 J_U4_PRESS 들림 끝(실린더 후퇴 스위치 자리)을 확인한다.
5. 각도 조절 ±5°는 정지 중 수동으로만 한다.

## 워크플로우 메모
- `batch` 끝에 일부러 실패하는 단계(없는 조인트 drive)를 두면 앞 단계 결과는 받고 묶음 전체가 롤백된다(undone 13). 측정부 메모(체크포인트가 batch를 넘으면 사라짐)의 대안으로 쓸 만하다.
- `motion.play` 응답이 자세 하나에도 약 20 KB다(위치·조인트 전부 실림). 응답을 줄이는 인자가 있으면 좋겠다(측정부와 같은 메모).
