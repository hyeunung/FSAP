## 워크플로우 메모

1. 모델링부의 이웃 목록이 scope `neighbors`보다 좁았다(긴 고정 관 7줄 빠짐 — 이유는 적혀 있었으나 중심선 어림). 검도가 bbox 쓸림 검사로 목록 빠짐을 CAD 없이 확인했다(3,188부품 1초). `ledger.py scope`가 조인트 행정으로 늘린 bbox 기준 이웃을 내주면 부서마다 목록을 따로 만들지 않아도 된다.
2. 긴 관(스윕 바디)이 against에 들면 `inspect.clearance`가 23~29쌍에 187~205 s다. 관은 중심선 + 반지름으로 틈을 셈하는 도구가 있으면 빠르다.
3. `component.list`는 compact로도 MCP 응답이 커서 검도가 앱에서 빈 컴포넌트를 직접 읽지 못했다(저장본 쪽은 바디 · occurrence · 조인트 이름으로 대신 확인). 빈 컴포넌트만 돌려주는 선택 인자가 있으면 좋다.
