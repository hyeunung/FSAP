## 4. L 1500 — concept_conflict

- 근거 있는 값: 수지 볼(0-8-1 "수지 볼", R375X 사진) 문헌 0.01~0.03(`catalog.md`, 형번별 값 없음). 강구+소구 지지 0.005~0.01. 둘 다 임시(미스미 로그인 풀림).
- 불리 가정(면밀도 6, μ 0.4~0.5, 40 N)에서는 실용 시간(≤ 15 s)에 c ≤ 0.004~0.009가 필요 — **수지 볼 근거값 아래**. 그래서 '근거 있는 선정 조건'으로는 SF ≥ 1이 안 나온다.
- R375X가 실제로 도는 것과 맞추면: 매트가 가볍고(4 kg/m²) 바퀴 μ 0.6이면 c 0.01에서 8.0 s, c 0.0174까지 12 s에 된다. 즉 **실물 값이 불리 가정보다 좋은 쪽에 있으면 된다**. 이것은 7절 시험으로만 확인된다.

개념의 무엇을 바꿔야 하나(사용자 결정 거리):
1. (현행 유지) L 1500 모서리는 U4+U5 — 0-8-3 U5 역할 "큰 매트 회전" 그대로. 사용자 요청 '긴 것도 혼자'는 못 맞춤.
2. 0-8-1 '수지 볼'을 휘두름 영역에서 강구+베어링 지지(c ≤ 0.005)로 — L μ 0.5 10.3 s·μ 0.6 8.9 s. 매트 뒷면 점자국(C-03) 위험, 볼 827개 형번·비용 변경.
3. d₁ 100 → ≥ 193(C-37 (가), 구조) — 이번에 하지 않기로 함.
4. 불리 가정 대신 7절 실측 판정(면밀도·μ·c)으로 L U4 혼자를 '조건부 허용' — 실측 판정 선: 12 s에서 c ≤ c_max(실측 면밀도, 실측 μ). 실측이 선을 못 넘으면 1로 돌아감(모델은 U5 승강 키만 다르므로 돌아가기 쉬움).
