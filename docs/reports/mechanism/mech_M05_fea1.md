요약

- 바뀐 부품 2: P_M05_CYL_BRKT(날개 Z 40 구멍 Ø5.5 → Ø7.14 압입 너트), P_M05_CST_PLATE(같은 자리 M5 탭 → Ø5.5 관통). STEP bbox 최대값이 model1 2절과 맞음(14~50 / −204~−171 / 34~110, 50~58 / −200~−40 / 20~328).
- 바뀐 하중 경로는 체결 한 곳(CB5-12_M05_5 → 압입 너트 STEP대기_S-M5-2_M05)뿐이라 E-18대로 손계산.
- **동작 문제 1 (M05-F3)**: 볼트 끝 X 46, 너트 나사 X 43.19~49.2 → 물림 3.2 mm(0.64d). 조임 4.5 N·m(1차에서 M5에 정한 값)에서 **조임 암나사 전단 SF 0.62** — 조일 때 너트 나사산이 뭉개진다(SF < 1.2, 부러짐).
- 고치는 법: CB5-12 → **CB5-15**(끝 X 43, 너트 끝 43.19에서 0.19 나옴 — 검도가 그쪽 틈 확인) + 조임 **2.5 N·m 지정** → 조임 SF 2.08, 운전 암나사 66, 분리 32. 길이를 못 바꾸면 CB5-12에 1.5 N·m 지정(조임 1.85, 분리 19).
- 그 밖 됨: 운전 하중(78.5 N) 암나사 35·분리 57, 너트 플랜지 → SUS304 날개 면압 133 MPa(p_G 400 대비 3.0), 날개 끝 거리 전단 SF 21.9, 판 구멍 확대 순단면 변화 0.8 %(1차 판정 그대로).
- 디테일 M05-F4: 압입 너트 S형(강)은 스테인리스 판에 쓰지 않는 계열 — SUS304 날개면 스테인리스 판용(SP형 상당)으로 형번 확정(형번 임시, STEP 대기).
- completion_met: 완료 판정(이음매 단계 간섭 0, 탈착 길 간섭 0, 묶음 폭 < 25)에 강도 항목 없음, 모델링부 1회차 검사 겹침 0 → true. pass false(동작 1).

## 1. 근거 규칙 (원문)
- E-18 "체결만 바뀐 자리는 손계산, FEA는 형상·하중 경로가 바뀐 부품만" — 바뀐 것은 구멍 하나와 체결 하나. 고체 FEA는 환경 없음(D-16).
- 지시서 "볼트·강도는 이번에 새로 만들거나 옮긴 것만 본다" — CB5-12_M05_5(뒤집어 옮김)와 압입 너트(새)만 봄.
- 지시서 "부러짐·영구 변형(SF < 1.2)·동작을 망가뜨리는 처짐만 kind='동작'" — 조임 시 나사산 전단 SF 0.62는 조립 때 부러짐.
- M-01 "상대 물림 ≥ 1.5d" — 지금 0.64d, CB5-15로 1.2d(너트 나사 길이 6.0이 한계, 압입 너트는 나사 길이 전부 물리면 됨으로 봄).
- 요구서 6-1 기본값 M-09 "필요 SF 일반 3, 오조작 2".
- 요구서 2-4 운전 압력 미정 → 0.5 MPa 임시(D-111), 1차와 같음.

## 2. 하중
- 볼트 하나 몫 78.5 N = CJ2B10 2개 추력 78.6 N의 지레 인장 39.3 + 전단 몫 39.3(1차 `CYL_BRKT_bolt` 식 그대로).
- 조임 4.5 N·m, K 0.2 → 예압 4,500 N. 이것이 이 자리를 정한다(운전 하중의 57배).
- 너트 모재는 handcalc 표에 압입 너트가 없어 SS400(Rp 245)로 대용(보수).
