# DC-01 이동 테이블 홈 덮개 — 측정부 (FSAP_v1.0.15)

요약(10줄 안쪽)
- 대상은 `3D_Modeling/FSAP_v1.0.15.sc`(config.json doc)이다. 앱에는 FSAP_v1.0.15가 이미 열려 있었다(dirty false, undo 0). 그래서 MCP로 다시 열지 않고 그 세션에서 쟀다. 판 홈 프로브 4자세는 CLI `run --results` 1회로 쟀다(저장 없음, 3분 7초). 끝은 REST step 0이고 저장하지 않았다.
- sigcheck 결과는 **reuse**(문서·해시가 같다, 306부품)다. bbox·부피·유닛은 `tools/out/signatures.json`을 그대로 썼다.
- **DC-01은 N04(v1.0.12~v1.0.15)가 이미 풀었다.** 요구서 5절 DC-01 행이 이미 '해결(N04에서, v1.0.15 슬랫 사슬 덮개)'로 적혀 있다. 원판 홈과 교차 칸은 안장 + 바깥 사슬 P·N + 안쪽 사슬 + 꼬리 멈춤 CDJ2B16-110 ×2가 덮는다. 바늘 홈 A 구간은 A 사슬 + CDJ2B16-150, 국면 L은 꼬리판, 바늘 홈 +X 쪽과 기둥 홈은 스트립 솔이 덮는다(N04-S01·S02).
- 받침 계산 `cov_hybrid`(4연구 2,279단계)에서 안 받친 넓이는 **0**이다. 매트 L·S·G의 4자세 실측에서 덮개 바디와의 겹침은 0이고, 덮개 윗면(Z 0)에 거리 0으로 닿는다. N04 검도 2회차에서는 갈 수 있는 26자세의 겹침이 0이다. → **already_ok = true.**
- CAD 바디만으로 보면 판 홈 윗면의 약 0.46~0.49 m²에 바디가 없다. 길이가 변하는 사슬 구간은 바디 없이 고정 프로브로 판정하고(N04-E02), 형번이 미정인 스트립 솔은 바디를 그리지 않기로(N04-S07, E-10) 결정로그에 정해 둔 결과다. 열린 홈이 아니라 '계산으로 덮음'이다.
- 미완(디테일·자료대기, 이번 판정 밖): 스트립 솔·정하중 스프링 형번(D-89), STEP대기_CDJ2B16-110/-150·HFS8-4080-248(D-89), 솔·사슬 자국과 처짐(요구서 7절 N04-T1~T3).

## 워크플로우 메모
- machine.json states의 CYCLE_G1 354 '홈 바닥 꺾임 끝 J_U4_X 1212.5·Y 862.5·회전 −90'과 모델 연구 CYCLE_G1 step 354의 실제 값(844.99·948.0·−50)이 다르다. N04에서 연구 키를 다시 쓴 뒤 states의 step 번호나 값을 고치지 않은 것으로 보인다. 다른 states도 연구와 맞는지 확인해야 한다(E-15).
- MCP batch 안의 `edit.restore_checkpoint`가 바로 앞 batch에서 만든 checkpoint id(507)를 찾지 못했다. 그 batch는 롤백됐지만 앞 batch의 편집은 남아 `undo`로 지웠다. 측정용 임시 바디는 CLI `run --results`(저장 없음)로 만드는 편이 안전하다.
- `inspect.clearance`에 `bodies`만 주면 그 목록 안의 쌍만 잰다. 프로브 측정에는 `against`가 꼭 필요하다.
