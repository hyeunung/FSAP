## 1. 구동 방식·동작

- 새 구동 0, 새 조인트 0. 커버·틀은 모두 BASE:1(접지)에 붙는 고정물이다.
- 움직이는 것은 정비 문 2짝뿐이다. 문은 사람이 손으로 여는 정비용이고 기계 동작 연구에는 넣지 않는다(자세: 닫힘 = 대기). 문 열림 궤적은 검사 상자 `K_T12_DOORSWEEP_L/R`로 둔다.
  - 문 회전축: 왼짝 X −871·Y 982 근처(경첩 자리), 오른짝 X 871. Z축 둘레로 바깥(+Y)으로 0 → 105°.
  - 쓸고 가는 공간: 왼짝 X −871~−40 / Y 940~1830 / Z −59~819(바깥 판 바깥쪽, 기계 안 부품 0).
- 사이클과의 순서(U-09 제약, PLC 단계로 넘김)
  - T12-Q1: 뒤 문 인터록이 열림이면 모든 축(J_MAT_X·Y·ROT, 링1·링2, 노루발·바늘, 칼, 패드)을 멈추고 시작을 받지 않는다(T07-Q1과 같은 정지).
  - T12-Q2: 테이프 롤 교체는 대기 자세(J_MAT_X 0, Y −700, ROT 0)에서 문을 열고 한다. 대기에서 매트 ↔ 문 면 Y 982: 매트 최대 Y −99 → 1081.
  - T12-Q3: 옆 정비판은 공구로 떼는 고정 보호판이다. 떼는 정비는 전원 차단(잠금·표지) 절차로 한다(설계검토서 '정비'에 적음). 인터록 없음.
  - T12-Q4: 문을 닫고 리셋(K_T07_BTN)을 눌러야 재시작한다.
