## 워크플로우 메모

1. MCP 서버가 여전히 `--allow-path` 없이 떠 있었다(실행 지시 (f)와 다름). `open`이 거부돼, 앱에 열려 있던 같은 내용(md5 같음)에서 이어 그렸다.
2. MCP 호출 하나(약 60 s)가 "Request timed out"으로 돌아온 뒤 MCP 서버가 새로 떴고 허용 임시 폴더 이름이 바뀌었다(앱 · 편집은 그대로). 이후 `batch path`는 새 폴더로.
3. `file.insert_step` 행렬은 4자리 반올림(0.866)이면 강체가 아니라고 거부된다(허용 1e-9). 기울어진 볼트는 전체 자리로 준다.
4. `inspect.clearance`의 `skip_within: "component"`는 같은 상위 컴포넌트(U3_HEAD) 아래의 바디 쌍을 빼서, 헤드에 붙는 부품 검사에서는 노루발 · 바늘 같은 같은 유닛 가동부도 빠진다. 헤드 부품 검사에는 쓰지 않는다.
5. 판금 `sheet.recognize`는 플랜지가 굽힘 판보다 넓은(탭이 있는) 접은 모양을 "walls 1.500 and 100.000 mm thick"로 거부했다.
