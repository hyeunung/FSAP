## 워크플로우 메모

1. MCP `batch {path}`는 `--allow-path`가 3D_Modeling · 복구 · 서버 임시 폴더뿐이라 `tools/out/` 파일을 거부했다. 서버 임시 폴더(`%TEMP%/solidcraft-mcp-*`)로 복사해 돌렸다. 안내서 '연결'에 배치 파일 자리가 적혀 있으면 덜 헤맨다.
2. `motion.play {study:"REST", step:0}` 응답이 1.35 MB(9만 줄)여서 파일로 떨어졌다. 상태 확인은 `joint.inspect`로 따로 했다. 요약 모드가 있으면 좋다.
3. 양끝 고정 케이블 구간에 '한 원호 R = L/θ'를 쓴 것이 지난 회차의 원인이다. 엔진 손계산 도구(handcalc)에 '양끝 고정 케이블 κ = (4θL + 6δ)/L²' 항목이 있으면 같은 실수를 막는다.
