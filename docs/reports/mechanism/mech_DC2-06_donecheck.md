- 핵심 수치: 정비 자세(J_U4_PRESS −1.867°)에서 트레드 윗끝 Z 123.86, 통로 밑면 Z 125와 틈 1.14, 통로 겹침 0 mm³. 바퀴 중심 X −100이라 d₁ 100이 유지된다.
- 자중 유지 손계산: 0.538 kg·m, 곧 5.28 N·m. 실린더 마찰 2.2 N·m 대비 SF 2.4로 다시 계산해 같았다.
- 남은 것(불합격 사유 아님): ① 틈 1.14는 867 머리판 밑끝을 Z 125로 둔 임시 상자 기준이다(D-10). ② REST 상태에서는 통로가 겹친다(77,038 mm³). 그래서 정비 인터록(매트 없음, 내림 끝 확인)은 제어 순서 제약으로 남긴다(U-09, DC2-06-D1).
- CAD는 쓰지 않았다. 측정 보고서와 설계안 수치로만 다시 셈했다.

## 1. 항목별 다시 계산

### 1-1. 머리판 탈착 길(X −140~−80 · Y ±90 · Z 125~560) 과제 범위 간섭 0
- 기하 검산: 피벗은 (−300, 0, 70)이다. 바퀴 중심은 X −100이라 팔 길이는 200이다(누름 0°에서 중심 Z 70, 트레드 Ø120 밑이 매트 10 위에 닿는다. 측정 보고서 1절과 맞다).
  - −1.867°에서 중심 Z는 70 − 200·sin1.867° = 70 − 6.52 = 63.48이다.
  - 트레드 Z 범위는 3.48~123.48이다. 측정값은 3.11~123.86이고, 차이 0.4는 기울어진 바퀴 bbox 때문이다.
  - 통로 밑 Z 125와의 틈은 1.14 > 0이다.
- CB5-20_M02_2·4(측정 때 불리언 실패 쌍) 검산: REST에서 대표점은 X −132 · Z 126이다. 피벗 기준 r 177.1, 각 18.43°다. 여기서 −10.49° 돌리면 7.94°가 되고 Z는 70 + 177.1·sin7.94° = 94.5다. 통로 밑보다 30 낮아 겹침 0이다.
- 측정 보고서 2절: PR_FACE60·LOW·HI 모두 −1.867°에서 0 mm³이다. 설계안의 MCP 재측정은 15바디에서 overlaps 0이다.
- 실물 행정 끝: 로드 24.83/25라 0.17 더 내려가 약 0.07° 더 돈다. 바퀴는 아래로 가므로 통로 틈은 커지고(약 1.4), 원판과의 틈은 약 2.9로 남는다. 바퀴가 원판에 닿지 않으므로 멈추는 곳은 실린더 행정 끝이다. 물리적으로 정해진 끝이다.
- 이웃 유닛: U5(X ≤ −1812), 노루발대(NOSE X ±11), 매트(Z 0~10)는 모두 통로 밖이다.
- **만족.**

### 1-2. d₁ 100 유지
- 형상과 피벗에 변경이 없고, 바퀴 중심은 X −100(바늘 X 0 기준)이다.
- 요구서 5절 DC2-06의 "약 60 띄움(d₁ 100 유지)" 가운데 60 띄움은 M02에서 이미 됐다. P_M02_BASE X ≤ −140이고, 통로 폭 60이다.
- **만족.**

### 1-3. 정비 자세 유지(상태가 성립하는지)
- 자중 모멘트를 피벗 기준 수평 거리로 셌다.
  - 서보: 0.96 × 0.065 = 0.0624
  - 감속기: 1.2 × 0.145 = 0.174
  - 바퀴·트레드: 0.63 × 0.200 = 0.126
  - 옆판: 1.37 × 0.079 = 0.108
  - FRONT: 0.39 × 0.172 = 0.067
  - 합 0.538 kg·m × 9.81 = **5.28 N·m**
- 마찰: 최저 사용 압력 0.05 MPa × π·10² = 15.7 N이다(M-06, SMC CM2 카탈로그). 팔 길이 140이면 2.2 N·m, SF 2.4다.
  - 로드 끝 X ≈ −169로 잡아 팔 131로 줄여도 2.06 N·m, SF 2.6이다. 결과는 같다.
- 방향: 바퀴 쪽이 피벗의 +X에 있어 무게는 내림(−) 방향이다. 공급을 끊고 배기하면 행정 끝까지 내려가 머문다.
- **성립.**

## 3. 남는 것(기록)
- D-10: 867 실물 머리판 밑끝 Z와 체결 방향이 정해지면 −1.867° 틈 1.14를 다시 잰다. 밑끝이 Z 125보다 낮으면 다시 열어야 한다.
