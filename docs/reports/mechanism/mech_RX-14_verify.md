## 워크플로우 메모

1. 내장 MCP 서버의 `batch {path}`가 프로젝트 폴더를 "outside the folders this agent may use"로 거부했다(허용 폴더가 recovery · 임시 폴더뿐). 지시문은 `--allow-path …/workspace`로 설정돼 있다고 적고 있다. 모델링부가 만든 `mcp_send.py`(허용 폴더를 준 MCP 서버를 따로 띄움)로 돌았다 — 부서 공용 도구로 올리거나 서버 설정을 실제로 확인하는 단계가 있으면 좋겠다.
2. 완료 판정 확인이 "5절 문구를 고쳐야 검도가 실패로 올리지 않는다"고 적었지만 문서 담당은 검도 뒤에 돈다. 검도가 받는 완료 판정 문구는 옛 것 그대로라, 감사가 받아들인 갈래를 검도 지시문에 함께 넘겨 주면 같은 판단을 다시 하지 않는다.
3. `view.pick {rays}`(읽기 전용, 329선에 0.14~1.8 s)는 프로브 바디를 만들지 않고도 볼트 접근 · 메운 구멍 · 위에서 보이는 면을 볼 수 있다. 저장본 CLI 한 번(열기 약 2.5분)을 아꼈다. 선은 원통 전체가 아니므로 원통 프로브와 함께 써야 한다.
4. `motion.play`는 `quiet: true`여도 모든 키 조인트 값을 돌려준다(약 160개). 화면에 그대로 받지 않게 파일로 받는 쪽이 낫다.
