## 3. 손계산 (완료 판정 ②)

가정은 다음과 같다. MGPM25 머리 면적은 π/4·25² = 490.9 mm², 로드 φ10(임시, MGP25 카탈로그 값으로 확인할 것)이면 로드 쪽 면적은 412.3 mm²다. 미끄럼 저항 41.2 N은 F01-S2 수정 1의 값이다. 움직이는 무게는 다음과 같다.
- 플로트: 6.593 kg(CAD)
- U5_LIFT: 약 1.67 kg. parts_table.csv의 LIFT_TOP 0.975, 스프링 0.251, LHFR16 0.339, 로드 0.088, 볼트 0.016을 더했다.
- 합계: 8.26 kg = 81.0 N

| 경우 | 식 | 값 | 판정 |
|---|---|---|---|
| 내림이 되나(0.10 MPa) | 49.1 + 81.0 − 41.2 | 88.9 N > 0 | 됨. IR 최저 0.005 MPa에서도 42.3 N으로 무게만으로 내려간다. 속도는 AS2201F 미터 아웃이 정한다 |
| 들기(B 주 공급 0.5 MPa, A에 설정압이 남는 최악) | 206.2 − (81.0 + 41.2 + 49.1) | 34.9 N, SF 1.20 | 됨. 0.15 MPa면 SF 1.05라 쓰는 범위 위끝으로만 둔다 |
| 내림 끝 힘(승강판 → 실린더 끝) | 0.5 MPa: 245.4 + 81.0 / 0.10 MPa: 49.1 + 81.0 | 326 → 130 N | −60 % |
| 매트 힘(정상, 승강판이 끝에 닿음) | 플로트 W − 스프링 | 45.74~46.54 N | 압력과 무관. 첫 안 3절 그대로 |
| 바닥 친 경우(칼라 오설정, u 20 넘음) | W 전체 + p·A | 130 N(0.10) / 326 N(0.5) | 자국 한도 51.6 N은 넘는다. 셋업 실수 경우라 '창'이 아니라 피해를 줄이는 몫으로 본다 |
| 바퀴 접지·기울기 | 형상 변경 0 | — | 첫 안 그대로 |

창 판정은 25 ≤ F − f = 41.74~42.54이고 F + f = 49.74~50.54 ≤ 51.6이다. 만족한다.

## 8. 위험

- IR1000을 A관 중간에 두면 들 때 A 배기가 IR을 거꾸로 지난다. U4 :1과 같은 배치이고, 들기 SF 1.20은 설정압이 남는 최악 경우로 셈했다. 실물 확인이나 체크 밸브 우회는 디테일로 한다.
- MGPM25 로드 φ10은 임시값이다. 로드가 φ12면 로드 쪽 면적이 377 mm²로 들기 188.5 N이 되고 SF 1.10이다. 설정을 0.08 MPa로 낮추면 된다.
- 0.10 MPa 설정은 판정 창이 아니라 충격을 줄이는 몫이다. 실물 감(요구서 7절)에 맞춰 0.05~0.15 MPa 안에서 고른다.

## 워크플로우 메모
- '검토' 과제에서 고른 안이 '모델 변경 0'이면 모델링부가 막혔다고 보고되고 수정 회차가 돌았다. 고른 안에 형상 변경이 없으면 모델링부를 건너뛰는 분기가 필요하다(앞 모델링부 메모와 같은 문제).
