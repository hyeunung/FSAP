# 기구설계부 1 — N02 U3 진공 원판 + 회전 조향 (구상 1: 벤치마크 그대로, 2026-11-03, 엔진 v3.7.2)

## 요약(10줄)
- 방향: US6557478 자유 회전 진공 원판(원판 Ø120 r60 그대로) + R375X 자동 회전 = 중공 회전 액추에이터 DGM130R-AZAC로 조향, 원판을 헤드 쪽으로 미는 힘은 U4 X·Y 서보의 바늘 쪽 힘 보조로(0-8-1 "필요하면 서보가 보조").
- 핵심 판단: DGM130R을 원판 축에 바로 달면(동축) 하우징+모터 높이 ≈ 140(임시) > 아래 띠 100(Z −230~−130), 모터가 U4_Y_CARR(Z −260~−230)·U4_X_BEAM(상대 X −150~+140, Z −340~−260)과 겹친다 → **DG를 −X로 225 옮기고 타이밍 벨트 2:1로 원판 축을 돌린다.** −X는 측정에서 "제한 없음"인 유일한 방향(mech_N02_measure 2-1)이고, 결정로그 DC-06 "모터 −X"와 같다.
- 바뀐 부품: U3_PLATE(상자 → 진공 홈 원판), U3_COLUMN(상자 → 회전축 U3_SHAFT, 같은 r50 외곽), U3_DRIVE(□130 상자 → 베어링 블록 U3_BRG_BLOCK, 같은 □130 외곽) + 새 U3_DG_PLATE·DGM130R·풀리 2·벨트·CRBH7013A·오일 실 2·ZH10DSA. 부품 수 +10.
- 핵심 수치: 조향 허용 토크(원판 축) = min(DG 12×2×0.95 = 22.8, 벨트 400 N×0.0382 = 15.3) = **15.3 N·m ≥ 6.75**(SF 2.26, 임시값). 진공 잡는 토크 13.6 N·m(r60, −60 kPa, μ 0.5) ≥ 6.75. 원판 중심–바늘 100.0·가장자리–바늘 40·매트 안 여유 40 그대로.
- 새 부품 틈(손계산, 측정 통로 기준): DG ↔ U4_X_BEAM 10, DG 모터 밑 ↔ U2_BASE 10(임시 높이), 마운트판 ↔ U5_POST Y 75(사이클)/25(조인트 끝), 벨트 ↔ 마운트판 6, 헤드 아랫유닛(LOWER·LINK) ↔ 새 부품 Z 35 이상.
- 진공 길(DC-02): 베어링 블록 안 오일 실 2개 글랜드 + 축 십자 구멍 → 회전 −90~360°에서 관 꼬임 없음. DG 모터 케이블은 U4_Y 고정쪽이라 꼬임 없음.
- N01에서 넘어온 것: J_U4_X 한계 −200~1217.5(+X 소프트 리밋·스토퍼, N03 구현), DC-05-D2는 J_U4_Y −350~1150 소프트 리밋(N03) 권고 — 이 안의 새 부품도 그 범위에서 틈 확인.
- 미완·임시: DGM130R 외형(하우징 50·모터 □60×90)·허용 토크 12·허용 관성, CRBH7013A·풀리·벨트·오일 실 값은 카탈로그 표 기억값 또는 표에 없음 → provisional(D-80, 새 자료대기 후보). STEP 없음 → 모델링부는 STEP대기_ 임시 형상.
- 해석: FEA 못 함 — 환경 없음(자료대기 D-16). 손계산만.

## 2. 구동 방식·행정·자세

### 2-1 구동
- 조인트: J_U3_ROT(revolute +Z, U4_Y → U3_ROT) 그대로. 쓰는 범위 −90~360°(연구 키), 한계 −360~720 그대로(벨트·글랜드라 회전 수 제한 없음).
- 구동 사슬: DGM130R 출력 테이블 → 작은 풀리 24T S5M(Dp 38.2) → 벨트 S5M 630(126T) 폭 25 → 큰 풀리 48T(Dp 76.4) → U3_SHAFT → U3_PLATE. 감속 2:1(관성 1/4, 토크 2배).
- 모드: 봉제 중 조향 = 위치/속도 지령(센서 비례 조향, US5367966), "자유 회전"은 DG 서보 저강성 추종(토크 제한)으로 낸다. 모서리·홈 바닥 바늘 중심 회전은 X·Y·회전 위치 모드(0-8-1).
- 미는 힘: U4 X·Y 따라가기 모드에 바늘 쪽 힘 오프셋(토크 제한). 제어 순서 제약만 남김(U-09).

## 9. 위험
