# DC2-03 기구설계 — 아랫유닛 북 교체 길 (2026-11-04, 기구설계부)

## 요약
- 설계안 하나: **포켓 벽 개구 + 칸 안 손 길 + 바늘판 밑 북 빼기 홈 + 북 받이 판.** 북(북집)만 −Y로 빼고, 아랫유닛(LOWER)은 움직이지 않는다(v1 DC-04-C1 기각 이유 피함).
- 바뀌는 부품: `U2_SUB` 자르기 X 40~640·Y −250~−200·Z −250~−40(6,300,000 mm³), `U2_PLATE` 밑면 홈 X ±30·Y −130~−65·Z −40~−6(윗면 살 6 남김, 132,600 mm³), `STEP대기_867-392342_LOWER` −Y 면 북 문 자리 X ±15·Y −60~−10·Z −37~−8(43,500 mm³). 새 부품: 북 받이 판 `P_DC203_TRAY`(SUS304 t1.5 판금) + CB5-12 ×2.
- CAD 확인(CLI, v2.0.2에 자르기·새 부품·프로브를 넣고 저장 안 함): 북 빼는 길·떨어뜨림 길·팔 길·개구·손가락 자리 **겹침 0**(checked 31, truncated false, unchecked 0). 남은 겹침은 윗면 살(의도) 23,400 mm³뿐.
- 손 거리(D-82 ≤ 600, 손 기준): 포켓 면 최근점 (400, −250) → 북 문 (0, −60) 442.8, 뺀 북 (0, −110) 423.8, 받이 판 끝 (−80, −62) 515.5.
- 새 조인트 없음. 덮개·인터록 문은 외장 단계(규칙 14, DC-04-S07 선례)로 기록만.
- 미완·임시: 북 방향(−Y)·북집 크기 Ø27×22·높이 Z −36~−9는 기종 조건(D-10·D-101, 임시). 해석 못 함 — 환경 없음(D-16), 손계산만.

## 1. 출발점(basis)
- 0-8-3 U3 "새로 하는 것": 분리 개조 — 사진에 테이블 밑 구조 없음. 그래서 **벤치마크 없음 — 0-8-3 새로 하는 것**.
- 따라간 선례: v1 DC-04-S01·S05(결정로그 1787·1791) "정비 포켓에서 손을 넣는다, 관계없는 부품을 떼지 않는다". M-02 원문 "관계없는 부품을 떼야 하면 결함" — 이 안은 LOWER_DRIVE·DISK_BRG·원판을 떼지 않는다.
- 측정 4절: "북 문은 Z −40 밑에 두어야 칸 안에서 빠진다"(PR16 U2_PLATE 162,000). 그런데 가마 Ø32는 바늘판 바로 밑(Z 약 −40~−4)에 있어야 하므로 북을 Z −40 밑으로 내릴 수 없다. **그래서 북 높이(Z −36~−9)의 판을 밑에서만 파서(윗면 살 6 남김) 북이 −Y로 빠지게 한다.** 테이블 윗면은 그대로 평평해 매트 가장자리가 걸릴 틈이 없다(요구서 1-1 마감 품질).
- +X 끼움판(완료 판정의 다른 길)을 쓰지 않은 이유: 아랫축 구동(U3_LOWER_DRIVE)이 +X에 있어 북집은 축 반대쪽(−X 또는 −Y)을 향한다. +X 위 구멍은 북에 닿지 않고, 북 위 X ±45는 NOSE·노루발·바인더가 막는다(PR08 149,601 mm³). 또 끼움판은 테이블 윗면에 이음을 하나 더 만든다.

## 2. 구동 방식·동작 순서
- 구동 없음(손 정비 길). 새 조인트 없음.
- 북 교체 순서(매트 없음 상태 — 측정 3절 가정을 이 안이 확정: 매트 내린 뒤·올리기 전, 0-8-4 ⑥ 뒤):
  1. 바늘 위 정지, 아랫축 서보·U4 원판 정지(제어 제약 Q1).
  2. 작업자가 포켓(X 400~975·Y ≤ −250)에 서서 개구(Y −250 면 X 400~640·Z −250~−40)로 오른팔을 넣는다. 팔꿈치는 개구, 아래팔은 잘린 띠 Y −250~−200(X 40~640)을 비스듬히 지나 칸 안 띠 Y −200~−65로.
  3. 손가락을 밑에서 바늘판 밑 홈(X ±30·Y −130~−65·Z −40~−6)으로 올려 북집 걸쇠를 잡고 −Y로 약 60 빼낸다(북 문 Y −10 → 홈 Y −125).
  4. 내려서(Z −40 밑) 칸 밖으로 꺼낸다. 놓치면 받이 판(Z −250 바닥, 테두리 15)에 떨어진다.
  5. 넣기는 반대. 개구 덮개(외장 단계)를 닫고 인터록이 풀린 뒤 운전.
- 대기/작동 위치: 고정 부품뿐이라 상태 하나(REST).

## 5. 하중 손계산(E-18, 바뀐 것만)
- 윗면 살 t6(U2_PLATE 국부, 지금 M00 상자 재질 Default → SUS304로 봄): 작업자가 바늘 앞을 짚는 200 N(임시 D-109 후보) 가운데 한 점, 단순 지지 보 폭 65·스팬 60.
  - M = PL/4 = 200×60/4 = 3,000 N·mm, Z = 65×6²/6 = 390 mm³ → σ = 7.7 MPa, SUS304 항복 205 → **SF 26.6**.
  - I = 65×6³/12 = 1,170 mm⁴, δ = PL³/(48EI) = 200×60³/(48×193,000×1,170) = **0.004 mm**.
- 받이 판: 자기 무게 약 1.2 kg(부피 약 146,500 mm³ × 7.93e-6) + 북 수십 g. U1_BASE 위에 면으로 얹혀 굽힘 없음. CB5-12 ×2는 위치만 잡음(전단 약 6 N/개).
- U2_SUB 자르기: M00 차지 상자라 강도 판정 없음. 실물 테이블 받침틀 설계(M07)에서 개구 둘레 틀을 둔다.
- 해석 못 함 — 환경 없음(D-16). 형상·하중 경로가 바뀐 부품은 살 t6뿐이고 SF 26.6이라 FEA 대상 아님(등급 M, 완료 판정에 강도 항목 없음).
