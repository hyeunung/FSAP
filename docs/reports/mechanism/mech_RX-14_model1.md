1. 이력 끝 쪽 피처(앞 과제에서 만든 것)의 `timeline.edit`는 큰 파일에서도 10 s였다(다시 계산 81피처). 수정 회차에서 '새 피처로 덧대기'보다 값 고침이 깨끗하다.
2. 생성기를 `from gen_rx14 import …`로 불러 쓰면 첫 회차 생성기가 다시 돌아 `model/stage_*.json`을 같은 내용으로 다시 쓴다(내용 변화 없음, 수정 시각만). 생성기의 출력 부분은 `if __name__ == "__main__":` 아래에 두는 편이 낫다.
3. 검증의 고침 안이 "받이 턱(Y 40~48)"만 적고 귀(Y 20~40)를 늘리라는 말이 없어, 턱이 귀 밑에 오지 않았다. 고침 안에는 닿는 두 면의 자리를 함께 적어 주면 좋다.
4. MCP 응답이 큰 명령(`motion.play` 값 목록, `inspect_design`)은 호출 결과가 대화에 그대로 실려 넘친다. 결과를 파일에 쓰는 작은 보내기 스크립트(`model1/send.py`)로 돌렸다.
