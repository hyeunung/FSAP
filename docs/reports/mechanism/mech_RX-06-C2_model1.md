## 워크플로우 메모

- 모델링 지시문 절차 2("먼저 다른 이름으로 저장해 새 파일을 만든다 … 그 파일에서 고치고 끝에 save")가 프로젝트 실행 규칙 2("저장 뒤에는 편집하지 않는다", "`save {}`는 쓰지 않는다")와 SolidCraft 안내서 '원복'("저장 뒤에는 편집하지 않는다")에 맞지 않는다 → SolidCraft일 때는 "편집 → `save {path: 새 번호}` 한 번"으로 적으면 좋겠다.
- `solidcraft-cli run … --results`는 한 단계가 실패하면 앞 단계 결과를 하나도 내지 않는다(열기 15분을 잃음). 저장 확인 측정과 프로브 검사를 스크립트 둘로 나누거나, 스크립트를 가벼운 파일에 먼저 시험하면 좋겠다. `solid.cylinder`의 새 바디 이름은 `name`(피처 이름)이 아니라 `body_name`이다 — 안내서 '볼트 검사' 3에 적으면 좋겠다.
- `selection.delete {occurrences}`는 지워도 `deleted: []`를 돌려준다(dry_run도 같음). 지워졌는지는 `occurrence.properties`가 "no occurrence"를 내는지로 확인했다.
- `inspect.clearance`의 unchecked("boolean Intersect: no result")를 '탭 물림'으로 읽어 온 쌍 가운데 실제로는 탭이 없는 살을 뚫은 것이 있었다(이번 건, v2.8.8부터). unchecked 쌍은 상대 바디에 그 자리 구멍이 있는지(`body_topology` 원통 목록)까지 봐야 물림으로 판정할 수 있다 — 검도 · 체결 절차에 넣으면 좋겠다.
- 볼트가 한 컴포넌트의 여러 occurrence일 때 측정 표(서명) 키(`… (U7_CASSETTE:1/CB5-12_M05_7:2)`)와 체결 목록 이름(`CB5-12_M05_7:2`, 옛 것은 `CB5-16_M05_1_PNEU01_52`)이 서로 달라 `sigpatch --removed`에 두 이름을 다 줘야 했다.
