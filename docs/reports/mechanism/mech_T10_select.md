PM(원칙 감사), 2026-11-01. 대상 `3D_Modeling/FSAP_v0.6.13.sc`(tools/config.json doc). CAD 확인은 저장본에 대고 CLI `solidcraft-cli run --results`(저장 안 함)로 했다. 저장본 SHA256은 세 번 모두 전후가 같다(`tools/out/mech_T10/sel/sha_before.txt`·`sha_after.txt`·`sha_after2.txt`). 스크립트·결과: `tools/out/mech_T10/sel/`(f1 = 고른 안을 그대로 적용해 봄, f2 = 틈·스패너 프로브, f3 = 외피 자르기 위치 확인).

**요약**
- **선정: T10-C1**(구상 1, 안 A 다듬은 안)에 구상 2의 위험 항목(포트 35, 공차 쌓임)을 합쳤다. 실린더·SNJ·로드·NTJ ×2·패드를 X +4.10 평행 이동하고, 위판 Ø8.2 구멍을 (−126.90, 572.5)로 옮기고, 작업 대상 외피 끝을 자른다. 부품 증감 0, 구매품 증감 0.
- **차순위: T10-C**(구상 3, 패드 누름 면만 어긋나게). 위판 구멍 이동이 막힐 때만 쓴다.
- **구멍 처리는 구상 1·2와 다르게 한다.** 옛 구멍은 `face.delete`(heal)로 메우고 새 구멍을 뚫는다. join으로 메우면 같은 평면 join이 거부되고(실행 규칙 8), "메운 구멍 자국"(U-10)이 남는다. CAD 시험: 부피 97 979.67 → 98 190.88(+211.2 = π·4.1²·4) → 97 979.67. 자국이 남지 않는다.
- 핵심 수치(CAD 시험 적용): 패드 X −140.90~−112.90, 중심 −126.90. 테이프 중심 −126.9025와 차 **0.0025** ≤ 0.5. 대기·0·−13.5 세 자세에서 정적 겹침 **0**. 외피 ↔ 안내 블록 1.842 → **0** mm³. 몸통·SNJ·로드 ↔ 위판 434/265 → **0**. +X 옆벽 틈 **0.845**(CAD 프로브). 앞·뒷벽 틈 0.3. 포트 피팅 35 겹침 0. 위판 −X 살 11.9 → **16.0**.
- **새 구동 문제(kind '동작', 이번에 생긴 것 아님): T05-W1 SNJ 스패너 자리 없음.** 스패너 판 20 × 3.9는 앞벽 뿌리 R3과 30.67 mm³ 겹친다. 21 × 4(맞변 11 + 턱 5 × 2, DP-2 관례)는 91.94 mm³ 겹친다. 주머니 벽 Y 562.2/582.8은 T10이 바꾸지 않는다. 고치려면 앞벽 오조작B(417.5 N, SF 2.96)를 다시 따져야 해서 T10에 넣지 않았다. 다음 구동 라운드 과제(T15 후보)로 올린다(실행 규칙 13: 구동 단계에서 끝냄).
- 미완: 전 사이클 `motion.interference`는 검증부가 한다(모델링 뒤). 해석 못 함 — 환경 없음(D-16), 손계산으로 했다.

좌표: 세계 좌표, 대기 자세(`motion.play 대기 0`), 바늘점 원점, 매트 밑면 Z 0, 단위 mm.

## 5. 모델링 지시서

문서 `tools/config.json` doc(v0.6.13)를 MCP로 연다. dirty면 멈추고 보고한다. 저장은 새 번호 **v0.6.14**(작은 형상 변경, 요구서 8-2·E-05)로 하고 config.json doc를 바꾼다.

1. **자세:** `motion.play {study:"대기", step:0}`.
2. **실린더 몸통+SNJ:** `occurrence.move {occurrence: 680 (이름 CJ2B10-15Z_T05:1, T05:1 아래), space:"world", translate:[4.10,0,0]}`. 결과 몸통 bbox X −132.9~−120.9, SNJ −133.251~−120.549. 허용 ±0.01.

## 워크플로우 메모

- 구상 1·2는 위판 구멍을 "재생성"·"join으로 메움"이라고만 적었다. 이 CAD에서 실제로 되는 방법(`face.delete` heal)을 확인하지 않아 그대로 그릴 수 없는 지시였다(WF-016·017과 같은 종류). 구상 단계에서 "구멍 이동"에 쓸 명령을 CAD로 한 번 돌려 보게 하면 좋다.
- 구상의 "가장자리 여유"는 가운데 줄 값이라 기울어진 작업 대상의 모서리 여유를 놓쳤다(2.27 → 실제 0.34). 기울어진 대상의 덮음은 모서리 투영으로 재게 하면 좋다.
- `inspect.clearance`가 겹침 0인 쌍에 거리 0.0인 점을 냈다(자른 외피). 부피 0인 잔면인지 측정 끝점인지 도구가 구분해 주지 않는다.
