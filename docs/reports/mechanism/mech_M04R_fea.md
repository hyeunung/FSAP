## 4. 문제

| kind | 무엇 | 어디 | 수치 | 고치는 법 |
|---|---|---|---|---|
| 디테일 | 볼 하나 손·누름 100 N 몰림 SF 1.98 < 2 | `STEP대기_BALL_D25_M04` ×827 | 101.2 N / 정격 200 N(D-96 임시) | 형번 고를 때 정격 ≥ 203 N(D-96에 적음). 또는 7절 시제품에서 매트의 하중 분산 확인 |
| 디테일 | T너트 물림 짧음, 조임 암나사 SF 1.17~1.19 | CB5-20 ×4, CB8-16 ×12 | le 5.5·5.3 < 1.5d | 조임 토크 시방(M5 ≤ 4, M8 ≤ 10 N·m)을 도면에 적음 — 기존 형재 체결과 같이 디테일링에서 |

동작 문제 0 → pass. 완료 판정: 사각 센터판 0·피치 100 격자·매트 받침·숨김·간섭은 모델링·측정 쪽 항목, 해석 항목(볼 하나 D-92 누름 SF ≥ 2)은 실제 하중 경로로 만족.

기록(문제 아님): E2 가운데 칸 자중 처짐 0.19 mm(1 g, 2방향 판) — 볼 꼭대기가 원판 윗면보다 최대 약 0.2 낮아질 수 있음. 원판이 받침을 맡는 쪽으로 낮아지는 것이라 매트가 걸리지 않는다. 볼 높이 공차(D-97 ±0.1)와 함께 시제품에서 봄.
