# DC-03 구상 3 — 눕힌 X 베어(56급, 송풍 호스 같이) + 끝 고정 Y 베어(보 +Y 모서리에서 X 베어로 바로 넘김)

## 요약
- 안: **X 베어를 바닥틀 위에 눕혀(XY면 고리) +Y 뒤 띠 Y 1098~1482에 둔다.** 눕히면 고리 지름이 높이 335가 아니라 폭 465에 걸려 내고 56급·R150이 들어가 송풍 호스 Ø50(N00-C3 메모, N04 미정)까지 한 베어에 싣는다. 세운 고리로는 56급 R150 높이 370 > 335(카탈로그 표 메모).
- **Y 베어는 보 −X 옆 세운 고리(X −1272~−1208 · Z −360~−178), 고정 끝을 보 +Y 끝 Y 900에 둔다(행정 가운데가 아님).** 회전 묶음(AZM·MBKT·벨트, Y ±806 안)이 지나가는 띠를 가로지르지 않고, 케이블이 X 베어 움직이는 끝(보 +Y 끝면)까지 약 300 mm만 건너간다.
- 바뀐/새 부품: 구매 3(X 베어 igus E4.56.10.150.0 L≈1267, Y 베어 igus 2400.05.075.0 L≈1965, UHMW-PE 미끄럼 띠), 가공 4(P_DC03_XTROUGH SPCC t2 판금, P_DC03_XMOV A5052 t3 판금, P_DC03_YTRAY A5052 t2 판금 — 걸이 탭 일체, P_DC03_YMOV A5052 t3 판금). 순 +7(볼트 별도).
- 핵심 수치: X 고정점 x_f −471, L' 760 → 고리 X −445.5~263.3, 차지 X −1250(브래킷)~455.3. Y 고정점 Y 900, L' 1705 → 고리 Y −780~−10, 차지 Y −871~920. 굽힘 X R150 ≥ 케이블 7.5D(Ø10 → 75)·호스 임시 R150, Y R75 ≥ 7.5·Ø8 = 60·TU0604 R15. 따라가기 저항 79.2 → 89.8 N ≤ 100 N(D-79 임시).
- 틈(상태별 최소, 손계산·측정 bbox): X 베어 ↔ Y 서보 묶음 23(Y), ↔ 테이블 밑 210, ↔ 레일 B 128. Y 베어 ↔ MBKT 38(X), ↔ 867 LOWER 58(Z, J 1217.5), ↔ 레일 A·B 탭/트레이 9.5 이상. 매트 Z ≥ 0 ↔ 베어 Z ≤ −178.
- 미완: 형번 전부 임시(카탈로그부 로그인 풀림, E-12) → 자료대기 D-88 후보. 호스 Ø50 굽힘 R은 R150과 같음(여유 0, N04가 지름 정할 때 다시 봄). X 이동 질량 +약 4.5 kg → N03-Q4 가속 SF 1.26 다시 계산(디테일 기록). FEA 못 함 — 환경 없음(D-16), 손계산만.

## 2. 앞 두 안과 다른 점(이 안이 새로 하는 곳과 이유)
벤치마크(0-8-3)는 케이블 베어 자리를 정하지 않는다. 케이블 베어 자체는 카탈로그 표준 배치를 그대로 쓰고, 새로 하는 것은 두 곳뿐이다.
1. **X 베어 눕히기**: 세운 고리면 높이 335에 들어가는 것이 35급(R125, 296)까지라 송풍 호스 Ø50을 못 싣는다(카탈로그 표 메모: 56급 R150 세우면 370 > 340). 송풍 호스를 따로 고정 덕트로 빼면 테이블(U4_X와 리지드, N00-S01)이 X로 1417.5 움직여 결국 따라가는 호스가 또 필요하다. 눕히면 고리 바깥 지름 2·150 + 84 = 384 ≤ 465 − 여유. 높이는 베어 폭 128만 쓴다.
2. **Y 베어 끝 고정**: 행정 가운데 고정이면 고정 브래킷이 보 −X 면(X −1050)에서 베어(X −1240)까지 회전 묶음이 Y로 다니는 칸(X −1170~−1050, Y ±806)을 가로질러야 하고, 지나갈 띠는 Z −160~−125 높이 35뿐이다(측정 4절). 끝 고정(Y 900)이면 브래킷이 Y 870~940(회전 묶음 밖 64 이상)에서 보에 붙고, 케이블이 X 베어 움직이는 끝과 바로 만난다. 대가: 베어 길이 L' 1705(가운데 고정이면 약 780).

### 3-3. 케이블 넘김
Y 베어 고정 끝(X −1240, Y 900, Z −340) → 트레이 +Y 탭(Z −324) 위로 X −1050 → 보 −X 면을 따라 Y 940 → 1000 → 모서리 돌아 P_DC03_XMOV 세움판 → X 베어 움직이는 끝(Y 1140). Y 서보(X −910~−784, Y 1010~1070) 케이블은 XMOV까지 약 100. 넘김 구간은 정지 배선(묶음 띠), 굽힘 ≥ 4D.
송풍 호스는 XMOV 윗판(Z −246)에서 테이블 밑면(Z −40, 같은 U4_X)으로 올라간다 — 정지 호스, 입구 자리는 N04.
