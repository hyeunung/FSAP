# 구동 RX-19 해석 — U4 매달림 블록 1 + 그네 1 (v2.29.0)

해석부, 2026-11-24. 대상은 `3D_Modeling/FSAP_v2.29.0.sc`의 새 하중 부품 4개다(해석용 STEP `tools/out/mech_RX-19/stepout/`). CAD는 쓰지 않았다. 형상은 모델링 보고서 `mech_RX-19_model.md` 2-1~2-5의 그린 치수를 썼다. STEP bbox로는 범위만 맞춰 봤다(스톱 블록 X ≥ −268 · Y ≤ 65.4 · Z ≤ 166). 케이스는 `fea/cases/mech_RX-19_handcalc.py`, 결과는 `fea/results/mech_RX-19_handcalc.json`이다. 체결 손계산은 `fea/results/mech_RX-19_hc_*.json`, 해석 모델 표는 `fea/models.json`에 새 4줄을 넣었다.

## 요약(10줄)

- **판정: 동작 문제 0(pass).** 새 부품 4개 모두 운전 SF ≥ 3이다. 오조작에서 SF < 1.2인 곳도 없다. 해석은 못 했다(FEA 환경 없음, 자료대기 D-16). 모두 손계산이다.
- 하중: 스톱 닿는 힘은 운전 245.7 N · 오조작 821.2 N이다(0.5 MPa 당김 117.8 N × 45 + 무게 · 스프링 × 3 g). 핀 반력은 운전 220.8 N · 오조작 717.3 N이다. 들기는 157.1 N이다.
- **블록 `P_RX19_BLOCK`:** 러그 SF 25.1 / 7.74다. 스톱 받침 기둥(비틀림 포함 von Mises)은 운전 SF 5.71이고 **오조작 1.71 < 2**다 → 디테일 RX19-FEA-D1.
- **스톱 받침 처짐:** 운전 0.197 mm < 옆 뜸 0.5다(검도 정정값 0.186과 맞다). **오조작에서는 0.66 > 0.5**다. 이때 스토퍼 로드 Ø12가 옆힘 약 194 N을 받는다 → 디테일 RX19-FEA-D2. 기둥을 X 8.5 → 12로 하면 오조작 SF 2.65 · 처짐 0.35가 되어 둘 다 풀린다.
- **그네 `P_RX19_SWING`:** 텅 SF 18.8 / 5.59(들기 15.5), 뺨 190 / 58.6, 앞 띠 목(12 × 12) 17.8 / 5.94(3 g)다.
- **스톱 블록 `P_RX08_STOP_BLOCK`:** 탭 밑 순 단면 SF 65.7 / 19.7이다. 텅 모서리와는 선으로 닿는다(오조작 68.4 N/mm). 그래서 모서리 C0.5를 권한다 → RX19-FEA-D4.
- **핀 `PSFJ12-80`:** 굽힘 SF 22.0 / 6.76, 부시 면압은 2.99 MPa(오조작)다.
- **바퀴 접지점 처짐 합: 0.103 mm < 0.5**다(Z 0.021 + X 0.082. 러그 · 앞 띠 목 · 뺨, 누름 끝 51.6 N + 옆힘 16 N).
- 새 볼트: 스토퍼 `CB5-16_RX08_LIP` ×4(Al 몸에 물림 4)는 3 N·m로 조이면 암나사 전단 SF 0.92다. 실린더 `CB6-16_RX13_CYL` ×4는 5.2 N·m에서 1.15다 → 디테일 RX19-FEA-D3(조임 토크 상한 1.8 · 4.0 N·m, 또는 RX19-D8의 CB5-20).
- 미완: completion_met은 false다. 검도(`mech_RX-19_verify.md`)의 동작 문제 2건(P1 관 ↔ 피팅, P2 U4 스토퍼 ↔ U5 대차, d₁ 195)이 과제 완료 판정 '간섭 0'을 깨기 때문이다. 강도 항목만 보면 모두 충족이다.

## 1. 일의 크기(E-18)

규칙 E-18 원문은 "체결만 바뀐 자리는 손계산, FEA는 형상·하중 경로가 바뀐 부품만"이다. 블록 · 그네 · 스톱 블록은 형상과 하중 길이 새것이다(L 등급). 원래는 FEA 대상이다. 그러나 이 컴퓨터에는 `engine/fea/.venv`가 없다. 그래서 **해석 못 함 — 환경 없음(자료대기 D-16)**으로 적고 손계산만 했다. 각 부품은 보 · 직사각 비틀림 · 면압으로 셀 수 있는 형상이다(두께/길이 ≥ 0.1, 얇은 판 아님). `handcalc.py beam`으로 기둥을 맞춰 보니 σ 24.42 MPa · 처짐 0.0636 mm로 케이스 값(24.4 · 0.0635)과 같았다(`mech_RX-19_hc_post_beam.json`). 도구는 `needs_fea: true`를 냈다. 하지만 기준 ±10% 안에 드는 항목은 오조작 기둥(SF 1.71, 기준 2의 −14.5%)뿐이고, 이것은 고칠 치수를 함께 냈다. 모델은 바꾸지 않았다(새 부품이라 옛 모델 없음). 스톱 블록은 옛 v2.12.1 모델(브래킷 발 위에 얹힘)을 새 받침 길로 바꿔 적었다.

Z와 X를 더해도 **0.103 mm < 0.5**다. 충족이다. 모델링 보고서의 '처짐 합 0.194'는 스톱 받침 처짐(뜸 0.5와 비교하는 값)에 러그를 더한 것이었다. 바퀴 접지점 처짐과는 다른 양이라 두 값을 나눠 적었다. 스톱 받침 처짐은 운전 0.197이다.

### 3-2. 스톱 받침의 오조작 미달과 고치는 치수(디테일 D1 · D2)

- 0.5 MPa 레귤레이터 고장과 3 g이 겹치면 기둥 VM SF는 1.71이다(기준 2). 처짐은 0.66 mm로 뜸 0.5를 0.16 넘는다. 넘는 동안은 로드(강성 58,790 N/mm)가 받침(1,247 N/mm)보다 훨씬 단단하다. 그래서 남는 하중 약 194 N이 스토퍼 로드 Ø12로 간다. 로드 굽힘은 25.1 MPa로 부러지지 않는다. 그러나 SMC 실린더 로드 옆하중 허용(M-06, 카탈로그 확인 필요)을 넘을 수 있다.
- 운전에서는 둘 다 충족이다(SF 5.71, 처짐 0.197 < 0.5). 부러짐 · 영구 변형(SF < 1.2)도 아니다. 그래서 디테일이다(E-02).
- 고침: 기둥 X 두께 8.5 → **12**(X −272~−260)로 한다. 그러면 굽힘 0.150 + 비틀림 0.171 + 머리 보 0.025 = 오조작 처짐 **0.35 mm**(< 0.5)이고, VM 73.5 MPa · **SF 2.65**다. 운전 처짐은 0.104다. −X로 키우는 쪽이 기둥 +X 앞에 있는 실린더 몸(X −258)을 피한다. 물러난 스톱 블록 · 잠금 너트(X −274.8~−250)는 Y ≥ 29이고 기둥은 Y 5~29라 Y로 갈린다. 그래도 Y 29 면이 맞닿으므로 CAD 틈 확인이 필요하다.

## 5. 과사양 note(M-09 원문: "SF가 필요치의 3배 이상 남으면 과사양")

## 워크플로우 메모

- 과제 완료 판정의 '블록 · 그네 바퀴 접지점 처짐 합 < 0.5 mm(설계 0.186)'에서 0.186은 바퀴 접지점 처짐이 아니다. 스톱 받침 처짐(뜸 비교값)이다. 과제 정리부가 두 양을 한 칸에 묶었다. 완료 판정에 수치를 옮겨 적을 때는 그 수치가 무엇을 잰 것인지(어느 점 · 어느 하중)도 함께 옮겨야 한다.
- 해석 환경이 없는데도 L 등급 과제마다 해석부가 돈다. 환경이 없으면 손계산만 할 수 있으니, 이 단계를 검도 · 체결부의 손계산 칸으로 합치면 부서 한 번을 줄일 수 있다.
