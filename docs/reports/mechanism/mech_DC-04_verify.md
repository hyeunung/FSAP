## 5. 손계산(E-18 — 완료 판정에 힘 항목, 형상 바뀐 하중 부품 없음 → 손계산, FEA 못 함 — 환경 없음 D-16)
- `tools/out/mech_DC-04/design/dc04design.py`를 다시 돌려 `dc04design.json`이 바이트 같음을 확인했다.
- 식 점검: need = c·Rg + 0.048 + (I + I_d)·4θ/t² + T_f, have = 0.4 × 40 × 0.1 = 1.6 N·m. T_f = μ위아래 0.8 × Fp 20 × r 0.006 = 0.096 N·m. 피벗 옆힘 합 Rt = F4 + 구름 + 원심·접선 관성, 노루발 몫 Q = 0.4 × 20 = 8 N, 바늘 = Rt − Q.
- 결과: U4 혼자 최저 SF 1.009(V 입구2 12.5 s), F4 최대 15.86 N ≤ 18 N, Rt 최대 17.77 N, 바늘 최대 9.77 N ≤ 20 N(노루발이 미끄러져 옆힘을 못 받아도 17.77 N ≤ 20 N). U4+U5 최저 SF 1.009.
- 민감도(검도 계산): V 입구2 여유 1.6 − 1.6/1.009 = 0.0143 N·m, dT_f/dFp = 0.0048 N·m/N → 피벗 누름 실제값이 **22.9 N**를 넘으면 SF < 1. 요구서 D-10 쓰는 곳에 "실제가 더 크면 T_f = 0.0048·Fp로 키를 다시 셈"이 이미 있다 → 디테일 DC04-V1로만 적는다.
