### 2-2. 차순위로 바꾸는 조건

- `CJ2B16-30SZ`·안내축 체결 형번을 끝내 못 정하거나, 헤드 기종(D-10)에 +X 면 탭 자리가 없어 브래킷 자리를 못 잡으면 C2.

## 워크플로우 메모

- 구상 부서가 구매품 STEP을 열지 못해(gmsh 없음) 축 끝 탭(없음)·플랜지 구멍 지름(M4)·플랜지가 굽힘 R 위에 얹힘을 모른 채 좌표를 냈다. 이미 모델에 같은 형번(`LHFR16_R1_1`, `PSFJ16-100_T05`)이 있으면 CLI `model.faces`로 면을 읽을 수 있다 → 구상 지시문에 "같은 형번이 모델에 있으면 `model.faces`로 구멍·탭을 확인" 한 줄을 넣으면 선정에서 고칠 것이 줄어든다(WF-016·017과 같은 계열).
- 구상 3개가 모두 M-04를 "구멍–굽힘선"으로만 적고 굽힘 R·굽힘 시작선을 넣지 않았다. 판금 지시서 틀에 "안쪽 R, 구멍–굽힘 시작선 거리"를 칸으로 두면 좋겠다.
