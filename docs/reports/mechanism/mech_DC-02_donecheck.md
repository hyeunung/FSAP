요약(10줄 안):

- 판정: **ok = true** — 완료 판정 3항목 모두 만족(문제 0).
- 다시 계산(닫힌 식, 설계안 스크립트와 독립): L 7.5 s 잡는 17.600 / 필요 17.352 N·m → **SF 1.014**, SF 1 최소 7.12 s. G 4.5 s(DC-03 미반영 대비) **1.045**. 설계안 값과 같다.
- G1 출구 9.5° 1.2 s: 설계안 1.051(피벗 X만 0.3 이동, 보수적). 감사 쪽 피벗 X·Y 0.3 이동 셈은 1.168 — 어느 쪽이든 ≥ 1.

- 기록(문제 아님): ⑦ '최대 매트 85.0 s'는 L 매트 사이클이다. DC-03 G1 사이클 약 160.8 s가 반영되면 '최대'가 아니므로 ⑦에 매트별로 적을 것.
- 미완: 구름·띠 μs 실측(요구서 7절, D-96·D-97), 해석 환경 없음(D-16, 손계산만).

## 1. 근거 규칙

- E-02 원문 취지: 구동 라운드 합격은 동작·간섭(E-03), 강도 여유·볼트 다듬기는 디테일로 기록만.
- E-18: "체결만 바뀐 자리는 손계산, FEA는 형상·하중 경로가 바뀐 부품만" — 이번은 형상 변경 0, 시간 키·손계산만(등급 S).
- E-17: 검사 범위는 "바뀐 바디·주변" — 바뀐 바디 0.
- 과제 완료 판정(요구서 5절 DC-02): "U5가 닿는 모든 모서리 회전 SF ≥ 1(띠 μs 0.30·가속 포함), FUNC-01 ②·⑦ 고쳐 적음, 과제 범위 간섭 0".

## 2. 항목별 재계산

식(설계안·dc02calc.py와 같음): 잡는 T = μ·F4·d₁ + μ·F5n·d₂, 필요 T = 구름·Rg + (I + I_disk)·4θ/t² + 원판 끌림 0.048 + 띠 μs·F5n·d₂. μ 0.4, F4 = F5n = 40 N, d₁ 0.1 m, 면밀도 6 kg/m², 구름 0.02(D-96), μs 0.30(D-97), I_disk 0.0217.

좌표 확인(측정 1절): 띠 P_DC205_STRIP X −1826~−391·Y ±25, U5 트레드 U5_X 800에서 X −1012.5~−987.5 → 띠 위, 띠 항을 넣은 것이 맞다. 민감도: 구름 0.025면 0.972 — 선정 조건 ≤ 0.02(D-96) 안에서는 성립.

속도 검산: α = 4θ/t² = 0.1117 rad/s², ω_max = 2θ/t = 0.419 rad/s = 24.0 °/s, U5 둘레 0.419×1000 = 419 mm/s(Ø120 → 66.7 rpm), U4 둘레 41.9 mm/s. U5 바퀴 토크 0.4×40×0.06 = 0.96 N·m 그대로, 속도는 옛 698 mm/s보다 낮아 구동 쪽 여유는 늘어난다.

### 2-2. FUNC-01 ②·⑦ 고쳐 적음 — 만족(지시서로)

설계안이 ② 4.5 s 1.15 → 7.5 s 1.014(띠 포함), ⑦ L 사이클 73.0 + 4×3.0 = 85.0 s를 모델링부 지시로 명시. machine.json `_timing`에 CYCLE_L 모서리 키가 없다는 측정 지적도 같은 지시에 포함(모델링부가 키를 새로 쓴다). 기록: ⑦의 '최대 매트' 표기는 DC-03 G1 사이클 약 160.8 s 반영 뒤 맞지 않으므로 매트별로 적는다.

### 2-3. 과제 범위 간섭 0 — 만족

자세·형상·조인트 변경 0(연구 단계 82~172·236~326·390~480·544~634, 1°/단계 그대로, U5 LIFT −10·FLOAT 10·누름 40 N 그대로). E-17에 따라 새 검사 대상 없음. 같은 v2.8.10의 DC-03 측정 CLI CYCLE_L 83·127·171 새 겹침 0을 근거로 받아들인다. G 모서리는 DC-03 쪽 U5 들림 Z 틈 28.0으로 닫음.

## 3. 조건·기록

- G 닫음은 DC-03 G 안 반영 전제. 반영되지 않으면 G 모서리 시간 키 3.0 → ≥ 4.1 s(4.5 s SF 1.045)를 대신 넣는다.
- L 모서리 U4 혼자 전환은 DC-03 concept_conflict(사용자 결정 대기)라 이번 판정은 L = U4+U5 그대로 기준.
- 해석: 해석 못 함 — 환경 없음(자료대기 D-16). 등급 S, 손계산으로 충분(E-18).

## 워크플로우 메모

- dc02calc.py의 `mat(a,b,px)`는 피벗 이동을 X에만 준다(Y는 0). G1 출구처럼 피벗이 모서리에서 두 방향으로 들어간 경우 보수적(I·Rg 크게)이라 판정은 안전 쪽이지만, 인자 이름만 보면 X·Y 같이 옮기는 것으로 오해하기 쉽다.
