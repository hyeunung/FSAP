- C-38: L 1500 모서리는 U4+U5 → L U4 혼자 36.6 N 경우는 판정에서 뺌.
- E-02: "강도 여유·정밀 체인·새 볼트 렌치 접근·판금 규칙은 디테일로 기록만". E-15 움직임은 machine.json 조인트로만(새 조인트 없음). E-17 과제 범위 검사. E-21 이전 결과 파일부터.

## 2. 구동 방식·순서(0-8-4 ④ 고친 순서)
바늘 꽂음(J_U3_NEEDLE −30) → 헤드 이송 정지 → 노루발 봉제 높이 유지, 누름만 2단의 피벗 쪽(낮은 누름)으로 → 바퀴로 바늘 중심 회전(U4 혼자 또는 U4+U5) → 누름 봉제 쪽으로 → 재개. 노루발 들림 20은 로딩(0~12단계)과 배출(끝)에서만.

## 5. CAD 확인(feasibility)
- 같은 저장본(v2.8.12) 서명 sigcheck reuse(2,881부품, 해시 같음) → 측정부가 MCP로 잰 값을 그대로 씀(E-21). 노루발 0 회전 자세 30점(L 4·S 4·G1 8·G2 4·V 10) 겹침 0, 최소 틈 NOSE 0.5·바늘 0.7·테이프 1.0·바인더 1.0·매트 2.0 mm.
- 매트·테이프는 평면 운동만, 윗면 Z ≤ 11(이음매 11~12) < 발바닥 Z 12 → 표본 사이 단계도 겹침 0(기하).
- 이번 부서는 설계 파일을 열지 않음(바뀐 바디 0, 연구 전환마다 motion.play 약 3분이라 같은 측정을 다시 하는 값이 없음).

## 6. 제어 순서 제약(설계검토서에 남길 것, U-09)
- DC04-Q1: 회전 중 노루발은 봉제 높이·피벗 낮은 누름(≤ 20 N 임시). 들림 20인 채로 U4 혼자 회전 금지.
- DC04-Q2: U4 혼자 회전 F4 ≤ 18 N, 시간 키 이하로 빨리 돌리지 않음(각가속도 ≤ 4θ/t²).
- DC04-Q3: 누름 2단 전환은 바늘 꽂힘(J_U3_NEEDLE −30) 뒤, 회전 끝·재개 전 봉제 쪽 복귀.

## 7. 디테일(기록만, E-02)
- DC04-D1: 바늘 Ø1.6 외팔 25(임시)에 9.8 N이면 약 607 MPa — 헤드 기종 바늘 굵기·Nm ≥ 180~200 확인(D-10).
- DC04-D2: 노루발–테이프·매트–바늘판 μ, 매트 바늘 구멍 찢김, 피벗 중 테이프 끌림 — 7절.
