## 2. 동작(구동)·순서

- 커버는 움직이지 않는다. 새 조인트 0, 리지드 그룹은 BASE:1 아래(T07과 같은 방식, `BASE` 아래 `T12` 컴포넌트). 동작 연구 변경 0.
- 대기/작동 위치: 문 닫힘 = 운전, 문 열림 = 정비(기계 정지). 뒤 문은 경첩 축 X −500에서 +Y 쪽으로 0~90° 열린다(사람이 손으로).
- PLC에 넘길 순서 제약(U-09, 설계검토서에 남김):
  - T12-Q1: 뒤 문 인터록이 열림이면 전 축 정지·운전 시작 금지(T07-Q1 커튼 가림과 같은 정지 범주).
  - T12-Q2: 옆 판이 떼어져 있으면 운전 금지(떼는 판은 공구 필요 고정 가드로 보고 인터록 없음. 판 고정 볼트 수 확인은 점검표, D-38 기준 확정 때 다시).
  - T12-Q3: 테이프 롤 교체는 정지 + 문 열림 상태에서만(① 정지 → ② 문 열림 → ③ 교체 → ④ 문 닫힘 → ⑤ 리셋).
