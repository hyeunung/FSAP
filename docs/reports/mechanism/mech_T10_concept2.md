# 구동 T10 구상 2 — T05 패드 위치: 실린더·패드 +X 4.10 평행 이동(부품 수·구매 최소)

**요약**
- 방식: 측정 안 A. `CJ2B10-15Z` 몸통·SNJ·로드·NTJ ×2와 `P_T05_PAD`를 통째로 **X +4.10** 평행 이동한다(축 (−131, 572.5) → (−126.90, 572.5)). 구동기·행정·조인트 한계·동작 순서는 그대로다.
- 바뀌는 가공품은 `P_T05_GUIDE` 하나다. 위판(Z 85.5~89.5)의 Ø8.2 구멍을 X −126.90으로 옮기고 옛 구멍은 다시 그려 메운다(출력 한 바디).
- T05-V1(동작 문제, 1.842 mm³): 작업 대상 외피 `MAT_TAPE_PATH`를 Y 552.5에서 자른다(T05-V1이 처음 낸 방법). BOM 밖이다.
- 판정: 패드 중심 ↔ 테이프 중심 X 차 **0.0025**, 길에 수직 **0.0025**(≤ 0.5 합격). 누름 면적 560/560 mm², 가장자리 여유 양쪽 2.31. 안내 블록과의 겹침 0, 최소 틈 +X 옆벽 0.85.
- 부품 증감 **0**, 구매품 증감 **0**(CJ2B10-15Z 실물 STEP 있음), 세트 비용 증감 0(위판 출력 형상만 바뀜).
- 하중: 패드 힘 39.3 N @0.5 MPa 그대로. 위판 다리 σ 약 0.75 MPa(바뀌지 않음). 새 하중 경로 없음.
- 미완·넘김: SNJ-010C 스패너 접근(맞변 11, 주머니 폭 20.6) 실물 스패너 판정은 검증(M-01·M-02). M5 포트 피팅 35 mm 프로브는 측정이 25까지만 쟀다. 그 너머는 bbox로 비어 있다고 봤고 검증에서 다시 잰다.

좌표: 세계 좌표, 대기 자세(`motion.play 대기 0`), 바늘점 원점, 매트 밑면 Z 0, 단위 mm.

## 10. 위험

- 테이프 실제 폭·위치는 D-06 임시값(폭 32)이다. 실물 폭이 달라지면 가운데 정렬은 그대로지만 가장자리 여유 2.31이 바뀐다.
- +X 옆벽 틈 0.85는 출력 공차·패드 돌림을 합쳐 0.7까지 쓴다. 출력 공차가 ±0.3보다 크면 닿을 수 있다(요구서 7절 시제품 확인).
- 외피 자르기는 작업 대상 근사를 고치는 것이라 실물 테이프 거동(받침면 앞모서리 R1 리드인 위로 올라탐)은 모델로 판정하지 않는다(요구서 7절).
- SNJ 스패너 접근은 위 9절대로 판정되지 않았다.
