## 워크플로우 메모

- MCP 서버 안내 `Backend: headless`라 실행 규칙 (2) 예외대로 CLI로 그렸다. 사용자가 앱 창에서 실시간으로 보는 T06 요구는 이번에 못 지켰다 — 워크플로우 시작 전에 SolidCraft 앱을 먼저 켜 두는 단계를 넣으면 좋겠다.
- CLI 0.27.1 `joint.sweep`이 이 설계에서 상대를 하나만 줘도(`HEAD:1` 또는 `T06:1`) "motion exceeds contact sweep collision budget"로 거부됐다(step 1·5 모두). 안내서 '조인트 자기 점검'에 "거부되면 이산 `joint.drive` + `inspect.clearance`"를 대안으로 적으면 좋겠다.
- 매트 컴포넌트가 사슬로 중첩돼 있어(MAT_LARGE > _BOUND > _SEAM > MAT_SMALL > …) `motion.interference`는 목록에 없는 하위 매트 바디를 위 occurrence 이름으로 보고한다(작은 매트 연구에 큰·홈 매트가 섞임). 준비물 생성기에서 매트 셋을 root 아래 형제로 두거나, 검도 지시에 "매트는 바디 단위 clearance"를 넣으면 좋겠다.
- `motion.interference` samples 상한 1000이라 홈 사이클(1039단계)은 전 단계가 안 된다 — 단계 수가 1000을 넘으면 나눠 보거나 바디 단위 검사로.
- 엔진 `stepcheck.py`가 Windows 기본 cp1252 콘솔에서 한글 출력 중 UnicodeEncodeError로 멈춘다 — `PYTHONIOENCODING=utf-8`을 실행 환경 줄에 넣으면 좋겠다.
- `file.insert_step` 행렬은 직교 오차 1e-9 안이어야 한다(cos45를 소수 6자리로 반올림하면 거부). 생성기에서 회전 성분은 반올림하지 않는다.
