- 식: S_RO = K·T + C_RO, K 2000 mm/s. d 14라 손끝 넘어옴 C = 8(d − 14) = 0.

판정(임시값):
- **앞 쌍(0800)**: 대차 위 체인 팔·케이블 베어(a 1,753, 앞 1,695)가 가장 불리하다.
  - 1,695 ≥ 2000·T + 750이어야 하니 T ≤ 0.47 s.
  - 슈(a ≈ 1,000, C_RO 0)는 1,410 ≥ 2000·T이니 T ≤ 0.70 s.
  - 두 조건 중 작은 쪽인 **T ≤ 0.47 s**면 앞 쪽은 0800으로 성립한다. 지금 D-130 앞 T ≤ 0.69 s보다 빠듯해진다.
