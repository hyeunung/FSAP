## 워크플로우 메모

1. MCP 서버 허용 폴더가 임시·recovery뿐이라 `file.insert_step`(purchased-step)과 `save`(3D_Modeling)가 거부됐다(실행 지시 (f)는 `--allow-path workspace`라고 함). 임시 폴더 복사 → 복사해 넣기로 우회. 지시와 실제 설정이 다르다.
2. `solid.split_body`의 `plane.origin`은 활성 컴포넌트 좌표다(월드 아님). 분할 전에 `component.activate root`를 넣어야 재현이 확실하다.
3. 분할로 생긴 새 바디는 재질을 물려받지 않고 `Default`가 된다 — 분할 뒤 재질 다시 지정이 필요.
4. 이력 앞쪽(3,751/4,058) 피처 4개 고침 + 컴포넌트 지우기를 `roll_to` 마커 안에서 몰아 하니 5.2 s, 끝까지 올림도 수 초였다(이번 앱 상태에서는 10~35분 재계산이 나지 않음).
