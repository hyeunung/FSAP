## 3. 손계산 다시 셈 (`tools/out/mech_M03/design/handcalc_m03.json`)
- 1200×1200 매트, 질량 6 kg(I = 5.76 kg·m²에서 역산), 바늘점(모서리) 둘레 회전 I = m(a² + b²)/3 = 6 × 2.88 / 3 = 5.76 kg·m².
- 90° 삼각 속도: α = 4θ/t² = 4 × 1.571 / 1.3² = 3.718 rad/s². T = Iα = 21.4 N·m.
- 바퀴 접선력 F = T / d₂ = 21.4 / 0.8 = **26.8 N**. 미끄럼 한계 μN = 0.5 × 90 = **45 N** → **SF 1.68**. 1.0 s면 F 45.2 N, SF 1.0(누름 90 N; 설계안 표는 N 100으로 1.11).
- 1500 매트(d₂ 1.0, 1.75 s): F 28.9 N, SF 1.56. 
- 볼 테이블 구름 저항·바늘 옆 바퀴 쪽 반력은 넣지 않았다(볼 저항은 필요한 힘을 늘리므로 불리 쪽). D-95 시제품 확인 대상으로 남긴다(V-3).

## 워크플로우 메모
- MCP `batch` 안 `joint.drive`·`motion.play`에 `quiet:true`를 줘도 occurrence 위치 전부를 싣는다(응답 약 40 KB). 읽기 부서는 자세 바꾸는 측정을 CLI로 묶는 것이 낫다.
- `document.inspect`(verbose false)도 210바디에서 195 KB다. dirty만 보는 가벼운 명령이 필요하다(M02 검도 메모와 같음, 반복 2).
- 케이블 체인처럼 모양이 바뀌는 구매품은 REST 형상과 움직이는 끝 브래킷이 행정 중간에서 겹친다. 띠 공간 프로브 + 길이 손계산으로 대신했다. 체인 굽힘을 조인트로 만드는 방법(또는 체인을 검사에서 빼는 표준)이 안내서에 있으면 좋겠다.
