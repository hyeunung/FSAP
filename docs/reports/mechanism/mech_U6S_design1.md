# U6S 설계안 수정 1회차 — 칼라 안내 마찰·모형 누름 키 (기구설계부, 2026-11-11)

요약(10줄 안):
- 고친 곳 2개만(WF-176): ① 누름 힘 띠에 칼라–장공 안내 마찰 f_g를 넣고 IR1000 설정을 0.15 → **0.18 MPa**로 올림 ② 근거 파일 `u6s_calc.py` heights의 모형 누름 −1.4 → **−0.4**.
- f_g = μg·μs,max·F_hi(μg 0.2·μs 0.4 임시, D-165), 자기 일관으로 F_lo·F_hi 양쪽에 넣음. 0.18 MPa에서 f_g 1.71 N.
- 누름 띠 **8.53 ~ 21.37 N**(이전 7.88~17.31), 잡음 여유율 **1.316**(필요 6.48 N), 자국 SF **2.11**(30 kPa)·**7.05**(100 kPa), 레귤레이터 최대 0.2 MPa에서도 1.96·6.53.
- 검토 지시 방식(F_drag 6.92 N 고정, 0.17 MPa)은 1.245로 같은 결론. 자기 일관(끌림 = 0.4·F_hi)으로는 0.17 MPa가 1.206이라 게이지 ±0.005 MPa에 1.2 아래로 내려갈 수 있어 0.18로 정함(0.175에서도 1.261).
- 압력 창(여유율 ≥ 1.2 ~ 30 kPa SF ≥ 2) **0.170 ~ 0.194 MPa**. 회전 SF는 피벗 중 슈 들림이라 그대로 1.009~1.047.
- 형상·좌표·부품·조인트 범위 변경 0 → CAD 다시 확인 없음(이전 회차 CAD 확인 `design/raw2.json`·`raw2t.json` 그대로 유효). 부품 수 순 +13 그대로.
- 미완: μg·μs·잡음 필요 힘·실린더 마찰은 임시(D-164·D-165), 직선 끌림 μ0.4 8.55 N(U4 견인 16 N의 0.53)은 헤드 이송 몫 — D-10·7절. FEA 못 함 — 환경 없음(D-16).

## 2. 손계산(E-18, `tools/out/mech_U6S/design/u6s_calc.json`, 이전 값은 `u6s_calc_r0.json`)

- 머리 쪽 단면 A = 78.54 mm²(CJ2B10), 움직이는 무게 W 0.814 N, 실린더 정지 마찰 띠 f ±4.71 N(최저 사용 압력 0.06 MPa × A, 카탈로그 기억값 D-165).
- 안내 마찰: k = μg·μs,max = 0.2 × 0.4 = 0.08. F_hi = (P·A + W + f)/(1 − k), f_g = k·F_hi, F_lo = P·A + W − f − f_g.
- 짝힘 걱정(검도): 끌림(슈 바닥 Z ≈ 10~12)과 칼라(Z 32.5) 사이 20.5 mm 팔의 모멘트는 슈 바닥 압력 중심이 μs·20.5 = **8.2 mm** 옮겨 받는다(바닥 길이 Y 90 mm의 반 45 안 → 슈가 기울지 않음). 칼라 두 개는 같은 Z에 있어 이 모멘트를 칼라 옆힘으로 받지 않으므로 칼라 옆 반력 ≈ F_drag 그대로. 그래서 f_g = μg·F_drag가 맞다.
