# DC-05 측정 — 아랫유닛 구동 자리 이동(XY 금지 구역 없애기)

요약
- 대상 문서는 `3D_Modeling/FSAP_v1.0.2.sc`(앱 제목 FSAP_v1.0.2)이고 바디는 36개다. sigcheck는 **reuse**라서 bbox·부피는 `tools/out/signatures.json` 값을 그대로 썼다.
- **이미 되는지: 아니다(already_ok=false).** U1_LOWER_DRIVE는 아직 X 30~500에 있다. J_U4_X −200→1250 스윕(Y 0)이 **864.99에서 U1_HEAD↔U4_Y 접촉**으로 멈췄다(점 30, −460, −140).
- 겹침(J_U4_X 1250, Y 0): U3_DRIVE↔U1_LOWER_DRIVE 162,500 mm³, U3_COLUMN↔U1_LOWER_DRIVE 549,717 mm³.
- **새로 찾은 것:** U1_LOWER_DRIVE를 옮겨도 완료 판정 스윕 '−200~1250 접촉 0'은 **J_U4_X 1222.49에서 또 멈춘다.** 에어 테이블 바늘 홈 끝이 STEP대기_867-392342_LOWER(X −30)에, 기둥 홈 끝이 U2_COLUMN(X 500)에 닿는다. 겹침은 1250에서 각각 99,000·132,000 mm³다. 조인트 한계를 ≤ 1212.5로 줄이거나(쓰는 최대 1212.5, 틈 10) 두 홈을 +X로 ≥ 37.5 늘려야 한다.
- 움직이는 묶음이 차지하는 범위(조인트 한계 전체)의 +X 끝은 **U3_DRIVE 415**(J_U4_X 1250)이고, 그 밖에 U3_COLUMN 400, U4_Y_CARR 475(Z −260~−230), U4_X_BEAM 500(Z −340~−260), U5_POST 490(|Y| 900~980)이다. 테이블 밑 **X 425~975**(틈 10)는 U2_COLUMN 자리만 빼면 Z −380~−40이 비어 있다.
- 남는 문제는 받침(X ±30·Y ±45, Z −120~0)에서 구동 상자까지 잇는 연결부다. 이것은 반드시 원판 묶음이 다니는 범위를 지나간다. 다만 Y ±45 띠로 +X로 가게 하면 겹치는 것은 원판 중심 |Y| < 95 띠뿐이다. 이 띠는 사이클이 쓰지 않는 방위(0°)이고, Y 0 스윕(원판 중심 Y −400)에도 걸리지 않는다.
- 바꾼 부품은 없다(측정만). 앱 문서는 저장하지 않았다. 대기 자세 REST 0으로 되돌렸다(X 0·Y 0·회전 0·노루발 20·바늘 0).

### 2-5. 받침과 구동 상자를 잇는 길(연결부) — 금지 구역이 남는 곳
- 받침은 바늘점에 있어서 원판 묶음 차지 범위 한가운데 있는 섬이다. 그래서 어떤 연결부든 차지 범위를 지나간다.
  - 아래로 내리는 길: Z −340~−260에서 U4_X_BEAM(J_U4_X 750~1050일 때 X 0 위)이, Z −260~−130에서 대차·U3_DRIVE가 막는다.
  - 테이블 높이(Z −40~0): U3_PLATE(−15~0)·U3_COLUMN(−130~−15)이 지나간다.
- 연결부를 Z −120~−60(U3_DRIVE 윗면 −130 위)에 Y 반폭 h로 X 30 → 상자까지 두면, 닿는 것은 U3_COLUMN(r50)뿐이다. 원판 중심 금지 띠는 |Y| < h + 50, X −20 ~ (상자 X + 50)이다. h 45이면 |Y| < 95다.
- 사이클이 원판 중심을 두는 방위(`tools/out/mech_N00/plate_center_sectors.json`, 바늘점 기준):
  - 120~210°: 최소 100~116.6(작은 매트 S)
  - 30°·60°·90°·240°: 최소 545~575(G1)
  - **0°와 270~330°는 쓰지 않는다**(N00-S04 '방위 255~375°').
- +X(0°) 띠의 금지 구역은 사이클이 쓰지 않는 방위에 있다. Y 0 스윕(원판 중심 Y −400)의 U3_COLUMN Y −450~−350, U3_DRIVE −465~−335와도 겹치지 않는다(띠 |Y| ≤ 45와 305 떨어짐).
- 지금 상자(Y −460~−20)는 270~330° 방위를 상자 통째로 막는다. 그래서 Y −400 줄(대기 Y)에서 X를 865 넘게 보내면 닿는다.

- `edit.checkpoint` 번호가 `joint.drive`·`joint.sweep` 뒤에 없어졌다("no checkpoint 238"). 읽기 부서의 원복은 `motion.play REST 0`과 형상 비교(measure)로 했다.
- `joint.sweep`은 첫 접촉에서 멈춘다. 그래서 완료 판정이 '전 행정 접촉 0'인 과제는 첫 접촉 뒤 구간을 나눠 다시 쓸어야 다음 접촉이 보인다. 이번에는 800→1250을 따로 쓸어 1222.49를 찾았다.
