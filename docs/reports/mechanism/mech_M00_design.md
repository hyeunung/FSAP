- 구매품 0(골격 상자 단계, 형번은 M01~M08). 해석 못 함 — 환경 없음(D-16), 보 처짐 손계산만.
- 미완: 없음. 전체 사이클 간섭은 라운드 끝 회귀(E-03).

## 1. 근거 규칙 (원문)
- E-02: "구동 과제는 승인된 구동 개념(E-01, 요구서 0-8)을 형상으로 옮기는 일이다 … 과제 안의 구상·선정은 개념 안의 세부(형상·치수·좌표·구매품 형번·브래킷)만 고른다."
- E-03: "과제 안 = 과제 범위 간섭 0 … 라운드 끝 = 전체 사이클 간섭 0".
- E-05: "이번 저장에서 새 컴포넌트(유닛·부품 묶음)가 생기거나 없어졌으면 가운데 +1·마지막 0, 아니면 마지막 +1", "이미 저장·커밋된 버전 파일은 덮어쓰지 않는다".
- E-10: "형번이 정해지지 않은 추정 바디, `REF`로 자리만 잡는 것은 금지다" — 상자는 구매품이 아니라 유닛 차지 공간(실행 규칙 20 "차지 공간 상자로 두고")이고, 이름이 `REF`가 아니라 간섭 검사에 들어간다.
- 실행 규칙 14: 커버·외장은 넣지 않았다(라이트 커튼·HMI는 0-8-3 U8 자리 상자만).
- L3 U-01 "핵심 기능의 정밀도는 비용으로 깎지 않는다" — 보 단면은 처짐 손계산으로 형재 묶음을 탈락시켰다(3절).
