## 워크플로우 메모
1. MCP 서버가 세션마다 바뀌어 허용 임시 폴더도 바뀐다(이번은 `solidcraft-mcp-12200-*`, 열린 문서는 앞 서버의 `-40196-*`). `batch {path}`와 `save`는 지금 서버 폴더만 받는다 — 거부 문구의 폴더 목록을 보고 그곳에 둔다.
2. `joint.edit` · `joint.delete`에 `quiet: true`를 안 주면 응답에 전 조인트 dof가 실려 1.7 MB가 된다. `motion.play`도 `quiet: true`면 응답이 작다.
3. `inspect.clearance`의 `against` 목록을 signatures.json REST bbox로 둘레만 골라 주면(371바디) 1초 안에 끝났다.
4. 첫 `batch`(편집 체크포인트 · 컴포넌트 3 · move_features)가 MCP 시간 초과로 돌아왔지만 `running` 빈 목록, 실제로는 적용돼 있었다(revision 2). 시간 초과 뒤에는 다시 보내지 말고 revision · 대상 상태부터 본다.
