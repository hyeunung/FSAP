## 워크플로우 메모
- MCP `batch` 하나에 `motion.play`(positions 전부) + `inspect.measure`를 18자세 넣으니 결과가 약 120만 자라 연결이 닫혔다(명령은 다 돌았다). 자세 측정 묶음은 `motion.play {quiet:true}`와 6자세 안팎으로 나눠야 한다 — 결과 크기 상한을 안내서 'MCP 편집 묶음'에 시간 말고 크기로도 적을 만하다.
- 스케치 숨김처럼 형상이 그대로인 저장이 서명 `full`을 부른다. 피처 수 비교 뒤 빈 sigpatch로 넘겼다(COLOR-01과 같은 길). 숨김·색만 바꾼 저장 뒤에는 저장한 부서가 빈 sigpatch를 찍게 하면 다음 부서가 헤매지 않는다.
