- 계산 파일 `tools/out/mech_F01-C1/design/newkeys.py`(→ `newkeys.json` 새 X·Y 키 전 단계, `newkeys_summary.json`), `wheelcheck.py`(→ `wheelcheck.json`).

- 측정부 19자세 미리 재기: 새 겹침 0(바늘 꿰뚫음 기준선만, MAT 20.1·TAPE 22.1·SEAM 1.01 mm³). 가장 가까운 틈 이음매↔슈 0.5.

## 1. 출발점
요구서 0-8-3 U3·U6·U7은 벤치마크가 있지만 이 과제는 유닛 형상이 아니라 작업 대상 모형 자리다. 근거: D-144/C-35 e = 날개 9 − 안쪽 여유 2.5 = 6.5(FUNC-01 손계산 ⑤), F01-S1 바인더 접힘선 X 6.5·바늘판 홈 X −4~10은 이미 e 6.5 기준(측정 6절). 벤치마크 없음 — FUNC-01 구동 후보 F01-C1(mech_FUNC-01_design.md 151행)을 그대로 옮긴다.

## 2. 왜 B인가
| 갈래 | 완료 판정 '가장자리 바늘 +X 6.5' | 바뀌는 키 | 판정 |
|---|---|---|---|
| A 키만 | REST·MAINT(키 0)에서 X 0 — 성립 안 함 | 직선 포함 거의 전 단계 X·Y | 버림 |
| **B 모형·원점 +6.5** | REST 포함 모든 자세 성립 | 피벗 단계 X·Y만(최대 6.5) | **택함** |

B에서 직선 키가 그대로인 이유: 바늘이 접선이 세계 Y인 가장자리 위에 있을 때 안쪽 법선 n은 세계 −X, 새 중심 c' = c − R(θ)·e·n = c + (6.5, 0), 원점도 +6.5 → 키 = c' − park' = c − park. 원호(홈 바닥)도 같은 식(접선이 세계 Y). 피벗은 θ가 도는 동안 매트 점이 꼭짓점에 고정이라 꼭짓점 차이 Δp = (−e, ±e)가 θ로 돌아 들어간다: 키 변화 = −R(θ)Δp − (6.5, 0), θ 0 → (0, −6.5)·θ 45 → (+2.69, 0)… 측정 표(+9.19 / 0 at 45°)와 같다.
