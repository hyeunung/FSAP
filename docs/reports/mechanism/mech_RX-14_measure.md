## 워크플로우 메모

1. MCP 서버의 허용 폴더가 작업 폴더가 아니었다(`recovery`와 `Temp/solidcraft-mcp-*`뿐). `batch {path}`가 `tools/out/` 파일을 거부해 선 목록을 임시 폴더에 복사해 불렀다. 저장본은 앱에 이미 열려 있어 `open`은 부르지 않았다.
2. `view.pick`은 숨긴 매트 모형도 맞힌다. X ≤ 6.5 칸은 매트 모형이 먼저 잡혀 바늘판 홈을 옆으로 쏜 선으로 다시 쟀다.
3. `view.pick` 1,000선은 0.2~3 s로 끝났다. 프로브 바디를 만들지 않고 빈 공간을 잴 수 있다(편집 0, dirty 그대로).
4. 이 컴퓨터 파이썬에 numpy가 없어 덮임 지도를 순수 파이썬으로 돌렸다.
5. 시간: MCP 19회(열기 0 — 앱에 열려 있던 저장본을 그대로 씀), 브라우저 0. 자세를 바꾸지 않아 동작 상태 초기화는 필요 없었다(측정 뒤 dirty false, 조인트 값 대기 그대로).
