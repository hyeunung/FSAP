## 4. 손계산(E-18 — 형상이 바뀐 것만)

### 4-1. 기둥 장공(`P_T01_POST`, PET-CF)
- 하중: DP-2 관 뿌리 오조작 275.6 N, 작용점 Z −0.5(레버 220.5 → −221). 장공 Z −203 레버 202.5 → **M = 55,809 N·mm**.
- 온 관 I = π(60⁴ − 40⁴)/64 = **510,509 mm⁴**. 장공 3개(120°)는 한 개 넓이 5.5 × 10 = 55, 반지름 25. 120° 셋은 굽힘 방향과 상관없이 Σcos² = 1.5라 ΔI = 55 · 25² · 1.5 = **51,563**(제 축 몫 ≤ 1,400 더해도 차이 0.3 %). I' = 458,946.
- σ = M · 30 / I' = **3.65 MPa**. 장공 긴 축이 응력 방향(관 축)과 나란해 Kt ≈ 1 + 2·(2.75/5) = 2.1, 보수로 **2.5** → 9.12 MPa. PET-CF 층간 20 MPa(DP-2와 같은 값, SF 5.60 ↔ 3.57 MPa) → **SF 2.19 ≥ 2**(M-09 오조작). 기준 +10 % 안(2.2 미만)이라 원래는 FEA 확인 대상이다 → **해석 못 함 — 환경 없음(D-16)**, 환경이 생기면 v0.6.15 `P_T01_POST` STEP으로 확인.
- 비교: 구상 1 Ø6 ×6(I_net 398,000) → SF 1.59(Kt 3) / 1.90(Kt 2.5). 둥근 Ø10 ×3 → ΔI 93,750 → SF 1.99.

### 4-2. 꼬임(관 6줄 `TU0425`, 묶음 피치 반지름 4 = 2/sin 30°)
- 꼬임 길이 L = 장공 −203 → 굽힘 시작 −351.5 = **148.5**.
- 중립 −180°(묶을 때)면 운전 ±π: 늘음 √(148.5² + (π·4)²) − 148.5 = **0.53 mm(0.36 %)**. 0°에서 잘못 묶으면 2π: **2.11 mm(1.4 %)**. 관 길이에 여유 10을 둔다.
- 관 제 비틀림: J = π(4⁴ − 2.5⁴)/32 = 21.3 mm⁴, G 10 MPa(PU 자리값, 카탈로그 미확인) → T = GJθ/L = 10·21.3·π/148.5 = 4.5 N·mm/줄, 6줄 **0.027 N·m**. Y판 결속 반력 = 0.027/0.085(굽힘 끝 → 결속) = **0.3 N**.
- 겉면 전단 변형 γ = 2·π/148.5 = 0.042. 반복 꼬임 수명은 요구서 7절 시제품 확인으로 기록(E-12).

### 4-3. 판금·가공품 구멍
- 스파이더 다리 Ø4: 아래 구멍 끝 Z −210.5 ↔ 밑 날개 굽힘 안면 −230 = **19.5 ≥ 2t 6**(M-04 "구멍–굽힘선 거리 ≥ 2t"). 위 구멍 끝 −195.5 ↔ 웹 −98.5 = 97. 다리 끝(Y −600·−210)까지 ≥ 40. 단면 감소 Ø4 ×2(세로) → 다리 높이 134.5 중 8(6 %), 스파이더 강도 판정 단면(뿌리)은 아니다 — 디테일 기록.
