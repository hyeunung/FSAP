## 1. 기하 다시 셈

피벗 P (−300, 70), 고정 핀 F (−161.006, 225), 크랭크 핀 θ0 C (−347.8, 203.6), 회전 x' = x cosθ − z sinθ, z' = x sinθ + z cosθ (피벗 기준).

| 자세 | θ° | C | 핀 사이 |C−F| | 설계안 |

| 내림 끝 | −1.867 | (−343.42, 205.09) | 183.50 | 183.50 |
| 누름 | 0 | (−347.80, 203.60) | 188.02 | 188.02 |
| 들림 | 8.626 | (−367.30, 194.92) | 208.47 | 208.47 |

- θ0 실린더 팔: (P−F) × (C−F) / |C−F| = |(−138.994)(−21.4) − (−155)(−186.794)| / 188.02 = 25,979 / 188.02 = **138.17**. 레버비 138.17/200 = 0.6909 → 맞음.
- 방향: 크랭크 핀은 피벗 위(+133.6)에 있어 당김(+X)이 θ를 줄인다(dx'/dθ = −133.6 at θ0) → 당김 = 누름 → 맞음.

## 3. 안 맞는 것 — 고칠 자리

### P1. U4 회로 재배선의 관·포트가 정해지지 않음 (항목 ④)

- 설계안 2-1: "IR1000-01BG(U4용)를 밸브 A → IR1000 IN, IR1000 OUT → TU0604_M08P_U4_A로 누름 관 사이에 둔다 … 새 구매품 0(있는 IR1000·관·피팅 재배선)". 근거로 낸 것은 이 문장뿐이고, 관 길·피팅·남는 포트가 없다.
- 지금 모델(signatures.json): IR1000-01BG_M08 몸 X 682.5~717.5 · Y 77.5~113 · Z 472.5~565, 포트에 KQ2L08-01AS(Ø8, TU0805 관, 포트 Z 482). 밸브 SS5Y3-20-06은 X 1035~1117, 밸브 포트 피팅은 KQ2L06-M5A(Ø6). 관 TU0604_M08P_U4_A는 X −178 ~ 1052.8 한 줄(밸브 1번 A → U4).
- 그대로 옮기면 생기는 것:
  1. 밸브 1번 A(Ø6) → IR1000 IN(Ø8 피팅): 관 지름이 안 맞는다. IR1000 IN·OUT 피팅을 KQ2L06-01AS(Rc1/8, Ø6)로 바꾸거나 이경 이음이 필요한데 구매품 표에 없다("새 구매품 0"과 어긋남).
  2. 1번 스테이션 개별 급기 스페이서의 급기 포트: 지금 IR1000 OUT이 들어오는 자리. IR1000을 빼면 이 포트가 빈다(또는 주 공급을 새로 이어야 한다). 설계안의 "1번 밸브 급기 = 주 공급"을 어떻게 만드는지(스페이서 급기 포트에 주 공급 티 KQ2T08-00A 가지 연결, 또는 스페이서를 빼고 매니폴드 공통 P) 정해지지 않음.
  3. 주 공급 → IR1000 IN의 지금 티 가지(KQ2T08-00A)가 IR1000을 떠나면 빈다(2와 합치면 그 가지를 스페이서 급기로 돌리면 된다).
  4. TU0604_M08P_U4_A를 IR1000 자리(X 약 700)에서 둘로 끊어 밸브 쪽 토막(X 700~1052)과 U4 쪽 토막(X −178~700)이 되는지, 끝점 좌표·굽힘 R이 없다.
- 고칠 자리(같은 설계자가 이 부분만):
  - (a) IR1000-01BG_M08 (U4용 한 대) IN·OUT 포트 피팅 KQ2L08-01AS ×2 → KQ2L06-01AS ×2(보유 여부 확인, 없으면 구매품 표에 2개 더함).
  - (b) TU0604_M08P_U4_A를 IR1000 포트(Z 482 부근, X 682.5~717.5)에서 끊어 `_A1`(밸브 1번 A 피팅 → IR1000 IN)과 `_A2`(IR1000 OUT → U4 J_A)로 나누고 두 토막의 끝점 좌표·접선·굽힘 R ≥ 15를 적는다.
  - (c) 1번 스테이션 개별 급기 스페이서 급기 포트를 지금 IR1000 IN에 가던 주 공급 TU0805 가지(KQ2T08-00A)에 그대로 잇는다(관 끝 좌표 적음) — 빈 포트 0, 막힌 가지 0을 표로.
  - (d) U6 쪽 IR1000(3번 스테이션)은 그대로임을 적는다.
  - (e) IR1000 릴리프로 로드 쪽이 빠지는 들기(밀기) 행정 부피 263.9 × 25 = 6.6 cm³ — 들기 시간은 7절 시제품 확인으로 이미 남김(설계안 9절), 그대로 둠.

- 회로를 바꾸는 과제(들기 SF 고침)가 유닛 과제 안에서 생기면, 설계안 '관 끊김·빈 포트' 증거가 유닛 쪽 관만 보고 U8 쪽을 빠뜨리기 쉽다. 설계안 서식에 '바뀐 공압 포트 표(포트·이어진 관·피팅 지름)'를 두면 좋겠다.
