## 7. CAD 통로·원복

- SolidCraft MCP `running`은 "headless — 앱 없음"이라고 답했다. 그래서 앱 MCP 대신 CLI `solidcraft-cli run <script> --in 3D_Modeling/FSAP_v2.3.2.sc --results`로 쟀다(저장 없음, 실행 규칙 2, WF-121). 앱 문서·저장본 모두 바뀌지 않았다. 스크립트마다 맨 끝에 `motion.play REST step 0`을 넣었다.

## 워크플로우 메모
- 3,762바디(볼 3,000여 개) 파일에서 CLI `inspect.clearance`에 `nearest`를 주면 1161바디 전수 거리를 계산해 25분을 넘었다. 측정 스크립트는 bbox 사전 걸러내기(30 mm) + `clearance`만으로 하고, `nearest`는 쓰지 않는다. 같은 저장본에 CLI를 3개 병렬로 돌리면 각각 2~3배 느려져 8분 상한에 걸렸다. 혼자 도는 측정은 직렬로 돌린다.
- signatures bbox가 U2 형재 3종에서 X −2650으로 잘못 잡혀 있다(실제 −2178). 이 bbox를 믿고 기둥과 '겹침 480,000 mm³'으로 읽을 뻔했다(WF-128과 같은 종류).
