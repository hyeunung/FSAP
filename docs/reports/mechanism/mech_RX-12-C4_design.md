# RX-12-C4 기구설계 — 긴 매트(MAT_W) 회전 시간 키·미끄럼 SF 정식 계산

## 요약

- 바뀌는 부품 0 · 조인트 0 · 연구 키 0(.sc 형상 변경 없음). 바뀌는 것은 `tools/machine.json` `_timing.CYCLE_W` 시간 메모뿐(연구에는 시간 키가 없다).
- 식: DC-02·DC-03·RX-11과 같은 미끄럼 SF = 바퀴 마찰 토크 ÷ (구름·원판·노루발·롤러·받침 밖 끌림 + 관성 × 삼각 속도 α). 원본 `tools/out/mech_RX-12-C4/design/rx12c4design.py` → `rx12c4design.json`.
- **판정 받침 상태: RX-12-C1 접이 받침 `U2_FLAP` 폄.** 지금 모델(v2.25.2)에는 포켓(X > 400 · Y < −300) 받침이 없어 W1 518~562 U4 혼자 45°에서 매트 1.327 kg이 받침 밖 → 끌림 μe 0.30이면 SF 0.343, 시간을 늘려도 정지 SF가 1 미만(측정부 μe 한계 0.070). 이 항은 시간 키로 풀 수 없고 C1 받침이 0으로 만든다(볼 받침 밖 0 kg, 패널 틈만 0.028~0.034 kg).
- 새 키(SF ≥ 1.10 목표, 0.1 s 올림): 볼록 A·D·B·C **4.1·4.2 → 2.9**, 오목 입구 **2.8 → 1.7**, 안 모서리 U4+U5 **1.6 → 1.0**, 안 모서리 U4만 **2.8 → 3.2**. 최소 SF 1.106(입구2), U4만 1.107·1.155. 회전 키 합 **31.0 → 23.4 s**(−7.6 s).
- 옛 키 2.8은 C1 받침 상태에서도 U4만 SF 0.992(< 1, 패널 틈 끌림 0.06 N·m 포함)라 늘렸다.
- 제어 순서 제약(U-09): CYCLE_W(오목이 포켓 위로 가는 매트)는 `J_U2_FLAP` 0(폄)·빗장 잠김 확인 뒤에만 돈다. C1이 바뀌거나 빠지면 이 키 중 입구2·안 모서리2(W1 350~562)는 무효.
- 미완: 없음(이 과제 범위). 임시값 D-92 · D-95 · D-96 · D-145 · D-152 · D-01 · D-02에 달림 — 실측이 오면 다시 낸다.

## 1. 식과 임시값

T_have = μ 0.4 × (F4 40 N × d₁ 0.100 + [U5] F5 40 N × d₂ 0.440)
T_need = c 0.02 × Rg + 원판 0.048 + 노루발 0.096 + [U5] 0.05 × 40 × d₂ + 2 × 0.18 × Σ|x|롤러 + μe 0.30 × Rg_받침밖 + (I + 0.0217 + [U5] 2 × 0.219 × d₂²) × 4θ/t²

| 값 | 임시 | 출처 |
|---|---|---|
| μ 바퀴–파일 | 0.4 | D-95(불리 쪽) |
| F4·F5 누름 | 40 N | D-92 |
| c 볼 구름 | 0.02 | D-96 선정 조건(C-37) |
| 면밀도 | 6 kg/m² → 5.4 kg | D-145 |
| d₂ | 440 | D-152 |
| 원판 끌림 0.048 · 관성 0.0217, 노루발 0.096 | DC-01 · DC-04 | machine.json `_timing._note` |
| 롤러 c_w 0.05 · 0.18 N/줄 · 환산 0.219 kg | RX-11 | rx11design.py |
| μe 받침 밖 끌림 | 0.30(참고) | 가정, 매트 뒷면–SUS 가장자리 — 판정에 쓰지 않음 |
| I · Rg · Σ\|x\| | 측정 2절 | measure_w.json |

## 워크플로우 메모

1. 연구에 시간 키가 없어 이 과제는 machine.json 메모만 바꾼다 — 모델링·검도 부서를 거치면 .sc 열기(13~27분)가 헛돈다. 시간 키 과제는 설계 → 문서로 바로 가는 갈래가 있으면 빠르다.
2. 저장본 .sc는 zip이고 document.json에서 연구 단계 수·조인트 키를 CAD 없이 읽을 수 있었다(읽기 확인 0.5분).
3. 키 과제가 동시 과제(RX-12-C1)의 결과 받침에 달린다. 동시 묶음에서 '받침 조건' 같은 의존을 표시하는 칸이 없다.
