# 구동 RX-11 모델링 수정 1회차 — 새들 볼트 조임 토크 3 → 0.6 N·m (형상 그대로)

## 요약

- 지적(검증·해석 RX-11-F1, kind 동작): `CB5-20_RX11` ×8을 지정 조임 3 N·m(예압 3,000 N)로 죄면 새들 `P_RX11_SADDLE` 축 홈 포켓 위쪽 압축이 231 ~ 250 MPa로 A5052 항복 195 MPa를 넘는다(SF 0.78 ~ 0.84).
- 고친 것: **형상·위치·재질·조인트는 그대로.** 볼트 컴포넌트 `CB5-20_RX11`(8 occurrence)의 부품 속성에 조임 토크 **0.6 N·m**(예압 약 600 N) + **중강도 나사 고정제(Loctite 243 상당)**, "3 N·m·표준 토크 금지"를 적었다(description의 "(3 N.m)"를 지우고 고쳐 씀, properties 조임토크·나사고정제·근거 3개 새로).
- 저장: `3D_Modeling/FSAP_v2.17.1.sc`(v2.17.0에서 마지막 자리 +1, 수정 1회차 — E-05·WF-179). `tools/config.json` doc · `tools/machine.json` doc 바꿈. 통로 MCP(앱). v2.17.0 파일은 덮어쓰지 않음.

## 4. 넘기기 전 확인 — 새들 3점 굽힘 손계산 (E-22)

해석부와 같은 모델: 볼트 예압 F가 가운데를 누르고 귀 두 곳(받침 가운데 Y ±24.75, 불리한 쪽)이 받친다. 단면은 해석부가 STEP에서 잰 Y 7.9 포켓 끝(I 999.18 mm⁴, c_위 9.86 mm). σ_위 = (F / 2) × (24.75 − 7.9) × c / I. 항복 195 MPa(A5052, 해석부와 같은 값). 바퀴 누름 항은 해석부 '새들 — 바퀴 누름 130 N만' 최대 10.8 MPa를 자리와 상관없이 더했다(불리). 원본 `tools/out/mech_RX-11/model1/fix1calc.json`.

| 조임 N·m | 예압 N | M N·mm | σ_위 MPa | SF(예압만) | SF(+ 운전 누름 46.54 N) | SF(+ 오설정 130 N) | 판정 |
|---|---|---|---|---|---|---|---|
| 3.0(앞 지정) | 3,000 | 25,275 | 249.4 | **0.78** | 0.77 | 0.75 | 항복(지적과 같음) |
| 0.78(0.6 + 30 %) | 780 | 6,572 | 64.8 | 3.01 | 2.84 | 2.58 | 흩어짐 위쪽 끝, 아래 디테일 |
