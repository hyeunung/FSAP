## 워크플로우 메모

- `motion.interference`에 `HEAD:1·PRESSER:1·NEEDLE:1`을 against로 더하면 "too many bodies for a contact sweep"로 거부된다(1회차 7개 연구 중 4개가 215초 뒤 실패). 측정과 같은 6개 occurrence로 돌렸다. 헤드 쪽 가동부는 Z만 움직이고 Y ≤ 850이라 문(Y ≥ 920)과 70 떨어진다. 안내서 '동작 검사'에 "against는 바디 수 상한이 있다, 헤드처럼 큰 묶음은 정적으로"를 적으면 좋겠다.
- 지시문의 "최신 문서 v0.6.10"이 config.json doc(v0.6.15)와 다르다. 실행 지시 (a)가 이전 실행 문구 그대로다.
- `stepcheck.py`는 Windows 기본 콘솔(cp1252)에서 한글 출력으로 예외가 난다. `python -X utf8 -B`로 돌려야 한다(실행 규칙 5에 있지만 지시문의 명령에는 빠져 있다).
