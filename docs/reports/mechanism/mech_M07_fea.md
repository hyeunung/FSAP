## 4. 문제와 고치는 법
**F1 (동작) 보 끝이 마찰로만 기둥에 걸림.**
- 어디: P_M07_SEAT_NX/PX 세로 다리 ↔ 기둥 홈의 CB5-12 + HNTT8-5 ×6, P_M07_SPLICE_NX/PX ↔ 4080 뒷면 ×4. 보 249.99 kg + 걸린 것 약 126 kg가 실린다.
- 수치: 3절 1·1′. 볼트 길이를 고쳐도 3 g에서 SF 0.96(μ 0.15)이다. T너트는 홈을 따라 미끄러지므로 받쳐 주는 턱이 없다.
- 고치는 법(구조 판단 — 기구설계부·PM이 정함):
  - **(안 A, 추천) 보를 기둥 위에 얹는다.**
    - 기둥 HFS8-80160·4080을 Z −840~250(1,090)으로 줄여 윗끝면이 보 밑면 Z 250을 받게 한다.
    - 보를 X −2380~1230(3,610)으로 늘려 끝 80이 기둥 윗면에 얹히게 한다.
    - 기둥 안쪽 면 X −2300·1150은 그대로라 휘두름 틈 177.3·225.9가 바뀌지 않는다.
    - 받침 L은 위치 맞춤용으로 남기거나 뺀다. 기둥 위 캡 HFC8은 보가 덮으므로 빠진다(U-19 '맞대 막힌 끝').
    - 보 끝 열린 속은 끝판으로 막는다(이음판을 끝판으로 겸할 수 있음).
    - 받침면 압축은 6,617 N / (80 × 200)이라 0.4 MPa이고, 반력 위치는 X −2340 / 1190이 된다.
    - 경간이 3,530으로 늘어 처짐은 약 9~12 % 는다(정하중 약 0.047 mm, 변화량은 그대로 ≤ 0.003).
  - (안 B) 받침 L 세로 다리 밑에 양의 받침을 둔다. 예: 기둥에 미스미 형재 추가공 관통 구멍 + 핀이나 볼트로 전단 받침. 형재 벽 지압·추가공 가격을 따로 봐야 해서 차순위다.
  - 마찰만 늘리는 길(M8 T너트 HNTT8-8 + CB8, 10 N·m → 6.25 kN)은 10개 × 6.25 kN × 0.15 = 9,375 N이다. 3 g SF 1.42 < 3이라 디테일이 남는다. U-12 예외도 필요하다. 추천하지 않는다.

**D1 (디테일) 받침 L t9 굽힘 SF 1.9~2.3 < 3.** 안 A를 쓰면 받침이 하중 길에서 빠진다. 안 B를 쓰거나 지금 구조를 유지하면 t12로 하거나 세로 다리 둘레에 리브(굽힘 R 쪽 삼각 판금 2장)를 단다.

**note 과사양.** 보 SF 47, 이음판 SF 49. 줄이지 않는 이유는 3절 5·6에 있다.
