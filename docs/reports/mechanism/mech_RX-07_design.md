## 2. 두 안 비교표 (완료 판정 ①)

가정: 플로트 W 64.7 N(CAD), 스프링 k 0.2 ×2, 자유 132.4, f 부시 4 N(D-146). 스무스 실린더 마찰은 최저 사용 압력 0.03 MPa × 면적(M02R-M6·D-188과 같은 가정, 카탈로그 미확인).

| 항목 | **A 스프링 플로트(고름)** | B1 스프링 + 아래로 미는 φ10 실린더 + IR1000 | B2 스프링 대신 위로 받치는 φ16 실린더 + IR1000 |
|---|---|---|---|
| 힘 식 | F = W − 0.4·(132.4 − 75 − u) | F = F_A' + p·78.5 − f_cyl | F = W − p·201.1 ± f_cyl |
| 설정 힘 | 45.74(매트)·46.14·46.54 N | F_A' ≈ 30 N + 0.1 MPa × 78.5 = 7.9 → 37.9 N. 단 F_A' 30 N은 칼라 39 mm 내림 = 휨 73 %로 지금 스프링(최대 48 %) 불가 → 센 스프링 새로(형번 없음) | p 0.131 MPa → 38.3 N |
| 조정 폭 | 칼라 1 mm = 0.4 N(공구, 칼라 2개) | 0.01 MPa = 0.79 N(손잡이) | 0.01 MPa = 2.0 N(손잡이) |
| 마찰 f | 4 N | 4 + 2.4 = 6.4 N | 4 + 6.0 = 10.0 N |
| 자국 SF min | **1.021**(이음매) | 51.6/(38.7+6.4) = 1.144 | 51.6/(38.3+10) = 1.068 |
| 잡기 SF min | **1.67** | (37.9−6.4)/25 = 1.26 | (38.3−10)/25 = 1.13 |
| 두께 변화 | 칼라 (t−6) 내림(F01-Q2), 두께 16 휨 47.9 % | A와 같음(스프링 몫) | 압력 일정이면 두께 무관 |
| 공기 0 | 45.7 N 그대로 | F_A' ≈ 30 N(창 안) | **64.7 N, 자국 SF 0.80** |
| 부품 수 | **0** | +13(실린더 1, 브래킷 1, 누름판 1, IR1000 1(브래킷 포함), 이음 3, 관 1, 볼트 4, 소음기 1) | +11 −6(스프링 2·자리 2·칼라 2) = +5 실질, 새 팔 1 |
| STEP | 있음(스프링·칼라는 이미 STEP대기) | 실린더 '없음' | 실린더 '없음' |
| 배치 | 바뀜 없음 | 빈 칸 X −1985~−1875·Y −68~−20(축 X −1847에서 83 떨어짐) | 같은 빈 칸, 플로트 위로 팔을 내야 함 |
| 회로 | 바뀜 없음 | 상시 급기(밸브 없음, 매니폴드 빈 스테이션 0이라 밸브 못 붙임) | 같음 + 잔압 배기 때 F = W |
| 벤치마크 일치 | 레귤레이터 2개(사진 3개와 다름) | 3개 | 3개 |

판정: B1·B2 모두 창 안에 들 수는 있으나 f_cyl이 카탈로그 미확인 가정이고(창 반폭 13.3에 대한 여유가 가정값에 달림), 부품·STEP 대기가 늘고, B2는 공기 0에서 자국 한도를 넘는다. A는 모든 항목이 이미 모델에서 측정된 값으로 창 안이다. **A를 고른다.** 벤치마크와 레귤레이터 수가 다른 것은 F01-S2 수정 2에서 이미 수치로 정한 것이고, 3번째 용도는 사진 추정이다.
