- 디테일(기록만): W2 타공 판 강도. 운전 SF는 2.48(B)·2.15(A)로 기준 3에 못 미친다. 오조작 SF는 1.33(B)·1.16(A)로 기준 2에 못 미친다. 1.2 경계 근처라 환경이 생기면 FEA로 다시 본다. 포켓 가장자리(M04-X3)는 작업자 100 N에서 1.82 mm다.
- 여유 큼(과사양 note): 센터판 SF 128(t40은 Z 0 기준면·평면도 때문, M04-X5 살빼기), 레일 72, 침목 40, DISK_BASE M5 탭 82.
- completion_met은 false다. 이유는 둘이다. 첫째, 위의 볼 정격 동작 문제가 있다. 둘째, 볼 바디가 저장본에 없다(모델링부 예외). 그래서 '매트 뒷면이 볼 위' 항목은 설계안 판정으로만 남는다. 해석 항목인 처짐 기록은 채웠다.

## 1. 근거 규칙 (원문)
- E-18: "체결만 바뀐 자리는 손계산, FEA는 형상·하중 경로가 바뀐 부품만" → 판·센터판·틀은 하중 경로가 새로 생긴 부품이다. 그러나 환경이 없어서 손계산만 했다.
- 지시서: "얇은 판·스프링(두께/길이 < 0.1)은 handcalc beam을 먼저 본다"
  - 판 t4는 경간 160~440이라 t/L은 0.009~0.025다.
  - 판 가운데 하중은 보로 보면 너무 보수적이다. 그래서 Roark 판식을 썼다.
  - 포켓 가장자리 외팔에는 `beam`을 썼다.
- 요구서 6-1: "기본값 — M-09" → 운전 SF 3, 오조작 SF 2.
- 요구서 6-2: "미정(D-08)" → 처짐은 기록만 했다.
- 지시서: "부러짐·영구 변형(SF < 1.2)·동작을 망가뜨리는 처짐만 kind='동작'" → 볼 정격 초과는 동작이고, 판 SF 1.33은 디테일이다.
- C-03: "영구 눌림자국 금지" → 볼이 영구 변형되면(평탄화·패임) 매트 뒷면에 점자국이 생길 위험이 직접 커진다.
- E-02: "강도 여유·정밀 체인·…은 디테일로 기록만" → 판 SF 미달은 기록만 했다.

## 2. 형상·하중

**하중**(1 g, N/mm²):

**바퀴:**

- 판정은 B로 한다. 레일 위에서 판이 이어져 고정 효과가 생기는데, 그것은 빼고 셌다. 그래서 B도 보수 쪽이다.
- 처짐이 0.2~0.9 mm면 볼 꼭대기가 그만큼 내려간다. 누름은 공압 일정 힘이라 행정·걸림에는 영향이 없다(측정 5절과 같다). 매트 위치 오차는 6-2(D-08)에서 정해진 뒤 본다.
- 디테일 M04-F2: 운전 2.48 < 3, 오조작 1.33 < 2. 고치는 안은 셋이다.
  - (a) W2만 t5로 바꾼다. σ가 ×0.64 → 운전 3.9, 오조작 2.08이 된다. 대신 높이 사슬이 1 mm 바뀐다(레일 윗면 −13 또는 볼 돌출 7).
  - (b) 바퀴 줄을 받는 레일을 Y ±60으로 좁힌다. 그러면 Y ±50 볼 줄이 빠진다.
  - (c) D-97 평판 띠안을 쓴다.
  - 3-2의 볼 교체와 함께 정하면 된다.

## 워크플로우 메모
- 지시서 하중의 '바퀴 누름 100 N'(완료 판정)과 M03 해석의 바퀴 접촉력(운전 238.6 N = 100 N + 자중 3 g 몫)이 다르다. 그래서 둘 다 셈했다. 받침 쪽 과제(M04)는 앞 과제(M03) 바퀴 경우 표를 그대로 이어받도록 지시서에 경우 표를 넣으면 좋겠다.
- 설계안 손계산(design_check)이 판 종횡비를 무시하고 정사각 계수를 썼다. 기구설계부 손계산에서 판식을 쓸 때는 a/b를 함께 적도록 하면 좋겠다.
