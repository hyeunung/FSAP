# N03 U4 X·Y 따라가기 받침 — 기구설계부 3번 구상 (v1.0.7 기준)

요약
- 안 C3 "보 속 Y 나사 + 낮은 넓은 Y 레일 + +Y 띠 X 나사 한 줄": X는 레일 A·B 자리에 SSEBL20 두 줄(H 30 + 받침판 10 = 높이 40 예산 그대로), X 볼나사 BSS2520-1700은 고정 +Y 띠(Y 1060·Z −335)에 한 줄. Y는 보를 알루미늄 각관 2본(95×80, 가운데 틈 100)으로 나눠 틈 속에 BSS2520-1950(축 Z −300)을 넣고, 각관 윗면에 낮은 넓은 소형 레일(H 16) 두 줄 + 대차판 14 → 높이 사슬 Z −230 그대로.
- Y 모터(MHMF042L1U2M)는 보 −Y 끝 밖 Y −1045~−1157(비어 있는 −Y 띠), X 모터(MHMF082L1U2M)는 X 나사 −X 끝 X −1377~−1265.
- 한계: J_U4_Y −355~1155(깨끗한 −360~1160 안, 쓰는 −350~1150 포함), J_U4_X −200~1217.5 그대로. xy_forbidden에 DC-05-D1 띠(원판 중심 X −90~90·|Y|<105) 추가.
- 핵심 수치: 따라가기 저항(나사·모터 회전 관성 환산 포함) X 약 72 N·Y 약 54 N ≤ 100 N(D-79). 위험 속도 X 1000 rpm(333 mm/s)·Y 783 rpm(261 mm/s) > 봉제 133 mm/s. 보 처짐 약 0.39 mm(기록만, 정밀 체인 디테일).
- 부품: 더함 38, 뺌 4(N00 상자) → +34(볼트 제외). STEP 있음: BSW20·BUN20·SCXW46-15-19. 없음(STEP대기_): BSS2520-1700·-1950, SSEBL20-1900, 낮은 넓은 레일 15, MHMF082/042, SCXW46-14-15.
- 미완: 카탈로그 값 전부 E-12 임시(provisional), 가격 미확인. 낮은 넓은 레일 형번은 카탈로그 표에 없음. 개념 충돌 없음.

## 5. 하중 손계산 (E-18, 카탈로그 값 E-12 임시)

입력: X 이동 질량 105 kg(N00, D-79), Y 이동 31 kg(측정 5절), 봉제 끌림 100 N(D-79), 따라가기 가속 0.2 m/s², 위치 모드 가속 상한 0.5 m/s², 블록 구름 μ 0.005, 블록 씰 저항 블록당 3 N(임시), 나사 예압 토크 0.05 N·m(임시), 역효율 0.8.

회전 관성(리드 20 → (2π/L)² = 98,696):
- X 나사 Ø25×1700: J = π/32·ρ·L·d⁴ = 5.12×10⁻⁴ kg·m², 모터 1.51×10⁻⁴, 커플링 0.4×10⁻⁴ → 환산 질량 7.03×10⁻⁴×98,696 = **69 kg**
- Y 나사 Ø25×1950: 5.87×10⁻⁴, 모터 0.67×10⁻⁴, 커플링 0.4×10⁻⁴ → **69 kg**

따라가기 저항(헤드가 끌 때, 서보 보조 없음 가정 = 가장 불리):
- X: (105+69)×0.2 = 35 + 105×9.81×0.005 = 5 + 씰 4×3 = 12 + 예압 2π×0.05/(0.02×0.8) = 20 → **72 N ≤ 100 N, SF 1.39**
- Y: (31+69)×0.2 = 20 + 1.5 + 12 + 20 → **54 N ≤ 100 N, SF 1.85**
- N00의 26 N은 나사·모터 회전 관성을 넣지 않은 값이다. 넣으면 X가 72 N으로 여유가 줄어든다 → 봉제 중 서보 보조 토크(속도 피드포워드)로 낮추는 것이 기본(0-8-1 "필요하면 서보가 보조").

서보 토크(위치 모드 0.5 m/s², α = 157 rad/s²):
- X: 관성 (1.06×10⁻³ 부하 + 7.03×10⁻⁴)×157 = 0.28 N·m + 추력 (105×0.5+5+12)×0.02/(2π×0.9) = 0.25 → 0.53 N·m ≤ 정격 2.39(SF 4.5). 부하 관성비 (1.06+0.51+0.04)/0.151 = 10.7
- Y: (3.1×10⁻⁴ + 6.94×10⁻⁴)×157 = 0.16 + (15.5+1.5+12)×0.02/5.65 = 0.10 → 0.26 N·m ≤ 1.27(SF 4.9). 관성비 (3.1+5.87+0.4)/0.67 = 14

위험 속도(고정-지지 λ 15.1, 골지름 약 21, 계수 0.8):
- X 지지 사이 1590: 15.1×21×10⁷/1590² = 1254 → 1000 rpm(333 mm/s)
- Y 지지 사이 1860: 15.1×21×10⁷/1860² = 917 → 733 rpm(244 mm/s). 위치 모드 Y 속도 상한 240 mm/s로 고침(2절의 250 대신). 봉제 최대 8 m/min = 133 mm/s(400 rpm)는 여유

가이드:
- Y 블록 한 개 최대: 자중 31×9.81/4 = 76 + 밀기 20/4 = 5 + 끌림 모멘트 100 N×Z 거리 0.25 m = 25 N·m ÷ 블록 간격 0.19 ÷ 2줄 = 66 → 약 147 N ≤ C0 7 kN(임시) SF 48
- X 한쪽 구동 비틀림: 0.5 m/s²에서 F = 105×0.5+17 = 70 N, 편심 1.06 m → 74 N·m ÷ (2줄 × 블록 간격 0.19) = 195 N/블록(옆방향) ≤ C0 15 kN
- 나사 축하중 최대 약 70 N ≪ Ca 6.9 kN

보 처짐(기록만, E-02 정밀 체인): 각관 2본 I = 2×(95×80³−85×70³)/12 = 3.25×10⁶ mm⁴, E 69 GPa, 지지 간격 1920(X 레일 ±960). 대차 304 N 가운데 0.19 + 보 위 분포 약 490 N 0.19 → 약 0.39 mm. 원판 윗면 Z 0 높이 흔들림이 되므로 디테일에서 강 각관 또는 단면 키움을 본다(테이블 기둥은 레일 가까이 |Y| 900~980에 있어 테이블 하중은 처짐에 거의 안 들어감).
