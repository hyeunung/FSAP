## 워크플로우 메모
- 지시문의 "지난 못 본 범위"가 회귀 8 기준이라, 같은 실행의 REG-01 r5가 이미 본 범위(CYCLE_G2·MAINT_U7·POSE 76점)가 다시 들어 있었다. 원장을 보고 알아채 세션 12개를 열다 말고 멈췄다(약 4분 낭비). 회귀 지시문은 원장의 최신 통과 항목으로 못 본 범위를 다시 셈해 넘겨야 한다.
- `TaskStop`으로 멈춘 `run.sh`(Git Bash)가 실제로는 살아 남아, 데우기 뒤 같은 `runsB`·같은 명세로 regrun을 하나 더 띄웠다. 두 regrun이 같은 세션 5개를 나눠 써 점이 두 번씩 재졌고 `runsB/regrun.json`이 덮였다(두 결과를 `regrun_B2.json`·`regrun_B1old.json`으로 따로 남김, 판정은 summary 합집합). 백그라운드 셸은 PID로 확인해 멈춰야 한다.
- regrun 시험 점이 다른 실행과 겹치면 235 s로 재져 어림이 22,286 s로 부풀었다(WF-197 반복). 같은 세션을 쓰는 실행이 둘이면 시험값이 쓸모없다.
- F_STATES 빠른 검사는 유닛 하나(U7_TAPE)만으로 18분이 넘는다. 전체 회귀 상한 30분 안에 들 수 없어, 검사 정의(유닛 사이 + near_all 전부)를 줄이거나 STATES 일반 검사로 대신할지 정해야 한다.
