# DC2-06 측정 — 바늘 옆 바퀴 마운트 ↔ 머리판 (v2.1.0)

## 요약
- 대상 `3D_Modeling/FSAP_v2.1.0.sc`(105바디, 피처 303). MCP로 한 번 열고 이어서 쟀다. 저장하지 않았다. 끝난 뒤 원복 확인: dirty false, 바디 105, REST step 0.
- 측정 표 sigcheck 결과는 `reuse`(문서·해시 같음, 105부품)였다. bbox·부피는 `tools/out/signatures.json`에서 가져왔고, 새로 잰 것은 프로브뿐이다.
- 과제에 적힌 "U4_MOUNT X −90, 틈 10"은 M00 차지 상자 때 값이라 지금은 맞지 않는다. M02 모델(v2.1.0)에서 마운트 P_M02_BASE는 X −330~−140으로 옮겨져 있다. 마운트 ↔ 머리판 면 틈은 이미 60이다.
- 머리판 통로 윗부분(X −140~−80 · Y ±90 · Z 165~560)은 REST·누름 0°·최저 −1.867° 세 자세 모두에서 **겹침 0**이다.
- 머리판 통로 밑띠(Z 125~165)는 REST(대기, 바퀴 들림 8.626°)에서 **겹침 77,038 mm³**이다. 바퀴 37,776, 트레드 30,048, FRONT 8,010, 옆판 602×2. 들린 바퀴 윗끝이 Z 161.2까지 올라와 헤드 −X 면 밑 36 mm를 가린다.
- 누름 0°(매트 10 위)에서는 트레드 4,030 mm³가 겹친다(Z 125~130). 최저 −1.867°(매트 없이 내림)에서는 **0**이다. 남는 틈은 트레드 1.14 아래, 옆판 3.06이다.
- d₁ 100은 유지된다. 바퀴 중심 X −100이고, 누름 0°에서 트레드는 X −112.5~−87.5, UPPER와 틈은 7.5다.
- **already_ok = false**: 정의된 대기 상태(REST)에서 통로 겹침이 0이 아니다. 형상은 그대로 두고 "정비 자세 = 바퀴 최저(J_U4_PRESS −1.867)"를 상태로 정하면 0이 된다(아래 6절).
- 미완: 867 머리판의 실제 외곽·체결 방향은 D-10(기종 확정 뒤)이다. 머리판 밑끝이 Z ≥ 165면 REST 그대로도 0이다.

## 3. 작업 대상
- 매트 3장(L·S·G)은 REST에서 로딩 자리(시작점 −Y 300)에 있고 Z 0~10이다. 사이클 어느 단계에서도 Z 125 위로 오지 않는다. 머리판 통로와는 관계없다.
- 떨어지는 조각은 없다(봉제, 절단 없음).
- 머리판 탈착은 정비 동작이라 기계 정지·매트 없음 조건이다. 그래서 바퀴를 매트 없이 최저(−1.867°)로 내리는 자세가 물리적으로 가능하다. 실린더를 전진 끝까지 보내고, 바퀴는 테이블 위에 놓인다.

## 4. 관련 결정·기각 이유 (같은 실수 막기)
- d₁ 100(바늘–바퀴 중심)은 고정이다. 요구서 DC2-06은 "통째 떼는 마운트 또는 약 60 띄움(d₁ 100 유지)"이라고 쓴다. 그래서 바퀴 자체를 −X로 옮기는 안은 안 된다. 바퀴 Ø120×25는 들림·누름 중 X −112.5~−87.5에 늘 있다.
- M02 설계(mech_M02_design.md 72행)에서 마운트를 X ≤ −140으로 옮겨 "들린 바퀴 위(Z ≥ 165)로 60 폭 비움"은 이미 했다. 측정으로도 확인했다(PR_FACE60_HI 0).
- M02-M2: 들림 위 끝 8.626은 실린더 후퇴 끝(스토퍼)이다. 들림 각을 키우면 바퀴가 더 올라가 밑띠를 더 가린다. 반대로 들림을 줄이면 테이프 이음매 0.611·로딩 여유가 걸린다(M02-M3 키).
- C-03(영구 눌림자국 금지): 정비 자세에서 바퀴를 매트 위로 내리지 않는다. 매트 없이 내린다.
- 머리판 체결 방향·외곽은 D-10(기종 확정 뒤)이다. 지금 UPPER는 867 공식 PDF 임시 상자다.

## 5. 이미 되는지 판정
완료 판정: "머리판 탈착 길(헤드 −X 면 앞) 과제 범위 간섭 0, d₁ 100 유지".

| 항목 | 값 | 판정 |
|---|---|---|
| 통로 Z 165~560 (모든 자세) | 0 mm³ | 통과 |
| 통로 Z 125~165, REST(정의된 대기 상태) | 77,038 mm³ | **불합격** |
| 통로 전체, 최저 −1.867°(machine.json에 정비 상태 없음) | 0 mm³(틈 1.14) | 상태가 정의되면 통과 |
| d₁ 100 | 바퀴 중심 X −100 | 통과 |

결론: **already_ok = false**. 마운트는 이미 60 떨어져 있다. 남은 원인은 마운트가 아니라 REST에서 들린 바퀴·FRONT·옆판 끝이 헤드 −X 면 밑 40 mm 띠에 들어오는 것이다.

## 6. 구상에 주는 실마리 (안 아님, 수치만)
1. **정비 상태 추가(형상 변경 0).** machine.json states에 "정비: 머리판 탈착"(J_U4_PRESS −1.867, 매트 없음)을 더하고 동작 연구 한 단계를 둔다. 그러면 통로 0이다. 다만 남는 틈이 1.14로 작고, 머리판 밑끝이 Z 125 그대로라는 가정이다.
2. **U4 묶음 통째 떼기.** P_M02_BASE의 보 앞면 체결(CB5-16 ×4, X −310·−160, Z 242)을 위치핀 2 + 원터치(클램프 레버)로 바꾼다. 공구 길: 볼트 머리 X −140 면 앞 PR_REACH_HI(Z ≥ 340)는 비어 있다. Z 242 체결 줄 앞(X −300~−140)은 실린더·CYLBRKT가 있다.
3. **머리판 쪽 기준 확인.** D-10 STEP이 오면 머리판 밑끝 Z를 다시 잰다. Z ≥ 165면 REST 그대로 0이다(PR_FACE60_HI 0).
