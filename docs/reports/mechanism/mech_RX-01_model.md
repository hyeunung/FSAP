## 워크플로우 메모

1. MCP 호출이 약 60 s에서 "Request timed out"으로 끊기고, 그때 서버가 다시 떠 허용 폴더(임시 폴더 이름)가 바뀐다. batch는 끊긴 단계에서 멈추고 앞 단계는 남는다(rollback 안 됨) → 끊길 때마다 `occurrence.properties`·`sketch.inspect`로 어디까지 됐는지 보고 남은 단계만 보냈다. 큰 모델에서 명령 하나가 5~20 s라 batch는 3~4단계씩.
2. `measure {"bodies": [...]}`는 bodies를 무시하고 전체를 재 시간이 넘었다 — `measure {"body": 이름, "summary": true}`를 쓴다. batch 안 `inspect.measure {"body"}`도 전체를 잰다.
3. MCP 서버의 `--allow-path`가 이 세션 서버에는 걸려 있지 않아(허용: 3D_Modeling · 그때 임시 폴더) `purchased-step` STEP을 바로 못 넣었다 — 임시 폴더로 복사해 넣었다.
4. 앞 실행이 끊겨 앱에 dirty로 남은 편집을 생성기 stage 파일과 피처 id로 대조해 이어 갔다(대조 방법: 저장본 document.json 피처 id ↔ `inspect_design` timeline id 차집합 = `stage_2b_delete.json`).
