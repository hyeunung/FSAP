## 0. 규칙 근거

- 요구서 5절 RX-18 내용 "모든 매트 연구(S·L·G1·G2·V·W1·W2·P)를 새 바인더·덮개·테이프 모형으로 다시 돌린다(SIM-01 방식)", 완료 판정 "… 그 밖 간섭 0".
- E-03 "동작 검사에는 항상 실제 작업 대상 모형(… 가공 뒤 형상과 떨어진 조각 포함)을 넣고".
- E-17 "측정은 바뀐 만큼만 다시 잰다" — 지난 결과를 다시 쓰려면 같은 대상 · 같은 상대의 지난 결과가 있어야 한다.
- 결정로그 RX-12-C3-X2 "RX-14 검사가 `WP_MAT_*`만 상대로 봐서 RX-14(v2.19.x) 뒤부터 있던 것이 이번에 드러났다. RX-18 완료 판정에 '그 밖 간섭 0'이 있어 거기서 닫힌다".
- E-02 디테일은 보지 않았다. 다른 안은 내지 않는다.

## 2. 모자라는 것 — "그 밖 과제 범위 간섭 0(truncated false)"

- 설계 5-4: "`CYCLE_L` · `S` · `G2`(키가 바뀐 배출 단계 = L 700~716 · S 434~450 · G2 614~630만 다시 — 그 앞은 키 변화 0이라 지난 결과를 쓴다, E-17)".
- 그런데 그 '지난 결과'가 없다. RX-14 전 구간(`mech_RX-14_model.md` 5절)은 "매트 occurrence ↔ `U7_KIT` · `U3_BIND_DRV` · `U7_BASE` · `U7_TAPE_LINE`"이고 조각은 대상이 아니었다 — 그래서 L 705 · 706 겹침이 그때 0으로 나왔다. 그 뒤 조각을 넣은 전 구간은 W1 · W2뿐이다(RX-12-C3). 이번 측정도 L · S · G2는 25단계 간격 표본 80자세다(측정 4-4).
- 그래서 지금 지시서대로면 L 0~699(700단계) · S 0~433(434) · G2 0~613(614)의 붙은 조각 · 이음매 ↔ 바인더 · 덮개는 표본으로만 본 채 과제가 닫힌다. 요구서 5절 "모든 매트 연구를 … 테이프 모형으로 다시 돌린다"와 완료 판정 "truncated false"에 닿지 않는다.
- 고칠 자리(지시서 5-4, 그 줄만): `CYCLE_L` 0~716 · `CYCLE_S` 0~450 · `CYCLE_G2` 0~630을 **전 구간**으로, 대상 = `WP_MAT_<M>:1` + `WP_TAPE_<M>:1`(조각 전부 + `SEAM_<M>`), 상대 = RX-14와 같은 `U7_KIT:1` · `U3_BIND_DRV:1` · `U7_BASE:1` · `U7_TAPE_LINE:1`(+ 3절의 54바디 가운데 노루발 · 바퀴 트레드), 저장본 CLI · truncated false 확인. 표본 수 717 + 451 + 631 = 1,799. 통과 기준은 그대로(기준선 밖 0, 조각 ↔ 바인더 겹침 X 최소 ≥ 12). 설계 요약 '미완' 줄과 완료 판정 대조 칸의 "연구 10개 + V2"도 이 범위로 맞춘다.
- 형상 · 키 · 기준선은 고칠 것이 없다. 직선 구간 틈은 띠 7.5 ↔ 턱 벽 8.0 = 0.5, 볼록 모서리 회전에서 박힌 변은 (−X, +Y) 쪽으로 돌아 바인더(X ≥ 8 · Y ≤ −4)에 오지 않는다 — 통과할 것으로 보지만 재지 않은 것이라 판정으로 쓰지 않는다.

## 3. 기록만(고치지 않음)

- 조각 18(홈 바닥: 벽 20 + 반원 + 벽 20)은 P2 314에 한 번에 붙는다. 박힌 만큼만 띠를 둔 계산(`check2.py`, 5 mm 조각 1,108개)으로는 앞 벽 20 mm(`TP_P_18a`)가 P2 256~312에 덮개 윗판(X ≥ 30.5) 위에 온다. 모형은 그 단계 값을 작게 낸다(예: 296단계 382.22 ↔ 232.07 mm²). 구간 239~359 · 최대 501.19(334) · 팔 272~333 · 턱 벽 0 · 바닥 0은 같다. G의 `TP_G_04`와 같은 규칙이고 완료 판정 표가 바뀌지 않아 problems에 넣지 않았다. 7절 '감긴 띠가 같이 넘는 구간' 줄에 한마디 적어 두면 된다(문서 담당).
- `CYCLE_V2` 시작 상태(노루발 0 · `J_U5_X` 1000)는 `CYCLE_V` 끝(노루발 20 · 1360)과 다르다. 설계가 machine.json `_note`로 남긴다고 했다 — 겹침 판정과 무관.
