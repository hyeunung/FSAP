## 4. 손계산(M-09 SF ≥ 2)

임시값: 리드 20, 골지름 17.2(측정 6절, 카탈로그 미확인), 빈 이동 300 mm/s = 900 rpm(D-12), 가속 2 m/s²(α = 628 rad/s²), 효율 0.9, 마찰 0.01. 위험 속도와 좌굴은 `calc_prelim.json`의 1350 고정–고정 값을 (1350/L)²로 늘리고 줄였다.

| 항목 | Y(고정–지지 1180) | X(고정–고정 1400) | 근거 |
|---|---|---|---|
| 위험 속도 | 1865 rpm → **SF 2.07** | 2067 × (1350/1400)² = 1922 rpm → **SF 2.14** | calc_prelim |
| 좌굴(추력 F) | 12,546 / 159.5 = **78.7** | 19,171 × 0.930 = 17,826 / 201.4 = **88.5** | 같음 |
| 부하 관성 | 7.70e-4 + 축 1.455e-4 × 1300/1100 = 1.72e-4 + 커플링 0.1e-4(임시) = **9.52e-4** | 9.73e-4 + 1.79e-4 × 1550/1450 = 1.91e-4 + 0.1e-4 = **1.174e-3** kg·m² | m(L/2π)² |
| 서보 회전자 관성(임시) | 1.51e-4 | 1.51e-4 | 750 W 80각 중관성 자리값, 카탈로그 미확인 |

| 피크 토크 | 0.655 + 0.017 + 모터 0.095 + 커플링 0.006 = 0.77 N·m | 0.825 + 0.008 + 0.095 + 0.006 = 0.93 N·m | calc_prelim T_peak + J·α |

- Y SF 2.07은 기준에서 +3.5 %다. 골지름 17.2가 실제보다 작거나 크면 판정이 갈릴 수 있다. 카탈로그 골지름을 받으면 다시 계산한다. 그때 2를 밑돌면 Y도 고정–고정(SF 3.01, 같은 부품 수에서 지지측 유닛을 고정측으로 바꿈)으로 한다.
