## 워크플로우 메모

- 수정 회차에서 모델링부가 해석부 케이스를 새 STEP으로 돌려 SF를 적는데(2.16·2.23), 케이스의 단면 중심 같은 상수 좌표는 옛 형상 그대로라 값이 1~2% 어긋났다. 해석 케이스는 단면·피벗 좌표를 STEP bbox에서 읽게 짜 두면(이번 케이스는 SEC를 bbox에서 읽게 고침) 다시 돌릴 때 그대로 맞는다.
- 출력품(PET-CF) 플랜지를 볼트가 지나 금속 탭에 물리는 자리는 `handcalc.calc`의 base 하나로 암나사와 좌면을 같이 넣어 좌면을 놓치기 쉽다(v0.4.0에서 놓침). 좌면 재질을 따로 받는 인자(`seat=`)가 있으면 좋겠다.
- `models.json` 같은 표를 파이썬으로 고칠 때 Windows 콘솔(cp1252)에서 한글 출력이 UnicodeEncodeError로 멈춘다 — `PYTHONIOENCODING=utf-8`을 부서 머리말 실행 환경에 넣어 두면 덜 막힌다.
