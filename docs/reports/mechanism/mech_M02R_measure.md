## 2. 지금 지렛대 기하와 누름 힘 범위 (손계산, `tools/out/mech_M02R/geom.py` → `geom.json`)

로드 핀 중심은 프로브 실행의 P_M02_KNUCKLE_PIN 겹침 bbox 중심, 위 핀은 (−161.006, 325.72).

| 자세 | 로드 핀 (X, Z) | 핀 사이 | 실린더 팔(피벗–실린더 축선 거리) | 바퀴 팔 | 레버비 |
|---|---|---|---|---|---|
| 들림 8.626 | (−169.4, 142.4) | 183.5 | 127.2 | 197.7 | 0.643 |
| 누름 0 | (−160.0, 122.0) | 203.7 | 140.3 | 200.0 | 0.701 |
| 내림 끝 −1.867 | (−158.4, 118.7) | 207.0 | 142.2 | 199.9 | 0.711 |

- 누름 힘 F = 바퀴점 무게 26.9 N(FUNC-01 handcalc, D-111) + 0.701 × p × 314.2 mm².
  - 0.005 MPa → 28.0 N, 0.05 MPa → 37.9 N, 0.2 MPa → 70.9 N. 40 N = **0.0595 MPa**.
- 창(FUNC-01 ①): 잡기 하한 25.0 N(옆힘 10 N / μ 0.4), 자국 상한 51.6 N(100 kPa), 설정 40 N → SF 1.60 / 1.29.
- 주의: 카탈로그부(`tools/out/mech_M02R/catalog.md`)에 따르면 CM2 Ø20 최저 작동압은 0.05 MPa다. 지금 설정 0.0595는 그 바로 위다. 무게만으로 26.9 N이 이미 나와서 실린더 몫이 13.1 N뿐이기 때문이다.
  - 새 레버비를 고를 때 할 일: 실린더 몫(F − 무게 모멘트)을 최저 작동압 × 단면적 × 레버비 이상으로 둔다. 또는 무게 모멘트를 줄이는 쪽(피벗 위치)을 같이 본다.
- 무게 모멘트 기준: 가동부 질량 합(서명 기준 서보 2.01 + 감속기 묶음 약 1.42 + 바퀴 0.64 + 레버 판 약 1.54 + 기타) 약 5.8 kg, 바퀴점 환산 26.9 N은 FUNC-01 값. 새 레버(크랭크) 무게가 더해지면 다시 셈.
