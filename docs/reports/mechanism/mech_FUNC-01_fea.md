# FUNC-01 해석 — U5 플로트 새 하중 부품 손계산 (v2.8.0)

## 요약 (10줄)
- **해석 모델을 바꿨다**: models.json의 P_M03_LIFT_TOP·LIFT_SIDE_N/P(v2.1.2)는 옆판 플랜지를 CB5-12 ×4로 승강판에 묶은 경계였는데, FUNC-01에서 그 볼트를 지우고 옆판 묶음을 PSFJ16 축 ×2 + LHFR16 부시 ×2로 띄웠다(J_U5_FLOAT). 그래서 경계를 '축·부시가 옆힘·모멘트, 위 정지(FLOAT 20)에서 플랜지 맞닿음이 수직'으로 바꿨다. 옛 식도 같은 하중으로 풀어 남겼다(3절).
- 해석 못 함 — 환경 없음(자료대기 D-16). 모두 손계산(`fea/cases/mech_FUNC-01_handcalc.py` → `fea/results/mech_FUNC-01_handcalc.json`, python -B로 다시 낼 수 있음).
- 대상 4부품(STEP bbox·원통면을 스크립트가 다시 읽음): P_F01_SHAFT_HLD_N(/P 거울), P_M03_LIFT_SIDE_N/P, P_M03_LIFT_TOP. 하중 경로의 새 구매품(PSFJ16·LHFR16·PSCS16)과 새 체결(M4·M5, 모델엔 아직 없음)도 봤다.
- 운전(SF 3)·오조작(SF 2) 모두 가공품 합격: 가장 얇은 곳은 오조작Y — LIFT_TOP 5.1, 받침 블록 5.6, 옆판 6.1, 축 10.8.
- 기준 미달 1건(디테일, kind 디테일): **LHFR16 부시 오조작 정적 비 1.55 / 1.68 < 2**(C0 1180 N 기억값 D-146, 옆힘을 모두 축이 받는다고 봄). 1.2보다 커서 부러짐·영구 변형 아님. 맞닿음 마찰 μ 0.15만 넣어도 2.2.
- 기준 +10% 안(기록): LHFR16 운전_뜸 3.06(기준 3). 구매품 정격 비라 FEA 대상 아님.
- 들기(0.5 MPa, 매달림 3 g 97 N/축): 칼라·멈춤나사 지지 비 10.3(기억값 1000 N), 승강판 SF 14.7.
- 형상 확인 요청 2: 받침 블록 STEP에 M5 멈춤나사 구멍(Ø4.2)이 없음, 받침 블록 구멍 Ø16이 Y −37 면에서 2 mm 열림(열린 쪽 웨브와 맞닿는 자리 확인). 동작 문제 아님.
- 동작 문제 0. 과사양(M-09) note: 옆판 웨브 운전 SF 33 — 그러나 오조작 6.1과 플랜지 맞닿음 몫이 있어 두께를 줄이지 않는다.

LHFR16 오조작 미달의 뜻: C0는 영구 변형이 볼 지름의 1/10,000이 되는 하중이라 비 1.55는 깨지거나 굳는 값이 아니다. 위 정지에서는 플랜지가 승강판을 493 N으로 누르므로 SUS 맞닿음 마찰 μ 0.15만 넣어도 축으로 가는 옆힘이 247 → 173 N, 비 약 2.2. 그리고 플랜지 두 줄(Y ±46)이 Mx를 일부 받는다. 그래서 '기준 근처 미달 = 디테일'(지시서 kind 기준)로 둔다. 운전_뜸 3.06도 같은 부시(속도 제어와 서보 토크 제한이 지켜지는 한).

## 5. 쓴 임시값 (자료대기 D-146 '쓰는 곳'에 적음)

## 워크플로우 메모
- 해석부 지시서의 '새 하중 부품 STEP'에 구매품(LHFR16·PSFJ16)과 아직 모델에 없는 체결이 빠져 있어, 하중 경로를 해석부가 다시 짰다. 플로트처럼 조인트가 끼는 하중 경로는 지시서에 '받는 쪽 구매품'도 같이 주면 좋다.
