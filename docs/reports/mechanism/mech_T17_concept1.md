# 구동 T17 구상 1 — 꼬임 구간 건너기 + 이젝터 MAT_Y 옮김 + 링1 굴림 고리

기구설계부 1번, 2026-11-02. CAD를 쓰지 않았다(측정 자료 `mech_T17_measure.md`, `tools/out/mech_T17/bodies.json`·`purchased_bbox.json`으로 손판정). 기준 모델 v0.8.2(측정과 같음). 방향: 결정로그에 적힌 원래 계획(T01 선정 3-4 "진공 이젝터 2(고정 쪽), 호스(DG 중공 → 허브 구멍 Ø40)", T11-S07 T17 후보)을 출발점으로 다듬었다.

**요약(10줄)**
- 방식: **로터리 조인트 없이 꼬임 구간**으로 건넌다. J_MAT_ROT −360~0은 끝없는 회전이 아니라서 된다(측정 2-4). Ø6 관 2줄(원판 회로·링1 회로 따로)을 T11 묶음(r ≤ 10) 바깥 고리 r13~25에서 **Z −400(고정) ~ −190(회전) L210, 중립 −180°에서 ±180°**로 꼰다.
- 이젝터 `ZH10DSA-06-06-08` ×2를 BASE 580 안쪽에서 **MAT_Y의 DG 받침 +X 면(X 100)**으로 옮긴다(측정 `QY_EJ` 빈 자리 안). 진공관이 X·Y 이송을 건너지 않게 되고, T13 헤드 받침 기둥 길도 풀린다. X·Y를 건너는 것은 SUP Ø6·EXH Ø8뿐이고 T16 몫이다(T11-S03).
- 링1 회로: 기둥 벽 θ270 Z −100에 Ø8 구멍 → 기둥 바깥 r48 고정 다리 → **굴림 U 고리 R26** → 링1 밑 r100 포트. 링1 행정 60은 고리 바닥이 30 움직여 받는다. 작은매트(링1 −60)에서는 r ≥ 70에 있는 관이 모두 Z −70.5 밑이라 헤드 막힘 ①(Z −59 위 금지)을 피한다.
- 원판 회로: 기둥 속을 올라가 원판 밑 가운데 `MBIS5-6.5-8` 인서트 + `KQ2H06-M5A`. 원판·링1 윗면(Z −0.5)은 건드리지 않고 밑에서 포트를 낸다(진공 밀봉면 유지).
- 막는 것 ②(허브 볼트 머리 Z −233~−227): 고리 가장 낮은 곳 −204, 틈 23. 기둥 플랜지 볼트 PB(−221.2)와는 17. 막는 것 ③(Y판 밑 +Y 길, Z ≤ −400): 관을 +X로 빼서 대기 Y ≤ −695, YMB(Y ≥ 243)까지 J_Y 40에서도 198.
- 꼬임 손계산: 늘음 5.9 mm(r16, 2.8 %)~11.1 mm(r22, 5.3 %), 나선 굽힘 반경 225~295 ≫ 임시 R15(Ø6, 새 자료대기)·R10(D-46). 늘음은 관을 당기지 않고 고리·Y판 위 여유 굽힘에서 빼낸다. 관 비틀림 토크 15.3 N·mm/줄.
- 손계산: 기둥 Ø8 구멍(Z −100) 오조작 SF 3.73(T11 장공 −203의 SF 2.19가 여전히 지배), Y판 장공 8×19.5 운전 SF 6.21 → 약 6.09. 해석 못 함 — 환경 없음(D-16).
- 부품: 새 구매품 `KQ2H06-M5A` ×2·`TU0604` 약 1.5 m·`MBIS5-6.5-8` ×1·`CB5-12` ×2, 새 가공품 `P_T17_TCLAMP` 1(3D 출력). 형상 바꿈 5(원판·링1·기둥·Y판·DG 받침), 옮김 4바디(이젝터). 부품 종류 +5. 가격 미확인(요구서 3-1 가격표 없음).
- 미완: `KQ2H06-M5A`·`TU0604` STEP·카탈로그 없음(needs_step), Ø6 관 굽힘 반경·허용 늘음, 이젝터 포트 면 위치(디테일), 모델링부가 CAD로 상태별 간섭을 다시 잰다.

좌표는 측정 자료와 같은 세계 좌표(mm)다. 대기 자세(J_MAT_X 0, J_MAT_Y −700, J_MAT_ROT 0, 링 0), 회전 중심 (0, −700). θ는 +X에서 반시계다. "기둥 각"은 MAT_ROT에 붙은 각이고(J 0에서 세계각과 같다), 세계각 = 기둥 각 + J다.

## 2. 구동 방식·동작

### 2-1. 회로와 길(관 중심선, 대기 자세)

**원판 회로(이젝터 T1 → 원판)**
1. 이젝터 T1 VAC Ø6(DG 받침 +X 면, 3-2) → Y판 윗면 위 여유 굽힘 R20(Z −345 근처) → Y판 장공 (120, −715.6)을 아래로 지난다.
2. Y판 밑 세로 X 120, Z −360 → −400, 아래 굽힘 R20(중심 X 100, Z −400) → 가로 Z −420(관 −423~−417), Y −715.6, X 100 → 35.6. 주의: 위 날개 X 28~35는 Y판 구멍 r35 밑이라 탭은 X 40에 둔다.
3. 굽힘 R20(중심 X 35.6, Z −400)으로 위로 꺾어 세로 (15.56, −715.56)(r22, 세계각 −45°)가 된다. 고정 끝은 `P_T17_TCLAMP`가 Z −406~−420에서 잡는다.
4. 꼬임 구간 Z −400 → −190(L210). 반지름은 Y판·받침 구멍(r35) 안에서 r22, DG 중공(r ≥ 49.5) 안에서 r16으로 좁아진다. 허브 구멍 r20·기둥 속은 r16(관 r13~19)이다.
5. 회전 고정점 Z −192~−182: 기둥 속 안내 갈래, 기둥 각 135°.
6. 기둥 속을 Z −70까지 올라가 S 굽힘 R15 두 번(옮김 16, 길이 26.5)으로 축선에 온다. 이어 `KQ2H06-M5A`(임시 Z −30.5~−12.5) → `MBIS5-6.5-8` 인서트(Z −12.5~−4.5) → Ø3 구멍(Z −4.5~−2.5) → 원판 윗면 진공 홈.

**링1 회로(이젝터 T2 → 링1)**
1. 이젝터 T2 VAC → Y판 장공 (120, −705.7).
2. Y판 밑 가로 Z −420, Y −705.7 → 세로 (21.25, −705.69)(r22, 세계각 −15°).
3. 꼬임 구간 L210, 회전 고정점은 기둥 각 165°다.
4. 기둥 속 Z −182 → −105에서 나선으로 기둥 각 165° → 270°로 옮긴다(호 29, 높이 77). T11 장공 210°는 Z ≤ −198이라 그 위를 지난다.
5. 기둥 벽 θ270 Z −100의 Ø8 구멍으로 나와 R15로 아래로 꺾는다. 고정 다리는 r48 세로(Z −115 아래)이고, 기둥 바깥 출력 클립 2개(Z −120·−135)가 잡는다. 클립은 관이 미끄러지게 Ø6.5다.
6. **굴림 U 고리**: 고정 다리 r48, 움직 다리 r100, R26, θ270 지름면. 링1 밑 r100의 `KQ2H06-M5A`(출구 Z = 링1 밑면 −18, 임시)에 이어진다.

### 3-3. 작업 대상·떨어진 조각

- 매트 밑면 Z 0, 진공 면 −0.5 그대로. 원판·링1의 Ø3 구멍은 진공 면 안쪽에 있고, 가장자리 밀봉선은 바뀌지 않는다.

- 매트를 꺼내는 길(위로, T07)과 관은 무관하다. 링1 피팅·고리는 링1 밑이다.

## 6. 하중 손계산(`tools/out/mech_T17/concept1_calc.py` → `concept1_calc.json`)

해석 못 함 — 환경 없음(D-16). 모두 손계산이다.

- **꼬임(L210, ±180°)**: r16일 때 나선 215.93, 늘음 5.93 mm(2.82 %), 나선 굽힘 R 295. r19일 때 8.32 mm(3.96 %), R 254. r22일 때 11.08 mm(5.28 %), R 225. 굽힘 반경은 임시 R15·R10보다 15배 이상 크다. 늘음은 관 늘음으로 받지 않고 여유에서 뺀다. 링1 관은 고리 바닥이 3.0~5.6 오르고(고정 직선 30이 남아 > 0), 원판 관은 Y판 위 R20 여유 굽힘이 빼 준다.
- **관 비틀림**: J = π(6⁴ − 4⁴)/32 = 102.1 mm⁴, G 10 MPa(D-46 임시값을 빌림). T = GJπ/L = 15.27 N·mm/줄. TCLAMP 반력은 2줄 / 85 = 0.36 N. CB5-12 ×2에 대면 SF ≫ 3.
- **기둥 Ø8 구멍(Z −100)**: DP-2 관 뿌리 오조작 275.6 N, 작용점 Z −0.5(T11 선정 119줄과 같은 케이스). M = 27,422 N·mm. I = 510,509 mm⁴에서 구멍 단면(8 × 10, 중심 거리 25)을 빼면 I_net = 459,842. σ = 1.79 MPa × Kt 3 = 5.37 MPa. PET-CF 층간 20 MPa이면 **SF 3.73 ≥ 2**(M-09 오조작). 기둥 전체로는 T11 장공(Z −203) SF 2.19가 여전히 지배한다(그대로다).
- **Y판 장공 8 × 19.5**: 판 폭 400 중 8이 빠진다. 운전 SF 6.21(T14-M04) → 약 6.09로 본다(보수적인 비례).
- **링1 실린더**: 고리 관 굽힘 저항은 1 N 미만으로 본다. CJ2B16 ×3이 내는 힘(0.5 MPa에서 약 100 N씩)에 견주면 무시할 수 있다(행정 60 그대로).
- **진공 응답**: 이젝터와 원판 사이 관 0.62·0.78 m는 BASE 안(이젝터 → X·Y 캐리어 → 축, 2 m가 넘는 길)보다 짧다. 응답 시간은 이번에 계산하지 않았다(유량 카탈로그 미확인).

## 8. 위험·확인할 것

1. **Ø6 관 반복 꼬임 수명·마모**(±180°, 하루 사이클 수 × 2). T11 묶음과 한 다발로 꼬여 서로 문지른다. 요구서 7절(시제품 확인)에 기록한다. 모델로 판정하지 않는다.
2. **임시 굽힘 반경 R15(Ø6)**는 근거 없음. 가장 작은 굽힘은 고리 R26, 아래 굽힘 R20, 원판 S 굽힘 R15다. 카탈로그 값이 R20보다 크면 원판 S 굽힘(기둥 속 r20 안)이 막힌다. 그때는 원판 관을 r16에서 곧게 올리고 원판 밑에 엘보 `KQ2L06-M5A`를 쓰며, 원판 포트를 r16으로 옮긴다(원판 볼트 r41과 틈 있음).
3. 원판 MBIS 인서트 겉 널링을 따라 새는 길이 있다. 피팅 가스켓이 원판 밑면에서 인서트 겉지름 6.5를 덮는지 STEP으로 확인한다(디테일). 안 덮으면 인서트를 접착 고정한다.
4. **기둥 속 갈래**는 지름 40·깊이 190 안에 출력된다. 조립은 원판을 뗀 뒤 위에서 누름 막대로 끼운다. 조립성은 시제품에서 확인한다.
5. 이젝터 EXH Ø8 배기가 MAT_Y 위에서 나온다. 소음기 또는 배기관은 T16에서 SUP와 함께 정한다(T11-S03). 정하지 않으면 매트 밑 먼지가 날린다.
6. 판정 근거 헤드는 D-10 임시 형상이다. 실물 헤드가 r < 70 또는 Z < −70.5까지 내려오면 작은매트 고리를 다시 본다.
7. 이 판정은 bbox 손판정이다. 모델링부가 상태별 `motion.interference`(사이클 3종, S18_XY·S18_Y, 되감기, budget 넉넉히, truncated 확인)로 다시 잰다. 특히 BASE ↔ 옮긴 이젝터(S18_XY), 링1 고리 ↔ 헤드(작은매트)를 본다.

## 워크플로우 메모

- 구상 부서가 측정의 "회전 대칭" 프로브만 보고 관의 기둥 각을 정하면, **T11 장공 높이에서 나선이 장공 각을 쓸고 지나가는 것**을 놓친다. 이 구상도 처음 안에서 그랬다(회전 고정점을 원판 쪽에 두어 장공 210°를 쓸었다). 측정 단계에서 "기존 관이 고리를 가로지르는 Z와 각"을 표로 주면 좋다.
