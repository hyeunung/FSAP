## 근거 규칙

- 과제 완료 판정(요구서 5절 U6S): "슈 누름 힘 범위가 잡음 ≥ 필요(여유율 ≥ 1.2)·자국 SF ≥ 기준 둘 다 만족, 슈 끌림 넣은 회전 SF 다시 셈 ≥ 1, 슈 들기·누름·비킴 자세와 매트 3장·V홈 과제 범위 간섭 0. 실제 자국은 7절."
- 자국 기준(요구서 5절 FUNC-01 ①): "접촉 면압(누름 힘 / 접촉 면적) ≤ 파일 면 허용 면압 가정 상한" → SF ≥ 1. 슈 미끄럼 허용은 D-165 임시 30 kPa(더 불리한 쪽)로 본다.
- E-02 원문 요지: "강도 여유·정밀 체인·새 볼트 렌치 접근·판금 규칙은 디테일로 기록만 하고 수정 회차를 쓰지 않는다." → 브래킷·탭 응력은 판정에 넣지 않았다.
- E-18 원문 요지: "체결만 바뀐 자리는 손계산, FEA는 형상·하중 경로가 바뀐 부품만." → 해석 환경이 없어 손계산(D-16).

## 항목별 다시 계산(독립 재계산, python 한 줄)

입력: A_head = π·10²/4 = 78.54 mm², W = (66.9 + 6.0 + 8.5 + 1.6) g × 9.81 = 0.814 N(움직이는 것은 슈·로드·너트뿐 — E32 센서는 캐리지에 남음, 측정 1-2표·설계 U-01 행), f = 0.06 MPa × 78.54 = 4.71 N, k = μg·μs,max = 0.2 × 0.4 = 0.08, 바닥 면적 1,506.6 mm²(측정).

### 1. 잡음 ≥ 필요(여유율 ≥ 1.2) — 만족

- 필요 6.48 N = 3·1.0·0.003/0.05³·0.09(EI 범위 중 가장 뻣뻣한 쪽).
- F_hi = (P·A + W + f)/(1 − k), f_g = k·F_hi, F_lo = P·A + W − f − f_g.

| P (MPa) | F_lo (N) | F_hi (N) | f_g (N) | F_lo/6.48 |
|---|---|---|---|---|
| 0.175(게이지 −0.005) | 8.17 | 20.95 | 1.68 | 1.261 |
| **0.18** | **8.53** | **21.37** | **1.71** | **1.316** |
| 0.20(레귤레이터 최대) | 9.96 | 23.08 | 1.85 | 1.538 |

- 안내 마찰을 F_hi 기준(μs 최대)으로 F_lo에서도 빼므로 F_lo 쪽은 보수적이다. 1회차 지적 방식(F_drag 6.92 N 고정, 0.17 MPa)으로도 1.245.
- 짝힘: 끌림–칼라 팔 20.5 mm × μs 0.4 = 압력 중심 8.2 mm 이동 < 바닥 반길이 45 → 슈가 기울지 않고, 칼라 두 개가 같은 Z라 칼라 옆 반력 ≈ F_drag. 설계안 논리 맞음.

### 2. 자국 SF ≥ 기준 — 만족

- 0.18 MPa: 21.37 / 1,506.6 = 14.19 kPa → SF 2.11(30 kPa)·7.05(100 kPa).
- 잘못 맞춰도(0.2 MPa): 15.32 kPa → 1.96·6.53. 기준 ≥ 1(FUNC-01 ①) 넘음. 설계안이 스스로 둔 창 위끝(30 kPa SF ≥ 2, 0.1944 MPa)은 설계 여유이지 판정 기준이 아니다.
- 창 0.170~0.194 MPa가 IR1000 조정 범위 0.005~0.2 안(FUNC-01 ① "두 사이 창이 레귤레이터 조정 범위 안").

### 3. 슈 끌림 넣은 회전 SF ≥ 1 — 만족

- 순서 ④: 바늘 꽂고 멈춤 → 노루발 낮은 누름과 동시에 슈 들기(밸브 7 B, 0.14 s) → 피벗. 들림 +4.5 → 바닥 Z 17.0, 매트 7.0·테이프 6.0·이음매 5.0 떨어짐 → 끌림 0.
- 들기 힘 0.5 MPa × 65.97 = 33.0 N / (W + f + f_g 7.24 N) = 4.56 → 들림 성립.
- U4 혼자 1.009·1.011·1.020·1.025, U4+U5 1.009·1.047·1.015·1.009 — 모두 ≥ 1.
- 눌린 채면 0.798~1.017이라 '피벗 전 슈 들기'는 제어 제약(U6S-K1)과 연구 키(피벗 구간 J_U6_PRESS +4.5)로 반드시 들어가야 한다(모델링부 몫).

### 4. 들기·누름·비킴 자세 간섭 0 — 만족

- 행정 9.5 mm(−5.0~+4.5) < 15. 실제 접촉 −2.5, 눌림 δ 0.284 → −2.78, 아래 끝 −5.0까지 2.2 남음.
- 모형 누름 키 −0.4: 바닥 Z 12.1, 매트 2.1·테이프 1.1·이음매 0.1 위. `u6s_calc.json` heights도 −0.4로 고쳐져 글과 일치(1회차 지적 해소).
- 수정 1은 형상·좌표·부품·조인트 범위 변경 0 → 이전 CAD 확인(`design/raw2.json`·`raw2t.json`: 자리 5상자·쓸기 2상자 ↔ 이웃·관 겹침 0, 관 틈 5.1)이 그대로 유효.
- J_U7_HGT와 같은 값 묶음(C-34) 유지 — 슈 높이는 두께를 따라 모든 두께에서 같은 틈.
