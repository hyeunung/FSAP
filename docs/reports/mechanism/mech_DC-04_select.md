# DC-04 방안 선정 — 정비 면·카세트 인출·가마 꺼내는 길 (v1.0.4 기준)

## 요약
- 고른 것은 **DC-04-C3(바닥틀 +X 정비 포켓 + 카세트 옆걸이 미니 LM 인출)의 고친 안**이다. 차순위는 DC-04-C2다. DC-04-C1은 고르지 않았다.
- 바뀌는 부품: U2_BASE에 포켓을 자른다(X 500~975 · Y 60~700 · Z −900~−380).
- 새 부품은 6종 8바디다. P_DC04_HANGER(SUS304 t3 판금), STEP대기_SSEB13-560 레일·블록, P_DC04_CARRIER(SUS304 t4 판금 ㄱ), STEP대기_IXP-M8, CB5-12 ×3. 새 조인트 J_U8_PULL(slide +X 0~511, 손), 상태 MAINT·MAINT_CAS.
- 손 닿는 거리(포켓 면 (500, 60)에서 수평, D-82 임시 600 이하)는 모두 기준 안이다. 카세트 498, 가마 474, 바늘 504, 노루발 501, 플런저 손잡이 572(어깨선 보수 595), 테이프 롤 206.
- CAD 확인(MCP, 읽기만)은 프로브 19개로 했다. J_U4_X −200에서 새 부품·포켓·팔 길·손 길의 겹침은 0이다. 예외는 포켓 칸과 U2_BASE의 겹침뿐이고, 의도한 자르기라 겹친 부피가 칸 부피 전부다. J 1250·Y ±에서 새 고정 부품과 포켓 칸은 가동부와 겹치지 않는다.
- 구상안 그대로는 그릴 수 없는 곳이 넷이라 고쳤다.
  - C3의 플런저 몸통(Y −49 ±6, X −20~20)이 카세트(Y −45, X ±11)와 겹쳐 자리를 옮겼다.
  - 걸이 플랜지 볼트가 블록 밑에 갇혀 Y −84 띠로 옮겼다.
  - 판금 재질 A5052는 요구서 2-1에 맞춰 SUS304로 바꿨다.
  - 레일 −X 끝(−29)이 앞 탭을 지나가 −20으로 옮겼다.
- 미완(기록만):
  - D-82·D-83은 이번에 자료대기에 올렸다.
  - 867 UPPER 밑면 탭 자리·가마 꺼내는 방향은 D-10을 기다린다.
  - 포켓 안 사람 감지는 U-09·D-38로 넘긴다.
  - M3 볼트(레일·블록)는 STEP대기다.
- 해석 못 함 — 환경 없음(자료대기 D-16). 손계산만 했다.

## 2. 선택과 이유
- **선택: DC-04-C3 고친 안.** 완료 판정(정비 면 인출 길·가마 길 간섭 0, 손 닿는 거리 ≤ 600)을 맞추는 안은 C3뿐이다. 바늘·노루발까지 맞춘다.
- 부품이 가장 적다(M-10, U-06 "부품 수가 적고 조립·정렬이 쉬운 쪽").
- 핵심 정밀도(바늘–가마)를 건드리지 않는다(U-01).
- 차순위 C2는 레일을 UPPER 밑면에 가로로 달고 손잡이·잠금을 +X 끝에 둔다. C3 포켓을 바닥틀에 못 낼 때 쓴다(예: N07 형재 배치가 포켓을 막을 때). 이때는 바늘·노루발 손 닿는 거리가 DC-04-N1로 남는다.
- 합친 것: C2의 정비 자세·인출 금지 인터록 생각(DC04-Q3)과 C3의 포켓·옆걸이를 합쳤다.

## 워크플로우 메모
- `edit.checkpoint`는 batch 안에서 id(263)를 돌려준다. 그런데 다음 batch의 restore는 "no checkpoint"로 실패했다(측정부와 같은 현상, 2회째). undo 횟수(Drive 포함)로 되돌렸다.
- `inspect.clearance`에 `against`를 안 주면 `bodies` 안의 쌍만 잰다. 프로브 대 모델은 `against`에 모델 바디 목록을 넣어야 한다.
- 구상안 3개 모두 bbox 손계산만으로 좌표를 냈다. 선정 CAD 확인에서 플런저·볼트·재질·레일 끝 4곳이 그릴 수 없는 지시로 나왔다(WF-016·017과 같은 유형).
