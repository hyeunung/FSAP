## 2. 방법
- 폴더 `tools/out/mech_REG-01/reg12/`. `worker.py`·`sup.py`·`ask.py`·`sets.json`·`states.json`·`chunk10.py`는 회귀 10(`mech_regrun/reg10/`) 것을 **그대로** 복사했다. 검사 내용(빠른 바디 ↔ 다른 유닛 움직이는 바디 + near_all + 매트 모형, skip_within component)은 같고, 묶음 id의 `%k/n`(against 목록을 n조각 중 k번째)만 새로 썼다. `ag[k::8][j::4] == ag[k+8j::32]`이므로 1/8 조각 k를 넷으로 나눈 것이 1/32 조각 k, k+8, k+16, k+24다.
- 명세(`mkspec12.py`):
