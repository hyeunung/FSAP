## 0. 출발점과 규칙 근거
- 출발점은 요구서 0-8-3 U8이다. 벤치마크는 "R375X 사진(게이지 달린 레귤레이터 3, 솔레노이드, 노란 라이트 커튼, 경광등, 터치패널)", 새로 하는 것은 "없음(제어·전장은 기구 뒤, U-09)", 위치는 "보 앞판(레귤레이터), 기계 양옆(라이트 커튼)"이다. 이 셋을 그대로 따른다.
- 실행 규칙 14 "옆·뒤 커버, 가드 판넬 … 구동 과제·구동 후보로 만들지 않는다": U5 풀리·벨트 가드와 +Y 뒤·+X 옆·테이블 밑 보호는 넣지 않는다. D-130과 외장 단계로 넘긴다.
- E-02 "강도 여유 … 새 볼트 렌치 접근 … 디테일로 기록만": 기둥 휨과 브래킷 미끄럼은 기록만 한다(4절).
- U-13 "하나를 지적받으면 같은 기준으로 전체를 본다": M07-K1이 HBLFSN8을 판금 L(SUS304 t6, 구멍 구석에서 30) + CB5-16으로 바꾼다. 새 형재 이음에도 같은 L을 쓴다.
- U-19 "드러난 끝면마다 마감캡": 기둥 3개의 위·아래에 HFC8-4080-B ×6을 단다. HMI 팔은 두 끝이 판에 가려 캡을 달지 않는다.
- U-12 "예외는 구매품의 공장 탭·장착 구멍이 지름을 정한 볼트뿐": 매니폴드(CB4-20)·경광등(CB4-12)만 M4로 가정하고 STEP으로 다시 본다. 나머지는 M5(CB5-12/16 + HNTT8-5)다.
- 앱 문서: SolidCraft 앱(27878)에 'merged' 문서가 dirty(433바디, path 없음)로 열려 있었다. 실행 규칙 2 "dirty면 멈추고 보고하고, 버리지 않는다"에 따라 앱 문서는 건드리지 않았다(open 안 함). 측정은 저장본 v2.4.0에 대고 CLI로만 했다.
