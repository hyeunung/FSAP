식과 값을 다시 계산해 모델링부 값과 같다. 지시 속도 300 mm/s에서 위험 속도 SF가 2에 못 미친다. 모델링부는 결정로그 T18-S03·자료대기 D-52(사용자 결정, 기본값 280으로 진행)를 근거로 280을 썼다 → 예외 요청(E-14)으로 올린다.

나사 물림(M-01 ≥ 1.5d, 모델링부 6절 표를 형상으로 확인): CB8-35 → HNTT8-8 7.5(< 12), CB8-25 → XNP t8 8(< 12), CB5-20 → YNB 웹 5(< 7.5). 자료대기 D-54 손계산은 YNB 웹 탭(물림 5) 조임 암나사 전단 **SF 0.91**(조임 4 N·m 임시값).

## 9. 원장·판정 기억

## 워크플로우 메모

- `motion.interference`에 occurrence 14개(약 380바디)를 주면 "too many bodies for a contact sweep"으로 거부되고, 한 스크립트 안 다른 단계 결과까지 모두 잃는다. 한 실행에 한 연구·한 묶음씩 나누고, 묶음은 약 190바디 이하로 했다. 쌍을 '상대 자세가 달린 조인트'로 나눠 높이 분리·쓸림 상자로 줄이는 방법이 실제로 통했다(엔진 안내서 '동작 검사' 보강 후보).
- 모델 열기만 약 3분. 병렬 5~8개면 각 실행이 30~60분으로 늘어난다.
- 볼트 ↔ 탭 불리언 실패(unchecked)는 `inspect.clearance`로도 같다. 구멍 실재는 부피 차로 확인하는 쪽이 빠르다.
