## 1. 구동 방식·행정·위치·순서

- 실린더 축 X. 몸 X −257.5~−210, Y 64~104, Z 72~112(축선 Y 84, Z 92), 로드 +X. 행정 20.
- **ON(스토퍼 걸림) = 로드 당김(후퇴 끝)**: 로드 끝 X −187, 블록 X −187~−163.5, 볼트 중심 (X −170, Y 70).
- **OFF = 로드 밂(전진 끝)**: 로드 끝 X −167, 볼트 중심 X −150 → 머리 X −156.5~−143.5, 윗판 +X 끝(X −161, 실측 S1·S2 프로브)에서 4.5 밖.
- 밸브: SY3120(단동 솔레노이드 2위치). 꺼짐 = P→B → 머리 쪽 → 밀기 = OFF(정전·비상 시 바퀴가 평소처럼 누름). 켜짐 = P→A → 로드 쪽 → 당김 = ON.
- 동작 순서 제약(U-09, 설계검토서에 남김):
  1. 스토퍼 ON·OFF 전환은 **U4 들림(J_U4_PRESS 13.006, 누름 실린더 후퇴)** 에서만. 그다음 누름 → 그네가 볼트 머리에 얹힘.
  2. 띄울 구간: 좁은 U홈 위 '바퀴 들기'(0-8-2 ②) 대신 살짝만 띄울 때, 'U4 혼자' 구간이 아닌 곳에서 바퀴를 잠깐 비울 때(C-39 F4 ≤ 18 N과 다른 방법 — 스토퍼로 띄우면 바퀴 힘 0, 이송력 없음).
  3. 실린더 자동 스위치 2개(ON·OFF 확인, D-M9 계열 자리만, 형번은 제어 단계).
  4. 볼트 높이는 매트 두께 셋업 때 OFF 자리에서 L 렌치로 맞추고 너트로 잠근다(2절 표).

## 2. 띄움 높이 근거 (calc.json)

멈추는 각 θ에서 볼트 머리 윗면 H. 윗판 밑면 Z(Y,θ) = 140 + cosθ + (120 − Y)·sinθ(측정 3절과 같은 식, θ0에서 141). 평평한 머리라 θ ≥ 0이면 머리 +Y 끝(Y 76.5), θ < 0이면 −Y 끝(Y 63.5)이 먼저 닿는다.

| 매트 두께 + 띄움 | θ (°) | 바퀴 밑 Z | H(볼트 머리 위) |
|---|---|---|---|
| 6 + 1 / 2 / 3 | −1.443 / −0.96 / −0.479 | 7 / 8 / 9 | 139.58 / 140.05 / 140.53 |
| 10 + 1 / 2 / 3 | 0.476 / 0.95 / 1.422 | 11 / 12 / 13 | 141.36 / 141.72 / 142.08 |
| 16 + 1 / 2 / 3 | 3.289 / 3.751 / 4.211 | 17 / 18 / 19 | 143.49 / 143.84 / 144.19 |

- 조절 4.61 mm. 볼트 CB8-20(머리 높이 8): 머리 밑 131.58~136.19. 블록 윗면 124, 너트 124~129 → 머리 밑과 2.6 이상. 블록 물림 7.8~12.4(+너트 5).
- 감도: 볼트 0.1 mm → 바퀴 0.28 mm(θ0 근처 바퀴 2.094 mm/°, 머리 +Y 끝 0.759 mm/°).
- CAD 확인: H 144.1 상자를 θ 4.3에 놓으면 그네와 0.17(멈춤각 ≈ 4.2 = 계산과 맞음), H 139.9를 θ −0.5에 놓으면 0.61.
- 바퀴 기울기: 그네 축·바퀴 축 모두 X → 바퀴 면 기울기 0°. 접지점만 Y −0.58~−4.82로 옮겨 간다. 떠 있는 동안 회전 SF·자국은 해당 없음. 목표보다 두꺼운 매트가 들어와 닿을 때만 M02R 손계산(두께 16 dY 4.32에서 rot_SF 1.079, mark_SF 1.013)과 같다.
- 누름 실린더(U4S) 반대쪽 끝: 그네가 스토퍼에 얹혀 누름 실린더가 다 나오지 않는다. 링크 −1.4535 mm/° 기준 θ 0.95면 로드 13.8 mm(행정 25 안).
