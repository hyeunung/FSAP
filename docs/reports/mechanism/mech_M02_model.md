## 워크플로우 메모
- `motion.study {study, keys}` 편집은 키를 덧붙이지 않고 통째로 바꾼다. 조인트 하나만 바꾸려면 전체 키를 다시 줘야 해서 MCP 인자가 연구당 12~20 KB가 됐다. 조인트 하나의 키만 바꾸는 명령이 있으면 좋겠다.
- STEP 하위 부품(실린더 몸통·로드)에 `joint.create {point, z}`로 조인트를 맺으면 부품 로컬 x축 기준으로 프레임이 잡혀 90° 돌아간다. `joint.as_built`로 맺어야 제자리다. 안내서 '알아둘 것'에 넣을 만하다.
- 고리 한계(실린더 행정 끝)와 조인트 한계가 같으면 연구 키가 고리에서 멈춰 motion.play 전체가 fraction에서 선다. 조인트 한계를 고리 한계 바로 안쪽에 둔다.
- `solidcraft-cli eval --json-out`이 motion.interference 대신 문서 검사를 남겼다. 연구 간섭은 `run --results`로 받았다.
- 설계안이 실린더 임시 길이(후퇴 120)를 썼는데 받은 실물은 183.5였다. 설계안 단계에서 purchased-step에 같은 사양 STEP이 있는지(형번 표기가 달라도) 먼저 보면 위 핀 위치가 처음부터 맞는다.
