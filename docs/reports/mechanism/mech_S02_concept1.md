- 방향: 결정로그가 남긴 다음 후보를 그대로 출발점으로 쓴다 — D-41·D-37 "STEP 수령 → 바디 교체", T07-X02 "실물 1580 STEP을 받으면 상자를 바꾸고 재판정", T06-D01 "실물 STEP(D-37) 받으면 교체". 새 기구·새 조인트·새 가공품은 없다.

## 3. 교체 좌표(측정 자료 좌표계, 세계 mm)

넣는 법은 S01·`gen_t07_mech.py`와 같다: `file.insert_step`(matrix = 부모 로컬 3×4 행 우선)로 root에 넣고 `occurrence.reparent`(세계 위치 유지)로 각자 형재 컴포넌트 아래로 옮긴 뒤 `STEP대기_` 바디를 지운다. 형재 STEP 로컬은 `frame_matrix` 규약: X = 길이(원점 = 길이 최소 끝), Y = 80, Z = 40(X×Y), 단면 중심이 원점.

### 3-1. 형재 6개 (`frame_matrix(bb, la, wa)` 입력)

| 컴포넌트 | 형번 | la(길이) | wa(80) | 원점 c(길이 최소 끝, 단면 중심) | ex / ey / ez | 끝 맞닿음 |
|---|---|---|---|---|---|---|
| `HFS8-4080-2850_G1` | HFS8-4080-2850 | X | Z | (−1425, −1720, −640) | (1,0,0) / (0,0,1) / (0,−1,0) | X ±1425 ↔ 1580_PL/PR 안쪽 면 |
| `HFS8-4080-2850_G4` | HFS8-4080-2850 | X | Z | (−1425, −1720, −100) | 같음 | 같음 |
| `HFS8-4080-680_SL` | HFS8-4080-680 | Y | Z | (−910, −1700, −640) | (0,1,0) / (0,0,1) / (1,0,0) | Y −1700 ↔ G1 뒷면, Y −1020 ↔ 1900_F 앞면 |
| `HFS8-4080-680_SR` | HFS8-4080-680 | Y | Z | (910, −1700, −640) | 같음 | 같음 |
| `HFS8-4080-1580_PL` | HFS8-4080-1580 | Z | X | (−1465, −1720, −680) | (0,0,1) / (1,0,0) / (0,1,0) | 위·아래 끝 = 캡 `_ZP`·`_ZM`(그대로 둠) |
| `HFS8-4080-1580_PR` | HFS8-4080-1580 | Z | X | (1465, −1720, −680) | 같음 | 같음 |

손검산: 2850 = 1425 − (−1425), 680 = −1020 − (−1700), 1580 = 900 − (−680). 각 c는 측정 1-1의 bbox 단면 중심과 길이 최소 끝에서 나왔다(지어낸 값 없음). HFS8-4080 단면은 대칭이라 길이 축 둘레 180° 뒤집힘은 형상이 같다.

**열린 끝 확인(마감캡, C-11·메모리 '형재 열린 끝엔 항상 마감캡'):** 2850 두 끝은 1580 기둥 면, 680 두 끝은 G1과 1900_F, 1580 두 끝은 이미 캡 4개. 새로 열린 끝이 없으므로 새 캡 0.

**위치 확인은 bbox가 아니라 면 거리로(측정 2-3, 1900_F bbox ±1425 대 실제 ±950).** 맞닿음 면 쌍과 기대값:

| 쌍 | 기대 |
|---|---|
| G1·G4 X 끝면 ↔ 1580_PL/PR | clearance 0.0, 겹침 0 |
| SL/SR Y −1020 끝면 ↔ `HFS8-4080-1900_F` | 0.0, 겹침 0 |
| SL/SR Y −1700 끝면 ↔ G1 | 0.0, 겹침 0 |
| G1·G4·PL·PR 앞면 Y −1740 ↔ `P_T07_SKIRT_C/L/R` | 0.0, 겹침 0 |
| 1580 ↔ 캡 `_ZP`·`_ZM` 4쌍 | unchecked 아님. 끼움부 겹침은 실물 STEP끼리 → M-08 "구매처 CAD끼리의 미세 겹침"으로 부피를 적고(S01-D1 1.2 mm³ 선례), 크면 캡을 끝면 기준으로 다시 맞춤 |
