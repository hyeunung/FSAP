# RX-05 설계안 — U5 대차 홈 솔 덮개 (기준 v2.22.4)

## 요약 (10줄 안쪽)

- 출발점: R375X 사진1 ⑥·사진2 ④ 보 밑 전폭 솔 띠(benchmark.md D-186) — 대차가 지나는 홈을 솔 띠로 막고 대차 기둥이 솔 사이를 지나간다. 이 기계에서는 레일·벨트가 보 앞면에 있어 **판금 덮개 한 장(윗판·앞벽·밑 날개·끝 날개·뒤 날개) + 솔 띠 4줄**로 감싼다.
- 새 부품: 판금 `P_M03_GCOV_SM`(A5052 t2, X −2180~−420), 판금 `P_M03_GCOV_RBRKT_SM`(A5052 t3, 보 밑 Z 받침), 솔 띠 `STEP대기_BRSEAL_B25` ×3·`STEP대기_BRSEAL_B40` ×1(형번 미확인, E-12 임시), CB5-12 ×14, CB4-12 ×36. 고칠 것: 관 `TU0604_M08P_U5C_2` 아랫부분 경로(앞벽 통과 71.3 mm³ 없앰).
- 솔이 지나가게 두는 것(기준선): 윗 솔 ↔ 체인 팔 t3·관 U5C_1·_2, 앞 밑 솔 ↔ 관 U5C_1·_2, 뒤 밑 솔 ↔ 대차판. 그 밖 겹침 0(CAD 상자 프로브 20개, inspect.clearance truncated false, unchecked 0).
- 덮인 길이 1,720(X −2160~−440) ≥ 행정 1,380 + 대차판 220 = 1,600. 위·앞·밑 세 면 모두 X 전 구간 덮음, 밑은 앞·뒤 솔 끝이 Y 75~80에서 5 겹침.
- 하중(손계산, FEA 못 함 — 환경 없음 D-16): 앞 C단면 손 100 N 수평 σ 35.8 MPa(SF 4.47, A5052-H32 0.2 % 160), 처짐 6.3 mm. 보 볼트 CB5-12 최대 137 N(SF 큼).
- 미완·임시: 솔 띠 형번·털 길이·고정 방식(새 자료대기 후보), TU0604 최소 굽힘 R(표에 없음, 임시 20), 끝 쪽 Y 80~90 틈 2~10(디테일).

## 1. 구동 방식·상태

덮개는 고정(U1 보에 붙음). 움직이는 것은 기존 대차 `J_U5_X` 0~1,380(+X slide)뿐, 조인트 변화 0. 대차와 함께 X로 움직이는 체인 팔·관·대차판이 솔 사이를 지나간다. LIFT(−10~30, 아래로)·FLOAT(0~20, 위로)는 대차판 앞·밑 Z ≤ 286에서 움직인다 → 덮개 밑 날개 Z 290과 틈 ≥ 4.0. 사이클 단계와 무관.
