## 워크플로우 메모

1. `sigcheck`가 볼트 목록이 낡았다는 이유만으로 'full'을 낸다. 같은 일이 RX-19 측정에 이어 두 번째다. 그런데 서명 parts의 U4 bbox 일부가 실측과 달랐다(HG-KR23_M02 Y·Z 최대 6.7 차이). RX-19가 형상을 바꾼 뒤 서명이 일부만 고쳐진 것으로 보인다. 'bolts' 모드와 '바뀐 유닛만 다시 재기'가 있으면 좋겠다.
2. MCP `batch`의 `path`는 서버 허용 폴더(3D_Modeling, recovery, 서버 임시 폴더)만 읽는다. `tools/out/`의 스크립트는 서버 임시 폴더로 복사해 돌렸다. 안내서에 적혀 있지 않다.
3. `motion.play`와 `inspect.measure {bodies}`를 묶으면 응답이 1.7 MB가 된다(모든 occurrence pose를 돌려준다). 측정만 할 때는 `motion.play`를 따로 부르는 편이 낫다.
