## 워크플로우 메모

- 지시문은 v0.7.2라 했지만 config doc는 v0.8.0이다(측정부와 같음). T05 영역 같음.
- 요구서 T15 완료 판정이 직선 판 21×4만 적어 C1·C2가 "된다"로 올라왔다. 렌치·스패너 자리는 흔들기 각도까지 판정 칸에 넣는 것이 좋다(과제 정리부 문구).
- SolidCraft: 위판 밑면에 딱 맞춘 join은 "change the body away from the tool"로 거부, 상자 자르기 뒤 같은 모서리 둘의 R1 필렛은 두 번째가 거부, −147 같은 평면 join은 뒤 자르기를 깨뜨림. 둥근 사각 스케치로 자르면 R1이 한 번에 나온다. 안내서 '알아둘 것' 후보.
- PM 단계의 CAD 시험이 일곱 번 돌았다(각 1~5분). 모델링 순서의 실행 가능성을 PM이 확인하는 것은 WF-016·017대로 맞지만, 실패 사례 목록이 안내서에 있으면 줄일 수 있다.
