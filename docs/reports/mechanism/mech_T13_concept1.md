## 1. 방식

구동 요소가 없는 고정 받침(BASE)이다. 행정 0, 대기 위치 = 작동 위치. 조인트를 더하지 않는다(machine.json 변경 없음).

틀은 사각 상자 하나다.
- 옆 두 면(YZ): 바닥 레일 + 앞 기둥 + 뒤 기둥 + 헤드판(위에서 앞·뒤 기둥 윗끝을 Y로 묶음).
- 앞·뒤 두 면(XZ): 기둥 2 + 위 가로대 + 아래 가로대.

하중 길은 이렇다.
- 끌림 비틀림: 판이 평면 안에서 기둥 4개 윗끝을 강체로 묶는다. 기둥은 강축(Y 80) 굽힘으로 받고, 밑의 레일이 YZ 굽힘으로 받는다. 레일 양끝은 1900_B·BB.
- X 밀림: 기둥 약축 굽힘으로 받는다. 기둥 밑 회전은 아래 가로대가 XZ 굽힘으로 막는다(레일 비틀림에 기대지 않음).
- 헤드 무게: 판 → 위 가로대(헤드 기둥 바로 밑) → 기둥 축력 → 레일 → 1900_B·BB.

조립 순서: 바닥 레일 2(1900_B·BB에 브래킷) → 아래 가로대 2 → 기둥 4 → 위 가로대 2 → 이젝터 2 → 헤드판 → 헤드(T너트 발).

## 3. 흔들림·세기 손계산(`tools/out/mech_T13/concept1_calc.py` → `concept1_calc.json`)

## 8. 위험

- 흔들림 0.162는 브래킷·이음 강성을 뺀 비교값이다. 8 시리즈 L 브래킷 이음은 실제로 무르다(D-31). 실제 값은 이보다 크다. 그래도 같은 가정의 지금 값 4.09와는 큰 차이가 남는다.
- -700·-260 STEP이 없다. 미스미 로그인이 풀려 있으면 STEP대기_로 남는데, 이는 규칙 13의 '형번 정해졌는데 STEP대기_' 항목이 된다. 대안은 같은 길이 표기 확인 뒤 받는 것이다.
- 측정 프로브 사이 두 띠(판 X 100~180 · Z −140~−134, 위 가로대 X 90~110)는 직접 재지 않았다. 검증에서 정적 1회 잰다.
- 헤드가 실물로 오면(D-10) 발 자리가 가로대 T홈 Y 640·680·790·830에 안 맞을 수 있다. 그때는 판에 구멍을 내고 판–가로대를 따로 체결해 흡수한다. 판 두께는 디테일에서 정한다.
- 이젝터를 옮기는 것은 T01 진공 배관 길이에 영향을 준다(모델 밖).
- 1900_B·BB는 긴 형재다(BB는 STEP 대기 D-48). 세로 스프링 6,452 N/mm는 양끝 단순지지로 가정한 값이다. 다리 자리(D-39)가 바뀌면 값이 바뀐다.
