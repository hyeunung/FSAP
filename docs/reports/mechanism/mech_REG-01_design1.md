# REG-01 기구설계 수정 1회차 — 판정 규칙 못 박기 (FSAP_v2.6.4, 2026-11-06)

요약
- **같은 안 REG-01-D1.** 형상·조인트·연구·구매품 변경 0, 저장 0. 범위·회차(A1~A4)·세션 나누기·도구 수정 2개(J_U6_SHIFT 0 몰기, POSE 이어 몰기)는 `mech_REG-01_design.md` 그대로.
- **고친 곳:** 4절 판정 — 회귀 담당이 그대로 쓰는 합격 규칙 3개와 truncated 다시 재기 규칙을 더했다.
- **이 판(2026-11-04 판 같은 이름 파일)은 덮어썼다.** 옛 내용은 결정로그 '구동 REG-01 설계안' 수정 1(2026-11-04) 행에 남아 있다.
- **미완:** 겹침 0·truncated 0의 실제 판정은 회귀 결과로 난다. 이 부서는 회귀를 돌리지 않는다(읽기 부서, E-17 "전체 사이클은 라운드 끝 전체 회귀가 한 번").

## 2. 회차별 시간 상한(요구서 6-4 "전체 회귀 상한 30분")
- regrun: 시험 20단계 → 어림 → 어림이 1,800 s를 넘으면 그 회차 끝 범위를 줄여 다음 회차로 → 호출 8분·커널 패닉 즉시 멈춤 → 상한에 끊긴 범위는 '못 본 범위'(E-17 전체 회귀 실행 절차, WF-153).
- 연구 A1~A4: 8병렬 실측 5.9 s/단계(mech_regression_6.md) → 회차 ≈ 300단계. 자세 2세션은 시험 20점으로 다시 어림.

- E-08 원복: CLI 읽기만, 앱 세션 건드리지 않음, 저장 없음. 이번 회차는 CAD를 열지 않았다(1회차 확인값 그대로).

## 4. 회귀 담당 지시(1회차 4절에 더함)
1. `r3`를 `r4`로 복사, chunk7.py 84·86줄 튜플에 `'J_U6_SHIFT'` 추가, POSE 이어 몰기(1회차 그대로).
2. 회차 A1~A4 + 자세 회차마다 `python -B r4/an.py` → `bad`·`truncated`·`unmoved`·`stopped` 개수를 보고서 표에.
3. `truncated` 단계는 1절 규칙으로 다시 잼. 남으면 못 본 범위.
4. 합격: 본 범위에서 네 개 모두 0. 못 본 범위는 다음 회귀 첫 묶음으로.
5. 끝나면 각 세션 `motion.play REST 0`, 저장 없음.
