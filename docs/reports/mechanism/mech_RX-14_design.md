# 구동 RX-14 설계안 — U7 테이프 길을 테이블 면으로 (2026-11-22, 기구설계부)

## 요약

- 대상 `3D_Modeling/FSAP_v2.18.0.sc`(읽기만, 저장 0). 출발점은 R375X 사진(바늘 앞 삼각 판 + 바늘 오른쪽 테이블 면의 덮개)과 867-392342-M 바인딩 장치다(요구서 0-8-3 U7).
- 걷는 것 약 119바디: 위 카세트 80, 걸이의 커넥터 소켓 묶음 21, U8의 U7 관 6 + 관 빗 1(+볼트), 옛 안내 롤러 받침 2 + 볼트 4, 테이프 모형 3. 조인트 6개, 억제 피처 13개, 빈 컴포넌트 5개.
- 새로 넣는 것 약 39바디: 툴 카세트(판 + 덮개 + 바인더 임시 형상), 카세트 자리(판넬 밑 받침 블록 + 핀 2 + 토글 클램프), 고정 테이프 길(홈통 + 뚜껑, X 125~1060), 안내 롤러 받침 2, 차동 바인더 구동부 임시 형상, 밸브 포트 마개 6.
- **테이프 길은 볼 줄 사이 골(볼 꼭대기 Z 0 아래)에 넣었다.** 뚜껑 윗면 Z −1이라 매트가 닿지 않는다. 테이블 면 위로 나오는 것은 바늘 오른쪽 X 8~55.7뿐이다(바인더 턱 14, 바닥 3, 덮개 2.5, 팔 1.5).
- 테이프 가운데 Y −20(폭 30 → Y −35~−5). 볼 받침 플랜지(Ø44, 윗면 Z −6)를 CAD에서 새로 찾아, 길을 플랜지 위(Z −6~−1)로 올렸다.
- 롤은 지금 받침을 쓰되 축 방향으로 +90 옮긴다(가운데 Y −110 → −20). 테이프는 롤 → 롤러 R1(X 1137 · Z 681) → 아래로 → 롤러 R2(X 1137 · Z 15) → 홈통 → 카세트 → 바인더. 내려오는 자리 X 1156은 매트가 오는 범위(최대 X 1052.1) 밖이다.
- 타고 넘는 구간(평면 계산): S·L 0. G·V·W·P는 바인더 턱 30~64 mm(0.6~1.7 %), 바닥 76~113 mm, 덮개 85~330 mm. 표는 4절.
- 미완·임시: 바인더·차동 구동부 치수(D-211), 덮개·롤 자리(D-212), MC01-5 외형(STEP 없음), M-5P STEP 없음. 절단·끝 접기는 RX-15.

근거 규칙: E-02 "핵심 원리·간섭 푸는 방법·유닛 나누기·배치·타이밍은 바꾸지 않는다", E-10 "구매품은 구상에서 정한다 … 못 구하면 비우지 않고 E-12 임시값과 provisional로 낸다", E-12 "자료대기는 수렴을 막지 않는다", 요구서 0-8-2 ④ "테이프는 바늘 오른쪽(+X)에서 테이블 면을 따라 바인더로 들어온다. 그 길은 낮은 덮개로 덮고, +X로 넘어온 매트는 덮개 위를 지난다".

## 워크플로우 메모

1. 측정 요약의 "볼 줄 사이 폭 75 골"은 볼 Ø25만 본 값이다. 볼 받침 임시 형상에 Ø44 플랜지(Z −8~−6)가 있어 판넬 면의 빈 폭은 56이다. 설계 중 `view.pick` 옆 방향 선에서 찾았다.
2. MCP `batch {path}`는 여전히 작업 폴더를 거부했다(허용: recovery, Temp/solidcraft-mcp-*). 임시 폴더로 복사해 불렀다.
3. `view.pick` 126선의 응답이 화면에 통째로 나왔다(verbose false여도). 선 수를 30개 안쪽으로 나누거나 결과를 파일로 받는 길이 필요하다(E-20).
4. `inspect.clearance`는 `against`를 주지 않으면 `bodies` 안의 쌍만 본다.
5. CAD: MCP 11회, 열기 0(앱에 v2.18.0이 열려 있었음), 저장 0, 자세 변경 0, 체크포인트 83 만들고 되돌림.
