# M02R 설계안 수정 1회차 (M02R-D2, C-41) — [수정 2회차로 1·2절 거둠] 낮은 누름 (기구설계부, 2026-11-11)

요약(10줄 안):
- **[수정 2회차] 아래 배기 관련 줄은 모두 거둔다.** U4 혼자 회전 구간도 봉제 누름 40 N 이상 유지, IR1000 0.129 MPa, 회전 SF0 1.01(`mech_M02R_design2.md`).
- 고친 곳은 글 두 칸이다: 설계안 `mech_M02R_design.md`(3차) 2-2 '낮은 누름' 행과 4-6 제어 제약. 형상·좌표·부품·조인트·연구 키·관은 그대로다(바뀐 부품 0).
- 지난 안의 낮은 누름 0.023 MPa(θ0)·0.0072 MPa(두께 16)는 CDQ2A20-25DMZ 사용 압력 0.05~1.0 MPa 밖이다(M-06). 0.05 MPa에서도 23.8·27.7 N이라 18 N을 넘는다.
- 바꾼 것: 낮은 누름 = **양 포트 배기(공기 0)**. 바퀴 힘은 스프링이 덜어 준 값만 남는다: 내림 끝 8.7, 두께 6 11.8, θ0 13.0, 두께 16 17.5 N. 모두 C-39 F4 ≤ 18 N 안이다.
- 제어 제약(U-09): 1번 밸브를 3위치 배기 중립으로 하거나 배기 밸브를 하나 더한다. 진입은 내려앉는 쪽으로 한다(B를 짧게 → 양 포트 배기).
- 패킹 정지 마찰(임시 상한 15.7 N, 바퀴로 환산 10.9 N)은 내려앉으며 들어가면 힘을 줄이는 쪽이라 F4에 불리하지 않다. 40 N에서 바로 배기하면 최대 23.9 N이 남을 수 있어 진입 순서를 정했다.
- 나머지 판정은 그대로다: 40 N = 0.124 MPa, 누름 SF 1.61, 들기 SF 2.66, 행정 23.85/25, 회전 SF 1.38·1.49, 모터 위 최고 Z 250.
- 미완: 실린더 실물 마찰값(자료대기 후보), 밸브 중립 형식(제어 단계), STEP대기_ 5형번(앞 안과 같음).

## 1. 고친 곳 (수정 2회차에서 다시 고침 — `mech_M02R_design2.md`)

수정 1회차의 '낮은 누름 = 양 포트 배기·3위치 배기 중립·배기 밸브·진입 순서(B 짧게 → 배기)'는 C-39를 잘못 읽은 것이라 지웠다(검도 2회: 배기면 회전 SF 0.33~0.05, IR1000이 A 관에 있어 ABR 배기 중립으로 A 쪽 압력이 갇힘).

그 자리: U4 혼자 회전 구간에서도 바퀴는 봉제 누름 40 N 이상(A 급기, IR1000 설정 그대로)을 유지한다. 낮은 누름(C-39) = 노루발 J_U3_PRESSER 피벗 높이 0이다. F4 = 접선 힘 ≤ μ0.4 × 40 = 16 N(DC-04 15.9) ≤ 18.

남는 사실(수정 1회차 그대로 유효): 0.023·0.0072 MPa는 CDQ2A20-25DMZ 사용 압력 0.05~1.0 MPa 밖이라 쓰지 않는다(M-06).

## 3. 바뀌지 않은 판정 (3차 안 그대로)

40 N = 0.124 MPa(IR1000 0.005~0.2 안), 0.05~0.14 MPa → 23.9~43.4 N, 누름 SF 1.61, 들기 SF 2.66(들림)·6.27(θ0), 행정 23.85 ≤ 25, 기울기(바퀴 면 0°, 접지 Y +1.19·−4.32) 회전 SF 1.38·1.49, 자국 SF 1.32·1.18, 모터 위 최고 Z 250, 관 R 16. 간섭은 모델링(E-03)에서 판정한다.
