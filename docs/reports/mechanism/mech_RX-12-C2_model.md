4. **새 L은 기존 부품 번호(`P_M04_LBRKC_PY_PZ`, `P_M07_LBRKC_PZ_PX`·`NZ_PX`)의 인스턴스**: 모양이 같은 부품이라 새 번호(`P_RX12C2_LBRKC`)를 만들지 않음 — BOM은 수량만 +.

## 워크플로우 메모

- MCP 서버에 `--allow-path`가 걸려 있지 않아(실행 지시 (f)와 다름) 저장본을 허용된 임시 폴더로 복사해 열고 저장 뒤 복사했다. batch `path`도 같은 폴더만 받는다.
- 리지드 그룹에 묶인 구매품(KQ2L·VP)은 `occurrence.move`가 거부되거나 되돌려진다(`reverted: true`). 실패한 batch는 앞 단계까지 되돌리므로, 같은 batch 앞쪽 이동도 함께 사라진다 — 이번에 VP 판·밸브 이동이 한 번 빠졌다가 뒤에 다시 넣었다.
- 부품 하나뿐인 컴포넌트의 인스턴스를 `selection.delete`로 지우면 그 컴포넌트의 피처(복사 피처 포함)가 지워지며 복사한 바디가 원본 컴포넌트로 돌아가 붙는다. 바디를 바꿀 때는 `solid.remove`로.
- `measure` summary 부피가 서명 부피와 몇백 mm³ 달라(근사) sigpatch 변화 판정은 bbox와 바꾼 바디 목록으로 했다.
