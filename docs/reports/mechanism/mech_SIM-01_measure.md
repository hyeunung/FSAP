## 4. 관련 기각·주의(같은 실수 막기)

- 동작 연구 키는 **조인트만** 받는다(`motion.study` params "keys: [{joint, …}]", 바디 표시 키 없음). '구간 바디 표시 켜기/끄기'는 연구로 못 한다 → 조인트로 움직이는 테이프 조각(예: 매트에 붙은 조각을 가림/펼침 조인트로) 또는 매트 좌표 단계 몇 개로 묶는 방식이 필요. 영상은 `motion.export_animation`(GIF/PNG 프레임, 헤드리스, 설계 안 바뀜)으로 가능.
- v0.4.0 T05에서 비틀린 경간을 52조각으로 그린 적이 있다(D-06 'T05 모델링' — 참고만, archive_v0 읽기만).
- 긴 동작 간섭은 앱에서 돌리지 않는다(실행 규칙 2·16): 전 단계 확인은 CLI `regrun`·나눠 병렬.
- 기준선(machine.json baseline_overlaps): 바늘↔TAPE 22.1(M-08), 바퀴↔TAPE 맞닿음만, 원판·바늘판↔WP 밑면 Z 0 맞닿음, 노루발↔SEAM 맞닿음.
- 자리값 롤 U7_TAPE_ROLL은 늘 가득(R150). 빈 심 쪽 줄은 롤과 겹쳐 보이므로 롤 반경을 단계에 따라 줄이는 형상이 없으면 간섭 판정에서 롤을 빼야 한다.
- 테이프 늘어남·주름·뭉침, 비틀림 늘어남 0.51 %는 7절 기록(프로젝트 CLAUDE.md).
