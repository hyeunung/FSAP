## 4. 기각·주의 요약 (같은 실수 막기)

- C-40 '모터 위 누운 실린더 + 크랭크'는 R375X 사진 오독으로 폐기(C-41). v2.10.2 기준 검도 결과는 쓰지 않는다.
- TL_FEED↔WP_MAT_* 회전 중 겹침만 기준선(TL_FEED 바디 225 mm³ 안). 다른 TL_*↔매트 겹침은 기준선 아님(donecheck1 2절).
- 영상: 엔진이 800×500에서 samples ≤ 167만 받음 → 167(모델링 보고 6절).
- 재부팅으로 끊긴 check2는 결과가 빈 파일 — '겹침 0'으로 읽지 말 것.
