# 과제 정리 — 구동 라운드 1회차 (v1.0 두 번째 실행, 2026-11-03, 엔진 v3.7.2)

과제 정리부(PM). CAD는 읽기만(CLI `eval`로 바디 목록 1번, 저장 없음). 모델·문서는 고치지 않았다. 이 파일은 첫 실행(엔진 v3.7.1)의 같은 이름 과제표(N00 하나)를 이번 실행 것으로 바꿔 쓴 것이다.

## 읽은 것

- 요구서 5절: N00 해결(v1.0.1). N01~N08 '구동'·미해결. 구동 후보 DC-01~DC-06 미해결(N00 구동 후보 점검부가 더함). '구동 아님(외장·안전)' 행 없음. 결정로그 외장 단계 X-03(이동 테이블 끝 끼임)은 기록만이라 넣지 않음.
- 모델: `tools/config.json` doc = `3D_Modeling/FSAP_v1.0.1.sc`(36바디, 유닛 차지 공간 상자). `STEP대기_` 바디 0개(N00-S07: 상자만). 그래서 STEPWAIT 과제 없음. 볼트 0.
- `tools/out/step_wait.json`: `login "확인 못 함"`, waiting 빈 배열. 지난 라운드 결과: 빈 배열 → 로그인 '확인 못 함'(N00 최종 보고는 그 시각 '풀림'이라 적었다).
- 자료대기: D-80 STEP 대기 6개(DGM130R-AZAC, DGM85R-AZAC, CRBH7013, MHMF042L1U2M, MHMF082L1U2M, HFS8-4080-3150)는 **선정 후보로만 나온 형번, 모델에 없음** → step_wait 0으로 세고, 해당 과제(N02·N03)가 고를 때 받거나 `STEP대기_`로 넣는다. DGM200R-AZAC은 `purchased-step/`·PartsLibrary에 이미 있음.
- runstats: 실행 2개(v0.x 14.1 h, N00 1.9 h). N00 전체 회귀 문제 0, 못 본 범위 0 → 남은 회귀 동작 문제 0. X 스윕 Y 0 접촉(X 865)은 DC-05로 기록됨.

### 과제 brief(좌표: 바늘점 원점, 작업면 Z 0, +Y 이송)

- **N01**: 0-8-3 U1. 지금 U1_UPPER(X −80~500·Y ±90·Z 125~560), U1_BUNDLE(X ±15·Y −10~15·Z 46~124), U1_PRESSER_BOX(X ±8·Y −20~−2·Z 33~45), U1_NEEDLE_PIN, U1_LOWER_POD(X ±30·Y ±45·Z −120~0), U1_LOWER_DRIVE(X 30~500·Y −460~−20·Z −140~−60). 조인트 J_U1_PRESSER(0~20)·J_U1_NEEDLE(−30~0) 컴포넌트는 비어 있음 → 노루발·바늘 바디를 값 0 자세로 넣는다. 867-392342 STEP 없음 → 공식 PDF 치수(암 밑 335×125, 들림 20, 가마 Ø32)로 `STEP대기_867-392342_UPPER/LOWER`(D-10). 홈 임시값 폭 25·깊이 150·R12.5(D-02·D-03). v0.x T02 노즈 r 8.5 식(홈 폭/2 − 테이프 1 − 0.5)은 참고만. 바인더 방향 = 867 그대로(0-8-3 작은 결정).
- **DC-05**: U1_LOWER_DRIVE Z −140~−60이 U3 묶음 띠(Z −230~−15)와 겹쳐 X 865·Y 0 접촉(N00 회귀). 원판 중심 X 최대 312.5 + U3 반폭 65 + 틈 → X ≥ 약 390, 또는 U2_COLUMN(X 500~620·Y −520~−400) 밑. mech_drive_check.md 4절.
- **DC-04**: 카세트 위 틈 1(U8 Z 13~124 ↔ U1_UPPER 밑 125), +X 바닥틀 끝 X 975. +X(C틀 열린 모서리) 정비 면, 카세트 +X 인출 안내, 가마는 바늘 홈 +X 열린 끝으로. 팔 닿는 거리 기준은 자료대기 새 번호 임시값(E-12).
- **N02**: 0-8-3 U3, US6557478. 지금 U3_PLATE r60(Z −15~0), U3_COLUMN r50(Z −130~−15), U3_DRIVE □130(Z −230~−130, U4_Y 소속). 진공 −60 kPa(N00-D5), 필요 토크 5.1~6.75 N·m. 후보 DGM130R-AZAC·DGM85R-AZAC(D-80, 로그인 문제로 못 받음 → 카탈로그 외형으로 `STEP대기_`), DGM200R-AZAC은 STEP 있음, CRBH7013. machine.json U3_ROT 접두어 디테일은 디테일링 몫(기록만).
- **DC-02**: 대차가 보 위(보 Y ±1000이 대차 밑을 덮음), 회전 450° → 기둥 구간(구동 윗면 −130 ~ 테이블 밑 −40, 높이 90)에 로터리 조인트 + 옆 포트.
- **DC-06**: □130×100 상자에 옆 모터 없음, DGM200R 외곽 197.8×247×200 안 들어감. 모터 −X·+Y로, 높이 > 100이면 기둥 115에서 뺀다(DC-02 90과 함께).
- **N03**: 0-8-3 U4, US5367966. 지금 U4_RAIL_A·B(X −1400~500·Z −380~−340), U4_X_BEAM(X −1050~−750·Y ±1000·Z −340~−260), U4_Y_CARR(Z −260~−230). 조인트 J_U4_X −200~1250(쓰는 −160.7~1212.5), J_U4_Y −400~1200(쓰는 −350~1150).
