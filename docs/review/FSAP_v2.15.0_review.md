# 설계검토서 FSAP v2.15.0 (변경분) — 구동 RX-06R U4 X축 볼나사·손잡이 빼기

요약: v2.14.0(M02R 4회차) → v2.15.0(RX-06R). U4 X 위치 조절축에서 볼나사 축·너트·지지 유닛 2·스페이서 2·손잡이·너트 볼트 4와 조인트 `J_U4_XSCREW`·motion link를 걷어 내고, 레일 2줄(실물 STEP `SSEB13-220`) + 블록 4 + 볼트 잠금(잠금 날 + 누름 판 + CB5-16 ×2)만 남겼다. d₁ 조절 범위 100~195(J_U4_X 0~95)는 그대로이고 손으로 밀어 옮긴다. 최종 판정 pass(완료 판정 ①~⑥ 만족, 동작 문제 0, 수정 1회차는 못 본 14자세 검사만 채움 — 형상 변화 0), 디테일 8, 예외 요청 0. BOM `docs/bom/FSAP_v2.15.0_*.csv`.

## 1. 이 버전이 생긴 이유
- 사용자 결정 C-46(2026-11-13 "응", 질문 `docs/images/r375x/decisions/q4_u4_xaxis.png`): R375X 보 앞 볼나사·레일 2줄은 U4가 아니라 헤드 위 대차 쪽으로 이어진다. U4가 X 레일 블록 위에 실린 것은 형제 기종 R375G 사진이 뒷받침한다. 그래서 RX-06(v2.11.x)이 넣은 볼나사·손잡이는 근거가 없어졌고, "레일 블록 + 고정만 남긴다".
- 같이 한 것: RX-06 예외 판정 E4(레일을 실물 STEP으로 — 그린 상자 레일 ↔ 블록 겹침 178.86 mm³ ×4 기준선 없앰).
- 번호: 컴포넌트 5개가 없어지고 볼트 컴포넌트 6개가 생겨 E-05 "이번 저장에서 새 컴포넌트(유닛·부품 묶음)가 생기거나 없어졌으면 가운데 +1·마지막 0"대로 v2.15.0.
