# 설계검토서 FSAP v1.0.4 — 구동 DC-05 아랫유닛 구동 자리 이동(변경분)

요약
- 저장본 `3D_Modeling/FSAP_v1.0.4.sc`(v1.0.3 → 수정 1회차). 기준 v1.0.2 대비 변경분을 적는다.
- 옛 U1_LOWER_DRIVE 상자(X 30~500·Y −460~−20)를 지우고, 아랫축 서보를 X 654~764로 옮겨 각관 팔로 이었다.
- 완료 판정 세 항목 합격: X 650 ≥ 390, J_U4_X −200~1250 × Y 0 접촉 0(최소 틈 10.0), 사이클 표본 25자세 간섭 0.
- 미완: 디테일 2건(N03 몫), STEP대기_MHMF042L1U2M(D-81).

## 1. 이 버전이 생긴 이유
N00 회귀에서 U1_LOWER_DRIVE 상자가 U3 묶음 높이 띠와 겹쳐 J_U4_X 스윕(Y 0) X 865에서 접촉했다(점 30,−460,−140, mech_regression.md 3절, mech_drive_check.md 4절). 요구서 5절 DC-05 판정 "XY 작업 영역 금지 구역 0 또는 machine.json 지도"를 맞춘다. v1.0.3은 자르기 3개가 움직이는 컴포넌트 안에서 월드 고정으로 잘려 자세마다 형상이 바뀌었고(검도 동작 1), v1.0.4에서 N00 원래 피처 치수를 고쳐 풀었다.
