# 설계검토서 FSAP v2.12.2 (변경분) — 구동 RX-08 U4 중간 높이 스토퍼 실린더

요약: v2.11.1 → v2.12.0(모델링) → v2.12.1(수정 1, 관 나눔) → v2.12.2(수정 2, STEP 레일 잔재 Chamfer2 지움). 새 가공품 2(P_RX08_STOP_BRKT·_BLOCK), 새 조인트 J_U4_STOP(0~20), 8번 밸브·매니폴드 08. 멈춤각 0.95°(바퀴 밑 Z 12 = 매트 10 + 2), 밀기 245.4 N ≥ 218.4 N(SF 1.69). 과제 범위 간섭 0, 빈 포트 0. 최종 판정 pass, 미완 0, 디테일 4.

## 1. 이 버전이 생긴 이유
- 요구서 5절 RX-08, 결정로그 C-42. R375X 사진(U4 옆 벽에서 가로로 나오는 소형 실린더, D-163, 신뢰 적음)을 바탕으로 좁은 홈·U4 혼자 구간에서 바퀴를 매트 위로 살짝 띄우는 중간 높이 자리가 필요했다.
- 수정 2회차는 사용자 지적("이거 안보이냐고"): 타임라인 Remove86 대상 이름이 틀려 STEP 원본 레일 Chamfer2가 남아 관 클램프 L_4·L_5와 1,871.3 mm³씩 겹쳐 보였다.

## 4. 동작 검증 (작업 대상 포함)
- J_U4_STOP OFF × 그네 13.006·3.751·0·−4.11°: 겹침 0, 머리–그네 최소 4.50 mm.
- ON × 13.006°: 겹침 0(9.29 mm). ON에서 `joint.sweep` 13.006 → −4.11은 0.932°에서 머리에 멈춤(설계 0.95°, 메시 공차 0.229). 바퀴 밑 Z 12 → 두께 10 매트 위 2 mm 띄움(두께 6~16에서 1~3 mm 조절).
- J_U4_X 0·95: U4 쪽 관 따라감, 겹침 0.
- v2.12.2 레일 2줄 ↔ 이웃 21: 겹침 0, unchecked 0. 보이는 STEP 잔재 0.
- 매트(작업 대상): ON에서 바퀴가 매트에 닿지 않음(2 mm), 눌림 거동은 7절 시제품 확인.

## 5. 강도 (해석 못 함 — 환경 없음, D-16; 손계산 `fea/results/mech_RX-08_handcalc.json`)
- 실린더 밀기 245.4 N ≥ 누름 반력 145.6 × 1.5 = 218.4 N(SF 1.69). 받침 반력은 발이 받고 실린더 축 힘 0. 짐 진 채 빼기 SF 2.00(0.5 MPa).
- 브래킷 윗판 SF 운전 2.07 / 오조작 1.40(기준 3/2 미달 → 디테일 D1). CB8-20 물림 10.28 < 12(암나사 SF 21.6 → 디테일 D2). 윗판 볼트 M5 SF 15.

## 6. 제어 순서 제약 (U-09)
- 스토퍼 ON(당김)은 그네가 들린 자세(13.006°, 윗판 밑 Z 150.76 > 머리 144.19)에서만 넣는다. 누른 채 넣지 않는다.
- 짐 진 채 OFF는 허용(SF 2.00)이나 그네를 먼저 살짝 든 뒤 빼는 순서를 권장.
- 정전·꺼짐 시 OFF(밀기) — 그네는 기존 누름·듦 동작으로 돌아간다. 센서 자리: 실린더 오토스위치(D 접미사) 2개.
