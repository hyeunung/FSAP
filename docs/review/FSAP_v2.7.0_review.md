## 1. 이 버전이 생긴 이유
사용자 2026-11-09 "모터쪽에 나사빠진것도 많고"(요구서 5절 MOT-01). 서보·감속기가 임시 상자(`STEP대기_MHMF022L1U2M`·`VRXF-PB-60-10`)라 플랜지 체결이 빠져 있었고, 결정로그 C-36으로 형번을 미쓰비시 HG-KR23/HG-KR43 + ATG PGX62-H-10으로 바꿨다. 실물 STEP으로 바꾸고 외형도대로 볼트·핀·와셔를 넣었다.

## 2. 구동 방식 전/후
- 전: U4·U5 바퀴·대차 X 서보 직결 감속기(임시 상자, 체결 없음). U3 아랫축은 차지 상자 `U3_LOWER_DRIVE`뿐.
- 후: 같은 구동 방식(서보 → 감속기 1:10 → 바퀴/풀리). 조인트·행정·연구 변화 없음(새 조인트 0). U3 아랫축은 HG-KR43 + 브래킷 `P_U3_LDRV_BRKT` + 커플링(`STEP대기_SCXW46-14-15`)으로 867 아랫축에 직결(축 Y 0·Z −90 임시, D-143).
