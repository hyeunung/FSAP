## 1. 이 버전이 생긴 이유

- 사용자 2026-11-11 R375X 사진 재판독(`docs/benchmark.md`): 사진1·2 노루발 밑 흰 LED(용도 추정, 신뢰 적음). 우리 기계에 바늘 둘레 조명이 없었다.
- 요구서 5절 RX-04 완료 판정: "과제 범위 간섭 0(노루발 들림·U4 d₁ 45~195 포함), E32 시야 가림 0, 배선 길, BOM". 붙는 자리가 RX-14 결과에 달려 그 뒤에 함.
- E-05 원문 "형상이 바뀌면 새 번호, 새 컴포넌트가 생기면 가운데 자리": `U3_LED`가 새로 생겨 v2.25.0.
