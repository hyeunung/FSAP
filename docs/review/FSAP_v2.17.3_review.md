## 8. 못 한 것 · 넘긴 것

- **검도 재확인 없음**: 최종 판정의 문제 2건(자세 검사, 두 판금 부피)은 수정 1회차에서 모델링부가 직접 재어 닫았다. 검도부가 그 뒤 따로 본 기록은 없다. 검증 원장은 갱신하지 않았다.
- **U7 카세트 것 13피처**는 억제 상태다(5절). RX-14가 걷는다. 그때까지 `P_M05_BINDER`에는 K2 홈이 없고 U7 카세트 관 4줄은 모델에 없다.
- **저장 방법이 지시와 다름**: MCP 서버가 `3D_Modeling/` 저장을 거부해, 앱에서 MCP 임시 폴더에 저장한 파일을 복사했다(바이트 같음 `cmp`). CLI로 265단계를 다시 돌리지 않았다(`mech_FIX-045_model.md` 6절).
- **v2.17.4 없음**: 수정 1회차는 확인만 해 형상이 바뀌지 않아 번호를 올리지 않았다.
- 매트 전 구간 간섭·전체 사이클은 라운드 끝 전체 회귀에서 본다(E-03).
- 구동 후보로 넘긴 것(이미 있는 과제): RX-06-C3 — `U6S_SHOE_SLOT`·`U6S_SHOE_TOP`·`Cylinder789`가 `U6_SHOE` 컴포넌트에 남아 있어 0.45.0에서는 다시 계산할 때의 자세에 따라 결과가 달라진다. `Cylinder789` 높이 10은 그때 5로 되돌려도 된다.
- 기록(디테일링에서 볼 것, 최종 판정 details는 0건): "found by geometry" 경고 3개(`Chamfer1`·`2`는 뒤에서 지워지는 옛 `P_M04_INSERT`, `Chamfer5`는 `P_DC204_PUSH_BLK` 부피 같음). 0.45.0은 오류 없이 다른 모서리를 잡을 수 있어(`Fillet2`) 부피 0.05 % 아래 차이는 이 비교로 못 잡는다. 누르기로 바꾸며 스케치 26개가 늘었다(모두 숨김).
- 재질 점검(`matcheck.py`): 불일치 2건(`P_M02_WHEEL_TREAD`·`P_M03_WHEEL_TREAD` 우레탄 A70)과 BOM에 없는 `P_M04_INSERT`는 이 과제 전부터 있던 것이다. 손대지 않았다.
