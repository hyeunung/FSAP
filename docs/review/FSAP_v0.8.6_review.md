## 1. 이 버전이 생긴 이유

구동 후보 T11-S07. 측정(v0.8.2)에서 진공 길이 없었다: 원판 가운데 막힘, 링1 포트 없음, 이젝터 VAC Ø6 미연결(BASE Y 300~361.7). 이젝터가 BASE에 있어 회전·이송부를 건너는 관 길이 없었다.

## 2. 구동 방식 전/후

- 전: 진공 원판·링1이 그려져 있으나 진공원과 이어지지 않음. 이젝터는 BASE 고정.
- 후: 이젝터를 MAT_Y(DG 받침 ±X 면)로 옮겨 X·Y 이송을 건너는 관을 없앴다. 남은 건너기는 J_MAT_ROT·J_RING1 회전뿐이다. 관은 Y판 Ø10 → Y판 밑 가로 → TCLAMP C클립 → 기둥 속 꼬임 고리 r15 → 기둥 벽 Ø8 → 원판 MBIS/KQ2H06(원판 회로), 링1 θ270 관 고리 → 링1 KQ2H06(링1 회로). 회전 꼬임은 사이클마다 되감는다(J_MAT_ROT −360~0).
