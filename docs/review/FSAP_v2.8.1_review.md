# 설계검토서 FSAP v2.8.1 — 구동 FUNC-01 (변경분, v2.7.0 → v2.8.0 → v2.8.1)

요약: FUNC-01 기능 이론 검증(①~⑦) 결과 불성립 4건을 같은 개념 안에서 고친 버전이다. 먼 쪽 바퀴를 플로트(볼 부시 + 받침 스프링)로 바꿔 누름 힘을 실린더 마찰과 떼었고, 임시 상자였던 바인더를 테이프를 U자로 접는 실제 형상으로 넣었다. v2.8.1은 검도에서 나온 축↔옆판 웹 겹침을 여유 구멍으로 푼 수정이다. 과제 범위 간섭 0, 불성립 0, 디테일 8건.
근거: `docs/reports/mechanism/mech_FUNC-01_calc.md`·`_design.md`·`_design1.md`·`_design2.md`·`_model.md`·`_model1.md`·`_verify.md`·`_verify1.md`·`_fea.md`·`_fea1.md`. BOM `docs/bom/FSAP_v2.8.1_made.csv`·`_purchased.csv`.

## 1. 이 버전이 생긴 이유
요구서 5절 FUNC-01: 간섭 0만으로는 '된다'가 아니다. 사이클 각 기능(① 잡기·자국 ② 미끄럼 ③ 속도 동기 ④ 추종 ⑤ 테이프·바인더 ⑥ 좁은 홈 ⑦ 사이클)을 실제 치수로 손계산했고, 불성립 4건이 나왔다.
- ① 먼 쪽 바퀴: MGPM25 미끄럼 저항 상한 41.2 N이 자국·잡기 창 반폭 13.3 N보다 커서, 실린더가 힘 경로에 있으면 맞는 압력이 없다.
- ⑤ 바인더: 상자 안에서 옆으로 16.5 mm 옮겨 접을 수 없다. 그래서 2단 45° 사선 접기로 바꿨다. 앞끝 보내기 길이 166.7이 행정 150보다 길어 2회 보내기로 했다.
- U5 들기: IR1000 상한 0.2 MPa에서 부하율 0.98로, 수직 권장 0.5를 넘는다.

## 4. 동작 검증 (작업 대상 포함)
- U5: J_U5_LIFT {30, −10} × J_U5_FLOAT {0, 10, 12, 20} 8자세에서 겹침 0. FLOAT 20에서 옆판↔승강판 맞닿음은 위 기계 정지로, 의도한 것이다. v2.8.1에서 REST·4자세를 skip_within null로 다시 쟀고 겹침 0, unchecked 0이었다.
- 바인더: REST·HGT +6·카세트 빼기(CST_X 25) 겹침 0. HGT −4의 두께 10 매트 모형 86.9 mm³는 두께 6 자세에 댄 기준선이고, 옛 바인더 220.5보다 줄었다.
- 높이 조정: 결정로그 C-34(J_U6_HGT·J_U7_HGT 한 값)를 따른다. 어긋난 자세는 회귀 자세에서 뺀다.
- 전체 사이클은 라운드 끝 회귀(REG-01)가 본다.

## 6. 제어 순서 제약 (U-09)
- 큰 매트 모서리 회전 중 먼 쪽 바퀴는 토크 제어로 쓴다(관성비 33).
- U5 승강은 주 공급 0.4 MPa 아래에서 운전하지 않는다. 내림은 미터 아웃으로 한다.
- 테이프 앞끝은 2회 보내기로 넣는다(166.7 > 행정 150).
- J_U6_HGT·J_U7_HGT는 같은 값으로만 움직인다(C-34, −4~+6).
