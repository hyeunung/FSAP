# 설계검토서 FSAP v2.6.4 (변경분) — STEPSWAP r3

- 문서: `3D_Modeling/FSAP_v2.6.4.sc` (이전 v2.6.3), 2026-11-06
- 근거 보고서: `docs/reports/mechanism/mech_step_wait.md`(선정), `mech_STEPSWAP_model.md`(모델링), `mech_STEPSWAP_verify.md`(검도)

## 1. 이 버전이 생긴 이유
M08R(v2.6.0)에서 2E 커튼 금구 볼트를 CB5-12 → CB5-6으로 바꿀 때 STEP이 없어 `STEP대기_CB5-6_M08_PY_LC2F` ×2 임시 형상으로 두었다(M08R-D4, D-135). 미스미 로그인 상태에서 CB5-6 STEP을 받아 실물로 바꾼다(실행 규칙 11 "빼먹지 말고 STEP 파일로 다 바꾸고 넘어가자", 규칙 13 완료 기준 'STEP대기_로 남은 구매품 0').

## 2. 구동 방식 전/후
바뀌지 않음. 조인트·행정·유닛 배치 변화 없음. 볼트는 U8_PNEU 고정 바디다.

- 과제 안 검사(REST, J_U5_X 0·690·1380), 이웃 12바디: 새 겹침 0, truncated false. unchecked 2쌍은 볼트 ↔ 2E 금구 M5 탭(M-08 의도 물림).
- 움직이는 유닛(U3·U4·U5·U6·U7)·매트·테이프 모형: Y로 1,032 mm 넘게 떨어짐, 매트 모형 Z 12 아래 / 볼트 Z 95.75 위 — 작업 대상 길과 무관.
- joint.list: floating 0, conflicts 0, errors 0. 저장본 다시 열기 타임라인 실패 0.

## 5. 강도
체결만 바뀐 자리(E-18) — 같은 형번·같은 자리라 하중 경로 변화 없음. 손계산 새로 할 것 없음. FEA 대상 아님(환경 없음 D-16과 무관).

## 6. 제어 순서 제약 (U-09)
새 제약 없음. M08R 제약(앞 커튼 정지 시간 T ≤ 0.47 s, 옆 바퀴 T ≤ 0.13 s) 그대로.
