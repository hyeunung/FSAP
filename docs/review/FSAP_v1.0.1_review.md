## 1. 이 버전이 생긴 이유
v1.0 새 시작(실행 규칙 17, C-22)의 첫 과제 N00 전체 골격. v1.0.0(준비부: 고정부·조인트 5·매트 3장·연구 6)에 0-8-3 유닛 9개(U1~U9)의 차지 공간 상자를 넣어 기계 크기·브리지 높이·원판–바늘 거리·작업면 높이를 정했다. 작은 변경이라 수 번호 +1(8-2, N00-S08).

## 2. 구동 방식 전/후
- 전(v1.0.0): 조인트·매트 모형만, 유닛 자리 없음.
