# FSAP v0.8.0 설계검토서 — 구동 T18 (X·Y 볼나사 이송 유닛)

문서 담당, 2026-11-02. 대상 `3D_Modeling/FSAP_v0.8.0.sc`(이전 v0.7.2). BOM `docs/bom/FSAP_v0.8.0_made.csv`·`FSAP_v0.8.0_purchased.csv`. 근거 보고서 `docs/reports/mechanism/mech_T18_select.md`·`mech_T18_model.md`·`mech_T18_verify.md`·`mech_T18_fea.md`, 결정로그 T18-S01~S08·M01~M09·X01~X05.

**요약**
- 새 바디 99: 가공품 6(SUS304), 실물 STEP 구매품(유닛 4·커플링 2·형재 2·이음 브래킷 8·너트 2·볼트 38·T너트 22), E-10 임시 형상 12(축 2·서보 2·CB8-35 ×4·CB8-25 ×4). 지운 부품 0, 기존 변경 1(`P_T01_YPLATE` M5 탭 2).
- 행정 J_MAT_X −620~620·J_MAT_Y −860~40 그대로. 정적 387바디·사이클 3·상태 3·되감기·S18 연구 3 T18 새 충돌 0(truncated false). 렌치 프로브 46 겹침 0.
- 위험 속도 SF @280 mm/s Y 2.05·X 2.02(판정), @300 mm/s 1.91·1.89(참고, D-52 사용자 결정).
- **남은 동작 문제:** 예외 판정 T18-X04(기각)로 오조작 하중은 서보 최대 2364 N이다. 이때 `P_T18_YNB` SF 0.72·`P_T18_XNP` 0.89(항복)이고 v0.8.0에는 아직 강화가 안 들어갔다 → T18은 '일부'.

## 1. 이 버전이 생긴 이유

결정로그 S-03은 X·Y 볼나사 구동(지지·너트 브래킷·커플링·서보·모터 브래킷)을 공간만 비워 두었다. v0.7.2 바디 279개 중 X·Y 볼나사·모터는 0개였다. 요구서 5절 T18로 이 구동 유닛을 실제로 넣었다. 부품 묶음 T18을 새로 만들어 부 번호를 올렸다(E-05 "부품 묶음 신설·삭제는 가운데 자리를 올린다").

## 8. 못 한 것

**남은 동작 문제(구동 라운드에서 처리, T18-X04):** 오조작 2364 N에서 `P_T18_YNB` SF 0.72·`P_T18_XNP` 0.89, 체결 CB5-16 YNB → Y판 암나사 0.66·CB8-25 X 너트 → XNP 0.71. YNB는 같은 단면이면 t14 이상, XNP는 +X 두께 증가 금지(BUN20 틈 5)라 매달린 부분 Y 양 끝을 −X로 굽힌 한 장 채널 등으로 SF ≥ 2.
