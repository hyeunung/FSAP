# 설계검토서 FSAP v2.8.12 (변경분) — 구동 PNEU-01R

요약: 공압 관이 고정품 구멍 벽을 0.03~0.28 mm 파고든 3쌍을 구멍 지름만 키워 겹침 0으로 했다(v2.8.11 2개, v2.8.12 1개). 관 경로·조인트·구매품 수량 변경 없음. 기준 v2.8.10 → v2.8.11 → v2.8.12.

## 이 버전이 생긴 이유
요구서 5절 PNEU-01R: PNEU-01 검도(mech_PNEU-01_verify2.md 78·79행, 결정로그 PNEU-01-R1·R2)의 남은 동작 문제 — 정적 겹침은 모델 전체 금지. v2.8.11 검도(mech_PNEU-01R_verify.md #1)가 체인 고정 끝 12PZ_F ↔ 관 U5_A 3.648 mm³를 더 찾아 수정 1회차(v2.8.12)로 고쳤다.

## 구동 방식 전/후
- 전·후 같음: 연질 우레탄 TU0604 관 + 원터치 피팅, 빗 고정품·체인 끝 통로로 관을 잡는다. 관 굽힘 R 16 ≥ 최소 15.

## 동작 검증 (작업 대상 포함)
바뀐 바디 3개 둘레(bbox ±5)를 대기 자세에서 쟀다. 이웃이 모두 고정품이라 움직이는 조인트 점에서 형상이 같다(E-17). 과제 범위 간섭 0, 맞닿음은 기존 의도 맞닿음(볼트 자리면·체인 링크 끝면)뿐. 매트·테이프와 닿는 부품 아님. 최종 판정 pass. 근거 `docs/reports/mechanism/mech_PNEU-01R_model.md`·`_model1.md`·`_verify.md`·`_verify1.md`.

## 강도
구멍만 0.25~0.5 mm 키움, 하중 경로 그대로 — 살 ≥ 3.25로 강도 검토 대상 아님(E-18). 해석 못 함 — 환경 없음(D-16).

## 제어 순서 제약 (U-09)
