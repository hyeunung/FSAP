- 사용자 2026-11-11 R375X 사진 재판독(`docs/benchmark.md`): 사진1 ⑫ 파란 관 끝 작은 노즐이 바늘 쪽(D-182, 용도 추정 — 신뢰 중간~낮음). 우리 기계에 바늘 둘레 불기가 없었다.
