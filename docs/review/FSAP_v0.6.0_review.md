# 설계검토서 FSAP_v0.6.0 (변경분) — 구동 T07 로딩·배출

- 설계 파일: `3D_Modeling/FSAP_v0.6.0.sc`(이전 v0.5.1, 그 이전 v0.5.0). 생성기 `tools/gen_t07_mech.py`(T07), `tools/gen_t06_mech.py`(v0.5.1 SEAM 단면)
- 선정: `docs/reports/mechanism/mech_T07_select.md`(T07-C1 수정안). 모델링 보고서: `docs/reports/mechanism/mech_T07_model.md`
- BOM: `docs/bom/FSAP_v0.6.0_made.csv`·`_purchased.csv`. 결정로그 T07-S01~S10, T07-M01~M07
- STEP·도면은 완성본일 때 일괄(E-06, U-15)

## 1. 이 버전이 생긴 이유

요구서 0-3 ①(작업자가 매트를 올리고 시작)과 ⑤(배출)의 자리를 만든다. 배출 방식 D-13이 미정이라 작업자가 꺼내는 방식을 기본으로 두고, 자동 배출 자리는 검사 상자로만 남긴다. 함께 v0.5.1에서 T06-X03(SEAM 단면, SEAM ↔ BOUND 748 mm³ → 0)을 했다.

## 2. 구동 방식 전 / 후

| 항목 | 전(v0.5.0) | 후(v0.6.0) |
|---|---|---|
| 로딩 | 대기 자세(Y −700)에 작업자가 올림, 작업자 쪽 경계 없음 | 같음. 작업자 쪽(−Y)에 BASE와 함께 고정된 가드틀, 판 앞면 Y −1742 = 서는 선. 큰·홈 매트 X 기준 = 판 윗변 V홈(X 0) |
| 배출 | ⑤ 대기로 돌아오면 작업자가 꺼냄 | 같음(D-13 기본). 위로 들거나(X1·X3) 앞으로 뺀다(X2·X4, 판 윗변 Z −60 위로 59) |
| 안전 | 없음 | 라이트 커튼 자리(검출면 Y −1720, X ±1395, Z −60~880)·버튼 자리 검사 상자. 커튼·버튼은 PLC 단계(U-09) |
| 자동 배출 | 없음 | 자리만: A4 → A5 밀어내기(1순위), A3 위 흡착(2순위) 검사 상자 |
| 조인트·동작 연구 | 10 구동 조인트, 8 연구 | 그대로(새 조인트 0, 변경 0) |
