# FSAP v2.11.1 설계검토서 (변경분) — 구동 RX-06 U4 X 위치 조절축

요약: v2.11.0에서 새로 넣은 U4 X 조절축(J_U4_X 0~95, d₁ 100~195)의 조각 문제를 고친 버전. 옛 루트 피처 34개를 U4_WHEEL_N·U4_PRESS로 옮겨 J_U4_X가 움직일 때 형상이 함께 간다. 최종 판정 pass(below_done false). 레일 STEP 자르기(E4)·지지 유닛 BSW15·BUN15 교체(E5)는 승인됐고 다음 회차에 적용한다. 디테일 7건.

## 1. 이 버전이 생긴 이유
v2.11.0 검도에서 J_U4_X를 움직이면 U4 일부 형상이 제자리에 남았다(옛 루트 피처가 컴포넌트 바디를 고침). 수정 1회차가 피처 34개를 해당 컴포넌트로 옮겼다(결정로그 RX-06 모델링·수정 1회차).

## 2. 구동 방식 전/후
- 전(v2.10.x): U4 그네 매달기 윗판이 보 P_M07_BEAM에 고정, d₁ 고정.
- 후(v2.11.x): 윗판을 SSEB13 레일 2줄·블록 4개에 얹고 BSS2020 볼나사 + 수동 손잡이 Ø50으로 X 이동(J_U4_X 0~95 → d₁ 100~195). 봉제 중 d₁ 변경 불필요 판단으로 수동(결정로그 RX-06 설계안).

## 3. 변경 표 (E-07)
| 부품 | 전 → 후 | 바꾼 이유 | 검증 수치 |
|---|---|---|---|
| U4 옛 루트 피처 34개 | 루트 → U4_WHEEL_N·U4_PRESS | J_U4_X 이동 시 형상 조각 | X0·X95 들림, X95 내림 끝 clearance: 레일↔블록 기준선 178.86 mm³ ×4 외 겹침 0 |

| BSW20·BUN20 | 유지 → 다음 회차 BSW15·BUN15 (E5) | STEP 축 저널 Ø15와 짝 | 시험: 축↔유닛 겹침 0(나사 물림 1쌍 기준선) |

## 4. 동작 검증
- J_U4_X 0·95 × 들림, 95 × 내림 끝: 겹침 0(레일↔블록 기준선 제외). 관 TU0604 3개 X95에서 겹침 0.
- J_U4_X 47.5, X0 × 누름: CAD 미측정(CLI 9점 시간 초과) — 라운드 끝 회귀로.
- 작업 대상(매트): 바퀴 접지 거동은 M02R과 같고, d₁만 바뀜. 유연 거동은 요구서 7절.

## 5. 강도
레일·볼나사 하중 손계산은 handcalc_rx06.json(설계안·모델 보고서). 이번 수정은 하중 경로 변경 없음. FEA: 해석 못 함 — 환경 없음(D-16).

## 6. 제어 순서 제약 (U-09)
- d₁ 조절은 정지·들림 상태에서 수동으로만.
- d2 ≥ d1 + 240 (J_U5_X ↔ J_U4_X) 연동 조건 — machine.json 반영은 디테일.

## 7. 예외 판정 요약 (결정로그 '구동 RX-06 예외 판정' 1·2회차)
1. 레일 그린 형상(규칙 18) — 기각 → STEP 자름 220(E1), 방법 고침 승인(E4).
2. 축 그린 형상 — 조건부 승인(E2) → BSW15·BUN15 교체 승인(E5), Ø20 끝 가공 지어내기는 기각.
3. 지시서 좌표·볼트(M3~M7) — 승인.
