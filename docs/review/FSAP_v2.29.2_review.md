# FSAP v2.29.2 설계검토서 (변경분) — 구동 RX-19 U4 매달림 단순화

2026-11-24, 문서 담당. 설계 파일 `3D_Modeling/FSAP_v2.29.2.sc`(v2.28.1 → v2.29.0 → v2.29.1 → v2.29.2). BOM `docs/bom/FSAP_v2.29.2_made.csv` · `_purchased.csv`. 근거 보고서 `docs/reports/mechanism/mech_RX-19_model.md` · `model1.md` · `model2.md` · `verify*.md` · `donecheck*.md` · `fea.md`.

## 요약

- 최종 판정: **설계 기준은 넘음(below_done), 완료는 아님(pass false)** — 동작 문제 0, 디테일 2건, 해석 못 봄(환경 없음 D-16).
- U4 매달림이 세 덩어리(캐리지 → 윗판 → 팔·그네)에서 **블록 1 + 그네 1**(+ 핀·볼트·실린더 부속)로 줄었다. 걷은 바디 47, 새 바디 2.
- 스토퍼 사슬을 블록 선반 밑 +X 쪽으로 옮겨(경로 3) U4↔U5 새 겹침(36,400~51,100 mm³)을 없앴다. U5 최소 틈 23.0.
- 잠금 너트 물림 7.25(≥ 6.5), 이음 ↔ 너클 틈 4.0(뜸 ±0.5 빼도 3.5).
- v2.29.2는 비교 그림을 다시 찍으려고 이름만 바꿔 저장한 것이다(형상·조인트는 v2.29.1과 같음, `cache/bodies.bin` 동일).

## 1. 이 버전이 생긴 이유

사용자 2026-11-24 "저거처럼 간단하게해 우린 왜 세덩어리야"(요구서 5절 RX-19, 결정로그 C-54). R375X는 보 앞 레일 블록에 두꺼운 블록 하나, 그 밑 서보·감속기 바로 위에 작은 그네가 있다. 우리 v2.28.1은 캐리지 `P_RX06_CARRIAGE` → 윗판 `P_M02_BASE` → 팔 옆판·묶음판·그네 `P_M02S_SWING`(피벗 Y 120·Z 140)의 세 덩어리였다.

## 4. 동작 검증 (작업 대상 포함)

- 판정 자세: J_U4_X 0·47.5·95 × PRESS 19.523·10·1.515·−8.171 × STOP 0·20, 이웃 J_U5_X 1365·1360·1310 × LIFT −10·30. 과제 범위 뜻하지 않은 겹침 0.
- 남는 닿음: PRESS 1.515°의 스톱 첫 닿음 0.01 mm³(의도), "STOP 0 + PRESS < 1.515" 조합의 텅 ↔ 발 겹침(스톱이 막는 자세 — 제어 제약으로 뺌).
- 매트(작업 대상): 바퀴 접지 자리·누름 힘 창은 그네·러그·핀·주 실린더를 바꾸지 않아 지난 회차 값 그대로(누름 힘 창·자국 SF·회전 SF·들기 SF·행정 여유 미달 0). 매트 눌림 복원은 요구서 7절(모델로 판정하지 않음).
- RX-16 입력 — d₁ 45에서 헤드 임시 상자(STEP대기_867-392342_UPPER, X ≥ −80, 밑 Z 125) 밑 여유(음수 = 들어감):

## 5. 강도

손계산만(해석 못 함 — 환경 없음, D-16). 스톱 판 세운 부분 SF 12.3, 목 벽 전단 2.3 MPa. 처짐 합 0.194 mm(정정 0.186 + 러그 0.008). 스톱 받침 기둥 오조작 SF 1.71·처짐 0.66은 디테일(FEA-D1·D2).

## 6. 제어 순서 제약 (U-09)

- 스톱 넣고 빼기(`J_U4_STOP` 0 ↔ 20)는 **PRESS ≥ 1.515°일 때만**.
- C-46 그대로: d₂ ≥ d₁ + 240, d₁ 바꾸기는 바퀴 든 상태에서만(U4↔U5 틈 ≥ 5.5, 한계 J_U5_X 1365에서 확인).
