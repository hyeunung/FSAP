# FSAP v1.0.7 설계검토서 — 구동 N02 U3 진공 원판 + 회전 조향

요약
- 저장본 `3D_Modeling/FSAP_v1.0.7.sc`(바디 84). v1.0.5에서 U3 차지 상자 3개를 실제 구동 유닛(진공 원판·축·크로스 롤러·씰 슬리브·조향 모터 벨트)으로 바꿨다(v1.0.6). 이어서 진공 관 길을 다시 잡았다(v1.0.7, 수정 1회차).
- 최종 판정 pass, 동작 문제 0, 디테일 1건(N02-D10, 7절).
- 완료 판정 네 항목을 모두 만족했다. 회전 전 구간 간섭 0, 원판 Ø120은 300×200 안(여유 40), 중심–바늘 100.0·가장자리–바늘 40.0, 조향 허용 토크 18.1 ≥ 6.75 N·m(임시 D-85).
- STEP 대기 7형번(D-86). 해석 못 함 — 환경 없음(D-16), 손계산으로 함.

## 1. 이 버전이 생긴 이유
요구서 5절 N02(0-8-3 U3)는 US6557478식 자유 회전 진공 원판과 조향 서보(R375X 자동 회전)를 요구한다. v1.0.5에서는 U3_PLATE·U3_COLUMN·U3_DRIVE가 차지 상자뿐이었다. 구동 후보 DC-02(진공을 회전부 아래로 빼는 길)와 DC-06(옆 모터를 포함한 외곽)도 열려 있었다. v1.0.6 검도에서 진공 관이 지나갈 자리가 배치 때문에 없다는 동작 문제가 나왔고(mech_N02_verify.md), v1.0.7에서 고쳤다.

## 2. 구동 방식 전/후
- 전: U3는 상자 3개(원판 r60, 기둥 r50, 구동 □130)뿐이고 회전은 조인트 J_U3_ROT만 있었다.
- 후(선정 N02-C3 고친 안): 원판 Ø120을 S45C 축에 볼트로 잇는다. 축은 CRBH5013 크로스 롤러로 U4_Y의 판금 틀이 받친다. 조향은 AZM66AC-PS25(감속 25)가 −X 옆에서 S5M 벨트 20T→60T(×3)로 돌린다. 진공은 고정 씰 슬리브(O링 P25 ×2)에서 축 속 Ø8로 원판에 들어간다. 슬리브 옆 포트는 엘보 KQ2L06과 관 TU0604로 ZH10DSA 이젝터에 이어진다. 원판을 헤드 쪽으로 미는 힘은 미는 기구 부품을 따로 두지 않고 U4 X·Y 토크 제한 모드로 준다(N02-Q4).

## 6. 제어 순서 제약(U-09)
- N02-Q1: 회전 토크 제한은 원판 12 N·m 이하로 둔다. 진공이 매트를 잡는 토크 13.6보다 낮아서, 매트가 원판에서 미끄러지기 전에 서보가 먼저 놓친다.
- N02-Q2: 진공 스위치로 −60 kPa 이상을 확인하기 전에는 회전·X·Y 이동을 금지한다.
- N02-Q3: J_U3_ROT 소프트 리밋은 −90~360°다. REWIND 360→0은 진공을 끈 뒤에 한다.
- N02-Q4: 따라가기 중 원판 밀기는 U4 X·Y 토크 제한 모드로 (바늘 − 원판 중심) 방향 F_push(임시 20 N)를 준다.
- N02-Q5: 봉제 중에는 센서 비례 조향을 쓰고, 모서리·홈 바닥에서만 위치 모드로 바꾼다.
- 센서 자리: 진공 스위치(이젝터 쪽), J_U3_ROT 원점 센서(자리만, 전장은 기구 뒤).
