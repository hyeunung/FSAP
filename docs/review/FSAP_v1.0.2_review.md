# 설계검토서 FSAP v1.0.2 (변경분, 구동 N01, 2026-11-03)

## 1. 이 버전이 생긴 이유
요구서 5절 N01(U1 헤드 개조 + 좁은 홈 묶음). v1.0.1의 U1 차지 공간 상자를 Dürkopp 867-392342 공식 PDF 치수 임시 형상(STEP대기_, D-10)으로 바꾸고, 비어 있던 노루발 조인트(J_U1_PRESSER 0~20)에 노루발 바디를 넣었다. 좁은 U홈(폭 25·R12.5 임시, D-02·D-03)에서 묶음이 홈 안에 드는지와 홈 바닥 회전을 확인했다. 작은 변경이라 수 번호 +1(8-2).

## 2. 구동 방식 전/후
- 전(v1.0.1): U1은 상자(UPPER·BUNDLE X ±15·PRESSER_BOX·LOWER_POD). 홈 바닥 회전은 CYCLE_G1 478단계.
- 후(v1.0.2): 방안 N01-C3 수정안 — 매트 띠(Z 0~11)에는 바늘만 둔다. 홈 바닥은 땀마다 바늘 중심으로 피벗(10땀 × 18°, 처음·끝 반각 9°). 윗헤드는 U2_BOOM에 매달고(UPPER 윗면 = 붐 밑면 맞닿음) 아랫유닛(LOWER)은 작업면 밑에 분리. 바인더 방향은 867 그대로. 차순위 N01-C2(띠 안 동심 코 r ≤ 9), N01-C1 탈락(순수 +Y 이송에서 날개↔테이프 겹침 −0.11~−0.53).
