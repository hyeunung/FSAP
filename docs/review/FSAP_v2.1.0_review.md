# 설계검토서 — FSAP_v2.1.0 (M02 U4 바늘 옆 바퀴)

대상 `3D_Modeling/FSAP_v2.1.0.sc`(문서 이름 FSAP_v2.1.0, 105바디). BOM `docs/bom/FSAP_v2.1.0_made.csv`(가공품 15, M02 새 13)·`_purchased.csv`(구매품 12행, M02 새 9). 근거 보고서 `docs/reports/mechanism/mech_M02_design.md`·`_design1.md`·`_model.md`·`_verify.md`·`_fea.md`.

## 이 버전이 생긴 이유
요구서 5절 M02: R375X 사진 그대로 바늘 옆 바퀴(서보 + 감속기 + 고무 바퀴, 핀 스윙 암, 세로 공압 누름·들기, 밑 자유 회전 원판 Ø250)를 차지 상자에서 실제 구동 유닛으로 바꾸기 위해서다. 새 컴포넌트 U4_DISK·U4_CYL·U4_ROD가 생겨 가운데 +1·마지막 0(E-05 "새 컴포넌트(유닛·부품 묶음)가 생기거나 없어졌으면 가운데 +1·마지막 0").

## 구동 방식 전/후
- 전(v2.0.2): U4 차지 상자 6개(U4_MOUNT·HOLDER·DRIVE·WHEEL_TIRE·DISK·DISK_BRG), J_U4_PRESS 슬라이더 0~30.
- 후(v2.1.0): 서보 MHMF022L1U2M(200 W, 임시 형상) → 유성 감속기 VRXF □60 1/10(임시 형상) → 앞판 → 외팔 바퀴 Ø120×25(우레탄 A70 트레드, 중심 (−100, 0, 70)). 레버는 피벗 (−300, Z 70, 축 −Y)의 핀 스윙 암(바퀴까지 200), 실린더 CDM2C20-25Z가 로드 핀 (−160, 122)을 누름(위 핀 (−161.006, 325.72), 닫힌 고리). J_U4_PRESS 회전 −1.867~8.626°(+ = 들림, 들림 끝 = 실린더 후퇴 끝). 밑 자유 원판 Ø250(중심 X −175, 6004ZZ ×2, U2_PLATE 밑 받침판). 매트 유무 E32-D36P1은 바퀴 앞 −Y, 각도 조절 ±5°는 보 밑 원호 장공.
