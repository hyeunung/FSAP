# 설계검토서 FSAP_v0.6.2 (변경분) — 디테일링 DP-1 헤드 둘레

- 설계 파일: `3D_Modeling/FSAP_v0.6.2.sc`(이전 v0.6.1). 생성기 `tools/gen_dp1_detail.py` → `tools/out/detail/DP-1/build.json`(CLI `solidcraft-cli run --save`, MCP가 headless)
- 지시서: `docs/reports/detailing/detail_plan.md` DP-1. 모델링 보고서: `docs/reports/detailing/detail_DP-1_model.md`
- BOM: `docs/bom/FSAP_v0.6.2_made.csv`('가공법' 칸 신설)·`_purchased.csv`(같은 형번 한 행). 결정로그 DL-D01~D26
- STEP·도면은 완성본일 때 일괄(E-06, U-15). 이 검토서의 4·5절은 모델링부 자기 확인이며 검증부·해석부가 이어 채운다

## 1. 이 버전이 생긴 이유

디테일링(E-02 ③) 첫 묶음. T06 칼 팔이 판금으로는 M-04 구멍–굽힘 2t와 오조작 SF 2를 함께 맞출 수 없어 절삭 L로 바꾸고(U-05 근거 BOM '가공법'), 그동안 구멍만 있던 T06 체결 자리에 볼트·너트를 넣었다. 노루발은 출력 재질로 오조작 SF가 모자라 A6061-T6로 바꿨다.

## 4. 동작 검증 (모델링부 자기 확인)

모델링 보고서 5·6절. 요약: 8개 동작 연구 truncated false, 바뀐·새 부품의 새 겹침 0(v0.6.1과 같은 쌍·같은 깊이, 새 쌍은 볼트 나사 물림). 볼트 프로브 9개 겹침 0, 팔 ↔ 헤드 1.0, 팔 ↔ 브래킷 14.0.

## 5. 강도·해석

해석 환경 없음(D-16) — 손계산. 팔: 오조작 T SF 2.29, 칼 막힘 4.64, 운전 10.23, 맞날 틈 0.053(해석부 `detail_handcalc.py` 같은 식, 형상이 입력과 같음). 축–팔 핀 전단 SF 2.3(핀 형번 D-43). 노루발 A6061-T6 오조작 SF 약 5.2. 해석용 임시 STEP `tools/out/detail/DP-1/stepout/`.
