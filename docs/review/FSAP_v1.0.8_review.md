# FSAP v1.0.8 설계검토서 — 구동 N03 U4 X·Y 따라가기 받침

요약
- 저장본 `3D_Modeling/FSAP_v1.0.8.sc`(바디 111). v1.0.7의 U4 레일 상자 2개를 지우고 X·Y 벨트 서보 십자 받침(선정 N03-C1 고친 안)을 그렸다.
- 최종 판정 pass, 동작 문제 0. 디테일 10건(7절). 예외 판정 0건.
- 완료 판정 3항목을 모두 만족했다. 행정 X 1417.5 ⊇ 310.7, Y 1510 ⊇ 1500(0-8-5). 과제 범위 5자세에서 간섭 0. 따라가기 저항 79.2 N ≤ 100 N(D-79 임시).
- STEP 대기 7형번(D-87). 해석 못 함 — 환경 없음(D-16), 손계산으로 함.

## 1. 이 버전이 생긴 이유
요구서 5절 N03(0-8-3 U4)은 US5367966식 받침(자유)과 직선 X·Y 이동을 요구한다. 봉제 중에는 따라가기, 모서리에서는 위치 모드다. v1.0.7까지 U4는 차지 상자(U4_RAIL_A·B, U4_X_BEAM, U4_Y_CARR)뿐이었다. 또 Y 1200 끝에서 U4_Y_CARR와 U5_POST_1·2가 48,750 mm³ 겹쳤다.

## 2. 구동 방식 전/후
- 전: 레일 상자 2개(X −1400~500·Z −380~−340), 보 상자(Z −340~−260), 조인트 J_U4_X −200~1250·J_U4_Y −400~1200만 있었다.
- 후(N03-C1 고친 안, 결정로그 N03-S01~S08): 고정 X 레일 SV2RL28-1800 ×2(U2_BASE 위) → A5052 리브 보 U4_X_BEAM(Z −352~−288) → Y 레일 SV2RL28-1800 ×2 → U4_Y_CARR → N02 원판. X는 MHMF082(750 W)가 S5M 25폭 오픈 벨트(28T 풀리)로, Y는 보에 실린 MHMF042(400 W)가 S5M 15폭 오픈 벨트(25T)로 끈다. U5_POST 밑을 −288로 내려 높이 사슬을 맞췄다(N03-S03).

## 4. 동작 검증(작업 대상 포함)
- 과제 범위(E-17): 새·바뀐 35바디와 주변 83바디(매트 3장·테이프 2 포함)를 J_U4_X·J_U4_Y 0·25·50·75·100 % 대각 5자세와 J_U3_ROT 45·90°에서 clearance 3으로 검사했다. 겹침 0, truncated false. 가장 좁은 틈은 0.08(X 물림판↔X 벨트)이다.
- 스윕: J_U4_X −200→1217.5 stopped_at null(최소 5.5), J_U4_Y −355→1155 stopped_at null(최소 5.0, 원판↔테이블 홈 끝).

- 매트: 받침은 매트에 닿지 않는다. 매트 눌림은 모델로 판정하지 않는다(요구서 7절).

## 5. 강도
해석 못 함 — 환경 없음(D-16). 손계산 `fea/cases/mech_N03_handcalc.py` → `fea/results/mech_N03_handcalc.json`(새 하중 부품 8개).
- 따라가기 저항: X 73.3 N(요 반력 굴림 마찰 11.9 포함), Y 29.9 N, 벡터 79.2 N ≤ 100 N(D-79 임시).
- 보 운전 29.0 MPa SF 6.0, 처짐 1.11 mm(D-08 한도 미정 → N03-D1).
- SF 미달은 디테일로 기록했다: 모터 L 판 소켓 띠 SF 1.6, X 물림 세움판 2.00/1.51, X 블록 볼트 미끄럼 0.87/0.66, 아이들러 축 Ø8 2.59, Y 물림 조임 6 N·m 0.92. 동작 문제(SF < 1.2로 움직임이 막히는 것)는 없다.

## 6. 제어 순서 제약(U-09)
- N03-Q1: J_U4_Y는 소프트 −350~1150, 하드(리밋·스토퍼) −355·1155로 둔다. J_U4_X는 소프트 −160.7~1212.5, 하드 −200·1217.5로 둔다.
- N03-Q2: xy_forbidden 두 띠(DC-05-S04, DC-05-D1)를 소프트 리밋 지도로 쓴다.
- N03-Q3: 봉제 중 X·Y는 토크 모드로 둔다(마찰 보상 + 헤드 쪽 20 N, N02-Q4). 노루발 들림을 확인하기 전에는 위치 모드로 바꾸지 않는다. 위치 모드는 모서리에서만 쓴다.
- N03-Q4: 모서리 가속은 1.53 m/s² 이하로 둔다(X 토크 SF 1.26). 더 빨라야 하면 X 1:2 감속 또는 1 kW 서보(D-12).
- 센서 자리: X·Y 원점·리밋 센서, 스토퍼(N03-D2). 케이블 베어 자리는 DC-03.
