# 설계검토서 FSAP v2.28.0 — 구동 후보 RX-DC-01 두께별 바인더 키트(변경분)

요약: 바인더 입 높이가 매트 두께 10에 고정돼 있던 것을 두께별 키트 T06·T10·T16으로 바꿔 끼우게 했다. 입 높이 실측은 8.5·12.5·18.5다. THICK_6·THICK_16 상태에 두께 6·16 매트 모형을 넣어 겹침 0을 확인했다. 키트 치수는 모두 임시값이다(D-211·D-04·D-10·D-214).

## 1. 이 버전이 생긴 이유
구동 후보 점검(mech_drive_check.md 3-1)에서 `STEP대기_BINDER_30_RX14`의 입 높이 12.5가 두께 10에 고정돼 있었다. 두께 임시 범위 6~16(D-04)이면 입 높이는 8.5~18.5가 필요하다. 그대로 두면 두께 16에서 윗입술이 매트 윗면보다 3.5 낮고, 두께 6에서는 4.0이 헐겁다. 또 THICK_6·16 상태가 매트 모형 두께를 바꾸지 않아서 회귀 검사가 이 문제를 잡지 못했다.
