# FSAP v0.10.0 설계검토서 — 구동 T19 (바닥틀 다리·조절발)

문서 담당, 2026-11-02(엔진 v3.4.0). 대상 `3D_Modeling/FSAP_v0.10.0.sc`(이전 v0.9.1). BOM `docs/bom/FSAP_v0.10.0_made.csv`·`FSAP_v0.10.0_purchased.csv`. 근거 보고서 `docs/reports/mechanism/mech_T19_select.md`·`_model.md`·`_verify.md`·`_fea.md`.

**요약**
- 새 바디 106(컴포넌트 `T19`, BASE에 리지드): 다리 `STEP대기_HFS8-4080-138` 8, HBLFSN8 18, 받침판 `P_T19_FOOT_*` SUS304 t16 8, 조절발 `STEP대기_ADJM16-66` 8, HNTT8-8 28, `STEP대기_CB8-16` 28, `STEP대기_CB8-25` 8. 지운 부품 0, 새 구동 조인트 0.
- 작업 높이 900(D-39 임시): 바닥 Z −900 → 형재 밑면 −680. 레일 두 줄 높이 차 0.126 < 0.201 mm(D-17 임시).
- 강도 손계산 최소 SF: 동하중 1.5 기준 3.19, 자중 ×3 g 기준 1.60(조절발 정격 10 kN 임시, 디테일). FEA 못 함 — 환경 없음(D-16).
- 과제 범위 간섭 0(의도된 나사 물림만). 판정 합격, 동작 문제 0.
- **T19는 '일부'**: 렌치 결함 18(HBLFSN8 구멍 20/30 고유). 예외 판정 2건 모두 기각 → 구동 후보 **T19-K1** 판금 L 브래킷 교체를 다음 구동 라운드에서.

## 1. 이 버전이 생긴 이유

v0.9.1까지 형재 밑면 Z −680 아래에 바디가 없었다. 다리·조절발이 없어 바닥 위 높이와 레일 수평을 맞출 길이 없었다(T07-S04, D-39). T18이 가로 이음을 넣은 뒤 남은 구동 후보다. 부품 묶음 신설이라 부 번호를 올렸다(T19-M01, 요구서 8-2).

## 2. 구동 방식 전/후

- 전: 바닥틀(1900_F·_B, 580_T1/T2)이 공중에 떠 있었고, 받침·높이 조정이 없었다.
- 후: 다리 8개(모서리 4, 가운데 2, 꼬리 2)를 둔다. 다리마다 HFS8-4080-138, 위아래 HBLFSN8, SUS304 t16 받침판, M16 레벨링 마운트로 짠다. 높이 조정은 ±15다. 고른 안은 T19-C1이다(T19-S01). C2는 작업 높이 720으로 묶이고, C3는 높이 차가 0.711이라 뺐다.

## 4. 동작 검증 (E-03, 작업 대상 포함)

- 과제 범위: 새 106 바디와 모델 전체를 `inspect.clearance`로 쟀다. 겹침 16쌍은 모두 의도된 나사 물림이다(CB8-25↔판 탭 8, M16↔판 탭 8). 그 밖의 겹침은 0이고, truncated false다.
- 이동부: 새 부품의 가장 높은 곳은 Z −678이고 이동부의 가장 낮은 곳은 −594.5다. 정적이라 모든 자세에서 같다. 매트·테이프 경로는 Z 0 위라 영향이 없다.
- 저장본을 다시 읽어 594바디의 bbox·부피 차이 0을 확인했다. 바꾸지 않은 488바디도 차이 0이다. 숨김 0, 재질 Default 0.
- 레일 F·B 윗면은 Z −584.5로 같다. 높이 차 손계산은 0.126 mm다.

## 5. 강도 (E-18, 손계산)

`fea/cases/mech_T19_model_handcalc.py`(동하중 1.5)와 `fea/cases/mech_T19_fea_handcalc.py`(자중 ×3 g)로 계산했다. 가장 큰 반력은 B_MID에서 3,134 N(1.5)과 6,268 N(3 g)이다. 최소 SF는 조절발로 3.19와 1.60이다. 1.60은 1.2 이상이라 동작 문제가 아니다. 다만 과제 기준 2에 못 미쳐 디테일로 올렸다. 형번을 정할 때 정격 ≥ 12.6 kN인 것을 고른다(D-75). FEA는 못 했다. 환경이 없다(D-16).

## 6. 제어 순서 제약 (U-09)

정적 부품이라 제어 순서 제약은 없다. 조립·설치 순서는 다음과 같다.
1. 모서리 4개(F_XM·F_XP·B_XM·B_XP)로 레일 윗면 수평과 두 줄 높이를 맞춘다.
2. 가운데 F_MID·B_MID를 닿게 한 뒤 1/4바퀴 더 돌린다.
3. 헤드를 얹은 뒤 꼬리 T1·T2를 닿게 한다.
4. 잠금 너트를 조인다.
