# 설계검토서 FSAP_v0.4.1 (변경분) — 구동 T05 테이프 공급·장력 유닛

**요약**
- 새 부품 묶음: `HEAD` 아래 `T05`(평판·홀더·축·허브·캡·안내 블록·실린더 튜브), `T05_PAD`(패드·로드, 조인트 `J_T05_PAD`), 작업 대상 외피 `T05_TAPE`(롤·테이프 길, BOM 밖). v0.4.0에서 신설, v0.4.1(수정 1회차)에서 평판 t3 → t5.
- 판정: **pass**(동작 문제 0). 테이프 경로 ↔ 매트·헤드 간섭 0 — `motion.interference` 8개 연구 2,518단계 모두 clear(truncated false), 단계별 바디 단위 겹침 0·15 mm 안 0.
- 강도: 해석 못 함 — 환경 없음(D-16). 손계산 평판 혀 오조작 SF 2.19·2.26(기준 2), 운전 SF 28.8. v0.4.0 동작 문제(SF 0.80·0.81)는 수정 1회차로 해결.
- 미완: 구매품 STEP 대기 `STEP대기_PSFJ16-100`·`STEP대기_CJ2B10-15`(D-33·D-34, 미스미 로그인 풀림), 볼트·인서트 안 그림, 디테일 과제 8건, 테이프 사양 D-06 임시값.

## 1. 이 버전이 생긴 이유

요구서 5절 T05 "테이프 롤에서 바인더까지 공급, 오목·볼록에서 장력을 바꿀 수 있는 구동." 완료 판정 "테이프 경로가 매트 회전 전 구간에서 매트·헤드와 간섭 0. 테이프 폭 D-06." v0.3.2에는 테이프 롤·장력 장치·공급 구동기·테이프 길 바디가 0개였다(측정 `mech_T05_measure.md`). 선정(T05-S01~S08)에서 C2 수정안 "봉제가 끌어가는 롤 + 둥근 실린더 1개 마찰 패드"를 골랐다(차순위 C1 스테핑 정량 + 댄서, C3 탈락).

- v0.4.0: 부품 묶음 신설 → 가운데 자리 +1(요구서 8-2, E-05). 커밋 438e664.
- v0.4.1: 해석부가 평판 혀 오조작 SF 0.80·0.81(< 1.2, 영구 변형 = 동작 문제)을 냄 → 수정 1회차로 평판 t3 → t5. 형상 변경 → 끝자리 +1. 커밋 3354984.

### 8-3. 그 밖

- 고체 FEA 못 함(D-16). 손계산은 보수 쪽 근사. 평판 혀 오조작A SF 2.19는 기준 +10% 안이라 환경이 생기면 `tools/out/mech_T05/stepout1/P_T05_PLATE.step`으로 확인.
