# 설계검토서 FSAP v2.14.0 (변경분) — 구동 M02R U4 그네 잔재 정리

요약: v2.13.0(RX-07 레귤레이터 3개, 검토서 없음) → v2.14.0(M02R 4회차). 구동 방식·조인트·행정 변화 0. 스프링 탭 볼트 4개를 s±12로 옮겨 윗고리–볼트 머리 겹침을 풀고(틈 1.75·2.75 mm), 옛 크랭크 U4 빈 컴포넌트 22개를 지우고(floating 0), 팔 3바디의 빗나간 메움·탭을 제자리로 고쳤다(셸 1·1·1). 최종 판정 pass(완료 판정 ①~⑤ 만족, 동작 문제 0), 디테일 10, 예외 요청 3건(같은 건) 기각. BOM `docs/bom/FSAP_v2.14.0_*.csv`.

## 1. 이 버전이 생긴 이유
- 요구서 5절 M02R이 '일부(v2.10.3) — 남은 동작 문제 2'였다. 예외 판정 M02R-E03이 "빈 컴포넌트 21개 … 다른 과제로 미루지도 않는다. M02R 수정 회차에서 지운다"고 정했는데 RX-06·RX-08·RX-07이 고치지 않아 v2.13.0에 그대로 있었다.
- ① `STEP대기_AUT12-45_1·_2_TOP` 윗고리가 탭 볼트 `CB5-12_M02S_BASE_5~8` 머리와 겹침(검도 최소 거리 0). ② 옛 크랭크 U4 빈 컴포넌트 21개(바디 0), 2묶음 floating(RX-08-D4). ③ 구동 후보 RX-06-C1: `P_M02_ARM_SIDE_N·_P·ARM_TIE`에 떨어진 조각 5건('joined piece doesn't touch').
- 번호: 컴포넌트 22개가 없어져 E-05 "이번 저장에서 새 컴포넌트(유닛·부품 묶음)가 생기거나 없어졌으면 가운데 +1·마지막 0"대로 v2.14.0. v2.13.0은 RX-07 형상이 든 저장본이라 덮어쓰지 않았다(실행 규칙 3).
