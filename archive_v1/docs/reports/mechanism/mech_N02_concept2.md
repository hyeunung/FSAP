## 2. 왜 이 모양인가(벤치마크 그대로가 안 되는 곳만)
### 2-1 뒤집어 다는 이유 — 세로 자리(측정 2-1)
| 배치 | 필요 높이 | 자리 | 판정 |
|---|---|---|---|
| DGM130R 바로(출력 위, 모터 아래) 아래 띠 | 하우징 50 + 모터 90 = 140(임시) | −230~−130 = 100, 그 밑은 U4_Y_CARR(−260~−230)·U4_X_BEAM(상대 X −150~140) | 안 됨(모터가 받침·X 보로) |
| 같은 것, 하우징을 위 띠로 | 하우징 □130 반폭 65 | 위 띠 +X는 LOWER 상대 X 70 → 틈 5(측정 PD) | 틈 10 못 맞춤 |
| DGM200R-AZAC(STEP 있음) 바로 | 64 + 114 | 같은 아래 띠 | 안 됨(측정 PA, U5_TABLE 120,000 mm³) |
| DGM200R 뒤집음 | 모터 114가 위로 → 윗면 −160+114 = −46 | 테이블 밑면 −40 | 틈 6 < 10, 하우징 반폭 100+모터 쪽 137.5 → 무거움·비쌈(4,020,380원) |
| DGM85R | 토크 2.5 N·m < 6.75 | — | 안 됨(M-06) |
| **DGM130R 뒤집음(이 안)** | 링 20 + 하우징 50 = 70 아래 띠, 모터 90은 −X 위 띠 | 아래 띠 반폭 ≤ 140, 위 띠 −X는 LOWER에서 110 | **됨**(3절) |
- 다른 방법(옆 모터 + 벨트 + CRBH7013 + 축받침)은 부품이 풀리 2·벨트·베어링·하우징으로 5개 이상 늘어 이 방향(부품 최소)에 안 맞는다.

### 2-2 베어링 따로 없음
DGII는 출력 테이블에 크로스 롤러 베어링이 들어 있다(catalog.md 메모). 원판 하중(진공 흡착력·옆 끌림)을 출력 테이블이 받는다 → CRBH7013 생략. 하중 4절.

### 2-3 원판 미는 장치 = U4 서보
US6557478은 헤드 테이블이 돌고 원판을 직선 액추에이터로 헤드 쪽으로 민다. 우리는 헤드 고정(C-01)이고 원판 밑에 이미 X·Y 서보 받침(U4)이 있으며 0-8-1이 "필요하면 서보가 보조"라 정했다. 같은 일(원판 중심 → 바늘 방향 힘)을 U4 두 축의 힘 한계 바이어스로 하면 직선 액추에이터·안내·브래킷 3개 이상이 빠진다. 방향 벡터는 원판 중심에서 바늘(0,0)로, 매 땀 갱신(제어 단계 U-09).

## 6. 디테일로 기록만(E-02, 수정 회차 안 씀)
- 원판–축 고정: 허브 분할 클램프(M4) 또는 키 4×4. 원판 윗면에 볼트 머리 안 냄(매트 뒷면).
- 하우징 고정: 하우징 모서리 통과 구멍 → 링 → 받침 탭(M6 ×4 임시). 뒤집어 달 때 볼트 렌치 접근은 위(모터 쪽)에서 — 모터 □60이 −X 모서리 두 개와 가까움(모서리 (−55, ±55) ↔ 모터 Y ±30: 25 틈) → 디테일에서 확인.
- 슬리브 고정 볼트는 하우징 윗면(모터 붙는 면) 중공 둘레 탭 유무 미확인(D-80).
- 진공 관·모터 선은 U4_Y 쪽 고정이라 회전 꼬임 없음, U4 케이블 길은 N03.

## 7. 위험
1. DGM130R 외형이 모두 임시: 하우징 높이 50, 모터 □60×90, 모터 축 거리 70, 중공 Ø29. 모터 ≤ 110·중공 ≥ Ø29면 그대로, 중공이 작으면 축을 Ø20 이하로(굽힘 SF 여전히 > 5).
2. 뒤집어 달기 허용·그 방향 허용 추력(진공 흡착 679~1,018 N이 출력 테이블을 떼는 방향): 카탈로그 확인 필요.
3. 허용 관성(표 기억값 0.03 kg·m²)이 큰 매트 4.5 kg·m²보다 훨씬 작음 — 사실이면 DGM200R(약 1.0)로도 모자라 개념(조향 서보로 큰 매트를 직접 돌림)의 크기 문제가 된다. 지금은 따라가기 모드라 서보는 보정만 한다는 0-8-1 안이라 판정 보류, D-80에 '허용 관성 실측' 추가.
4. O링 회전 실 수명·누설(시제품 7절).
5. U4 서보 바이어스로 미는 힘 크기는 시제품(7절).
