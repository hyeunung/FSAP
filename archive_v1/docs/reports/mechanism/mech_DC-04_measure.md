# DC-04 측정 — 정비 면·카세트 인출·가마 꺼내는 길 (v1.0.4)

## 요약
- 대상 `3D_Modeling/FSAP_v1.0.4.sc`(문서 이름 FSAP_v1.0.4, 해시 32b40c1d4c2c4913, 바디 39). sigcheck **reuse** → 부품 bbox·부피는 `tools/out/signatures.json` 그대로, 새로 잰 것은 통로 프로브 6개뿐.
- 바뀐 부품: 없음(읽기만). 구매품 실물 0 — 과제 영역엔 `STEP대기_867-392342_UPPER/NOSE/LOWER`, `STEP대기_MHMF042L1U2M`만 있다.
- **통로는 이미 비어 있다.** 대기(0,0,0)와 J_U4_X −200에서 프로브 6개 모두 겹침 0이다. 카세트 +X 미끄럼 길 X 11.5~522·Y −45~−21·Z 13~124, 들어 빼는 길 X 500.5~522·Z 124.5~559.5, 가마 길 X 30.5~975·Y ±45·Z −59.5~−0.5, +X 서는 자리 X 975.5~1575를 쟀다.
- **손 닿는 거리는 안 된다.** +X 바닥틀 끝(X 975)에서 카세트 손잡이(X 11)까지 964, 가마 앞(X 30)까지 945, 바늘까지 975이다. 임시 기준 600(자료대기 새 번호 제안 D-82)을 넘는다.
- 카세트 +X 인출 안내 부품이 아직 없다. 지금은 상자뿐이고 위 틈은 1이다.
- 운전 끝 자세(J_U4_X 1250)에서는 테이블이 +X 서는 자리와 13,178,400 mm³ 겹친다. Y 400을 더하면 원판(U3_PLATE·COLUMN)이 가마 길과 최대 336,402 mm³ 겹친다. 그래서 정비는 **정비 자세(J_U4_X ≤ 0 쪽, 아래 2-3)** 에서만 한다.
- **already_ok = false.** 간섭 조건(정비 자세)은 만족한다. 손 닿는 거리 기준은 없어서 새 번호가 필요하고, 임시 기준으로 재면 넘는다. 인출 안내도 없다.
- 미완: 손 닿는 거리 기준(D-82 제안)은 자료대기에 아직 적지 않았다. 측정부는 문서를 쓰지 않으니 구상·선정부가 올린다. 실제 가마 꺼내는 방향(867 공식 정비 절차)은 D-10을 기다린다.

### 2-5. 구상이 쓸 수치(풀어야 할 것)
- **카세트**
  - +X 미끄럼 안내를 Y −45~−21, Z 13~124 띠에 둔다. 위 1, 옆 U6 1.8, NOSE 1.0 틈 안이다.
  - 행정 ≥ 511(X 11 → 522)이면 UPPER 밖으로 나와 위로 들어 뺄 수 있다. BOOM 밑 559.5까지 435다.
  - 손잡이·원터치 풀림을 안내 +X 끝(X ≥ 375)에 두면 600 기준을 맞춘다.
  - 안내 레일 자리는 Z 13 아래(매트 띠 Z 0~11, N01-S01 'Z ≥ 12')를 쓰지 못한다. 위(UPPER 밑면 125)나 옆 Y −21~−10(NOSE까지)·Y −46~−45를 쓴다.
- **가마**
  - 길은 X 30.5~975, Y ±45, Z −59.5~−0.5로 비어 있다.
  - 하지만 가마는 X ≈ 0 근처 867 아랫유닛 속이라 손 닿는 거리 945다. 방법은 셋이다.
    - (a) 가마를 꺼내 담는 +X 인출 받침(서랍)을 두고, 손잡이를 X ≥ 375에 둔다.
    - (b) 긴 공구를 쓴다. 근거로 기록만 남긴다.
    - (c) 위(바늘판)로 꺼낸다. 위 창은 Z 0~125, 정비 자세 테이블 끝 X 10이다.
  - 셋 다 867 실물 정비 절차(D-10)를 확인해야 한다.
- **운전 중 막힘**: J_X ≥ 810.5이고 Y 295~505일 때 원판이 가마 길에 든다. J_X ≥ 765일 때 테이블이 서는 자리에 든다. 정비는 정비 자세에서만 하고, 인터록은 U-09 제어 순서 제약으로 넘긴다.

- `edit.checkpoint`가 batch 첫 단계에서 id 256을 돌려줬다. 그런데 뒤 batch의 `edit.restore_checkpoint {checkpoint:256}`은 "no checkpoint 256"으로 실패했다. batch 사이에서 체크포인트가 남지 않는 것 같다. undo로 원복했고 바디 39·dirty false를 확인했다. 안내서 '원복'에 "체크포인트는 같은 batch 안에서 restore"를 더하면 좋겠다.
- 손 닿는 거리 기준이 엔진 규칙(L2)과 요구서에 없다. 공구 접근 과제가 나올 때마다 임시값을 새로 만든다.
