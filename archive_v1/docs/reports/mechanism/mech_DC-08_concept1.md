## 4. 계산 근거 (측정 4절 값 그대로 다시 셈)

- 굽힘 시작 Z = −287 + R = −287 + 150 = −137 ≤ 니플 끝 −85 → 곧은 구간 −85 → −137 = 52(밴드 끝 −75에서 62). 최대 R: −287 + R ≤ −45(판 밑 플랜지) → R ≤ 242, 측정 기준(−55) R ≤ 232. R150 여유 82.
- 수직→+X 굽힘 X 거리: −1030 − (−1180) = 150 = R(완료 판정 "≥ R" 만족), 첫 링크까지 190.
- 브래킷 면 X −1030에서 호스 위 면 = −137 − 127 = −264 = 베어 안 윗면(여유 0, 수평 진입). 브래킷 안에서는 곧게라 넘지 않는다. 첫 링크까지 굽히는 안(−1140)은 위 면이 −257.5로 안 윗면을 6.5 넘으므로 버림(측정 4절).
- 굽힘 바깥 최저 Z −310: 홈통 벽 Y 1086~1088·1485~1487과 Y로 32 이상 떨어짐, 홈통 바닥 −380까지 70, 베어 안 아래 −364 위. X < X_e 쪽은 베어 링크가 없다(움직이는 끝 뒤, 측정 3절).
- 행정 쓸기: 기둥 −X 끝 J −200에서 −1403. 고정 부품 W_ABOVE(X −1410~257.5, Z −250~−55) 겹침 0, 홈통까지 112.6. 플랜지 φ70은 Z −45~−40으로 판 밑면과만 맞닿음, 가장 가까운 STORE_P(−970)까지 −1145 → 175. 판 기둥 HFS8-4080-248_1(Y 900~980)까지 Y 128.

### 하중 손계산(새로 만든 P_N04_INLET만, E-18 최소 단면 = 니플 관 OD38/ID34)

- 하중(임시, E-12): 호스 무게 ID38 PVC 약 0.4 kg/m × 곧은 0.09 + 굽힘 π/2 × 0.15 = 0.33 m → 1.3 N. 호스 펴짐 반력은 끝 브래킷 고정판이 받으나 보수로 니플 끝에 옆힘 10 N, 팔 40 → M = 0.4 N·m. 송풍 내압 ≤ 0.05 MPa(카탈로그 표 1절 가정).
- 니플 굽힘: I = π/64 (38⁴ − 34⁴) = 36,757 mm⁴, Z = I/19 = 1,935 mm³, σ = 400/1,935 = 0.21 MPa. 내압 후프 σ = pD/2t = 0.05 × 34 / 4 = 0.43 MPa. PA12 인장 약 45 MPa(SLS 일반값, 임시) → SF > 60. 처짐 δ = FL³/3EI = 10 × 40³ / (3 × 1,500 × 36,757) = 0.004 mm.
- 플랜지 접착면(환 φ70/φ46, 2,187 mm²): 내압 밀어냄 F = 0.05 × π/4 × 38² = 57 N → 0.026 MPa, 굽힘 M 0.4 N·m → σ = M/Z_환 = 400/27,394 = 0.015 MPa. 에폭시 판정 5 MPa(임시) → SF > 100. 판 표피 1 mm(D-89)에 나사를 내지 않는다(작업면 윗면을 건드리지 않음).
- FEA: 해석 못 함 — 환경 없음(자료대기 D-16). 체결·형상이 단순한 관이라 손계산으로 충분(E-18).

## 8. 위험

- 브래킷 면 X_e = x_m − 40은 띠 −X 끝에서 읽은 값(D-88). 받은 STEP으로 끝 브래킷 길이가 40보다 길면 굽힘 끝을 맞추려 기둥을 더 −X로(최대 R 232까지 여유), 짧으면 그대로 됨.
- 호스 위 면과 베어 안 윗면 여유 0(DC-03-D6과 같음, 디테일 기록). 호스 실물 OD가 46을 넘으면 베어 안에서 닿음 — 형번 확정 때 다시 본다.
- 니플 ID34로 유로 면적 −20 %(38² → 34²): 짧은 40 구간이라 압력 손실은 작다고 봄, 송풍량 판정은 N04 자료대기(D-89).
- 호스 바디가 없어 간섭은 계산 판정(측정 3절). 베어 실물 바디로 바꾸면 링크 대 굽힘 자리를 다시 본다.
