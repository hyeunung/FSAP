요약
- 대상(새로 만들거나 옮긴 것만): `P_N04_CHAIN_NP_BAR` +X 끝, `P_N04_CHAIN_PN_BAR` 러그, `P_N04_PANEL` 이 NP·이 PN. 막대 몸(140×10×t3)·PIN_3/4는 하중 경로가 그대로라 다시 풀지 않음(E-18).
- 방법: 손계산(`fea/cases/mech_regfix_handcalc.py` → `fea/results/mech_regfix_handcalc.json`). FEA는 **해석 못 함 — 환경 없음(자료대기 D-16)**. 이 덩어리 1~2 mm 크기의 맞닿음이라 보·지압 손계산으로 충분하다.
- 하중: 정하중 스프링 운전 20 N(D-89 임시), 오조작 100 N(사슬을 손으로 당김, `mech_N04_fea.md` 하중표).
- 결과: 가장 약한 곳은 **PN 러그 목**(몸과 겹침 X 0.5 × Y 9), 오조작 SF 2.58(기준 2), 운전 SF 12.9(기준 3). 지압 NP 오조작 SF 3.30, PN 4.95. 부러짐·영구 변형(SF < 1.2) 0 → 완료 판정 M-09 만족.
- 동작 문제 0, 새 디테일 2(이를 허니컴 판에 붙일 수 없음, PN 러그 목 여유 작음 — N04-D13에 묶어 기록). 과사양은 1~2 mm 이라 줄일 것 없음(note).
- 해석 모델: `fea/models.json` `P_N04_CHAIN_BAR`를 홈 멈춤 → 이 멈춤으로 바꿈(형상이 바뀌었으므로). 옛 홈 형상은 피처를 꺼서 같은 형상으로 다시 풀 수 없다 — 옛 값은 `mech_N04_fea2_handcalc.json` bar_lug_allow_N(NP 165 N, PN 110 N, 오조작 SF 2)이고 이번 NP 165 N·PN 지배 129 N과 같은 크기다.
