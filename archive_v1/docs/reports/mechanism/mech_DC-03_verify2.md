## 1. 지난 문제 확인
지난 문제(v1.0.10): 옆판 2장이 Z −230에서 끝났다. 그래서 볼트 조임 끝 Z −239까지 9 mm 구간에 웹(60×3)만 남았고, 이 띠가 다리 모멘트 26.9 N·m를 받아 오조작 때 영구 변형된다(SF 0.69).

| 확인 | 값 |
|---|---|
| 부피 | 69,720.3 → 72,240.3 mm³ (+2,520 = 15×3×28×2, 옆판 2장을 Z −258까지 늘린 양과 같다) |
| bbox | Z 최소 −258.0004(다리 아래 끝). 0.4 µm 어긋남은 커널 boolean 재시도에서 생겼고 제작과 관계없다(모델링 보고) |
| 면 | 49(평면 42, 원통 6). 옆판과 다리가 한 바디로 이어졌다(closed true, shell 1) |
| 강도(M-09, 손계산) | 다리 전 높이가 ㄷ 단면(Z 495 mm³)이다 → 오조작 SF 3.77, 운전 3 g SF 20.0(모델링부 손계산 안 A2, 단면 치수는 실측과 맞음). FEA는 못 했다 — 환경 없음(D-16) |
| 결론 | 문제는 없어졌다 |

- 새로 넣은 볼트와 옮긴 볼트는 0이다. 그래서 M-01은 해당 없음이다. 참고로 CB5-12_DC03YM ×2는 다음과 같다.
