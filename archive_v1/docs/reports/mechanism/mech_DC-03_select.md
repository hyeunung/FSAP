# DC-03 방안 선정 — X·Y 케이블 베어 자리 (FSAP_v1.0.8 기준)

## 요약
- **선정: DC-03-C3 고친 안(DC-03-S)** — X는 igus E4.56.10.150.0을 바닥틀 위 판금 홈통에 눕힌 고리(XY면, 고정점 행정 가운데), Y는 igus 2400.05.075.0 세운 고리(YZ면, +Y 끝 고정)를 보 −X 옆 판금 홈통(걸이 탭 일체)에 둔다. **차순위: DC-03-C1**(같은 배치, 홈통 받침 귀를 따로 둔 안). DC-03-C2는 기각(X 세운 고리 높이 여유 1 mm).
- 고친 것 5가지: ① M8·M6 → M5(CB5-12, U-12) ② A5052·SPCC → SUS304(요구서 2-1) ③ UHMW 띠 뺌(형번 없는 추정 바디, E-10) ④ Y 움직이는 끝을 P_N02_MBKT(SPCC t4, 탭 물림 4 < 1.5d)에서 U4_Y_CARR −X 면으로 옮김(M-01) ⑤ X 홈통 바닥 볼트를 베어가 쓸지 않는 자리로.
- 새 부품: 구매 2(STEP대기_ 2), 판금 4(P_DC03_XTROUGH·XMOV·YTRAY·YMOV), CB5-12 ×14. 지울 부품 0. 새 조인트 0(기존 J_U4_X·J_U4_Y에 묶기만).
- **CAD 확인(MCP, 읽기만)**: 새 부품 자리 프로브 6종 × 8자세(J_U4_X 0·25·50·75·100 %, J_U4_Y 양 끝·중간) — 모델과 겹침 **0**, truncated false. 최소 틈 X 레일 6.36, MBKT 10.0, YMBKT 11.0, 테이블 5.0.
- 굽힘: X R150 ≥ 서보 케이블 7.5d 75·호스 Ø50 R150(임시, 여유 0), Y R75 ≥ 7.5·Ø8 60·TU0604 R15. 모두 임시값으로 합격(D-88 후보).
- 따라가기 저항 89.8 N(μ 0.15)~94.9 N(μ 0.3) ≤ 100 N(D-79 임시, 구상 3 손계산). FEA 못 함 — 환경 없음(D-16).
- 미완: 베어 형번·외형·STEP 전부 임시(미스미 로그인 풀림), 베어 끝 브래킷 체결 볼트·너트는 실물 STEP 구멍으로(디테일), 송풍 호스 지름은 N04.

## 3. 선정 이유
- 세 안 모두 X·Y 통로(측정 PX2·PY1) 안에 들고, 가격이 모두 미확인이라 M-10 단서대로 부품 수·조립성으로 고른다.
- C3 배치(눕힌 X + 세운 Y, Y 홈통·걸이 탭 한 장)가 부품이 가장 적다: 판금 4장, 볼트 14(C1은 판금 6·볼트 26·너트 14). 가공(밀링) 0.
- X 베어 외폭 128(C3) < 178(C1): 칸 Y 1080~1545 안 여유가 크고 질량·가격이 준다. 채움 40 %로 Ø50 호스 + 케이블이 든다(구상 3).
- C2는 X 세운 고리가 칸 높이를 1 mm만 남겨(같은 56급 외고 84 기준) "된다"고 말할 수 없다(U-04).

## 워크플로우 메모
- `inspect.clearance`에 `bodies`만 주면 그 목록 안 쌍만 잰다(첫 batch에서 상대 0으로 나옴). 프로브 검사에는 `against`에 모델 바디 이름 목록을 꼭 넣어야 한다 — 안내서 '간섭'에 한 줄 있으면 좋겠다.
