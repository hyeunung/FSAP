# N04 U5 에어 테이블 — 선정 PM·원칙 감사 (v1.0.11 기준)

요약
- **두 방안 모두 그대로는 완료 판정을 못 맞춘다(반박 계산).** C2(솔 6줄)는 원판 홈과 바늘 홈이 만나는 **교차 칸 C(X −970~−830 · Y ±55, 140×110)**에 벽이 없어 솔이 날 자리가 없다. 그래서 4개 연구 전 단계에서 C가 빈다. 최대 L 15,700 / S 13,900(작은 매트의 23 %) / G 15,800 mm²(`select/cov_brush.json`). N04-C3은 CYCLE_S J 782~800에서 B 사슬 꺾임 자리와 14 mm 겹친다(E-03 위반).
- **선정 = N04-C3 고친 안 + C2 합침(이하 N04-S).** 원판 홈과 교차 칸은 C3의 안장 + 바깥 사슬 P·N + 안쪽 사슬 + 꼬리 멈춤으로 덮고, 국면 L(G1 J > 800)은 A 사슬과 꼬리 메움판으로 덮는다. 바늘 홈 +X 쪽(B 포함)과 기둥 홈은 C2의 솔로 덮는다. 판·송풍은 C2(타공 코어 허니컴 h40 = 공기실, 링 블로어 0.4 kW 1대)를 쓴다. 겹침을 만들던 B 사슬, 기둥 사슬·감개, 긴 NFILL, SUS 공기실은 뺀다.
- 받침 다시 계산(`select/cov_hybrid.json`): 4개 연구 2,279단계에서 **안 받친 넓이 0**이다. 이동 틈(벽 틈 ≤ 8, 바닥 있음)은 받침으로 셌다. PM 판정 근거는 5절에 있다.
- 간섭(`select/studycheck.json`, CAD 실측 bbox): 안장·안쪽 감개 ↔ LOWER·꼬리판 최소 **4.0**(CYCLE_S J 800), 원판 ↔ LOWER 10.0이다. 새 자리 상자는 행정 전체를 쓸어 봤다(`select/screen.json`). 기둥 HFS8-4080은 보 윗면에 닿고(0, 받침면), 다른 바디와는 12 이상 떨어진다. 사슬 보관 ±Y는 10·50, A 보관은 15.5, 호스 기둥은 XMOV에 접속하고 보와 26 떨어진다.
- 외팔 처짐(손계산): ±X 960은 0.45 / 손 0.56 mm다. 혀(목 A6061 인서트)는 0.85 / 1.35 mm다. 이동 질량은 약 81 kg으로 D-79 68.9 kg보다 17 % 많다(N03-Q4 다시 계산 필요).
- CAD: MCP로 v1.0.11을 한 번 열었다(읽기만, dirty false, 오류 0). 바디 269개 bbox를 실측해 서명과 비교했고 차이는 최대 0.004 mm다. motion.play REST 0의 결과는 moved false(이미 대기)다. 저장하지 않았다.
- 미완·위험: 구매품 STEP 0이다. CDJ2B16-110·-150, VB-004-E2, HFS8-4080-248은 STEP대기 대상이다. 스트립 솔·정하중 스프링·호스는 형번이 미정이라 바디를 그리지 않는다(E-10). 사슬 덮개는 길이가 변하는 유연 요소라 강체 바디로 그리지 않고 계산으로 판정한다. X 따라가기 저항은 99~119 N이 될 수 있다(예산 100 N, 서보 보조).
