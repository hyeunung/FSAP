# DC-05 선정 — 아랫유닛 구동 자리 이동(등급 S, 안 하나)

요약
- 고른 안: **DC-05-C1 수정본(C1-R)**. 차순위: C1 원안 좌표(서보 X 450~560 + 별도 받침 L판) — 단, 아래 2번 하중 길 결함을 고쳐야 한다.
- C1을 반박해 고친 것 3가지:
  1. **U4_X_BEAM ↔ U2_COLUMN 면 접촉(J_U4_X 1250)**: CAD 스윕이 1249.99에서 멈췄다(점 500, −520, −340). 측정·구상이 '맞닿음 0.0, 겹침 없음'으로 넘긴 것이다. 완료 판정 '접촉 0'에 걸린다. → 빔 +X 면을 10 깎는다(국부 X −1050~−760, U5_POST +X 면 −760과 맞춤).
  2. **하중 길 끊김**: C1은 LINK(X 30~425)와 받침 기둥 STAND(X 530~610) 사이에 서보 상자만 있다. LINK가 STAND에 닿지 않아 외팔 570이 성립하지 않는다. → LINK 각관을 X 30~650까지 늘려 STAND 위에 얹는다. 커플링은 각관 안(안쪽 82×52)에 넣는다. 서보는 각관 끝판(X 650~654)에 플랜지로 달고 X 654~764에 둔다.
  3. **기둥 홈 좌표**: 기둥 홈 시작은 −1252.5+J가 아니라 −722.5+J다(생성기 gen_v1_n00.py 71행). 두 홈 모두 국부 −X 끝을 40 늘린다(바늘 홈 −1292.5, 기둥 홈 −762.5).
- CAD 확인(CLI eval, 저장본은 그대로): 고친 배치로 J_U4_X −200→1250(Y 0) 스윕이 **끝까지 접촉 0**(최소 틈 10), J_U4_Y −400→1200(X 0)도 접촉 0. 새 바디 4개 × 60자세의 겹침은 금지 띠 자세(1250/400) 하나뿐(U3_COLUMN↔LINK 453,576 mm³, 예상대로).
- 남는 금지 띠: 원판 중심 X −20~350 · |Y| < 95. 사이클 원판 중심은 이 띠에 들 수 없다(띠 안 최대 반지름 362.7 < G1 최소 538.8, S는 X ≤ −100, L은 X ≤ −750) → machine.json xy_forbidden + N03 소프트 리밋.
- 강도(새 LINK만 손계산): 외팔 530, 3배 하중에서 σ 4.2 MPa, SF 58, 처짐 0.06 mm다. FEA는 못 했다 — 환경 없음(D-16).
- 구매품: MHMF042L1U2M 1개, stepcheck '없음' → `STEP대기_MHMF042L1U2M`(임시값, D-81). 새 볼트 형번은 없다(체결은 디테일).
- 미완(디테일로 기록만, E-02): 커플링 형번, 각관 안 베어링, LINK↔STAND·STAND↔U2_BASE 볼트와 렌치 길, 가마↔바늘 정렬(정밀 체인).

## 6. 손계산(새 LINK만, E-18)
- 단면은 90×60 t4: I 659,179 mm⁴, Z 21,973 mm³.
- 외팔 L = 530(STAND −X 면 X 530 → 받침 X 0).
- P = 받침 5.1 kg × 3배 = 150 N, 자중 8.9 kg/m.
- M = 150×530 + 0.0873×530²/2 = 91.7 N·m → σ 4.2 MPa, SS400 245 → SF 58.
- 처짐 PL³/3EI = 0.055 + 자중 0.006 = 0.061 mm(3배), 1배 약 0.02 mm.
- 서보 1.2 kg(임시)는 STAND +X 면에서 약 100 나가 있어 무시한다.
- 해석 못 함 — 환경 없음(D-16).

## 워크플로우 메모
- 측정부가 '면 접촉 0.0(겹침 없음)'을 통과로 적었지만 `joint.sweep`은 면 접촉에서 멈춘다. 완료 판정이 '스윕 접촉 0'이면 0.0 틈도 결함으로 넘겨야 한다.
- `inspect.clearance`에 `bodies`만 주면 그 목록 안끼리만 잰다. 다른 바디와 재려면 `against`를 줘야 한다.
- `joint.sweep`의 occurrences는 machine.json units 이름(U2_BRIDGE, U5_AIRTABLE)이다. 루트에 만든 임시 바디는 스윕에 들지 않아 자세별 clearance로 따로 쟀다.
