# N04 U5 에어 테이블 — 기구설계부 2번 구상안 C2 "부품 최소: 허니컴 공기실 판 + 홈 솔 + 링 블로어 1대"

요약
- 방향: 부품 수·구매 최소. TITAN 에어 테이블(구멍 뚫린 윗판 + 밑 공기실 + 송풍기)을 그대로 쓰고, 벤치마크로 안 되는 곳 **움직이는 홈 3개**만 바꾼다. 홈은 기성 **스트립 솔(나일론 털, 홈 벽에서 가로로)** 6줄로 메운다. 지나가는 몸(867 LOWER·U2_COLUMN·원판)은 털을 헤치고 지나간다. 움직이는 덮개·감는 띠·스프링·액추에이터는 0개다.
- 바뀌는 부품: U5_TABLE 상자 → 허니컴 판(타공 코어 h40, 표피 1+1, 바깥 2220×3105, 홈 3개 그대로)이 그대로 공기실이 된다. 윗판 구멍 Ø0.8, 피치 50, 2,551개. 목(X −830~−762.5·Y −530~−390)에는 통 Al 인서트를 넣는다. U5_POST_1~4 상자 → HFS8-8080-248 ×4. 송풍은 링 블로어 0.4 kW 1대(고정, 바닥)에서 호스 ID38/OD46으로 X 케이블 베어를 지나 입구(−900, 1040, Z −40 밑면)로 간다.
- 강체 외형은 측정본과 같다(테이블 바깥·홈 좌표·기둥 80□ 그대로). 그래서 X 행정 스윕의 접촉 0과 최소 틈 10.0이 그대로 유지된다. 솔 홀더는 판 가장자리 안에 묻힌다. 털은 유연 요소로, 매트·테이프처럼 강체 간섭 판정에서 빼고 7절에 기록한다.
- 받침: 홈 넓이 515,625 mm²가 모두 털 끝(Z 0)으로 덮인다 → 홈 때문에 안 받치는 넓이는 0이다. 남는 것은 지나가는 몸 바로 뒤에서 털이 다시 닫히는 자리뿐이다(유연 거동, 7절). 테이블 밖은 측정과 같이 0이다.
- 처짐 손계산: ±X 외팔 0.467 / 손 0.571 mm(측정 허니컴 h40). 혀 끝은 굽힘 0.617 + 목 비틀림 → 허니컴 목이면 1.98 / 4.43 mm, **통 Al 목 인서트로 0.85 / 1.35 mm**. 평면도 허용 기준은 없다 → 자료대기 후보.
- 송풍 운전점(계산): 챔버 338 Pa, 1.10 m³/min, 호스 손실 725 Pa. 큰 매트 면압 126.5 Pa의 2.67배다. 이동 질량은 70.6 kg으로 D-79 예산 68.9 kg과 거의 같다.
- 부품 수: +17 / −5 → 순증 +12. 구매품 형번은 모두 임시(provisional)다. 카탈로그 표에는 블로어만 있고, 솔·호스·허니컴 판은 표에 없다.
- 미완(위험): 솔 끌림이 X 따라가기 저항에 더해진다(임시 10~15 N → 89~110 N, 예산 100 N 넘을 수 있음, 서보 보조로 상쇄). 원판 테두리 마찰 토크는 약 0.27 N·m이다. 호스가 X 베어 끝(P_DC03_XMOV)으로 들어가는 굽힘은 모델에서 다시 본다(DC-03-D6).

## 2. 구동 방식·행정·상태·순서

- 구동: **없음(수동 요소)**. U5는 J_U4_X에 리지드로 붙은 그대로다(N00-S01). 조인트는 바뀌지 않는다. 움직이는 것은 공기(블로어 ON/OFF)뿐이다.
- 행정: 테이블 X −200~1217.5(하드), 원판 Y −355~1155, 회전 −360~720°는 측정 그대로다. 털은 행정 내내 몸을 헤치고 뒤에서 닫힌다.
- 순서(0-8-4): ① 매트 올림 → 진공·**블로어 ON**(인버터 기동은 제어 단계 U-09) → ②~⑤ 블로어 계속 → ⑥ 노루발 들기·진공 OFF·**블로어 OFF**(또는 약하게 해 매트를 꺼내기 쉽게, 제어 단계) → 작업자가 −Y로 꺼냄.
- 대기 자세 J 0·0·0: 원판 홈(X −970~−830)의 털은 원판 Ø120과 축 둘레를 빼고 닫혀 있다. 바늘 홈 털은 LOWER(X ±30) 둘레만 열린다. 기둥 홈 털은 기둥이 테이블 +X 끝(210) 밖에 있어 다 닫혀 있다(기둥은 J > 290에서 들어온다).

### 5-2. 혀 목 비틀림(새로 본 것)

혀(Y −390~−55, 폭 335)는 목(67.5 × 140 × 40)으로만 붙어 있다. 그래서 혀 뿌리 모멘트가 목에서는 비틀림이 된다. q = 0.0703 N/mm, M = qL²/2 = 38.0 N·m(손 104 N·m), θ = M·140/(G·J), G 26,000 MPa.

| 목 | J mm⁴ | 비틀림 끝 처짐 자중+매트 / 손 | 혀 끝 합 자중+매트 / 손 |
|---|---|---|---|
| 허니컴(표피 1+1·옆 마감 t2, 상자 근사) | 156,424 | 1.362 / 3.723 | **1.98 / 4.43** |
| 통 A6061 인서트(0.21·b·t³) | 907,200 | 0.235 / 0.642 | **0.85 / 1.35** |

→ 목 인서트를 넣는다(부품 1, 판 공급사가 코어 대신 채움). 혀 밑에 보강 형재(뿌리를 U4_X 보에 걸기)도 따져 봤지만 버렸다. U4_Y_CARR(X −1025~−775, Z −260~−230)가 Y로 지나가 X −775보다 −X에는 기둥을 세울 수 없다. 원판 축(X −950~−850, Z −222~−15)이 혀 밑 Y 범위를 지나가 판 밑을 따라 −X로 뻗을 수도 없다. 가로 보를 POST_3에 걸면 형재 비틀림이 혀 끝 25.7 mm가 된다(40×80 J 5e4 가정). 강관 □80 t4로 바꾸어도 합이 약 0.6 mm라 인서트 안(0.85)과 비슷한데 부품이 3개 는다.

### 5-3. 기둥 4개(새로 만든 것)

합하중 978 N → 기둥당 244 N 압축, X 가속 2 m/s²(임시) 전단 합 141 N. HFS8-8080 끝 탭 M8 ×4/끝(임시)이면 볼트당 전단 9 N, 인장 0이다. 여유가 크다. 체결 상세는 디테일.

| 항목 | 값 |

| 구멍 | Ø0.8 × 2,551(피치 50) |

### 5-5. 솔 털 처짐(유연, 기록용)

나일론 Ø0.5·E 3,000 MPa, 묶음 8 mm에 채움 50 % → 20.4개/mm. 큰 매트 면압을 털이 전부 진다고 보면 끝 처짐은 바늘 홈(57) 0.89 mm, 원판·기둥 홈(72) 2.27 mm다. 매트 자체 굽힘 강성이 나누어 지므로 실제는 더 작다 → 요구서 7절 기록.

### 5-6. 이동 질량·저항

- 테이블 쪽 질량 70.6 kg(판 54.2 + 마감·인서트 7 + 솔 2.5 + 기둥 5.5 + 입구 1.5), D-79 예산 68.9 kg(+2.5 %).
- 솔 끌림(임시): 털 수직력 0.05 N/mm × 접촉 둘레(LOWER 300 + 기둥 480 mm) × μ 0.3 ≈ 12 N. N03 79.2 N·D-88 89.8~94.9 N에 더하면 91~107 N이다. 예산 100 N을 넘을 수 있다 → 0-8-1 "필요하면 서보가 보조"로 상쇄(일정 방향이 아니라 움직임 반대 방향 마찰이라 속도 피드포워드로 보상). 원판 테두리 마찰 토크 0.05 × 300 × 0.3 × r 60 ≈ 0.27 N·m(자유 회전 저항, 조향 서보 보조), Y 끌림 약 5 N.

## 9. 위험·미완

1. 솔 끌림이 X 따라가기 저항을 예산 100 N 넘게 만들 수 있다(91~107 N 임시). 털 수직력은 카탈로그 값이 없다 → 자료대기. 넘으면 서보 보조(0-8-1 범위 안).
2. 털이 LOWER(바늘판) 옆을 문지른다. 바늘판 둘레 털이 위로 들려 매트 뒷면을 미는지, 실밥이 털에 끼는지 → 요구서 7절 기록.
3. 털이 몸 뒤에서 다시 닫히는 거리, 털 위 매트 처짐(0.89~2.27 mm 상한) → 7절.
4. 혀 끝 처짐 0.85 mm(인서트) / 손 1.35 mm. 평면도 허용 기준 없음 → 자료대기 후보(작업면 평면도·처짐 허용).
5. 호스 Ø46이 P_DC03_XMOV로 들어가는 굽힘(R100)은 XMOV 몸과 맞춰 모델에서 본다(DC-03-D6). Ø50(D-88)을 그대로 두면 R150 여유 0 그대로다.
6. 블로어 자리(+Y 바닥, U2_BASE 밖)에 이웃 설비가 있는지 모른다. 소음 기준 없음.
7. 모델링 판정: 털은 유연 요소다. 강체 간섭 판정(E-03)에서는 홀더만 강체로 넣고, 털 묶음 바디는 매트·테이프처럼 유연 구분(`flex`)으로 빼야 한다. 검도부가 이것을 받아들이지 않으면 털 바디는 그리지 않고 홀더 + 털 영역 메모로 둔다.
8. 이동 질량 70.6 kg은 D-79 예산보다 2.5 % 많다(N03 서보 여유 안에서 다시 볼 것).
