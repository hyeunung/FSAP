## 워크플로우 메모
- 지시문 현재 상태 "FSAP_v1.0.0.sc가 아직 없음 — new_design"은 준비부 뒤 시점과 맞지 않았다(파일 있음, 상자만 없음). 모델링부는 new_design이 아니라 v1.0.0을 열어 상자를 넣고 v1.0.1로 저장해야 할 것(실행 규칙 3 "이미 있는 버전 파일은 덮어쓰지 않는다").
- `edit.checkpoint`를 batch 안에서 만들면 다음 batch의 `edit.restore_checkpoint`가 "no checkpoint"로 거부했다. 측정만 하는 부서는 `motion.play REST 0`으로 충분했다.
- `inspect.measure {body}`가 batch 안에서 body 거름 없이 전 바디를 돌려줘 결과가 78 KB가 됐다.
- 이 컴퓨터 파이썬에 numpy 없음 → 점유 계산은 순수 파이썬(1 s).
