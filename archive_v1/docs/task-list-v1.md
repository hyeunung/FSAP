## 0-8 (v1.0) 전체 구동 개념 (모델링 시작 조건, 엔진 E-01)

**상태: 확립(2026-11-03, 0-8-6).** 대화 과정·이유는 [v1.0 구동 개념 대화 기록](concept/v1-drive-concept-discussion.md). v0.x(헤드 이송 없음·기계 서보가 매트를 한 땀씩 옮김)는 버리고, 2차 벤치마크([보고서](../reports/매트%20바인딩기%20벤치마크%20조사.md))와 사용자 대화로 다시 세운 개념이다. 대상은 **카펫 매트**(코일 매트는 범위 밖, 사용자 2026-11-03 "일단 카펫매트라 생각하고 진행하자").

| 0-8-1 핵심 원리 | **매트를 끄는 것은 재봉 헤드다.** 헤드는 고정, 바늘 둘레의 3중 이송(아래 톱니·바늘 이송·교대 노루발)이 테이프로 감쌀 가장자리 띠만 물고 한 땀씩 끈다(Dürkopp 867 방식, R375A·US6557478). 매트 몸통은 가운데 **작은 진공 원판**이 뒷면을 잡고, 둘레는 **에어 테이블**이 띄워 받친다(파일 면에 아무것도 닿지 않음, C-03). 원판은 **자유 회전 + 조향 서보**, 원판 밑 **X·Y 받침은 따라가기 모드**(헤드가 끄는 대로 따라가고 필요하면 서보가 보조). 바늘 앞 가장자리 센서가 원판 회전으로 방향을 잡는다(C-02, US5367966). **모서리·홈 바닥**: 바늘을 꽂은 채 멈춤 → 노루발 들기 → 바늘 중심 회전(이때만 X·Y·회전 위치 모드) → 센서가 가장자리를 다시 잡으면 재개(US5367966). **헤드는 Dürkopp 867-392342 차 매트 바인딩 모델을 기둥 없게 개조**: 윗헤드(바늘·노루발·위 이송·바인더)는 위 브리지에 매달고, 아랫유닛(가마·톱니)은 바늘 밑 작은 받침에만 두고 동기. 좁은 홈 안에서 홈 건너편 매트 몸통이 헤드 밑을 지나가야 하기 때문(사용자 사진 2026-11-03, R375X "매트가 헤드 밑을 지나며 자유롭게") |

## 5절 과제 목록 (v1.0)

구동 과제를 먼저 둔다(1-4). 구동 과제마다 0-8의 유닛(U1~U8, 0-8-3 유닛 표)에 속한다. 0-8에 없는 유닛·원리(커버·외장 포함, T12)는 구동 과제로 두지 않는다. 0-8이 확립되면 이 표를 그 개념에 맞춰 다시 본다. 합격 기준의 수치 중 측정이 필요한 것은 D-번호로 가리키고, 값이 들어오기 전에는 임시값으로 진행한다(E-12).
